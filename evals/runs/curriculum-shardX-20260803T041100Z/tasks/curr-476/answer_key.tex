\problem{\textbf{$\displaystyle\int 2x\left(x^2+5\right)^3 dx$.}

\textbf{Step 1.} Look for an inner function whose derivative also appears. The
inner function is $x^2+5$, so let $u = x^2+5$; then $du = 2x\,dx$, which is
exactly the factor sitting outside the bracket.

\textbf{Step 2.} The integral becomes $\displaystyle\int u^3\,du = \frac{u^4}{4}$,
and back-substituting returns the answer in $x$.
\ans{\dfrac{(x^2+5)^4}{4} + C}

\textit{Check by differentiating:} $\frac{4(x^2+5)^3\cdot 2x}{4} =
2x(x^2+5)^3$, the original integrand.}

\problem{\textbf{$\displaystyle\int x\cos\!\left(x^2\right)dx$.}

\textbf{Step 1.} Let $u = x^2$, so $du = 2x\,dx$. The integrand offers only
$x\,dx$, which is $\frac{1}{2}\,du$ --- a constant short, not a function short.

\textbf{Step 2.} Part (b): a constant may be moved across the integral sign
because $\int k f = k\int f$; a variable may not, since $x$ changes as the
integration variable moves. So
$\displaystyle\int x\cos(x^2)\,dx = \frac{1}{2}\int \cos u\,du =
\frac{1}{2}\sin u$.
\ans{\dfrac{\sin\!\left(x^2\right)}{2} + C}

\textit{Check:} $\frac{1}{2}\cos(x^2)\cdot 2x = x\cos(x^2)$.}

\problem{\textbf{$\displaystyle\int \frac{(\ln x)^2}{x}\,dx$.}

\textbf{Step 1.} Part (a): $\ln x$ is the inner function and $\frac{1}{x}$ is
its derivative, so the integrand is already in the form $f(u)\,du$.

\textbf{Step 2.} With $u = \ln x$ and $du = \frac{1}{x}\,dx$, the integral is
$\displaystyle\int u^2\,du = \frac{u^3}{3}$.
\ans{\dfrac{(\ln x)^3}{3} + C}

\textit{Check:} $\frac{3(\ln x)^2}{3}\cdot\frac{1}{x} = \frac{(\ln x)^2}{x}$.}

\problem{\textbf{$\displaystyle\int_{0}^{2} x\,e^{x^2}\,dx$.}

\textbf{Step 1.} Let $u = x^2$, so $du = 2x\,dx$ and $x\,dx = \frac{1}{2}du$.
Because the integral is definite, convert the limits too: $x = 0$ gives $u = 0$,
and $x = 2$ gives $u = 4$.

\textbf{Step 2.} The integral becomes
$\displaystyle\frac{1}{2}\int_{0}^{4} e^{u}\,du = \frac{1}{2}
\left[e^{u}\right]_{0}^{4} = \frac{e^4 - 1}{2}$.
\ans{\dfrac{e^4 - 1}{2}}

\textit{Why convert the limits:} once the bounds are in $u$, no
back-substitution is needed. Evaluating $\left[\frac{1}{2}e^{u}\right]$ at the
\emph{old} bounds 0 and 2 is the single most common error on this problem type.}

\problem{\textbf{$\displaystyle\int \sin^3 x\,\cos x\,dx$.}

\textbf{Step 1.} Part (a): with $u = \sin x$, $du = \cos x\,dx$; with
$u = \cos x$, $du = -\sin x\,dx$. Test each against what the integrand actually
supplies before committing.

\textbf{Step 2.} Part (b): $u = \sin x$ consumes the whole integrand, since
$\sin^3 x\,\cos x\,dx = u^3\,du$. The other choice absorbs only one $\sin x$ and
strands $\sin^2 x\cos x$ behind, which cannot be written in $u$ alone.

\textbf{Step 3.} $\displaystyle\int u^3\,du = \frac{u^4}{4}$, then
back-substitute.
\ans{\dfrac{\sin^4 x}{4} + C}

\textit{Check:} $\frac{4\sin^3 x\cdot\cos x}{4} = \sin^3 x\cos x$.}

\problem{\textbf{$\displaystyle\int_{1}^{3} \frac{2x}{x^2+1}\,dx$.}

\textbf{Step 1.} Let $u = x^2+1$, so $du = 2x\,dx$ --- the numerator exactly. New
limits: $x = 1$ gives $u = 2$, and $x = 3$ gives $u = 10$.

\textbf{Step 2.} $\displaystyle\int_{2}^{10} \frac{du}{u} =
\left[\ln|u|\right]_{2}^{10} = \ln 10 - \ln 2$.

\textbf{Step 3.} Part (c): a difference of logarithms is the logarithm of the
quotient, and $10 \div 2 = 5$.
\ans{\ln 5}

\textit{Note on absolute values:} on the new interval $u$ runs from 2 to 10, so
$u > 0$ throughout and the absolute value can be dropped without comment.}

\problem{\textbf{$\displaystyle\int x^2\sqrt{x^3+1}\;dx$.}

\textbf{Step 1.} Let $u = x^3+1$, so $du = 3x^2\,dx$ and $x^2\,dx =
\frac{1}{3}du$. The integral carries a factor of one third.

\textbf{Step 2.} Part (b): write the root as a power ---
$\displaystyle\frac{1}{3}\int u^{1/2}\,du$ --- so the power rule applies.

\textbf{Step 3.} $\frac{1}{3}\cdot\frac{u^{3/2}}{3/2} =
\frac{1}{3}\cdot\frac{2}{3}u^{3/2} = \frac{2}{9}u^{3/2}$.
\ans{\dfrac{2\left(x^3+1\right)^{3/2}}{9} + C}

\textit{Check:} $\frac{2}{9}\cdot\frac{3}{2}(x^3+1)^{1/2}\cdot 3x^2 =
x^2\sqrt{x^3+1}$.}

\problem{\textbf{Challenge: $\displaystyle\int_{0}^{\infty} x\,e^{-x^2}\,dx$.}

\textbf{Step 1.} Part (a): infinity is not a value the Fundamental Theorem can
be evaluated at, so the integral is \emph{defined} as
$\displaystyle\lim_{b\to\infty}\int_{0}^{b} x\,e^{-x^2}\,dx$. Everything else is
an ordinary substitution.

\textbf{Step 2.} Let $u = -x^2$, so $du = -2x\,dx$ and $x\,dx = -\frac{1}{2}du$.
The antiderivative is $-\frac{1}{2}e^{-x^2}$, and on $[0, b]$ it evaluates to
$-\frac{1}{2}e^{-b^2} + \frac{1}{2}$.

\textbf{Step 3.} Part (b): as $b\to\infty$, $e^{-b^2}\to 0$, so the limit is the
constant term that survives.
\ans{\dfrac{1}{2}}

\textbf{Step 4.} Part (c): the limit exists and is finite, so the improper
integral converges, and its value is that limit.
\ans{\dfrac{1}{2}}

\textit{Why the substitution still governs:} the limit only decides
convergence. The number itself came from the antiderivative $u$-substitution
produced --- and note that $u = x^2$ works just as well, giving
$\frac{1}{2}\left(1 - e^{-b^2}\right)$, the same expression rearranged.}
