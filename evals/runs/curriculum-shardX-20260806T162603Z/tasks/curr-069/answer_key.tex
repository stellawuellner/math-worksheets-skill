\problem{This array has 3 rows with 5 dots in each row. How many dots are there in all?}

\textbf{Solution:} The total counts every dot, so multiply the rows by the number in each row: $3 \times 5 = 15$. Skip counting checks it: $5, 10, 15$. \ans{15}

\vspace{0.2cm}\noindent\rule{\linewidth}{0.2pt}

\problem{Nadia packs 4 bags with 6 apples in each bag. How many apples in all?}

\textbf{Solution:} This is 4 equal groups of 6, so the total is $4 \times 6 = 24$. Adding the two numbers ($4 + 6 = 10$) would only mix the group count with the group size --- it does not count the apples. \ans{24}

\vspace{0.2cm}\noindent\rule{\linewidth}{0.2pt}

\problem{The chairs are in an array: 5 rows with 7 chairs in each row. How many chairs in all?}

\textbf{Solution:} Each of the 5 rows holds 7 chairs, so the total is $5 \times 7 = 35$. Answering 5 would only name how many rows there are --- the question asks for every chair. \ans{35}

\vspace{0.2cm}\noindent\rule{\linewidth}{0.2pt}

\problem{Maya wrote $4 + 8 = 12$ for an array with 4 rows and 8 stickers in each row.}

\textbf{Solution (a):} Maya added the number of rows to the number of stickers in each row. But the array shows 4 equal groups of 8 stickers, so the counts must be multiplied, not added --- $12$ does not count every sticker. A correct answer says the array means ``4 groups of 8,'' so it needs $4 \times 8$.

\textbf{Solution (b):} The correct total is $4 \times 8 = 32$. \ans{32}

\vspace{0.2cm}\noindent\rule{\linewidth}{0.2pt}

\problem{Leo wrote $6 + 3 = 9$ for 6 boxes with 3 crayons in each box.}

\textbf{Solution (a):} Leo added the number of boxes to the crayons in each box. The story means 6 equal groups of 3 crayons, so the total needs multiplication --- $9$ counts a box number plus a crayon number, which is not a number of crayons.

\textbf{Solution (b):} The correct total is $6 \times 3 = 18$. \ans{18}

\vspace{0.2cm}\noindent\rule{\linewidth}{0.2pt}

\problem{Each row holds 6 muffins and there are 24 muffins in all. How many rows? ($n \times 6 = 24$)}

\textbf{Solution:} We know the total (24) and the number in each row (6); the unknown is the number of rows. Think of the related fact: $4 \times 6 = 24$, so $n = 4$. Check: 4 rows of 6 muffins is $4 \times 6 = 24$ muffins. \ans{n = 4}

\vspace{0.2cm}\noindent\rule{\linewidth}{0.2pt}

\problem{Kai says ``$5 + 5 = 10$'' for an array of 5 rows with 5 dots in each row.}

\textbf{Solution (a):} Kai's sum $5 + 5$ counts only two rows' worth of dots (or a row number plus a dot number) --- it is not the total. The array has 5 rows and \emph{each} row holds 5 dots, so all five rows must be counted.

\textbf{Solution (b):} The correct total is $5 \times 5 = 25$. Skip count to check: $5, 10, 15, 20, 25$. \ans{25}

\vspace{0.2cm}\noindent\rule{\linewidth}{0.2pt}

\problem{Rosa wrote $7 + 8 = 15$ chairs for 7 rows with 8 chairs in each row.}

\textbf{Solution (a):} Rosa's 15 counted the 7 rows and then the 8 chairs of a single row --- a row count plus one row's chairs. That misses the chairs in the other six rows, so it cannot be the total.

\textbf{Solution (b):} Each of the 7 rows holds 8 chairs: $7 \times 8 = 56$. \ans{56}
