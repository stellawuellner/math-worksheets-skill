\problem{The picture shows 6 apples. 2 are crossed out. How many apples are
left?}

\textbf{Solution:} Count all the apples: 6. The 2 crossed-out apples are
taken away, so count only the plain ones: 1, 2, 3, 4. So $6-2=4$. \ans{4}

\problem{Your turn to make the picture! Draw 7 circles. Cross out 3 of them.
How many circles are left?}

\textbf{Solution:} The drawing shows 7 circles with 3 crossed out. Counting
the circles without a cross: 1, 2, 3, 4. So $7-3=4$. \ans{4}

\emph{Drawing (instructor judges):} 7 circles drawn, exactly 3 crossed out,
4 left plain --- the picture and the equation tell the same story.

\problem{There are 8 counters. 3 are crossed out. Write the story numbers in
the equation, then write how many are left.}

\textbf{Solution:} The start number is 8 and the taken-away number is 3, so
the equation reads $8 - 3 = {}$? Count the plain counters: 5. So $8-3=5$.
\ans{5}

\problem{5 birds sit on a fence. 2 birds fly away. Write the story numbers
in the equation, then write how many birds are still on the fence.}

\textbf{Solution:} Flying away is taking away: start with 5, take away 2.
The equation is $5 - 2 = {}$? Count back from 5: 4, 3. So $5-2=3$. \ans{3}

\problem{The ten-frame shows 9 dots. Cross out 4 dots. How many dots are
\emph{not} crossed out?}

\textbf{Solution:} Cross out any 4 dots --- say the bottom row's four. The
unmarked dots are the full top row of 5. So $9-4=5$. \ans{5}

\emph{Crossing out (instructor judges):} exactly 4 dots crossed out,
5 left unmarked.

\problem{Think: 6 and how many more make 10? Find $10-6$.}

\textbf{Solution:} Use the partner pair: $6+4=10$, so taking 6 from 10
leaves the partner 4. $10-6=4$. \ans{4}

\problem{Rosa has 9 grapes. She eats 3 of them. Write the story numbers in
the equation, then write how many grapes are left.}

\textbf{Solution:} Start with 9, take away 3: the equation is
$9 - 3 = {}$? Count back from 9: 8, 7, 6. So $9-3=6$. \ans{6}

\problem{Challenge! The picture shows 10 balloons. Some popped, and now 7
balloons are left. Cross out balloons to show the ones that popped. How many
balloons popped?}

\textbf{Solution:} We know the start (10) and what is left (7), and we need
the taken-away number. Cross out balloons one at a time until 7 remain:
that takes 3 crosses. Check: $10-3=7$. So the missing number is \ans{3}

\emph{Crossing out (instructor judges):} exactly 3 balloons crossed out,
7 left plain, matching the story.
