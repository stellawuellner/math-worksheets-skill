\problem{Differentiate $y = \arcsin(3x)$.}

\textbf{Solution:} With $u = 3x$ we have $u' = 3$, and
$\frac{d}{dx}\arcsin u = \frac{u'}{\sqrt{1-u^2}}$:
\[
  y' = \frac{3}{\sqrt{1 - (3x)^2}} = \frac{3}{\sqrt{1-9x^2}}.
  \qquad \ans{\dfrac{3}{\sqrt{1-9x^2}}}
\]
The $3$ upstairs is the chain-rule factor; squaring $3x$ puts a $9$ downstairs.

\problem{Differentiate $y = \arctan\!\left(x^2\right)$.}

\textbf{Solution:} With $u = x^2$, $u' = 2x$, and
$\frac{d}{dx}\arctan u = \frac{u'}{1+u^2}$:
\[
  y' = \frac{2x}{1 + \left(x^2\right)^2} = \frac{2x}{1+x^4}.
  \qquad \ans{\dfrac{2x}{1+x^4}}
\]

\vspace{0.15cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.15cm}

\problem{$f(x) = x^3+2x+1$ with $f(1) = 4$. (a) $f'(x)$. (b)
$\left(f^{-1}\right)'(4)$.}

\textbf{Solution (a):} Power rule term by term: \ans{3x^2 + 2}

\textbf{Solution (b):} The rule is
$\left(f^{-1}\right)'(b) = \dfrac{1}{f'(a)}$ where $f(a) = b$. Here $b = 4$ and
$a = 1$, so evaluate $f'$ at the \emph{input} $1$, not at $4$:
\[
  f'(1) = 3(1)^2 + 2 = 5 \qquad\Longrightarrow\qquad
  \left(f^{-1}\right)'(4) = \frac{1}{5}.
\]
So the answer is \ans{\tfrac{1}{5}}

Using $f'(4) = 50$ instead is the standard slip; $50$ is the number to watch for
on a wrong page.

\vspace{0.15cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.15cm}

\problem{Differentiate $y = x\arctan x$.}

\textbf{Solution:} Product rule with $u = x$ and $v = \arctan x$:
\[
  y' = (1)\arctan x + x \cdot \frac{1}{1+x^2}
     = \arctan x + \frac{x}{1+x^2}.
\]
So the derivative is \ans{\arctan x + \dfrac{x}{1+x^2}}

The answer keeps an $\arctan$ in it; that is normal and not a sign of an error.

\vspace{0.15cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.15cm}

\problem{Differentiate $y = \arccos(2x)$.}

\textbf{Solution:} With $u = 2x$, $u' = 2$, and the arccosine rule carrying the
minus sign:
\[
  y' = \frac{-2}{\sqrt{1-(2x)^2}} = \frac{-2}{\sqrt{1-4x^2}}.
  \qquad \ans{\dfrac{-2}{\sqrt{1-4x^2}}}
\]
Arcsine and arccosine have the same derivative up to sign, because their sum is
the constant $\frac{\pi}{2}$.

\vspace{0.15cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.15cm}

\problem{$g(x) = x^5+3x-2$ with $g(1) = 2$. (a) $g'(x)$. (b)
$\left(g^{-1}\right)'(2)$.}

\textbf{Solution (a):} \ans{5x^4 + 3}

\textbf{Solution (b):} The input that produces the output $2$ is $a = 1$, so
\[
  g'(1) = 5 + 3 = 8 \qquad\Longrightarrow\qquad
  \left(g^{-1}\right)'(2) = \frac{1}{8}.
\]
So the answer is \ans{\tfrac{1}{8}}

Note it is the \emph{derivative} that gets reciprocated, not the input:
$\frac{1}{2}$ is the wrong answer this problem is built to catch.

\vspace{0.15cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.15cm}

\problem{Differentiate $y = \left(\arctan x\right)^2$.}

\textbf{Solution:} Chain rule with the outside function $(\ )^2$ and the inside
function $\arctan x$:
\[
  y' = 2\arctan x \cdot \frac{1}{1+x^2} = \frac{2\arctan x}{1+x^2}.
  \qquad \ans{\dfrac{2\arctan x}{1+x^2}}
\]
Contrast with problem 2, where $\arctan$ was the \emph{outside} function ---
same two ingredients, opposite order, different answer.

\vspace{0.15cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.15cm}

\problem{Differentiate $y = \arctan\!\left(\sqrt{x}\right)$.}

\textbf{Solution:} With $u = \sqrt{x}$ we have $u' = \frac{1}{2\sqrt{x}}$ and
$u^2 = x$, so
\[
  y' = \frac{1}{1 + x} \cdot \frac{1}{2\sqrt{x}}
     = \frac{1}{2\sqrt{x}\,(1+x)}.
  \qquad \ans{\dfrac{1}{2\sqrt{x}\,(1+x)}}
\]
Squaring $\sqrt{x}$ back to $x$ is what makes this one simplify so cleanly.

\vspace{0.15cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.15cm}

\problem{Differentiate $y = x^2\arccos x$.}

\textbf{Solution:} Product rule with $u = x^2$ and $v = \arccos x$:
\[
  y' = 2x\arccos x + x^2\left(\frac{-1}{\sqrt{1-x^2}}\right)
     = 2x\arccos x - \frac{x^2}{\sqrt{1-x^2}}.
\]
So the derivative is \ans{2x\arccos x - \dfrac{x^2}{\sqrt{1-x^2}}}

\problem{Challenge. $f(x) = 2x + \sin x$, $f(0) = 0$. (a) $f'(x)$.
(b) $\left(f^{-1}\right)'(0)$. (c) Why does the inverse exist?}

\textbf{Solution (a):} \ans{2 + \cos x}

\textbf{Solution (b):} The input producing the output $0$ is $a = 0$, and
$f'(0) = 2 + \cos 0 = 2 + 1 = 3$, so
$\left(f^{-1}\right)'(0) = \frac{1}{3}$. \ans{\tfrac{1}{3}}

Notice that $f^{-1}$ has no formula here --- there is no way to solve
$y = 2x + \sin x$ for $x$ --- and the rule still delivers the slope. That is the
point of the inverse-function rule.

\textbf{Solution (c) --- instructor-judged, no machine check.} The argument must
use part (a). Cosine never falls below $-1$, so $f'(x) = 2 + \cos x \ge 1 > 0$
for every $x$. A function whose derivative is positive everywhere is strictly
increasing, and a strictly increasing function takes each value at most once, so
it is one-to-one and has an inverse on all of $\mathbb{R}$. Full credit needs the
positivity of the derivative \emph{and} the step from strictly increasing to
one-to-one. Do not accept ``it passes the horizontal line test'' with no reason
given for why it does.
