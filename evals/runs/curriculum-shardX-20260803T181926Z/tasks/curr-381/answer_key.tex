\problem{\textbf{$(f \circ g)(2)$ for $f(x) = x + 4$, $g(x) = 3x$.}

\textbf{Step 1.} Identify which rule is inner. In $f \circ g$ the letter
closest to the input is $g$, so $g$ runs first.

\textbf{Step 2.} $g(2) = 3 \cdot 2 = 6$.

\textbf{Step 3.} Feed that output to $f$: $f(6) = 6 + 4 = 10$.

\textbf{Step 4.} Same result from the composed rule: $f(g(x)) = 3x + 4$, and at
$x = 2$ that is $6 + 4$.

\ans{(f \circ g)(2) = 10}

\textit{Common wrong answer:} $14$ --- the rules were run in the other order,
$g(f(2)) = 3(2 + 4)$. The inner rule is the one written next to the input.}

\problem{\textbf{Table of $(g \circ f)(x)$ for $f(x) = 2x - 1$, $g(x) = x^2$.}

\textbf{Step 1.} $f$ is inner here, so each input is doubled and reduced by one
first; the square is applied to that result, never to the original input.

\textbf{Step 2.} Middle column: $f(0) = -1$, \ $f(2) = 3$, \ $f(3) = 5$.

\textbf{Step 3.} Last column, squaring each of those:

$g(f(0)) = (-1)^2 = \ans{1}$ \qquad $g(f(2)) = 3^2 = \ans{9}$ \qquad
$g(f(3)) = 5^2 = \ans{25}$

\textit{Teaching note:} the composed rule is $(g \circ f)(x) = (2x - 1)^2$.
Reading the finished table left to right is exactly that rule, one input at a
time --- worth pointing out, because the next problems ask for the rule
directly.}

\problem{\textbf{$(f \circ g)(x)$ for $f(x) = x^2 + 1$, $g(x) = x - 3$.}

\textbf{Step 1.} $g$ is inner. Wherever $f$ shows its input, write the whole
inner rule in parentheses: $f(g(x)) = (x - 3)^2 + 1$.

\textbf{Step 2.} Expand the square: $(x - 3)^2 = x^2 - 6x + 9$.

\textbf{Step 3.} Add the $+1$: $x^2 - 6x + 9 + 1 = x^2 - 6x + 10$.

\ans{(f \circ g)(x) = x^2 - 6x + 10}

\textit{Common wrong answer:} $x^2 + 9 + 1 = x^2 + 10$ --- the square of a
binomial was taken term by term. $(x - 3)^2$ is $(x-3)(x-3)$, which has a
middle term.}

\problem{\textbf{$(g \circ f)(x)$ for the same $f(x) = x^2 + 1$, $g(x) = x - 3$.}

\textbf{Step 1.} Now $f$ is inner, so the input of $g$ becomes $x^2 + 1$.

\textbf{Step 2.} $g$ subtracts $3$ from its input: $(x^2 + 1) - 3$.

\textbf{Step 3.} Combine the constants: $1 - 3 = -2$.

\ans{(g \circ f)(x) = x^2 - 2}

\textit{Compare with problem 3.} The same two rules gave $x^2 - 6x + 10$ one
way and $x^2 - 2$ the other. Composition is not commutative --- ask the student
to check one input, say $x = 1$: $4$ versus $-1$.}

\problem{\textbf{$(f \circ g)(x)$ for $f(x) = x^2 - 2x$, $g(x) = x + 5$.}

\textbf{Step 1.} $f$'s input appears twice, in $x^2$ and in $-2x$, so the inner
rule is substituted in both places: $f(g(x)) = (x + 5)^2 - 2(x + 5)$.

\textbf{Step 2.} Expand each piece: $(x + 5)^2 = x^2 + 10x + 25$ and
$-2(x + 5) = -2x - 10$.

\textbf{Step 3.} Combine: $x^2 + 10x + 25 - 2x - 10 = x^2 + 8x + 15$.

\ans{(f \circ g)(x) = x^2 + 8x + 15}

\textit{Common wrong answer:} $x^2 + 10x + 25 - 2x$ --- the distribution
stopped after the first term of $-2(x + 5)$.}

\problem{\textbf{$f(g(x))$ for $f(x) = \frac{1}{x - 2}$, $g(x) = x + 2$.}

\textbf{Step 1.} The input of $f$ is the whole inner rule, so the denominator
becomes $(x + 2) - 2$, not $x - 2$.

\textbf{Step 2.} Simplify that denominator: $(x + 2) - 2 = x$.

\textbf{Step 3.} The composition is therefore one over $x$.

\ans{f(g(x)) = \dfrac{1}{x}}

\textit{Teaching note:} the shift $g$ applies is undone by the shift built into
$f$, which is a first look at why the inverse test in problem 9 works. Worth
saying aloud: $x = 0$ must still be excluded, because $g(0) = 2$ is exactly the
input $f$ cannot take.}

\problem{\textbf{Both orders for $f(x) = 2x + 1$, $g(x) = x^2$.}

\textbf{Step 1.} $(f \circ g)(x)$: the input of $f$ is $x^2$, so double it and
add one.

\textbf{Step 2.} $f(g(x)) = 2(x^2) + 1$.

\ans{(f \circ g)(x) = 2x^2 + 1}

\textbf{Step 3.} $(g \circ f)(x)$: now the input of $g$ is $2x + 1$, so that
whole binomial gets squared: $(2x + 1)^2 = 4x^2 + 4x + 1$.

\ans{(g \circ f)(x) = 4x^2 + 4x + 1}

\textbf{Step 4.} The two rules differ --- swapping the order changes the
function, so composition is not commutative.

\textit{Common wrong answer:} $4x^2 + 1$ for the second one --- the middle term
$4x$ is lost when $(2x+1)^2$ is squared term by term.}

\problem{\textbf{Solve $(f \circ g)(x) = 12$ for $f(x) = x + 3$, $g(x) = 2x - 1$.}

\textbf{Step 1.} Build the composed rule first: $f(g(x)) = (2x - 1) + 3$, which
simplifies to $2x + 2$.

\textbf{Step 2.} Set that rule equal to the target value: $2x + 2 = 12$.

\textbf{Step 3.} Subtract $2$ from both sides: $2x = 10$; divide by $2$.

\textbf{Step 4.} Check by running the input through both machines:
$g(5) = 9$ and $f(9) = 12$ $\checkmark$

\ans{x = 5}

\textit{Common wrong answer:} $x = 6.5$ --- the equation $2x - 1 = 12$ was
solved, i.e. the outer rule was never applied.}

\problem{\textbf{Inverse test for $f(x) = 3x + 7$, $g(x) = \frac{x - 7}{3}$.}

\textbf{Step 1.} A composition test needs both directions, because a rule can
undo another on one side only. Do $f(g(x))$ first.

\textbf{Step 2.} $f(g(x)) = 3 \!\left(\dfrac{x - 7}{3}\right) + 7$. The factor
of $3$ cancels the division, leaving $(x - 7) + 7$.

\ans{f(g(x)) = x}

\textbf{Step 3.} Now the other direction:
$g(f(x)) = \dfrac{(3x + 7) - 7}{3} = \dfrac{3x}{3}$.

\ans{g(f(x)) = x}

\textbf{Step 4.} Both compositions return the input untouched, so $f$ and $g$
are inverses: $g = f^{-1}$.

\textit{Listen for:} ``I only did one side.'' One direction alone is not
enough in general --- the two-sided check is what the definition asks for.}

\problem{\textbf{Decomposing $h(x) = \frac{1}{x^2 + 6}$.} \emph{Open response
--- many correct answers, flagged for manual review. The response below is a
model full-credit answer.}

\textbf{Step 1.} Look for a chunk of $h$ that is computed first when you
evaluate it by hand. Given a number, you would square it, add $6$, and only
then divide into $1$. That last-computed step belongs to the outer rule.

\textbf{Step 2.} A clean split is $g(x) = x^2 + 6$ (the inside chunk) and
$f(x) = \dfrac{1}{x}$ (the outside chunk). Neither is the identity rule.

\textbf{Step 3.} Compose back to check: $f(g(x)) = \dfrac{1}{g(x)}
= \dfrac{1}{x^2 + 6} = h(x)$ $\checkmark$

\textbf{Step 4.} Other splits also earn full credit, for example
$g(x) = x^2$ with $f(x) = \dfrac{1}{x + 6}$, which composes to
$\dfrac{1}{x^2 + 6}$ as well.

\textit{Full credit:} two rules are named, neither is the identity, and the
student composes them back and lands on $h$. A pair that is merely asserted,
with no composition shown, is missing the justification the question asks
for.}
