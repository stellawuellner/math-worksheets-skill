\problem{\textbf{Full top row, one dot below.}

\textbf{Step 1.} The top row of a ten-frame holds five boxes and every one of
them is filled, so that row is five without counting it dot by dot.

\textbf{Step 2.} Count on into the bottom row: ``six''. That is $5 + 1$.

\textbf{Step 3.} The last number said tells how many. \quad $\ans{6}$

\textit{Listen for:} a child who goes back to one for the bottom row. The
whole point of the frame is that the full row can be trusted.}

\problem{\textbf{Full top row, four dots below.}

\textbf{Step 1.} Top row full, so start at five.

\textbf{Step 2.} Count on: ``six, seven, eight, nine'' --- that is $5 + 4$.

\textbf{Step 3.} One box is still empty, which is a useful check: nine is one
less than ten. \quad $\ans{9}$}

\problem{\textbf{Four above four.}

\textbf{Step 1.} Neither row is full here, so the five-shortcut does not
apply --- count the top row.

\textbf{Step 2.} The top row holds four. Count on through the bottom row:
``five, six, seven, eight''. That is $4 + 4$.

\textbf{Step 3.} Four and four make eight. \quad $\ans{8}$

\textit{Teaching note:} this is the doubles fact $4 + 4$. Seeing it as two
equal rows is what makes doubles quick to remember.}

\problem{\textbf{How many boxes are empty?}

\textbf{Step 1.} The question asks about the \emph{empty} boxes, so first find
how many are filled: the top row is full and two more sit below, which is
$5 + 2 = 7$.

\textbf{Step 2.} The whole frame holds ten, so the empty boxes are what is
left after seven: $10 - 7$.

\textbf{Step 3.} Three boxes are empty. \quad $\ans{3}$

\textit{Listen for:} the answer $7$. That is the number of dots, not the
number of empty boxes --- reread the question together.}

\problem{\textbf{Both rows full.}

\textbf{Step 1.} Each full row is five, and both rows are full.

\textbf{Step 2.} Five and five make ten, and a full ten-frame is ten by
definition --- that is what the frame is for.

\textbf{Step 3.} There are $\ans{10}$ dots.}

\problem{\textbf{Comparing Frame A and Frame B.}

\textbf{Step 1.} A comparison needs two finished counts, so count each frame
before deciding anything. Frame A: $5 + 2 = 7$.

\textbf{Step 2.} Frame B: $5 + 4 = 9$.

\textbf{Step 3.} Seven is less than nine, so the true sentence uses the
\emph{less than} sign. \quad $\ans{<}$

\textit{Teaching note:} both frames have a full top row, so only the bottom
rows can decide it --- a first taste of comparing by place.}

\problem{\textbf{How many more dots to fill the frame?}

\textbf{Step 1.} Count what is there: two dots on top and two below, which is
$2 + 2 = 4$.

\textbf{Step 2.} A full frame is ten, so the missing dots are $10 - 4$. The
empty boxes can also simply be counted: three on the top row and three below.

\textbf{Step 3.} Six more dots are needed. \quad $\ans{6}$}

\problem{\textbf{The top row is not full.}

\textbf{Step 1.} Check the top row before using the five-shortcut --- here it
holds only three dots, so five would be wrong.

\textbf{Step 2.} Count the top row (three), then count on through the bottom
row: ``four, five''. That is $3 + 2$.

\textbf{Step 3.} The frame shows $\ans{5}$ dots.

\textit{Common wrong answer:} $7$ --- the top row was assumed to be full.}

\problem{\textbf{Same amount, different arrangement.}

\textbf{Step 1.} Count each frame separately. Frame A: $4 + 4 = 8$.

\textbf{Step 2.} Frame B: $5 + 3 = 8$.

\textbf{Step 3.} The two amounts are the same, so neither sign is correct ---
the true sentence uses equals. \quad $\ans{=}$

\textit{Teaching note:} eight looks different in the two frames, and it is
still eight. That idea --- the arrangement can change while the amount does
not --- is the heart of this page.}

\problem{\textbf{Which frame needs more dots?}

\textbf{Step 1.} This question is about the \emph{empty} boxes, not the dots,
so count the empty boxes in each frame.

\textbf{Step 2.} Frame A shows six dots, so it has $10 - 6 = 4$ empty boxes.
Frame B shows nine dots, so it has $10 - 9 = 1$ empty box.

\textbf{Step 3.} Four is more than one, so Frame A needs more dots to be full
and the true sentence uses the \emph{greater than} sign. \quad $\ans{4 > 1}$

\textit{Listen for:} ``Frame B, because it has more dots.'' More dots means
\emph{fewer} empty boxes --- worth acting out with counters.}
