\problem{$f(x) = x^{2}$; a student claims $g(x) = f(x) + 5$ and $h(x) = f(x+5)$ have the same graph. \textbf{(a)} $g(2)$ and $h(2)$. \textbf{(b)} Name the error.}

\textbf{Solution (a):} $g(2) = 2^{2} + 5 = 9$ \ans{g(2) = 9}

\noindent $h(2) = (2 + 5)^{2} = 49$ \ans{h(2) = 49}

\textbf{Solution (b):} \emph{Instructor-judged.} The two values differ, so the claim fails --- but the diagnosis is what is graded. The $+5$ in $g$ sits \emph{outside} $f$: it adds $5$ to the output, so the graph moves up $5$. The $+5$ in $h$ sits \emph{inside} $f$: it changes the input, so the graph moves $5$ units \emph{left}. Naming which is vertical and which is horizontal is the full answer.

\problem{$y = 2(x-3)^{2} + 1$ built in the wrong order. \textbf{(a)} True vertex height. \textbf{(b)} Name the error.}

\textbf{Solution (a):} At $x = 3$ the squared term vanishes: $2(3-3)^{2} + 1 = 0 + 1$. \ans{y = 1}

\textbf{Solution (b):} \emph{Instructor-judged.} A vertical stretch multiplies whatever is already there, so it must be applied before the vertical shift. Shifting up $1$ first and then stretching by $2$ doubles that $1$ and puts the vertex at height $2$ --- which is exactly the value the student reported. The horizontal shift of $3$ is not implicated; an answer blaming it earns no credit.

\vspace{0.1cm}\noindent\rule{\linewidth}{0.2pt}

\problem{$f(x) = x^{2}$ with $f^{-1}(x) = \sqrt{x}$ and no restriction. \textbf{(a)} $f(-4)$, then its square root. \textbf{(b)} The restriction.}

\textbf{Solution (a):} $f(-4) = (-4)^{2} = 16$ \ans{f(-4) = 16}

\noindent $\sqrt{16} = 4$, not $-4$. \ans{\sqrt{f(-4)} = 4}

\textbf{Solution (b):} \emph{Instructor-judged.} The round trip started at $-4$ and came back at $4$, so $\sqrt{x}$ is not undoing $f$ on negative inputs. The repair is to restrict $f$ to $x \geq 0$, where it is one-to-one; then $\sqrt{x}$ is genuinely its inverse. A student may instead restrict to $x \leq 0$, but only with the inverse changed to $-\sqrt{x}$. Repeating that the numbers disagree is not a diagnosis.

\problem{Maya wrote $g(x) = 3(|x| - 4)$ for ``stretch by 3, then shift down 4'', and reported $g(2) = -6$. \textbf{(a)} Correct rule and $g(2)$. \textbf{(b)} Name her error.}

\textbf{Solution (a):} Stretch first, then subtract: $g(x) = 3|x| - 4$, so $g(2) = 3(2) - 4 = 2$. \ans{g(2) = 2}

\textbf{Solution (b):} \emph{Instructor-judged.} Her bracket subtracts $4$ and \emph{then} triples, so the $4$ was multiplied by $3$ and the graph dropped $12$ instead of $4$. The stretch has to come first, and the $-4$ must stay outside the multiplication. A correct answer names the order and identifies the $4$ as the number that was wrongly multiplied.

\vspace{0.1cm}\noindent\rule{\linewidth}{0.2pt}

\problem{$f(x) = \sqrt{x-2}$ with $f^{-1}(x) = x^{2} + 2$ on all reals. \textbf{(a)} $f(f^{-1}(-3))$. \textbf{(b)} Why the domain claim fails.}

\textbf{Solution (a):} $f^{-1}(-3) = (-3)^{2} + 2 = 11$, then $f(11) = \sqrt{11 - 2} = \sqrt{9} = 3$. \ans{f\bigl(f^{-1}(-3)\bigr) = 3}

\textbf{Solution (b):} \emph{Instructor-judged.} The round trip returned $3$, not $-3$, so on that input the rule is not an inverse at all. The reason is that $f$ never produces a negative output --- its range is $y \geq 0$ --- and the domain of $f^{-1}$ must be exactly that range. So $f^{-1}(x) = x^{2} + 2$ is correct only on $x \geq 0$. Changing the formula instead of restricting it is not the fix.

\problem{$f(x) = \sqrt{x}$; a student says $y = f(2x)$ stretches horizontally by $2$. \textbf{(a)} Solve $f(2x) = 4$ and $f(x) = 4$. \textbf{(b)} Stretch or compression?}

\textbf{Solution (a):} $\sqrt{2x} = 4 \Rightarrow 2x = 16 \Rightarrow x = 8$. \ans{x = 8}

\noindent $\sqrt{x} = 4 \Rightarrow x = 16$. \ans{x = 16}

\textbf{Solution (b):} \emph{Instructor-judged.} The height $4$ that used to be reached at $x = 16$ is now reached at $x = 8$: every point has moved to half its distance from the $y$-axis. That is a horizontal \emph{compression} by a factor of $\tfrac{1}{2}$, not a stretch by $2$. The two computed inputs are the evidence, and an answer that names compression without them is only half the response.

\vspace{0.1cm}\noindent\rule{\linewidth}{0.2pt}

\problem{$y = -(x+1)^{2} + 5$ with the reflection carried out last. \textbf{(a)} True vertex height. \textbf{(b)} Name the error.}

\textbf{Solution (a):} At $x = -1$: $-(-1 + 1)^{2} + 5 = -0 + 5$. \ans{y = 5}

\textbf{Solution (b):} \emph{Instructor-judged.} In the printed rule the minus sign attaches to the squared term alone, so the reflection happens before the $+5$ is added. Reflecting last negates the shift as well and drops the vertex to $-5$ --- the student's number. A correct answer states that a reflection in the $x$-axis must precede any vertical shift, or equivalently that the minus sign does not reach the $+5$.

\problem{$f(x) = x^{2} - 4x + 7$ on $x \leq 2$; a student used $f^{-1}(x) = 2 + \sqrt{x-3}$ and got $f^{-1}(12) = 5$. \textbf{(a)} Correct value. \textbf{(b)} Which branch.}

\textbf{Solution (a):} Complete the square: $f(x) = (x-2)^{2} + 3$. Solving $y = (x-2)^{2} + 3$ gives $x = 2 \pm \sqrt{y - 3}$, and $x \leq 2$ forces the minus sign, so $f^{-1}(x) = 2 - \sqrt{x - 3}$. Then $f^{-1}(12) = 2 - \sqrt{9} = 2 - 3$. \ans{f^{-1}(12) = -1}

\textbf{Solution (b):} \emph{Instructor-judged.} The vertex sits at $x = 2$, and the restriction $x \leq 2$ keeps the \emph{left} branch. Every output of $f^{-1}$ must therefore be at most $2$, which is what forces the minus square root; the plus root returns values at or above $2$ and inverts the right branch instead. A complete answer names the vertex, says which branch is kept, and ties that to the sign.
