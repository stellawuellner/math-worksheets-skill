\problem{\textbf{$\left(6, \frac{\pi}{3}\right)$ to rectangular.}

\textbf{Step 1.} The angle is already in radians and $\frac{\pi}{3}$ is a first
quadrant angle, so both coordinates will come out positive --- a check to make
at the end.

\textbf{Step 2.} $x = r\cos\theta = 6\cos\frac{\pi}{3} = 6 \cdot \frac{1}{2}$,
so $\ans{x = 3}$

\textbf{Step 3.} $y = r\sin\theta = 6\sin\frac{\pi}{3} =
6 \cdot \frac{\sqrt{3}}{2}$, so $\ans{y = 3\sqrt{3}}$

\textbf{Check.} $x^2 + y^2 = 9 + 27 = 36 = 6^2$ $\checkmark$ --- the rectangular
pair really is $6$ units from the origin.}

\problem{\textbf{$(3,4)$ to polar.}

\textbf{Step 1.} $r = \sqrt{3^2 + 4^2} = \sqrt{25}$, so $\ans{r = 5}$ --- the
familiar $3$-$4$-$5$ triangle.

\textbf{Step 2.} $\tan\theta = \frac{4}{3}$, and the point is in quadrant I,
where the arctangent key already returns the right answer.

\textbf{Step 3.} $\theta = \arctan\frac{4}{3} = 53.1301\ldots^\circ$, so
$\ans{\theta \approx 53.13^\circ}$

\textbf{Answer.} $(5,\ 53.13^\circ)$. No correction was needed here, which is
exactly why quadrant I lulls students into trusting the key everywhere.}

\problem{\textbf{$\left(4, \frac{3\pi}{4}\right)$ to rectangular.}

\textbf{Step 1.} $\frac{3\pi}{4}$ sits in quadrant II, so expect $x < 0$ and
$y > 0$.

\textbf{Step 2.} $x = 4\cos\frac{3\pi}{4} = 4\left(-\frac{\sqrt{2}}{2}\right)$,
so $\ans{x = -2\sqrt{2}}$

\textbf{Step 3.} $y = 4\sin\frac{3\pi}{4} = 4\left(\frac{\sqrt{2}}{2}\right)$,
so $\ans{y = 2\sqrt{2}}$

\textbf{Check.} Signs match the quadrant, and
$(-2\sqrt{2})^2 + (2\sqrt{2})^2 = 8 + 8 = 16 = 4^2$ $\checkmark$}

\problem{\textbf{$(-2,2)$ to polar.}

\textbf{Step 1 (part a).} $r = \sqrt{(-2)^2 + 2^2} = \sqrt{8}$, so
$\ans{r = 2\sqrt{2}}$

\textbf{Step 2 (part b).} $\tan\theta = \frac{2}{-2} = -1$. On one full turn the
tangent takes each value twice, half a turn apart:
$\ans{\theta = 135^\circ \text{ or } 315^\circ}$

\textbf{Step 3 (part c).} The point has $x < 0$ and $y > 0$, so it is in
quadrant II. Of the two candidates only $135^\circ$ lands there;
$315^\circ$ points into quadrant IV, at $(2,-2)$ --- the same line through the
origin, but the opposite ray.

\textbf{Answer.} $\left(2\sqrt{2},\ 135^\circ\right)$.

\textit{Note:} the two candidates always differ by exactly $180^\circ$, because
$\tan$ has period $180^\circ$. That is the whole reason the quadrant has to be
checked.}

\problem{\textbf{$\tan\theta = \sqrt{3}$, $r = 4$, third quadrant.}

\textbf{Step 1 (part a).} $\tan\theta = \sqrt{3}$ gives
$\ans{\theta = 60^\circ \text{ or } 240^\circ}$ on $[0^\circ, 360^\circ)$.

\textbf{Step 2 (part b).} $60^\circ$ is in quadrant I; $240^\circ$ is in
quadrant III, which is the one we were told. So $\theta = 240^\circ$.

\textbf{Step 3.} $x = 4\cos 240^\circ = 4\left(-\frac{1}{2}\right)$, so
$\ans{x = -2}$

\textbf{Step 4.} $y = 4\sin 240^\circ = 4\left(-\frac{\sqrt{3}}{2}\right)$, so
$\ans{y = -2\sqrt{3}}$

\textbf{Check.} Both coordinates negative, as quadrant III requires, and
$4 + 12 = 16 = 4^2$ $\checkmark$}

\problem{\textbf{$(6, 210^\circ)$ to rectangular.}

\textbf{Step 1.} $210^\circ$ is $30^\circ$ past a half turn, so it is in
quadrant III with reference angle $30^\circ$; both coordinates will be
negative.

\textbf{Step 2.} $x = 6\cos 210^\circ = 6\left(-\frac{\sqrt{3}}{2}\right)$, so
$\ans{x = -3\sqrt{3}}$

\textbf{Step 3.} $y = 6\sin 210^\circ = 6\left(-\frac{1}{2}\right)$, so
$\ans{y = -3}$

\textbf{Check.} $27 + 9 = 36 = 6^2$ $\checkmark$, and in decimals the point is
about $(-5.20,\ -3)$, which is where the plot lands.}

\problem{\textbf{$(-3,-4)$ to polar.}

\textbf{Step 1 (part a).} $r = \sqrt{(-3)^2 + (-4)^2} = \sqrt{25}$, so
$\ans{r = 5}$ --- the same $3$-$4$-$5$ triangle as problem 2.

\textbf{Step 2 (part b).} $\tan\theta = \frac{-4}{-3} = \frac{4}{3}$, exactly
the ratio from problem 2, because the two minus signs cancel. The reference
angle is therefore the same $53.13^\circ$.

\textbf{Step 3.} But this point is in quadrant III, so add a half turn:
$180^\circ + 53.1301\ldots^\circ$, giving $\ans{\theta \approx 233.13^\circ}$

\textbf{The comparison asked for.} $r$ is identical and the reference angle is
identical; only the quadrant differs, and it shifts the polar angle by exactly
$180^\circ$. The tangent alone cannot tell these two points apart --- which is
why the plot is not optional.

\textit{Common wrong answer:} $53.13^\circ$ --- the reference angle was
reported as if the point were in quadrant I.}

\problem{\textbf{$(-4,4)$ to polar --- what the calculator does.}

\textbf{Step 1 (part a).} $r = \sqrt{16 + 16} = \sqrt{32}$, so
$\ans{r = 4\sqrt{2}}$

\textbf{Step 2 (part b).} $\frac{y}{x} = \frac{4}{-4} = -1$, and the arctangent
key returns $-45^\circ$. The key always answers in
$(-90^\circ, 90^\circ)$ --- quadrants I and IV only --- so it can never return
a quadrant II angle no matter what is typed in.

\textbf{Step 3 (part c).} The point has $x < 0$ and $y > 0$: quadrant II. Add
a half turn to the key's answer: $180^\circ + (-45^\circ)$, giving
$\ans{\theta = 135^\circ}$

\textbf{Answer.} $\left(4\sqrt{2},\ 135^\circ\right)$, and $-45^\circ$ names
the point $(4,-4)$, the mirror image through the origin.

\textit{Common wrong answer:} $-45^\circ$ --- the key's output was copied
without adjusting for the quadrant.}

\problem{\textbf{The curve $r = 4\cos\theta$.}

\textbf{Step 1 (part a).} At $\theta = \frac{\pi}{3}$ the radius is
$r = 4\cos\frac{\pi}{3} = 2$. Then
$x = r\cos\theta = 2 \cdot \frac{1}{2}$, so $\ans{x = 1}$

\textbf{Step 2.} $y = r\sin\theta = 2 \cdot \frac{\sqrt{3}}{2} = \sqrt{3} =
1.7320\ldots$, so $\ans{y \approx 1.73}$

\textbf{Step 3 (part b) --- manual review.} \emph{Full credit says:} multiply
both sides by $r$ to get $r^2 = 4r\cos\theta$. Now substitute
$r^2 = x^2 + y^2$ and $r\cos\theta = x$:
\[ x^2 + y^2 = 4x. \]
Complete the square in $x$: $x^2 - 4x + 4 + y^2 = 4$, that is
$(x-2)^2 + y^2 = 4$ --- a circle of radius $2$ centred at $(2,0)$, passing
through the origin.

\textbf{Check.} The point from part (a) should satisfy it:
$(1-2)^2 + (\sqrt{3})^2 = 1 + 3 = 4$ $\checkmark$

\textit{Why multiply by $r$ first:} the conversion identities are
$r^2 = x^2+y^2$, $x = r\cos\theta$ and $y = r\sin\theta$. A bare $\cos\theta$
matches none of them; $r\cos\theta$ matches one exactly.}

\problem{\textbf{$(0,-5)$ --- the case the formula cannot handle.}

\textbf{Step 1 (part a).} $r = \sqrt{0^2 + (-5)^2}$, so $\ans{r = 5}$

\textbf{Step 2 (part b).} Here $x = r\cos\theta = 0$ with $r \neq 0$, so
$\cos\theta = 0$, giving
$\ans{\theta = 90^\circ \text{ or } 270^\circ}$ on one turn. The point is
\emph{below} the origin, so $y$ must be negative: that selects $270^\circ$.

\textbf{Step 3 (part c).} Converting back:
$x = 5\cos 270^\circ = 0$ $\checkmark$ and $y = 5\sin 270^\circ$, so
$\ans{y = -5}$ $\checkmark$

\textbf{Step 4 --- manual review.} \emph{Full credit says:} the formula
$\tan\theta = \frac{y}{x}$ needs a division by $x$, and here $x = 0$, so the
ratio is undefined --- there is no angle whose tangent is $\frac{-5}{0}$. On
the $y$-axis the tangent is not merely hard to invert, it does not exist. What
decides the angle instead is the position: the point lies on the negative
$y$-axis, which is the ray at $270^\circ$ (equivalently $-90^\circ$).

\textit{Note:} the same thing happens on the positive $y$-axis, at
$90^\circ$. A student who reaches for the arctangent key here gets an error
message, not a wrong number --- one of the few times the calculator warns you.}
