\problem{\textbf{Classify $\sqrt{64}$.}

\textbf{Step 1.} $64$ appears in the perfect-square row of the table
($8^2 = 64$), so the root comes out exactly.

\textbf{Step 2.} $\sqrt{64} = 8$, and $8 = \dfrac{8}{1}$ --- a ratio of two whole
numbers with a non-zero denominator. That is exactly the definition of rational.
\ans{8}

\textit{Classification:} \textbf{rational}.}

\problem{\textbf{Terminating decimal to fraction.}

\textbf{Step 1.} Read the decimal aloud: ``twenty-four hundredths''. The words
give the fraction: $0.24 = \dfrac{24}{100}$.

\textbf{Step 2.} Reduce by the common factor $4$:
$\dfrac{24}{100} = \dfrac{6}{25}$.
\ans{\tfrac{6}{25}}

\textit{Classification:} \textbf{rational}. Completed table row: $0.24$ $\mid$
$\frac{24}{100}$ $\mid$ $\frac{6}{25}$ $\mid$ yes. Every terminating decimal
converts this way, so \emph{every} terminating decimal is rational.}

\problem{\textbf{$\sqrt{20}$: locate, classify, approximate.}

\textbf{(a)} From the table, $4^2 = 16$ and $5^2 = 25$. Since
$16 < 20 < 25$, we get $4 < \sqrt{20} < 5$.

\textbf{(b)} $20$ is not a perfect square, and no fraction squares to $20$
either, so $\sqrt{20}$ is \textbf{irrational}: its decimal never ends and never
repeats.

\textbf{(c)} $\sqrt{20} = 4.4721359\ldots$, which rounds to
\ans{4.47}

\textit{Why the rounded value is a different number:} $4.47$ terminates, so
$4.47 = \frac{447}{100}$ is rational; $\sqrt{20}$ is not. The rounded value is a
useful stand-in on a number line, never an equality.

\textit{Common wrong answer:} $10$ --- halving the radicand instead of taking
the square root.}

\problem{\textbf{Classify $\sqrt{225}$.}

\textbf{Step 1.} Read the table: the last column gives $15^2 = 225$, so $225$ is
a perfect square.

\textbf{Step 2.} $\sqrt{225} = 15 = \dfrac{15}{1}$.
\ans{15}

\textit{Classification:} \textbf{rational}. A root is rational precisely when
the radicand is a perfect square (of a rational number) --- being ``a decimal
that looks tidy'' is not the test.}

\problem{\textbf{Order $\sqrt{11}$, $3.1$, $\frac{16}{5}$.}

\textbf{Step 1.} Put all three in decimal form.
$\dfrac{16}{5} = 3.2$ exactly, and $3.1$ is already a decimal.

\textbf{Step 2.} Bracket the root with the square table: $3^2 = 9$ and
$4^2 = 16$, so $\sqrt{11}$ is between $3$ and $4$. Squaring the candidate
settles it: $3.2^2 = 10.24 < 11$, so $\sqrt{11} > 3.2$.
\[ \boxed{3.1 \;<\; \tfrac{16}{5} \;<\; \sqrt{11}} \]

\textit{Classification:} $\sqrt{11}$ is the irrational one; $3.1$ and
$\frac{16}{5}$ are both rational. Note that the irrational number is not the
largest ``because it has a radical'' --- it lands where its size puts it.}

\problem{\textbf{Repeating decimal to fraction.}

\textbf{(a)} A repeating decimal is rational because the repeat is a
\emph{pattern}, and any repeating pattern can be captured by a fraction. Only
decimals that never end \emph{and} never repeat escape being a ratio.

\textbf{(b)} Reduce $\dfrac{63}{99}$ by the common factor $9$:
$\dfrac{63}{99} = \dfrac{7}{11}$.
\ans{\tfrac{7}{11}}

\textit{Check:} dividing $7$ by $11$ by hand returns the repeating block
again. \textit{Classification:} \textbf{rational}.}

\problem{\textbf{$\sqrt{40}$: locate, classify, approximate.}

\textbf{(a)} Two entries from the square table bracket it: $6^2 = 36$ and
$7^2 = 49$, and $36 < 40 < 49$, so $6 < \sqrt{40} < 7$.

\textbf{(b)} $40$ is not a perfect square, so $\sqrt{40}$ is
\textbf{irrational}.

\textbf{(c)} $\sqrt{40} = 6.3245553\ldots$, which rounds to
\ans{6.32}

\textit{Common wrong answer:} $20$ --- halving $40$ instead of taking its
square root.}

\problem{\textbf{Is $\sqrt{3} = 1.73$?}

\textbf{Step 1.} Test the claim by squaring the right-hand side:
$1.73^2 = 2.9929$, which is less than $3$. A number whose square is too small is
itself too small.

\textbf{Step 2.} Therefore
\[ \boxed{\sqrt{3} \;>\; 1.73} \]

\textit{What $1.73$ really is:} a rational two-decimal approximation of
$\sqrt{3}$ --- close enough for a sketch, but a different number. The true
decimal $1.7320508\ldots$ never ends and never repeats.}

\problem{\textbf{Classify $\sqrt{\frac{25}{36}}$.}

\textbf{Step 1.} The square root of a quotient is the quotient of the roots:
$\sqrt{\dfrac{25}{36}} = \dfrac{\sqrt{25}}{\sqrt{36}}$.

\textbf{Step 2.} The table shows $5^2 = 25$ and $6^2 = 36$, so both roots are
exact and the result is a ratio of whole numbers.
\ans{\tfrac{5}{6}}

\textit{Classification:} \textbf{rational}. A radical sign does not make a
number irrational --- what matters is whether the root comes out exactly.}

\problem{\textbf{A product of two irrational numbers.}

\textbf{(a)} Multiply under one radical:
$\sqrt{12} \cdot \sqrt{3} = \sqrt{12 \cdot 3} = \sqrt{36}$, and $36$ is a
perfect square.
\ans{6}

\textbf{(b)} Expected sentence: the claim is \textbf{false}, and this is a
counterexample --- $\sqrt{12}$ and $\sqrt{3}$ are both irrational, yet their
product is the rational number $6$. One counterexample is enough to disprove an
``always'' statement. (Accept any answer that identifies the claim as false and
points at this product as the reason.)}
