\problem{$a = 8$, $b = 5$, $C = 60^\circ$. Find $c$.}

\textbf{Solution:} two sides and the angle between them --- SAS --- so use the law of cosines with $c$ on the left, because $C$ is the known angle.
\[ c^2 = 8^2 + 5^2 - 2(8)(5)\cos 60^\circ = 64 + 25 - 80\left(\tfrac{1}{2}\right) = 49 \]
\ans{c = 7}

\smallskip
\noindent\textit{Common wrong answer:} $9.43$, from dropping the $-2ab\cos C$ term and using $\sqrt{8^2 + 5^2}$. That is the Pythagorean theorem, which is the law of cosines only when $C = 90^\circ$.

\vspace{0.1cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.1cm}

\problem{$a = 5$, $b = 7$, $c = 8$. Find $C$.}

\textbf{Solution:} three sides --- SSS --- so rearrange for the cosine of the angle opposite $c$.
\[ \cos C = \frac{5^2 + 7^2 - 8^2}{2(5)(7)} = \frac{25 + 49 - 64}{70} = \frac{10}{70} = 0.142857\ldots \]
\[ C = \cos^{-1}(0.142857\ldots) = 81.7868\ldots^\circ \]
\ans{C \approx 81.79^\circ}

\vspace{0.1cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.1cm}

\problem{$b = 11$, $c = 14$, $A = 38^\circ$. Find $a$.}

\textbf{Solution:} $A$ lies between $b$ and $c$, so put $a$ on the left.
\[ a^2 = 11^2 + 14^2 - 2(11)(14)\cos 38^\circ = 121 + 196 - 308(0.7880\ldots) = 74.3272\ldots \]
\[ a = \sqrt{74.3272\ldots} = 8.6193\ldots \]
\ans{a \approx 8.62}

\vspace{0.1cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.1cm}

\problem{$a = 9$, $b = 12$, $c = 15$. Find $A$.}

\textbf{Solution:} SSS again, this time solving for the angle opposite $a$ --- so $a^2$ is the term that gets subtracted.
\[ \cos A = \frac{12^2 + 15^2 - 9^2}{2(12)(15)} = \frac{144 + 225 - 81}{360} = \frac{288}{360} = 0.8 \]
$A = \cos^{-1}(0.8) = 36.8699\ldots^\circ$. Since $9^2 + 12^2 = 15^2$, this triangle is right-angled at $C$, and the answer is the familiar $36.87^\circ$. \ans{A \approx 36.87^\circ}

\vspace{0.1cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.1cm}

\problem{$a = 6$, $b = 10$, $C = 110^\circ$. Find $A$.}

\textbf{Solution:} no side has a known opposite angle yet, so the law of cosines has to run first.
\[ c^2 = 6^2 + 10^2 - 2(6)(10)\cos 110^\circ = 136 + 120(0.3420\ldots) = 177.0424\ldots, \quad c = 13.3057\ldots \]
Now $c$ and $C$ are a pair, so the law of sines finishes it:
\[ \sin A = \frac{6\sin 110^\circ}{13.3057\ldots} = 0.4236\ldots, \qquad A = 25.0709\ldots^\circ \]
$A$ must be acute here, since $C$ is already obtuse and a triangle has only one obtuse angle. \ans{A \approx 25.07^\circ}

\vspace{0.1cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.1cm}

\problem{$a = 23$, $c = 17$, $B = 73^\circ$. Find $b$.}

\textbf{Solution:} $B$ lies between $a$ and $c$, so $b$ goes on the left.
\[ b^2 = 23^2 + 17^2 - 2(23)(17)\cos 73^\circ = 529 + 289 - 782(0.2923\ldots) = 589.3653\ldots \]
\[ b = 24.2768\ldots \]
\ans{b \approx 24.28}

\vspace{0.1cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.1cm}

\problem{$a = 13$, $b = 14$, $c = 15$. Find $B$.}

\textbf{Solution:} solve for the angle opposite $b$, so $b^2$ is subtracted.
\[ \cos B = \frac{13^2 + 15^2 - 14^2}{2(13)(15)} = \frac{169 + 225 - 196}{390} = \frac{198}{390} = 0.5076\ldots \]
$B = 59.4898\ldots^\circ$. As $b$ is the middle-length side, $B$ should be the middle-sized angle, and it is. \ans{B \approx 59.49^\circ}

\vspace{0.1cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.1cm}

\problem{$b = 9$, $c = 12$, $A = 47^\circ$. Find $B$.}

\textbf{Solution:} SAS, so find the third side first.
\[ a^2 = 9^2 + 12^2 - 2(9)(12)\cos 47^\circ = 225 - 216(0.6819\ldots) = 77.6884\ldots, \quad a = 8.8140\ldots \]
Then, with $a$ and $A$ a pair,
\[ \sin B = \frac{9\sin 47^\circ}{8.8140\ldots} = 0.7468\ldots, \qquad B = 48.3121\ldots^\circ \]
$B$ is acute because $b$ is not the longest side. \ans{B \approx 48.31^\circ}

\vspace{0.1cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.1cm}

\problem{$a = 20$, $b = 16$, $c = 9$. (a) Find $A$. (b) What did $\cos A$ tell you first?}

\textbf{(a)} \[ \cos A = \frac{16^2 + 9^2 - 20^2}{2(16)(9)} = \frac{256 + 81 - 400}{288} = \frac{-63}{288} = -0.21875 \]
$A = \cos^{-1}(-0.21875) = 102.6356\ldots^\circ$. \ans{A \approx 102.64^\circ}

\textbf{(b)} \emph{Instructor-judged.} A correct response reads the sign before computing: the cosine came out negative, and cosine is negative only between $90^\circ$ and $180^\circ$, so $A$ is obtuse. A strong answer adds the structural reason --- $a = 20$ is the longest side, so it faces the largest angle, and only the largest angle of a triangle can be obtuse. Reporting the computed value alone is not an explanation.

\vspace{0.1cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.1cm}

\problem{Paths: $a = 120$ m, $b = 95$ m, included angle $C = 53^\circ$. Find $c$.}

\textbf{Solution:} the car park is the vertex between the two paths, so the angle there is included between $a$ and $b$ --- SAS.
\[ c^2 = 120^2 + 95^2 - 2(120)(95)\cos 53^\circ = 23425 - 22800(0.6018\ldots) = 9703.6\ldots \]
\[ c = 98.5069\ldots \]
\ans{c \approx 98.51\text{ m}}

\vspace{0.1cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.1cm}

\problem{Markers: $a = 340$ m, $b = 410$ m, $c = 520$ m. Find $C$.}

\textbf{Solution:} SSS, solving for the angle opposite the longest side.
\[ \cos C = \frac{340^2 + 410^2 - 520^2}{2(340)(410)} = \frac{115600 + 168100 - 270400}{278800} = \frac{13300}{278800} = 0.0477\ldots \]
$C = 87.2657\ldots^\circ$. The cosine is small and positive, so the angle is just under a right angle --- the triangle is very nearly right-angled. \ans{C \approx 87.27^\circ}

\vspace{0.1cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.1cm}

\problem{Drone: $a = 75$ m, $b = 110$ m, angle between them $C = 132^\circ$. (a) Find $c$. (b) Why not the law of sines first?}

\textbf{(a)} \[ c^2 = 75^2 + 110^2 - 2(75)(110)\cos 132^\circ = 17725 - 16500(-0.6691\ldots) = 28765.6\ldots \]
Because $C$ is obtuse its cosine is negative, so the last term \emph{adds} --- and $c$ comes out longer than either leg, which it must.
\[ c = 169.6044\ldots \]
\ans{c \approx 169.60\text{ m}}

\smallskip
\noindent\textit{Common wrong answer:} $81.76$ m, from using the reference angle $48^\circ$ instead of $132^\circ$. That flips the sign of the middle term and produces a distance shorter than the longer leg, which no triangle with a $132^\circ$ angle can have.

\textbf{(b)} \emph{Instructor-judged.} A correct response says the law of sines needs a side together with the angle opposite it, and here the one known angle sits \emph{between} the two known sides, so no such pair exists to start from. The law of cosines is the tool that accepts exactly this arrangement; once $c$ is known, every side has a partner and the law of sines can finish the triangle. Naming the law of cosines without the missing-pair reason is partial credit.
