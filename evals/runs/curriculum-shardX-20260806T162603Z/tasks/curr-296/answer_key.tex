\problem{Complete the table for $f(x) = |x-3| + 2$ at $x = 0$, $3$, $7$.}

\textbf{Solution:} Work inside the bars first, then take the distance from zero, then add $2$. The value inside can be negative; the value after the bars never is.
\begin{align*}
  f(0) &= |0-3| + 2 = 3 + 2 \\
  f(3) &= |3-3| + 2 = 0 + 2 \\
  f(7) &= |7-3| + 2 = 4 + 2
\end{align*}
\[ \boxed{f(0) = 5, \quad f(3) = 2, \quad f(7) = 6} \]
The smallest value is at $x = 3$, where the bars close on zero --- that is the corner of the graph.

\problem{For $g(x) = -2|x+1| + 5$, find $g(-4)$.}

\textbf{Solution:} Inside first: $-4 + 1 = -3$, so $|{-3}| = 3$. Then multiply by $-2$, then add $5$.
\[ g(-4) = -2(3) + 5 = -6 + 5 \]

\problem{$f(x) = 3x+1$ for $x < 2$ and $x^2 - 3$ for $x \ge 2$. (a) $f(0)$, $f(2)$, $f(5)$. (b) Why does $x = 2$ use the second rule?}

\textbf{Solution (a):} Check the condition before computing. $0 < 2$, so use $3x+1$. Both $2$ and $5$ satisfy $x \ge 2$, so use $x^2 - 3$.
\begin{align*}
  f(0) &= 3(0) + 1 \\
  f(2) &= 2^2 - 3 = 4 - 3 \\
  f(5) &= 5^2 - 3 = 25 - 3
\end{align*}
\[ \boxed{f(0) = 1, \quad f(2) = 1, \quad f(5) = 22} \]
\textbf{(b) --- instructor-judged.} The second rule carries the condition $x \ge 2$, which \emph{includes} $2$; the first stops strictly below $2$. Full credit requires that comparison of the two inequality signs. ``$2$ is bigger, so use the second rule'' is not the reason --- it would give the same answer here and the wrong one on a function written the other way round.

\problem{For $f(x) = |x-3| + 2$, find every $x$ with $f(x) = 7$.}

\textbf{Solution:} Isolate the absolute value first, then remember that \emph{two} numbers have the same distance from zero.
\begin{align*}
  |x-3| + 2 &= 7 \\
  |x-3| &= 5 \\
  x - 3 = 5 \quad &\text{or} \quad x - 3 = -5
\end{align*}
\[ \boxed{x = -2 \quad \text{and} \quad x = 8} \]
Solving only $x - 3 = 5$ gives $8$ and loses the other solution; both are the same distance, $5$, from the corner at $x = 3$.

\problem{$E(t) = |t-68|$. (a) $E(74)$. (b) $E(63)$.}

\textbf{Solution:} The bars turn a signed difference into a distance, which is why a temperature above the setting and one below both give a positive error.
\begin{align*}
  E(74) &= |74 - 68| = |6| \\
  E(63) &= |63 - 68| = |{-5}|
\end{align*}
\[ \boxed{E(74) = 6, \quad E(63) = 5} \]
Both answers are in degrees Fahrenheit, and both are positive: an error of five below the setting is still an error of five.

\problem{$C(h) = 4 + 2h$ for $0 \le h \le 3$, and $10 + 5(h-3)$ for $h > 3$. Find $C(2)$, $C(3)$, $C(6)$.}

\textbf{Solution:} $2$ and $3$ both satisfy $0 \le h \le 3$, so the first rule applies to each --- note that $3$ is included by the $\le$ sign. Only $6$ falls into the second rule.
\begin{align*}
  C(2) &= 4 + 2(2) \\
  C(3) &= 4 + 2(3) \\
  C(6) &= 10 + 5(6-3) = 10 + 15
\end{align*}
\[ \boxed{C(2) = 8, \quad C(3) = 10, \quad C(6) = 25} \]
The two rules agree at $h = 3$, which is what makes this a sensible price list: the cost does not jump at the boundary.

\problem{For $g(x) = -2|x+1| + 5$, find every $x$ with $g(x) = -1$.}

\textbf{Solution:} Undo the outside operations first, and divide by $-2$ before opening the bars.
\begin{align*}
  -2|x+1| + 5 &= -1 \\
  -2|x+1| &= -6 \\
  |x+1| &= 3 \\
  x + 1 = 3 \quad &\text{or} \quad x + 1 = -3
\end{align*}
\[ \boxed{x = -4 \quad \text{and} \quad x = 2} \]

\problem{$p(x) = x+4$ for $x \le -1$ and $2 - x^2$ for $x > -1$. Find $p(-1)$, $p(-3)$, $p(2)$.}

\textbf{Solution:} The boundary $-1$ belongs to the \emph{first} rule this time, because that is where the $\le$ sits.
\begin{align*}
  p(-1) &= -1 + 4 \\
  p(-3) &= -3 + 4 \\
  p(2) &= 2 - 2^2 = 2 - 4
\end{align*}
\[ \boxed{p(-1) = 3, \quad p(-3) = 1, \quad p(2) = -2} \]

\problem{Using $f$ from Problem 3: (a) solve $3x+1 = 13$; (b) solve $x^2 - 3 = 13$; (c) which values really solve $f(x) = 13$?}

\textbf{Solution (a):} $3x = 12$, so \ans{x = 4}

\textbf{Solution (b):} $x^2 = 16$, so $x = \pm 4$.
\[ \boxed{x = -4 \quad \text{and} \quad x = 4} \]
\textbf{(c) --- instructor-judged.} Only $x = 4$ solves $f(x) = 13$, and the reasoning must run through the conditions, not the arithmetic. The $4$ from part (a) is discarded because the rule $3x+1$ only applies when $x < 2$, and $4$ is not. The $-4$ from part (b) is discarded because the rule $x^2 - 3$ only applies when $x \ge 2$. The $4$ from part (b) survives both tests, so it is the single solution. Keeping a value without testing it against its condition, or rejecting $-4$ as bad arithmetic, is not full credit.

\problem{\textbf{Synthesis challenge.} (a) Solve the system $y = x+1$, $y = x^2 - 1$. (b) What do the solutions mean?}

\textbf{Solution (a):} Both rules give $y$, so set them equal --- that is exactly the question ``for which inputs do the two models agree?''
\begin{align*}
  x + 1 &= x^2 - 1 \\
  0 &= x^2 - x - 2 \\
  0 &= (x-2)(x+1)
\end{align*}
So $x = 2$ or $x = -1$, and substituting back into $y = x+1$ gives $y = 3$ and $y = 0$.
\[ \boxed{(-1,\, 0) \quad \text{and} \quad (2,\, 3)} \]
\textbf{(b) --- instructor-judged.} Each solution is an input at which the two models produce the same output; on a graph they are the two points where the line crosses the parabola. Full credit requires noticing that there are \emph{two} of them --- a student who tested a single input and found agreement would have concluded far too much. Restating the coordinates without saying what they mean is not full credit.
