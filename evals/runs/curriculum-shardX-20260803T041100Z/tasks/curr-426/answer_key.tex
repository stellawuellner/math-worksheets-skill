\problem{\textbf{Given $A = 42^\circ$, $B = 63^\circ$, $a = 10$; find $C$.}

\textbf{Solution:} No law of sines is needed --- the angle sum settles it.
\[ C = 180^\circ - 42^\circ - 63^\circ \]
\[ \ans{C = 75^\circ} \]
The side $a = 10$ is not used here; it is the pair that later problems build on.}

\problem{\textbf{Given $A = 35^\circ$, $C = 80^\circ$, $b = 12$; find $B$.}

\textbf{Solution:} $B = 180^\circ - 35^\circ - 80^\circ$, so
\[ \ans{B = 65^\circ} \]
The given side $b$ sits between the two given angles $A$ and $C$, so this data is
\textbf{ASA}. Once $B$ is known, $b$ and $B$ form a complete pair and every other part
of the triangle is reachable.}

\problem{\textbf{AAS: $A = 40^\circ$, $B = 75^\circ$, $a = 12$; find $b$.}

\textbf{Solution:} Side $a$ is opposite the given angle $A$, so the pair
$a/\sin A$ is already complete --- the law of sines applies with no extra step.
\begin{align*}
  \frac{b}{\sin B} &= \frac{a}{\sin A} \\
  b &= \frac{12 \sin 75^\circ}{\sin 40^\circ} = \frac{12(0.965926)}{0.642788} = 18.0326\ldots
\end{align*}
\[ \ans{b \approx 18.03} \]
Reasonable: $B > A$, so $b$ must come out larger than $a = 12$.

\noindent\textit{Watch for:} $7.99$ --- that is $12\sin 40^\circ / \sin 75^\circ$, the
ratio built upside down.}

\problem{\textbf{ASA: $A = 52^\circ$, $B = 48^\circ$, $c = 20$; find $a$.}

\textbf{Solution:} The given side $c$ lies between the given angles, so no pair is
complete. Find $C$ first.
\[ C = 180^\circ - 52^\circ - 48^\circ = 80^\circ \]
Now $c$ and $C$ are a pair:
\begin{align*}
  \frac{a}{\sin A} &= \frac{c}{\sin C} \\
  a &= \frac{20 \sin 52^\circ}{\sin 80^\circ} = \frac{20(0.788011)}{0.984808} = 16.0033\ldots
\end{align*}
\[ \ans{a \approx 16.00} \]}

\problem{\textbf{AAS: $B = 105^\circ$, $C = 35^\circ$, $b = 24$; find $c$.}

\textbf{Solution:} Side $b$ is opposite the given angle $B$, so the pair $b/\sin B$ is
complete and $c$ is one proportion away.
\begin{align*}
  \frac{c}{\sin C} &= \frac{b}{\sin B} \\
  c &= \frac{24 \sin 35^\circ}{\sin 105^\circ} = \frac{24(0.573576)}{0.965926} = 14.2514\ldots
\end{align*}
\[ \ans{c \approx 14.25} \]
Reasonable: $C$ is the smallest angle, so $c$ must be the shortest side.

\noindent\textit{Watch for:} $40.42$ --- that is the reciprocal set-up, and it wrongly
makes the side opposite the $35^\circ$ angle the longest in the triangle.}

\problem{\textbf{ASA: $B = 38^\circ$, $C = 71^\circ$, $a = 15$; find $b$.}

\textbf{Solution:} The given side $a$ is opposite $A$, which is \emph{not} given, so
this is ASA and $A$ must come first.
\[ A = 180^\circ - 38^\circ - 71^\circ = 71^\circ \]
Set up the proportion before computing:
\begin{align*}
  \frac{b}{\sin B} &= \frac{a}{\sin A} \\
  b &= \frac{15 \sin 38^\circ}{\sin 71^\circ} = \frac{15(0.615661)}{0.945519} = 9.7670\ldots
\end{align*}
\[ \ans{b \approx 9.77} \]
Note $A = C = 71^\circ$, so the triangle is isosceles with $a = c$.}

\problem{\textbf{Surveying, AAS: $A = 28^\circ$, $B = 47^\circ$, $a = 60$ m; find $b$.}

\textbf{Solution:} The measured distance $a$ is opposite the measured angle $A$, so the
data is AAS and the pair is ready to use.
\begin{align*}
  b &= \frac{a \sin B}{\sin A} = \frac{60 \sin 47^\circ}{\sin 28^\circ} \\
    &= \frac{60(0.731354)}{0.469472} = 93.4694\ldots
\end{align*}
\[ \ans{b \approx 93.47 \ \text{m}} \]
Units carry through unchanged: the ratio $\sin B / \sin A$ is dimensionless, so metres
in gives metres out.}

\problem{\textbf{Baseline, ASA: $A = 63^\circ$, $B = 41^\circ$, $c = 120$ m; find $b$.}

\textbf{Solution:} The baseline $c$ joins the two stations, so it lies between the two
measured angles --- ASA. The angle opposite the requested side $b$ is $B = 41^\circ$,
and the complete pair must be built from the third angle.
\[ C = 180^\circ - 63^\circ - 41^\circ = 76^\circ \]
\begin{align*}
  \frac{b}{\sin B} &= \frac{c}{\sin C} \\
  b &= \frac{120 \sin 41^\circ}{\sin 76^\circ} = \frac{120(0.656059)}{0.970296} = 81.1372\ldots
\end{align*}
\[ \ans{b \approx 81.14 \ \text{m}} \]

\noindent\textit{Watch for:} $88.36$ --- that comes from dividing by $\sin 63^\circ$,
pairing the baseline with a station angle instead of with the angle at the transmitter.}

\problem{\textbf{Two steps, AAS: $A = 33^\circ$, $B = 58^\circ$, $a = 45$; find $c$.}

\textbf{Solution:} The pair $a/\sin A$ is complete, but $c$ needs the angle opposite it,
which is not given --- so the third angle is the required first step.
\[ C = 180^\circ - 33^\circ - 58^\circ = 89^\circ \]
\begin{align*}
  \frac{c}{\sin C} &= \frac{a}{\sin A} \\
  c &= \frac{45 \sin 89^\circ}{\sin 33^\circ} = \frac{45(0.999848)}{0.544639} = 82.6109\ldots
\end{align*}
\[ \ans{c \approx 82.61} \]
$C$ is nearly a right angle, so $c$ is nearly the hypotenuse of an almost-right triangle;
the check $45 / \sin 33^\circ \approx 82.62$ confirms the size.}

\problem{\textbf{Triangulation: $A = 57^\circ$, $B = 49^\circ$, $c = 500$ m.}

\textbf{(a) Find $a$.} The shoreline $c$ joins the two posts and lies between the two
measured angles, so this is ASA. Find the angle at the buoy first.
\[ C = 180^\circ - 57^\circ - 49^\circ = 74^\circ \]
\begin{align*}
  \frac{a}{\sin A} &= \frac{c}{\sin C} \\
  a &= \frac{500 \sin 57^\circ}{\sin 74^\circ} = \frac{500(0.838671)}{0.961262} = 436.2343\ldots
\end{align*}
\[ \ans{a \approx 436.23 \ \text{m}} \]

\textbf{(b) Model answer (open response --- grade the reasoning).}
With AAS or ASA you know two angles, so the third is forced by the angle sum, and the
shape of the triangle is completely fixed. The one given side then fixes the size: the
law of sines produces exactly one positive value for each remaining side, because the
ratio $\sin(\text{known angle}) / \sin(\text{known angle})$ is a single number. So AAS
and ASA data determine exactly one triangle. SSA is different: there you solve for an
angle using $\sin$, and the equation $\sin \theta = k$ with $0 < k < 1$ has \emph{two}
solutions between $0^\circ$ and $180^\circ$, namely $\theta$ and $180^\circ - \theta$.
Both can produce a valid triangle, so SSA may give two triangles, one, or none --- that
is the ambiguous case. The classmate is wrong: no extra measurement is needed here.

\noindent\textit{Look for:} the angle sum forcing the third angle; the single given side
setting the scale; and, for SSA, the two supplementary solutions of $\sin \theta = k$.}
