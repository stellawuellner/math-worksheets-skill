\wstitleblock{Deciding Whether a Relation Is a Function}{Grade 8 / Pre-Algebra \quad Function Concepts and Comparisons}{}

\begin{center}
\textit{Deciding from mapping diagrams, from sets and tables, and from graphs
with the vertical line test}
\end{center}

\noindent\textbf{Directions.} A relation is a \textbf{function} when every
input has exactly \emph{one} output. Use the same two-step count every time:
\begin{itemize}[leftmargin=1.2cm, itemsep=2pt, topsep=2pt]
\item Count the \textbf{pairs} (arrows, rows, or plotted points).
\item Count the \textbf{different inputs} (left-hand values, or first
coordinates).
\item If the two counts are \textbf{equal}, no input was used twice, so the
relation is a function. If the number of different inputs is \textbf{less} than
the number of pairs, some input has two outputs and it is not a function.
\item On a graph the same test is the \textbf{vertical line test}: if any
vertical line meets the graph more than once, that input has two outputs.
\item Outputs are allowed to repeat. Only \emph{inputs} may not.
\end{itemize}
