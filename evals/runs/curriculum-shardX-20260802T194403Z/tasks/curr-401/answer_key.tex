\noindent\small Throughout, parameters are read against
$g(x) = a\,f\bigl(b(x-h)\bigr) + k$: \ $a$ and $k$ act on outputs and do what they say;
$b$ and $h$ act on inputs and do the opposite, and only after the inside is factored into
$b(x-h)$.\normalsize

\problem{\textbf{$f(x) = x^2$, \ $g(x) = 2f(x - 3) - 5$; complete the chain and find $g(5)$.}\par
The chain is the parameter order made visible --- input shift, then the parent, then the
output stretch, then the output shift:
\begin{center}\small
\begin{tabular}{|c|c|c|c|c|}
\hline
$x$ & $x - 3$ & $f(x-3)$ & $2f(x-3)$ & $2f(x-3)-5$\\\hline
$5$ & $2$ & $4$ & $8$ & $3$\\\hline
\end{tabular}
\end{center}
The $-3$ is applied to the \emph{input} before $f$ ever runs, which is why the table's
second column changes 5 into 2. $\ans{g(5) = 3}$}

\problem{\textbf{$h(x) = -f(x + 1) + 4$ with $f(x) = x^2$; name the parameters, find $h(2)$.}\par
Two parameters are non-trivial: $a = -1$ (a reflection across the $x$-axis, an
\emph{output} move) and $h = -1$ (a shift 1 unit \emph{left}, an input move --- the inside
reads $x + 1 = x - (-1)$). There is no stretch ($b = 1$) and the vertical shift is $k = 4$.
\[ h(2) = -(2 + 1)^2 + 4 = -9 + 4 \]
$\ans{h(2) = -5}$\par
\textit{Watch:} squaring happens before the reflection, so the answer is $-9+4$, never
$(-3)^2 + 4$.}

\problem{\textbf{Solve $3\sqrt{x - 4} + 1 = 7$.}\par
Undo the parameters in the reverse of the order that builds them --- outputs first, inputs
last:
\begin{align*}
3\sqrt{x-4} + 1 &= 7 &&\text{undo } k = 1:\\
3\sqrt{x-4} &= 6 &&\text{undo } a = 3:\\
\sqrt{x-4} &= 2 &&\text{undo the parent (square both sides):}\\
x - 4 &= 4 &&\text{undo } h = 4:\\
x &= 8
\end{align*}
Check: $3\sqrt{8-4} + 1 = 3(2) + 1 = 7$ $\checkmark$ \ans{x = 8}}

\problem{\textbf{$y = 4\sin\bigl(2(x - \pi/6)\bigr) + 1$: parameters, then $y$ at $x = 5\pi/12$.}\par
Amplitude $= |a| = 4$. Period $= 2\pi / b = 2\pi/2 = \pi$. Phase shift $= h = \pi/6$ to the
right. Midline $= y = k = 1$.\par
The inside is already factored, so substituting is safe:
\[ 2\left(\frac{5\pi}{12} - \frac{\pi}{6}\right) = 2\left(\frac{5\pi}{12} - \frac{2\pi}{12}\right)
   = 2 \cdot \frac{\pi}{4} = \frac{\pi}{2} \]
\[ y = 4\sin\frac{\pi}{2} + 1 = 4(1) + 1 \]
That input is exactly a quarter period past the phase shift, which is where a sine reaches
its maximum --- so 5 should be the largest value on the graph, and it is. $\ans{y = 5}$}

\problem{\textbf{$s(x) = x + 4$, $d(x) = 2x$; simplify $(d \circ s)(x)$.}\par
$(d \circ s)(x) = d(s(x))$ means $s$ runs \emph{first}: the shift happens, then the stretch
acts on the already-shifted value.
\[ d(s(x)) = d(x + 4) = 2(x + 4) \]
$\ans{(d \circ s)(x) = 2x + 8}$\par
Notice the shift got multiplied by the stretch factor: shifting 4 and then doubling moves
the graph 8, not 4. That is the whole reason order matters.}

\problem{\textbf{Solve $(d \circ s)(x) = 20$, and why $(s \circ d)$ differs.}\par
From problem 5, $(d \circ s)(x) = 2(x + 4)$:
\[ 2(x + 4) = 20 \;\Rightarrow\; x + 4 = 10 \;\Rightarrow\; x = 6 \]
\ans{x = 6}\par
\textit{Why the other order differs:} $(s \circ d)(x) = s(2x) = 2x + 4$. Here the stretch
happens first, so the shift is applied afterwards and is \emph{not} scaled. Setting
$2x + 4 = 20$ would give $x = 8$ instead. Same two parameters, different composition
order, different function.}

\problem{\textbf{Rewrite $y = 3\sin(2x - \pi/3)$ as $A\sin\bigl(B(x - C)\bigr)$.}\par
$C$ cannot be read off until $B$ is factored out of the whole inside expression:
\[ 2x - \frac{\pi}{3} = 2\left(x - \frac{\pi}{6}\right) \]
because $2 \cdot \pi/6 = \pi/3$. So
\[ \boxed{y = 3\sin\left(2\left(x - \frac{\pi}{6}\right)\right)}, \qquad
   A = 3,\quad B = 2,\quad C = \frac{\pi}{6} \]
\textit{Why $C \ne \pi/3$:} the $\pi/3$ is subtracted \emph{after} the input has already
been doubled, so it measures a shift in the compressed variable, not in $x$. Dividing by
$B$ converts it back: $C = (\pi/3)/2 = \pi/6$.}

\problem{\textbf{$g(x) = -2f\bigl(3(x-1)\bigr) + 5$ with $f(x) = \sqrt{x}$; parameters and $g(4)$.}\par
Four parameters: $a = -2$ (reflect across the $x$-axis and stretch outputs by 2),
$b = 3$ (compress inputs horizontally by a factor of $1/3$), $h = 1$ (shift 1 unit right),
$k = 5$ (shift 5 units up).
\[ g(4) = -2\sqrt{3(4 - 1)} + 5 = -2\sqrt{9} + 5 = -2(3) + 5 = -6 + 5 \]
$\ans{g(4) = -1}$\par
Order check: the input move $3(4-1) = 9$ happens before the square root; the $-2$ and the
$+5$ act only on the output the parent returned.}

\problem{\textbf{$x$-intercept of $g(x) = 2\sqrt{x + 3} - 4$.}\par
Set the output to 0 and peel the parameters off from the outside in:
\begin{align*}
2\sqrt{x+3} - 4 &= 0\\
2\sqrt{x+3} &= 4 &&\text{undo } k = -4\\
\sqrt{x+3} &= 2 &&\text{undo } a = 2\\
x + 3 &= 4 &&\text{square}\\
x &= 1 &&\text{undo } h = -3
\end{align*}
Check: $2\sqrt{1+3} - 4 = 2(2) - 4 = 0$ $\checkmark$ \ans{x = 1}}

\problem{\textbf{Sketch $y = -2f\left(\frac{x}{2} + 1\right) + 3$ for $f(x) = \sqrt{x}$.}
\quad (open construction --- verify the sketch and read the ordering argument)\par
\textbf{Step 1 --- factor the inside.} $\dfrac{x}{2} + 1 = \dfrac{1}{2}(x + 2)$, so
$b = \dfrac{1}{2}$ and $h = -2$.\par
\textbf{Step 2 --- the four parameters, in a correct order of application:}
horizontal stretch by 2 (since $1/b = 2$), then shift 2 units left, then vertical stretch by
2 with a reflection across the $x$-axis, then shift 3 units up. The two input moves must be
done before the output moves, and within the input moves the stretch is applied before the
shift when the inside is written in factored form.\par
\textbf{Step 3 --- track the parent's starting point.} $f$ starts at $(0,0)$. The inside is
zero when $x = -2$, and the output there is $-2(0) + 3 = 3$, so the image of the starting
point is $(-2, 3)$ --- the sketch must begin there.\par
\textbf{Step 4 --- shape.} From $(-2,3)$ the curve falls to the right (because $a<0$),
passing through $x = 0$ at $y = -2\sqrt{1} + 3 = 1$ and $x = 6$ at $y = -2\sqrt{4} + 3 = -1$.
Domain $x \ge -2$.\par
\textbf{Why the shift is 2 left, not 1.} Written as $\frac{x}{2} + 1$ the constant is
measured in the \emph{stretched} input, so it must be divided by $b = \frac12$ to be read in
$x$: $1 \div \frac12 = 2$. Factoring does that division for you, which is why the factored
form is the only one a shift can be read from directly.\par
\textit{Full credit} requires the factored inside, the four parameters with input moves
before output moves, a curve starting at $(-2,3)$ and decreasing to the right, and the
explanation of the 2-versus-1 shift. $\ans{\text{start } (-2,\,3),\ \text{falling, domain } x \ge -2}$}
