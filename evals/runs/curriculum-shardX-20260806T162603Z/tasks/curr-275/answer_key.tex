\problem{Stack of chairs: first chair $82$ cm, each extra chair adds $9$ cm. Height of a stack of $6$?}

\textbf{Solution:} Let $n$ count chairs, so $a_n = 82 + 9(n-1)$. A stack of six has five \emph{added} chairs: $82 + 5(9) = 82 + 45$. \ans{127\ \text{cm}}

\vspace{0.2cm}\noindent\rule{\linewidth}{0.2pt}

\problem{Gym: \$30 to join plus \$22 a month. Total paid after $8$ months?}

\textbf{Solution:} Here $n$ counts months and the joining fee is paid once, so the total is $30 + 22n$. At $n = 8$: $30 + 176$. \ans{206}

\vspace{0.2cm}\noindent\rule{\linewidth}{0.2pt}

\problem{Running: $12$ minutes in week $1$, $+4$ minutes each week. Total minutes over $8$ weeks?}

\textbf{Solution:} Weekly minutes form the sequence $a_n = 12 + 4(n-1)$, so week $8$ is $12 + 7(4) = 40$. Pair first with last: $S_8 = \frac{8}{2}(12 + 40) = 4(52)$. \ans{208\ \text{min}}

\vspace{0.2cm}\noindent\rule{\linewidth}{0.2pt}

\problem{Tank: $240$ litres, losing $15$ litres a day. On which day is it empty?}

\textbf{Solution:} Empty means the amount left is zero: $240 - 15n = 0$, so $15n = 240$. Check: $240 - 15(16) = 0$ $\checkmark$ \ans{n = 16}

\vspace{0.2cm}\noindent\rule{\linewidth}{0.2pt}

\problem{Theatre: $20$ seats in row $1$, $+3$ per row. Seats in row $15$?}

\textbf{Solution:} Row $15$ is fourteen rows past row $1$, not fifteen: $20 + 14(3) = 20 + 42$. \ans{62}

\vspace{0.2cm}\noindent\rule{\linewidth}{0.2pt}

\problem{Same theatre. Total seats in rows $1$ through $15$?}

\textbf{Solution:} The first and last rows hold $20$ and $62$ seats, and there are $15$ rows, so $S_{15} = \frac{15}{2}(20 + 62) = \frac{15}{2}(82) = 15(41)$. \ans{615}

\vspace{0.2cm}\noindent\rule{\linewidth}{0.2pt}

\problem{Savings: \$45 after week $1$, $+$\$18 a week. Which week reaches \$261?}

\textbf{Solution:} Solve $45 + 18(n-1) = 261$. Subtract $45$: $18(n-1) = 216$, so $n - 1 = 12$. Check: $45 + 18(12) = 261$ $\checkmark$ \ans{n = 13}

\vspace{0.2cm}\noindent\rule{\linewidth}{0.2pt}

\problem{Plumber: \$95 for the first hour, \$60 for each additional hour. Cost of a $7$-hour call-out?}

\textbf{Solution:} With $n$ counting hours on site, $a_n = 95 + 60(n-1)$; six of the seven hours are charged at the lower rate: $95 + 6(60) = 95 + 360$. \ans{455}

\vspace{0.2cm}\noindent\rule{\linewidth}{0.2pt}

\problem{Brick pile: $48$ in the bottom row, $3$ fewer each row up, $12$ rows. Total bricks?}

\textbf{Solution:} With $n$ counting rows from the bottom, $a_n = 48 - 3(n-1)$, so the top row holds $48 - 11(3) = 15$. Twelve rows, so $S_{12} = \frac{12}{2}(48 + 15) = 6(63)$. \ans{378}

\vspace{0.2cm}\noindent\rule{\linewidth}{0.2pt}

\problem{Data plan: $500$ MB in month $1$, $+250$ MB a month. Which month first reaches $3000$ MB?}

\textbf{Solution:} Solve $500 + 250(n-1) = 3000$. Subtract $500$: $250(n-1) = 2500$, so $n - 1 = 10$. Check: $500 + 250(10) = 3000$ $\checkmark$ \ans{n = 11}

\vspace{0.2cm}\noindent\rule{\linewidth}{0.2pt}

\problem{Offer $A$: \$2400 in year $1$, $+$\$1500 a year. Offer $B$: \$3600 in year $1$, $+$\$900 a year. (a) Equal year. (b) Six-year total for $A$.}

\textbf{Solution (a):} Set the two year-$n$ salaries equal: $2400 + 1500(n-1) = 3600 + 900(n-1)$. Collect: $600(n-1) = 1200$, so $n - 1 = 2$. Check: $A$ pays $2400 + 3000 = 5400$ and $B$ pays $3600 + 1800 = 5400$ $\checkmark$ \ans{n = 3}

\textbf{Solution (b):} Offer $A$ in year $6$ pays $2400 + 5(1500) = 9900$, so the six-year total is $S_6 = \frac{6}{2}(2400 + 9900) = 3(12300)$. \ans{36900}

\vspace{0.2cm}\noindent\rule{\linewidth}{0.2pt}

\problem{Hall of $24$ rows: $18$ seats in row $1$, $+2$ per row. (a) Last row. (b) Total. (c) Why doubling the rows more than doubles capacity.}

\textbf{Solution (a):} Row $24$ is twenty-three rows past row $1$: $18 + 23(2) = 18 + 46$. \ans{64}

\textbf{Solution (b):} $S_{24} = \frac{24}{2}(18 + 64) = 12(82)$. \ans{984}

\textbf{(c) --- instructor-judged.} A correct answer says the rows added on top are all larger than the rows already there, because each row holds two more seats than the one below, so the extra twenty-four rows contribute more than the original twenty-four did and the total more than doubles. (For reference, $S_{48} = \frac{48}{2}(18 + 112) = 3120$, well past $2 \times 984$.)
