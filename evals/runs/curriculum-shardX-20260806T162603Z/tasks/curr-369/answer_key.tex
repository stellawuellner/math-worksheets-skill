\problem{Write $\dfrac{x^2-9}{x^2-x-6}$ in fully simplified form.}

\textbf{Solution:} Factor both parts, then cancel the shared factor:
\[ \frac{x^2-9}{x^2-x-6} = \frac{(x-3)(x+3)}{(x-3)(x+2)} . \]
The factor $(x-3)$ is common to top and bottom, so it cancels.
\ans{\dfrac{x+3}{x+2}}

\vspace{0.25cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.25cm}

\problem{$f(x) = \dfrac{x^2-9}{x^2-x-6}$. (a) Zeros of the original denominator.
(b) Which is a hole, which is a vertical asymptote, and why.}

\textbf{Solution (a):} $x^2 - x - 6 = (x-3)(x+2)$, which is zero when
$x = 3$ or $x = -2$. \ans{x = -2 \text{ or } x = 3}

\textbf{Solution (b):} \emph{Instructor-judged.} After factoring,
$f(x) = \dfrac{(x-3)(x+3)}{(x-3)(x+2)}$. The factor $(x-3)$ appears above and
below and cancels, so $x = 3$ is a \textbf{hole} --- the simplified function is
perfectly well behaved there, the original just has no value assigned. The
factor $(x+2)$ survives the cancelling, so as $x \to -2$ the denominator goes to
zero while the numerator does not, and the values run off without bound:
$x = -2$ is a \textbf{vertical asymptote}. Full credit needs both labels and the
cancelling reason.

\vspace{0.25cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.25cm}

\problem{Coordinates of the hole in the graph of
$f(x) = \dfrac{x^2-9}{x^2-x-6}$.}

\textbf{Solution:} The hole sits at the $x$-value of the cancelled factor,
$x = 3$. Its height is the value the \emph{simplified} function takes there:
\[ \frac{x+3}{x+2} \Big|_{x=3} = \frac{6}{5} . \]
So the graph is a smooth curve with one point missing, at
\ans{\left(3,\ \tfrac{6}{5}\right)}

\vspace{0.25cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.25cm}

\problem{$g(x) = \dfrac{2x^2-8}{x^2+x-6}$. (a) Simplify. (b) Values excluded from
the domain.}

\textbf{Solution (a):} Take out the common factor $2$ on top, then factor both
quadratics:
\[ \frac{2x^2-8}{x^2+x-6} = \frac{2(x-2)(x+2)}{(x+3)(x-2)} . \]
Cancelling $(x-2)$ leaves \ans{\dfrac{2(x+2)}{x+3}}

\textbf{Solution (b):} The domain is set by the \emph{original} denominator,
before any cancelling: $(x+3)(x-2) = 0$ at $x = -3$ and $x = 2$. Cancelling
removes the factor from the formula, not the restriction from the domain.
\ans{x = -3 \text{ or } x = 2}

\vspace{0.25cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.25cm}

\problem{Student work on the hole of $h(x) = \dfrac{x^2-4}{x-2}$: ``the top is
$0$ at $x=2$, so the hole is at height $0$.'' (a) Correct height. (b) The error.}

\textbf{Solution (a):} $\dfrac{x^2-4}{x-2} = \dfrac{(x-2)(x+2)}{x-2} = x+2$ for
every $x \ne 2$. The height of the hole is the value of that cancelled form at
$x = 2$, namely $2 + 2$. \ans{4}

\textbf{Solution (b):} \emph{Instructor-judged.} The error is substituting into
the original quotient. At $x = 2$ the numerator and the denominator are
\emph{both} zero, so the expression $\frac{0}{0}$ says nothing at all --- it is
not $0$. The shared factor $(x-2)$ has to be cancelled first; the height of the
hole is then read from $x+2$. A full-credit answer says a zero numerator does not
force the value to be zero when the denominator vanishes at the same place.

\vspace{0.25cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.25cm}

\problem{Student work on $k(x) = \dfrac{x^2-x-6}{x^2-4}$: ``the bottom is zero at
$x=2$ and $x=-2$, so both are vertical asymptotes.'' (a) Simplify. (b) The only
vertical asymptote. (c) The error.}

\textbf{Solution (a):} $\dfrac{x^2-x-6}{x^2-4} = \dfrac{(x-3)(x+2)}{(x-2)(x+2)}$,
and $(x+2)$ cancels. \ans{\dfrac{x-3}{x-2}}

\textbf{Solution (b):} Only the denominator left after cancelling can produce an
asymptote, and $x - 2 = 0$ gives \ans{x = 2}

\textbf{Solution (c):} \emph{Instructor-judged.} The student used the original
denominator instead of the cancelled one. Because $(x+2)$ divides out, the graph
does not run off to infinity at $x = -2$; it simply has one missing point there,
a hole at $x = -2$. Vertical asymptotes come from the factors that survive
cancelling. A full-credit answer names $x=-2$ as a hole and states that rule.

\vspace{0.25cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.25cm}

\problem{$m(x) = \dfrac{x^3-x}{x^2-1}$. (a) Simplify. (b) $x$-values of the
holes. (c) Number of vertical asymptotes, with a reason.}

\textbf{Solution (a):} Factor completely:
\[ \frac{x^3-x}{x^2-1} = \frac{x(x-1)(x+1)}{(x-1)(x+1)} . \]
Both denominator factors cancel. \ans{m(x) = x}

\textbf{Solution (b):} The cancelled factors were $(x-1)$ and $(x+1)$, so the
graph is the line $y = x$ with two points removed.
\ans{x = -1 \text{ or } x = 1}

\textbf{Solution (c):} \emph{Instructor-judged.} There are \textbf{none}. Every
factor of the denominator cancelled, so nothing is left to drive the function to
infinity; the graph is the straight line $y = x$ with holes at $(-1,-1)$ and
$(1,1)$. A full-credit answer says zero asymptotes \emph{and} explains that all
denominator factors cancelled.

\vspace{0.25cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.25cm}

\problem{$n(x) = \dfrac{x^2+2x-15}{x^2-2x-3}$. (a) Simplify. (b) Height of the
hole. (c) The vertical asymptote.}

\textbf{Solution (a):} $\dfrac{x^2+2x-15}{x^2-2x-3} = \dfrac{(x+5)(x-3)}{(x-3)(x+1)}$,
and $(x-3)$ cancels. \ans{\dfrac{x+5}{x+1}}

\textbf{Solution (b):} The cancelled factor puts the hole at $x = 3$; its height
comes from the simplified form: $\dfrac{3+5}{3+1} = \dfrac{8}{4}$. \ans{2}

\textbf{Solution (c):} The surviving denominator factor is $(x+1)$, zero at
\ans{x = -1}
