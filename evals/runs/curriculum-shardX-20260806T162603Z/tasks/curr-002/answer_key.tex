\problem{A row of dots --- count and write how many.}

\textbf{Solution:} Touch each dot once: ``one, two, three.'' The last number
said tells how many, so there are \ans{3}

\problem{A row of dots --- count and write how many.}

\textbf{Solution:} One number per dot: ``one, two, three, four, five.'' The
count ends at \ans{5}

\problem{A row of dots --- count and write how many.}

\textbf{Solution:} Count steadily, one touch per dot: the count runs from one
up to seven, so there are \ans{7}

\problem{Ten-frame with a full top row and one dot in the bottom row.}

\textbf{Solution:} The full top row is 5 without recounting. Count on for the
bottom row: ``six.'' $5 + 1 = 6$, so there are \ans{6}

\problem{Array with 2 rows of 3 dots.}

\textbf{Solution:} Count the first row: 3. Count on through the second row:
``four, five, six.'' $3 + 3 = 6$, so there are \ans{6}

\problem{Ten-frame with a full top row and 3 dots in the bottom row.}

\textbf{Solution:} Top row is 5. Count on: ``six, seven, eight.'' $5 + 3 = 8$,
so there are \ans{8}

\problem{Array with 3 rows of 4 dots.}

\textbf{Solution:} Each row has 4. Count row by row: $4 + 4 + 4 = 12$. The
count ends at \ans{12}

\problem{A long row of dots.}

\textbf{Solution:} A long row is where skipped or double-counted dots happen
--- touch each dot exactly once. The count ends at \ans{9}

\problem{A completely full ten-frame.}

\textbf{Solution:} A full row is 5, and there are two full rows:
$5 + 5 = 10$. A full ten-frame always shows \ans{10}

\problem{Challenge: big array (4 rows of 5 dots), then tell how you counted.}

\textbf{Solution:} Each row has 5 dots and there are four rows:
$5 + 5 + 5 + 5 = 20$. The total is \ans{20}

\textbf{Telling how (instructor-judged):} accept any real one-to-one strategy
--- ``I touched every dot once,'' ``I counted one row and added the rows,'' or
``I counted by fives.'' The strategy must explain the count; a bare guess with
no method does not earn credit.
