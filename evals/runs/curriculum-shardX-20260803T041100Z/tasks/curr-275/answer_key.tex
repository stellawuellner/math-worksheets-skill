\problem{\textbf{7th term of the sequence with $a_1 = 3$, $d = 5$.}

\textbf{Step 1.} The question asks for one specific term, so the explicit
formula $a_n = a_1 + (n-1)d$ is the right tool; identify
$a_1 = 3$, $d = 5$, $n = 7$ before substituting.

\textbf{Step 2.} $a_7 = 3 + (7-1)(5) = 3 + 30 = 33$.
\ans{33}

\textit{Why $n-1$:} getting from term 1 to term 7 takes six steps, not seven.
Using $n$ instead gives 38, one common difference too many.}

\problem{\textbf{$f(10)$ for $f(n) = 3n + 1$.}

\textbf{Step 1.} The sequence has already been packaged as a linear function of
the term number, so the work is a single substitution rather than a recursion.

\textbf{Step 2.} $f(10) = 3(10) + 1 = 30 + 1 = 31$.
\ans{31}

\textit{Reading the form:} the slope 3 is the common difference, and the
constant 1 is the value the line would take at $n = 0$ --- one step \emph{before}
the first term, which is why it is not the first term itself.}

\problem{\textbf{$1 + 3 + 5 + \cdots + 19$.}

\textbf{Step 1.} This is a total, not a term, so pair the ends: every pair of
terms equally far from the two ends has the same sum, which turns the addition
into a multiplication.

\textbf{Step 2.} $1 + 19 = 20$, $3 + 17 = 20$, $5 + 15 = 20$, and so on. With 10
terms there are 5 such pairs, each worth 20.

\textbf{Step 3.} $5 \times 20 = 100$.
\ans{100}

\textit{General form:} $S_n = \dfrac{n(a_1+a_n)}{2} = \dfrac{10(1+19)}{2} = 100$
--- the same pairing written once and for all.}

\problem{\textbf{Which term of $5, 9, 13, \ldots$ is 45?}

\textbf{Step 1.} Here the term \emph{value} is known and the term \emph{number}
is not, so write the explicit formula as an equation and solve for $n$ rather
than listing terms.

\textbf{Step 2.} $5 + (n-1)(4) = 45$, so $4n + 1 = 45$, then $4n = 44$ and
$n = 11$.
\ans{11}

\textit{Sanity check:} $n$ must be a positive whole number. If it came out as
$10.5$, the value 45 would simply not be in the sequence.}

\problem{\textbf{12th term of a sequence starting at 20 and decreasing by 3.}

\textbf{Step 1.} ``Decreases by 3'' makes the common difference negative, so
record $d = -3$ before substituting --- the formula itself does not change.

\textbf{Step 2.} $a_{12} = 20 + (12-1)(-3) = 20 - 33 = -13$.
\ans{-13}

\textit{The common error:} using $d = +3$ gives 53, and a sequence that was
described as decreasing would have grown. Check the sign against the story.}

\problem{\textbf{Auditorium: 12 rows, 18 seats in row 1, 2 more per row.}

\textbf{Step 1.} Part (b) asks for a total across all rows, so this is a sum;
but the sum formula needs the last term, so find that first.

\textbf{Step 2.} Last row: $a_{12} = 18 + (12-1)(2) = 18 + 22 = 40$ seats.

\textbf{Step 3.} Total: $S_{12} = \dfrac{12(18+40)}{2} = 6 \times 58 = 348$.
\ans{348}

\textit{The trap:} $12 \times 18 = 216$ counts every row as the front row and
throws away the growth entirely.}

\problem{\textbf{$7, 11, 15, \ldots$ as $f(n) = 4n + 3$; find $f(25)$.}

\textbf{Step 1.} Identify the two constants from the sequence itself: the
terms rise by 4 each step, so the slope is 4, and the constant is chosen so that
$f(1)$ returns the first term.

\textbf{Step 2.} $f(1) = 4(1) + 3 = 7$, which confirms the form. Then
$f(25) = 4(25) + 3 = 100 + 3 = 103$.
\ans{103}

\textit{Where the numbers come from:} the 4 is the common difference (the
slope), and the 3 is $a_1 - d = 7 - 4$, the imaginary ``term zero''.}

\problem{\textbf{Priya's savings reach 500 dollars in which month?}

\textbf{Step 1.} The balance is arithmetic with $a_1 = 150$ and $d = 35$, and
the unknown is the month number, so solve the explicit formula for $n$.

\textbf{Step 2.} $150 + (n-1)(35) = 500$, so $35n + 115 = 500$, then
$35n = 385$ and $n = 11$.
\ans{11}

\textit{Check:} $n = 11$ is a whole number, so the balance hits 500 exactly at
the end of month 11. Had $n$ come out fractional, the answer would be the next
whole month, since deposits arrive in whole steps.}

\problem{\textbf{Sum of the first 20 terms of $3, 7, 11, \ldots$}

\textbf{Step 1.} The sum formula needs the last term, so compute $a_{20}$ before
summing anything.

\textbf{Step 2.} $a_{20} = 3 + (20-1)(4) = 3 + 76 = 79$.

\textbf{Step 3.} $S_{20} = \dfrac{20(3+79)}{2} = 10 \times 82 = 820$.
\ans{820}

\textit{The trap:} $20 \times 79 = 1580$ treats every term as if it were the
largest one. The correct factor is the \emph{average} of the first and last
terms, 41, not the last term itself.}

\problem{\textbf{4th term 14, 9th term 34 --- find $d$ and $a_1$.}

\textbf{Step 1.} Neither the first term nor the common difference is given, but
the gap between two known terms is made only of common differences, so count the
steps rather than guessing $a_1$.

\textbf{Step 2.} From term 4 to term 9 is $9 - 4 = 5$ steps, so
$14 + 5d = 34$, giving $5d = 20$ and $d = 4$.
\ans{4}

\textit{Part (c):} now $a_4 = a_1 + 3d$, so $14 = a_1 + 12$ and the first term is
$a_1 = 2$. The sequence is $2, 6, 10, 14, \ldots$, and indeed its 9th term is
$2 + 8(4) = 34$.}

\problem{\textbf{Theatre: 15 rows, 20 seats in row 1, 3 more per row.}

\textbf{Step 1.} Part (a) asks for a rule, not a number, so write the explicit
formula with the row number as the variable: seats in row $k$ is
$20 + (k-1)(3)$, which simplifies to $3k + 17$.

\textbf{Step 2.} Last row: $20 + (15-1)(3) = 20 + 42 = 62$ seats.

\textbf{Step 3.} Capacity: $S_{15} = \dfrac{15(20+62)}{2} = \dfrac{15 \times 82}{2}
= 615$.
\ans{615}

\textit{The trap:} $15 \times 62 = 930$ fills every row to the size of the back
row. The average row holds 41 seats, not 62.}

\problem{\textbf{Challenge: factory output, 120 units in week 1, $+15$ per week.}

\textbf{Step 1.} Part (a) asks for a single week's output and part (b) for a
running total, so separate the two tools before computing: explicit formula
first, sum formula second.

\textbf{Step 2.} Week 20: $a_{20} = 120 + (20-1)(15) = 120 + 285 = 405$ units.
\ans{405}

\textbf{Step 3.} Total over 20 weeks:
$S_{20} = \dfrac{20(120+405)}{2} = 10 \times 525 = 5250$ units.
\ans{5250}

\textit{Part (c):} multiplying the week-20 output by 20 gives 8100, which
assumes every week matched the best week. The correct idea is to multiply by the
\emph{average} weekly output, $\dfrac{120+405}{2}$, which is what the sum formula
does.}
