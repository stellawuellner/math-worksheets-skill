\problem{Polar $(6, 60^\circ)$ to rectangular.}

\textbf{(a)} $x = r\cos\theta = 6\cos 60^\circ = 6\left(\tfrac{1}{2}\right)$. \ans{x = 3}

\textbf{(b)} $y = r\sin\theta = 6\sin 60^\circ = 6\left(\tfrac{\sqrt{3}}{2}\right)$. \ans{y = 3\sqrt{3}}

\vspace{0.12cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.12cm}

\problem{Rectangular $(3, 3)$ to polar.}

\textbf{(a)} $r = \sqrt{3^2 + 3^2} = \sqrt{18}$, and $\sqrt{18} = \sqrt{9 \cdot 2}$. \ans{r = 3\sqrt{2}}

\textbf{(b)} $\tan\theta = \dfrac{3}{3} = 1$, and the point is in quadrant I (both coordinates positive), so the calculator's $\tan^{-1}(1)$ needs no correction. \ans{\theta = 45^\circ}

\vspace{0.12cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.12cm}

\problem{Polar $(8, 210^\circ)$ to rectangular.}

\textbf{(a)} $210^\circ$ is in quadrant III, where cosine is negative: $x = 8\cos 210^\circ = 8\left(-\tfrac{\sqrt{3}}{2}\right)$. \ans{x = -4\sqrt{3}}

\textbf{(b)} $y = 8\sin 210^\circ = 8\left(-\tfrac{1}{2}\right)$. Both coordinates are negative, which is exactly what quadrant III requires. \ans{y = -4}

\vspace{0.12cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.12cm}

\problem{Rectangular $(5, 12)$ to polar.}

\textbf{(a)} $r = \sqrt{5^2 + 12^2} = \sqrt{25 + 144} = \sqrt{169}$. \ans{r = 13}

\textbf{(b)} The point is in quadrant I, so no correction is needed:
$\theta = \tan^{-1}\!\left(\dfrac{12}{5}\right) = 67.3801\ldots^\circ$. \ans{\theta \approx 67.38^\circ}

\vspace{0.12cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.12cm}

\problem{Rectangular $(-2, 2\sqrt{3})$ to polar. (a) $r$. (b) $\theta$. (c) Why the calculator is wrong.}

\textbf{(a)} $r = \sqrt{(-2)^2 + (2\sqrt{3})^2} = \sqrt{4 + 12} = \sqrt{16}$. \ans{r = 4}

\textbf{(b)} $\tan\theta = \dfrac{2\sqrt{3}}{-2} = -\sqrt{3}$, and the calculator returns $-60^\circ$. The point has $x < 0$ and $y > 0$, so it lies in quadrant II; adding $180^\circ$ moves the angle there:
$\theta = -60^\circ + 180^\circ = 120^\circ$. \ans{\theta = 120^\circ}

\textbf{(c)} \emph{Instructor-judged.} A correct response says $\tan^{-1}$ only ever returns angles between $-90^\circ$ and $90^\circ$, so its output always lands in quadrant I or IV, while this point is in quadrant II. The repair --- add $180^\circ$ whenever $x < 0$ --- is justified by the period of tangent being $180^\circ$, so two exactly opposite directions share the same ratio $y/x$. Reporting the corrected angle without that reason is partial credit.

\vspace{0.12cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.12cm}

\problem{Polar $(-4, 45^\circ)$ to rectangular.}

\textbf{(a)} The formulas are unchanged by the sign of $r$:
$x = -4\cos 45^\circ = -4\left(\tfrac{\sqrt{2}}{2}\right)$. \ans{x = -2\sqrt{2}}

\textbf{(b)} $y = -4\sin 45^\circ = -4\left(\tfrac{\sqrt{2}}{2}\right)$. \ans{y = -2\sqrt{2}}

\smallskip
\noindent A negative $r$ means: face $45^\circ$, then walk \emph{backwards} $4$ units --- which lands the point in quadrant III, where both coordinates are indeed negative.

\vspace{0.12cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.12cm}

\problem{Polar $\left(5, \tfrac{2\pi}{3}\right)$ renamed as $(-5, \theta')$.}

\textbf{(a)} Flipping the sign of $r$ reverses the direction, so the angle turns by a straight angle:
$\theta' = \dfrac{2\pi}{3} + \pi = \dfrac{2\pi}{3} + \dfrac{3\pi}{3}$. \ans{\theta' = \tfrac{5\pi}{3}}

\textbf{(b)} Check with the $x$ formula: $x = -5\cos\dfrac{5\pi}{3} = -5\left(\tfrac{1}{2}\right)$, and the original name gives $5\cos\dfrac{2\pi}{3} = 5\left(-\tfrac{1}{2}\right)$ --- the same value. \ans{x = -\tfrac{5}{2}}

\vspace{0.12cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.12cm}

\problem{Rectangular $(-6, -6)$ to polar.}

\textbf{(a)} $r = \sqrt{36 + 36} = \sqrt{72} = \sqrt{36 \cdot 2}$. \ans{r = 6\sqrt{2}}

\textbf{(b)} $\tan\theta = \dfrac{-6}{-6} = 1$, and $\tan^{-1}(1) = 45^\circ$ --- but both coordinates are negative, so the point is in quadrant III, not quadrant I. Since $x < 0$, add $180^\circ$: $\theta = 45^\circ + 180^\circ = 225^\circ$. \ans{\theta = 225^\circ}

\vspace{0.12cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.12cm}

\problem{Rectangular $(0, -7)$ to polar. (a) $r$. (b) Check $\theta = 270^\circ$. (c) Why $\tan^{-1}$ fails.}

\textbf{(a)} $r = \sqrt{0^2 + (-7)^2} = \sqrt{49}$. \ans{r = 7}

\textbf{(b)} $7\sin 270^\circ = 7(-1) = -7$, which is the given $y$; and $7\cos 270^\circ = 0$, the given $x$. So $270^\circ$ is confirmed. \ans{-7}

\textbf{(c)} \emph{Instructor-judged.} A correct response says the formula requires the ratio $y/x$, and $x = 0$ here, so the ratio is undefined and the formula cannot be applied at all. The angle is read from the picture instead: the point lies on the negative half of the vertical axis, a straight angle plus a right angle round from the positive horizontal axis, so $\theta = 270^\circ$. Saying only that the calculator errors is not full credit.

\vspace{0.12cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.12cm}

\problem{Radar: aircraft at $(-9, 12)$ km. (a) $r$. (b) $\theta$. (c) $\theta''$ for the $(-15, \theta'')$ name. (d) Explain.}

\textbf{(a)} $r = \sqrt{(-9)^2 + 12^2} = \sqrt{81 + 144} = \sqrt{225}$. \ans{r = 15\text{ km}}

\textbf{(b)} $\tan^{-1}\!\left(\dfrac{12}{-9}\right) = -53.1301\ldots^\circ$, and $x < 0$ puts the aircraft in quadrant II, so add $180^\circ$:
$\theta = 180^\circ - 53.1301\ldots^\circ = 126.8699\ldots^\circ$. \ans{\theta \approx 126.87^\circ}

\textbf{(c)} Reversing the sign of the distance turns the direction through a straight angle:
$\theta'' = 126.8699\ldots^\circ + 180^\circ = 306.8699\ldots^\circ$, which lies in $[0^\circ, 360^\circ)$. \ans{\theta'' \approx 306.87^\circ}

\textbf{(d)} \emph{Instructor-judged.} A correct response explains that a negative first coordinate means facing the stated direction and stepping \emph{backwards}, which puts you in exactly the same place as facing the opposite direction and stepping forwards. Adding $180^\circ$ to the angle and flipping the sign of the distance therefore leaves the point unmoved, so both entries log the same aircraft. Noticing only that the two angles differ by $180^\circ$, without the reversal argument, is partial credit.
