\begin{center}
\small Tables, rules, graphs, solving for the input, and domains that fit the situation
\end{center}
\vspace{0.15cm}

\noindent\textbf{Directions}
\begin{itemize}[leftmargin=0.8cm, itemsep=1pt, topsep=2pt]
  \item A function can be given by a rule, a table, a graph, or a situation. These problems move between all four, so read carefully what each one gives you and what it asks for.
  \item Filling a table means substituting an \emph{input}; solving means you were handed an \emph{output} and must find the input that produced it.
  \item Grids are for you to plot on. Label the axes with the quantities they carry.
  \item When a function models a real situation, ask which inputs actually describe something that could happen.
\end{itemize}
