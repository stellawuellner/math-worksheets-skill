% ---------------------------------------------------------------- Problem 1
\problem{Each book symbol stands for 5 books. Ana's row shows 3 symbols. How
many books did Ana read?}

\textbf{Solution:} Each symbol counts 5 books, so multiply the symbols by the
scale: $3 \times 5 = 15$. Ana read \ans{15} books.

% ---------------------------------------------------------------- Problem 2
\problem{Ben's row shows 4 symbols and Cara's row shows 2 symbols. How many
books did they read together?}

\textbf{Solution:} Together they show $4 + 2 = 6$ symbols, and each symbol is
5 books: $6 \times 5 = 30$. Ben and Cara read \ans{30} books together.

% ---------------------------------------------------------------- Problem 3
\problem{Dev read 25 books. (a) How many symbols show 25 books? (b) Draw Dev's
row.}

\textbf{Solution (a):} Each symbol is 5 books, so divide: $25 \div 5 = 5$.
Dev's row needs \ans{5} symbols.

\textbf{Model answer (b), instructor judges:} The drawn row must show exactly
5 book symbols --- the same number found in part (a). Any clear book-symbol
drawing counts.

% ---------------------------------------------------------------- Problem 4
\problem{Use Graph B (the number line counts by twos). How many dogs are
there?}

\textbf{Solution:} The dogs bar reaches the gridline labeled 12 --- six steps
of 2 above zero. There are \ans{12} dogs.

% ---------------------------------------------------------------- Problem 5
\problem{How many pets does the whole graph show in all?}

\textbf{Solution:} Read each bar against the scale, then add every group:
$8 + 12 + 6 + 4 = 30$. The graph shows \ans{30} pets in all.

% ---------------------------------------------------------------- Problem 6
\problem{How many more dogs are there than birds?}

\textbf{Solution:} ``How many more'' compares the two bars, so subtract:
$12 - 4 = 8$. There are \ans{8} more dogs than birds.

% ---------------------------------------------------------------- Problem 7
\problem{Which pet group is the smallest?}

\textbf{Solution:} The shortest bar is the smallest group. The bars read
8, 12, 6, and 4, and the shortest is the birds bar at 4. The smallest group is
\ans{\text{birds}}

% ---------------------------------------------------------------- Problem 8
\problem{(a) Write the four pet counts in order from least to greatest.
(b) Which display makes comparing easier --- picture graph or bar graph? Say
why.}

\textbf{Solution (a):} The four counts are 8, 12, 6, and 4. From least to
greatest: \ans{4,\ 6,\ 8,\ 12}

\textbf{Model answer (b), instructor judges:} Either display can earn credit
with a fitting reason --- for example: the bar graph, because taller and
shorter bars can be compared at a glance without counting; or the picture
graph, because the symbols can be counted one by one. The answer must name a
display and give a why.
