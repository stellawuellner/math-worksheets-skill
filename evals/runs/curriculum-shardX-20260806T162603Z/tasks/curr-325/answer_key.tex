\problem{Legs $9$ cm and $12$ cm; find the hypotenuse, in centimetres.}

\noindent\textbf{Solution.} Two sides and no angle, so the Pythagorean theorem
applies:
\[ c = \sqrt{9^2 + 12^2} = \sqrt{81 + 144} = \sqrt{225} . \]
Therefore \ans{c = 15 \text{ cm}}

\vspace{0.15cm}\noindent\rule{\linewidth}{0.2pt}

\problem{Hypotenuse $26$ in, one leg $10$ in; find the other leg, in inches.}

\noindent\textbf{Solution.} The unknown is a leg, so the known hypotenuse is
subtracted from, not added to:
\[ b = \sqrt{26^2 - 10^2} = \sqrt{676 - 100} = \sqrt{576} . \]
Therefore \ans{b = 24 \text{ in}}

\vspace{0.15cm}\noindent\rule{\linewidth}{0.2pt}

\problem{Isosceles right triangle with both legs $7$ cm; find the hypotenuse, in
centimetres.}

\noindent\textbf{Solution.} Equal legs means a $45$--$45$--$90$ triangle, whose
hypotenuse is a leg times $\sqrt{2}$ (Pythagoras gives the same:
$\sqrt{7^2+7^2} = 7\sqrt{2}$):
\[ c = 7\sqrt{2} = 9.8994\ldots \]
Therefore \ans{c = 9.90 \text{ cm}}

\vspace{0.15cm}\noindent\rule{\linewidth}{0.2pt}

\problem{Hypotenuse $18$ m, acute angle $37^\circ$; find the opposite side, in
metres.}

\noindent\textbf{Solution.} An angle that is not $30^\circ$, $45^\circ$ or
$60^\circ$ means trigonometry. Opposite with hypotenuse is sine:
\[ \text{opp} = 18 \sin 37^\circ = 10.8326\ldots \]
Therefore \ans{10.83 \text{ m}}

\vspace{0.15cm}\noindent\rule{\linewidth}{0.2pt}

\problem{Legs $8$ and $15$; find the acute angle opposite the leg of length $8$,
in degrees.}

\noindent\textbf{Solution.} Two legs and an unknown angle: the pairing is
opposite with adjacent, so use the inverse tangent.
\[ A = \tan^{-1}\!\left(\frac{8}{15}\right) = 28.0724\ldots^\circ \]
Therefore \ans{28.07^\circ}

\vspace{0.15cm}\noindent\rule{\linewidth}{0.2pt}

\problem{One acute angle $30^\circ$ with the opposite leg $11$ ft; find the
other leg, in feet.}

\noindent\textbf{Solution.} This is a $30$--$60$--$90$ triangle: the leg opposite
$30^\circ$ is the short one, and the other leg is $\sqrt{3}$ times it. Using the
tangent gives the same number, with the unknown underneath:
\[ b = \frac{11}{\tan 30^\circ} = 11\sqrt{3} = 19.0525\ldots \]
Therefore \ans{b = 19.05 \text{ ft}}

\vspace{0.15cm}\noindent\rule{\linewidth}{0.2pt}

\problem{A $17$ ft ladder with its foot $8$ ft from a wall; how far up the wall
does it reach, in feet?}

\noindent\textbf{Solution.} The ladder is the hypotenuse and the ground distance
is a leg; no angle is given, so Pythagoras:
\[ a = \sqrt{17^2 - 8^2} = \sqrt{289 - 64} = \sqrt{225} . \]
Therefore \ans{15 \text{ ft}}

\vspace{0.15cm}\noindent\rule{\linewidth}{0.2pt}

\problem{A path of $32$ m to the foot of a tower, with the top seen at
$54^\circ$; find the tower's height, in metres.}

\noindent\textbf{Solution.} The $32$ m path is adjacent to the $54^\circ$ angle
and the height is opposite it, so tangent:
\[ a = 32 \tan 54^\circ = 44.0442\ldots \]
Therefore \ans{44.04 \text{ m}}

\vspace{0.15cm}\noindent\rule{\linewidth}{0.2pt}

\problem{A $40$ ft cable reaching $22$ ft up a mast; find the angle the cable
makes with the ground, in degrees.}

\noindent\textbf{Solution.} The $22$ ft height is opposite the angle and the
$40$ ft cable is the hypotenuse, so the pairing is sine and the angle is the
inverse sine:
\[ A = \sin^{-1}\!\left(\frac{22}{40}\right) = 33.3670\ldots^\circ \]
Therefore \ans{33.37^\circ}

\vspace{0.15cm}\noindent\rule{\linewidth}{0.2pt}

\problem{A square tile cut along a $24$ cm diagonal. (a) Find the length of each
leg of one resulting right triangle, in centimetres. (b) Explain how the special
right-triangle relationship gives the same answer and why it is quicker.}

\noindent\textbf{Solution (a).} The diagonal of a square makes two
$45$--$45$--$90$ triangles with the diagonal as hypotenuse, so each leg is
opposite a $45^\circ$ angle:
\[ \text{leg} = 24 \sin 45^\circ = 16.9705\ldots \]
Therefore \ans{16.97 \text{ cm}}

\noindent\textbf{Solution (b) --- instructor-judged.} A complete response names
the triangle as $45$--$45$--$90$, states that the hypotenuse is a leg times
$\sqrt{2}$, and rearranges to $\text{leg} = 24/\sqrt{2} = 12\sqrt{2}$, the same
$16.97$ cm. It should add that the special-triangle route is exact and needs no
calculator, while the sine route reaches the same value only after evaluating a
trigonometric function. Award full credit only when both the alternative method
and a reason for preferring it appear.
