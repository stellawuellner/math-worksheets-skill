\problem{$f(x) = x^{3} - 4x^{2} + x + 6$. (a) List the possible rational zeros.
(b) Find $f(-1)$.}

\textbf{Part (a) --- instructor-judged.} Numerators divide the constant term
$6$: $1, 2, 3, 6$. Denominators divide the leading coefficient $1$, so only $1$.
The complete list is $\pm 1, \pm 2, \pm 3, \pm 6$ --- eight values. The usual
omission is the negatives; deduct for a list that drops them, and for any value
that does not divide $6$.

\textbf{Solution (b):} $(-1)^{3} - 4(-1)^{2} + (-1) + 6 = -1 - 4 - 1 + 6$.
Since the value is $0$, $-1$ is a zero and $x + 1$ is a factor. \ans{f(-1) = 0}

\vspace{0.15cm}
\noindent\rule{\linewidth}{0.2pt}

\problem{$g(x) = 2x^{3} - 3x^{2} - 8x - 3$. Find $g(3)$.}

\textbf{Solution:} $2(27) - 3(9) - 8(3) - 3 = 54 - 27 - 24 - 3$. The value is
$0$, so $3$ is a zero of $g$. \ans{g(3) = 0}

\vspace{0.15cm}
\noindent\rule{\linewidth}{0.2pt}

\problem{Find all zeros of $f(x) = x^{3} - 4x^{2} + x + 6$.}

\textbf{Solution:} Problem 1 established that $-1$ is a zero. Dividing by
$x + 1$ (synthetic division with $-1$ on $1, -4, 1, 6$) gives the quotient
$x^{2} - 5x + 6$, which factors as $(x - 2)(x - 3)$. A cubic has three zeros and
all three are here. \ans{x = -1,\ 2,\ 3}

\vspace{0.15cm}
\noindent\rule{\linewidth}{0.2pt}

\problem{Find all zeros of $f(x) = x^{3} + 2x^{2} - 5x - 6$.}

\textbf{Solution:} Candidates are $\pm 1, \pm 2, \pm 3, \pm 6$. Testing
$x = -1$: $-1 + 2 + 5 - 6 = 0$. Dividing by $x + 1$ leaves $x^{2} + x - 6$,
which factors as $(x + 3)(x - 2)$. \ans{x = -1,\ -3,\ 2}

\vspace{0.15cm}
\noindent\rule{\linewidth}{0.2pt}

\problem{$h(x) = 3x^{3} + x^{2} - 8x + 4$. (a) List the possible rational zeros.
(b) Find $h(-2)$.}

\textbf{Part (a) --- instructor-judged.} Numerators divide $4$: $1, 2, 4$.
Denominators divide $3$: $1, 3$. The complete list is
$\pm 1, \pm 2, \pm 4, \pm \tfrac{1}{3}, \pm \tfrac{2}{3}, \pm \tfrac{4}{3}$.
Full credit needs the fractional candidates as well; dropping them is the error
this problem exists to expose, and it is why problem 6 has a zero of
$\tfrac{2}{3}$.

\textbf{Solution (b):} $3(-8) + 4 + 16 + 4 = -24 + 24$. The value is $0$, so
$-2$ is a zero. \ans{h(-2) = 0}

\vspace{0.15cm}
\noindent\rule{\linewidth}{0.2pt}

\problem{Factor completely: $3x^{3} + x^{2} - 8x + 4$.}

\textbf{Solution:} From problem 5, $-2$ is a zero, so $x + 2$ is a factor.
Synthetic division with $-2$ on $3, 1, -8, 4$ gives $3, -5, 2$ and remainder
$0$, so the quotient is $3x^{2} - 5x + 2$. That factors as $(3x - 2)(x - 1)$.
\ans{(x+2)(3x-2)(x-1)}

\vspace{0.15cm}
\noindent\rule{\linewidth}{0.2pt}

\problem{Find all zeros of $f(x) = 2x^{3} - 5x^{2} - 4x + 3$.}

\textbf{Solution:} Candidates are
$\pm 1, \pm 3, \pm \tfrac{1}{2}, \pm \tfrac{3}{2}$. Testing $x = 3$:
$54 - 45 - 12 + 3 = 0$. Dividing by $x - 3$ leaves $2x^{2} + x - 1$, which
factors as $(2x - 1)(x + 1)$, giving a fractional zero and a whole one.
\ans{x = 3,\ \tfrac{1}{2},\ -1}

\vspace{0.15cm}
\noindent\rule{\linewidth}{0.2pt}

\problem{$q(x) = x^{3} - 6x^{2} + 11x - 6$. Find $q(2)$ and $q(4)$, then say
which is a zero.}

\textbf{Solution:} $q(2) = 8 - 24 + 22 - 6$. \ans{q(2) = 0}

\noindent And $q(4) = 64 - 96 + 44 - 6$. \ans{q(4) = 6}

\textbf{Written part --- instructor-judged.} The answer must name $2$ as the
zero and give the reason: substituting $2$ made the polynomial equal $0$, while
$4$ gave a non-zero value, and a number is a zero exactly when the polynomial
evaluates to $0$ there. Naming $2$ with no reference to the computed values does
not earn the mark.

\vspace{0.15cm}
\noindent\rule{\linewidth}{0.2pt}

\problem{Find all zeros of $p(x) = x^{4} - 2x^{3} - 7x^{2} + 8x + 12$.}

\textbf{Solution:} Candidates are $\pm 1, \pm 2, \pm 3, \pm 4, \pm 6, \pm 12$.
Testing $x = -1$ gives $1 + 2 - 7 - 8 + 12 = 0$, so divide by $x + 1$; the
quotient is $x^{3} - 3x^{2} - 4x + 12$, which groups as
$x^{2}(x - 3) - 4(x - 3) = (x - 3)(x - 2)(x + 2)$. A quartic has four zeros.
\ans{x = -1,\ 2,\ 3,\ -2}

\vspace{0.15cm}
\noindent\rule{\linewidth}{0.2pt}

\problem{Factor completely: $6x^{3} + 5x^{2} - 3x - 2$.}

\textbf{Solution:} Numerators divide $2$ and denominators divide $6$, so the
candidate list is long --- start with the whole numbers. Testing $x = -1$:
$-6 + 5 + 3 - 2 = 0$, so $x + 1$ is a factor. Synthetic division with $-1$ on
$6, 5, -3, -2$ gives $6, -1, -2$, so the quotient is $6x^{2} - x - 2$, which
factors as $(3x - 2)(2x + 1)$. \ans{(x+1)(3x-2)(2x+1)}

\vspace{0.15cm}
\noindent\rule{\linewidth}{0.2pt}

\problem{Find all zeros of $f(x) = x^{3} - x^{2} - 8x + 6$.}

\textbf{Solution:} Candidates are $\pm 1, \pm 2, \pm 3, \pm 6$. Only $x = 3$
works: $27 - 9 - 24 + 6 = 0$. Dividing by $x - 3$ leaves $x^{2} + 2x - 2$, which
has no rational roots, so finish with the quadratic formula:
$x = \dfrac{-2 \pm \sqrt{4 + 8}}{2} = -1 \pm \sqrt{3}$. The other two zeros are
irrational, which is exactly why no candidate on the list found them.
\ans{x = 3,\ -1 + \sqrt{3},\ -1 - \sqrt{3}}

\vspace{0.15cm}
\noindent\rule{\linewidth}{0.2pt}

\problem{$f(x) = x^{3} - 5x^{2} + 9x - 5$. (a) The rational zero. (b) The
remaining zeros. (c) Why the theorem could not find them.}

\textbf{Solution (a):} Candidates are $\pm 1, \pm 5$. Testing $x = 1$:
$1 - 5 + 9 - 5 = 0$. \ans{x = 1}

\textbf{Solution (b):} Dividing by $x - 1$ leaves $x^{2} - 4x + 5$, whose
discriminant is $16 - 20 = -4$, so the remaining zeros are non-real:
$x = \dfrac{4 \pm 2i}{2}$. \ans{x = 2 \pm i}

\textbf{Part (c) --- instructor-judged.} A full-credit explanation says the
theorem only ever proposes \emph{rational} numbers, so a zero that is not
rational --- and these two are not even real --- can never appear on its
candidate list. It should add that the theorem is a first step that lowers the
degree, after which the leftover quadratic is handled by the quadratic formula.
Restating the two zeros with no comment on why the theorem missed them earns
nothing.
