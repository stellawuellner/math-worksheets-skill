\problem{Graph of $y = 3\sin x + 2$: maximum $5$, minimum $-1$. (a) Amplitude. (b) Midline value.}

\textbf{(a)} Amplitude is half the vertical spread between the extremes:
$\dfrac{5 - (-1)}{2} = \dfrac{6}{2} = 3$. \ans{A = 3}

\textbf{(b)} The midline sits halfway between them: $\dfrac{5 + (-1)}{2} = \dfrac{4}{2} = 2$, so the midline is $y = 2$. \ans{D = 2}

\problem{Graph of $y = -2\cos x + 1$: maximum $3$, minimum $-1$. (a) Amplitude. (b) Midline value.}

\textbf{(a)} $\dfrac{3 - (-1)}{2} = 2$. Amplitude is a distance, so it is positive even though this curve opens downward first. \ans{A = 2}

\textbf{(b)} $\dfrac{3 + (-1)}{2} = 1$, so the midline is $y = 1$. \ans{D = 1}

\vspace{0.1cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.1cm}

\problem{One cycle of $y = A\cos(Bx)$ runs from $x = 0$ to $x = 4\pi$. Find $B$.}

\textbf{Solution:} the graph completes one cycle over $4\pi$, so the period is $4\pi$. For a sinusoid the period is $\dfrac{2\pi}{B}$, so
\[ B = \frac{2\pi}{\text{period}} = \frac{2\pi}{4\pi} = \frac{1}{2}. \]
A period longer than $2\pi$ always gives $B$ between $0$ and $1$, which is a useful check. \ans{B = \tfrac{1}{2}}

\vspace{0.1cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.1cm}

\problem{Graph of $y = 5\sin x - 3$: maximum $2$, minimum $-8$. (a) Amplitude. (b) Midline value.}

\textbf{(a)} $\dfrac{2 - (-8)}{2} = \dfrac{10}{2} = 5$. \ans{A = 5}

\textbf{(b)} $\dfrac{2 + (-8)}{2} = \dfrac{-6}{2} = -3$, so the midline is $y = -3$ --- below the $x$-axis, which is exactly why amplitude cannot be read as the maximum. \ans{D = -3}

\vspace{0.1cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.1cm}

\problem{Graph of $y = \sin(Bx)$: one cycle runs from $x = 0$ to $x = \dfrac{2\pi}{3}$. Find $B$.}

\textbf{Solution:} the curve returns to the start of its pattern at $x = \dfrac{2\pi}{3}$, so that is the period:
\[ B = \frac{2\pi}{2\pi/3} = 2\pi \cdot \frac{3}{2\pi} = 3. \]
Three complete cycles fit in $2\pi$, which matches the picture. \ans{B = 3}

\vspace{0.1cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.1cm}

\problem{Graph modelled by $y = A\cos(Bx) + D$: maximum $9$, minimum $1$, period $\pi$. (a) $A$. (b) $D$. (c) $B$.}

\textbf{(a)} $A = \dfrac{9 - 1}{2} = 4$. \ans{A = 4}

\textbf{(b)} $D = \dfrac{9 + 1}{2} = 5$. \ans{D = 5}

\textbf{(c)} The maximum recurs every $\pi$ units, so the period is $\pi$ and $B = \dfrac{2\pi}{\pi} = 2$. The model is $y = 4\cos(2x) + 5$; because the graph peaks at $x = 0$, cosine needs no shift. \ans{B = 2}

\problem{$d(t) = 2\sin\!\left(\dfrac{\pi t}{6}\right) + 7$ metres. Find all $t$ in $0 \le t < 12$ with $d = 8$.}

\textbf{Solution:} isolate the sine, then use the two angles in $[0, 2\pi)$ with that sine.
\begin{align*}
  2\sin\!\left(\frac{\pi t}{6}\right) + 7 &= 8 \\
  \sin\!\left(\frac{\pi t}{6}\right) &= \frac{1}{2} \\
  \frac{\pi t}{6} = \frac{\pi}{6} \quad&\text{or}\quad \frac{\pi t}{6} = \frac{5\pi}{6}
\end{align*}
Multiplying by $\dfrac{6}{\pi}$ gives $t = 1$ and $t = 5$. As $t$ runs over $[0, 12)$ the angle $\dfrac{\pi t}{6}$ runs over $[0, 2\pi)$ exactly once, so there are no further solutions. \ans{t = 1,\ 5\text{ hours}}

\vspace{0.1cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.1cm}

\problem{Two complete cycles fill $16$ seconds on the sensor graph. For $y = A\sin(Bt)$, find $B$.}

\textbf{Solution:} two cycles in $16$ seconds means one cycle in $8$ seconds, so the period is $8$:
\[ B = \frac{2\pi}{8} = \frac{\pi}{4}. \]
\ans{B = \tfrac{\pi}{4}}

\vspace{0.1cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.1cm}

\problem{Wheel of diameter $40$ m, centre $22$ m up, one turn every $8$ minutes, $h(t) = A\sin(Bt) + 22$. (a) $A$. (b) $B$. (c) Sketch two revolutions.}

\textbf{(a)} The rider moves from the centre out to the rim, so the amplitude is the radius --- half the diameter: $\dfrac{40}{2} = 20$. \ans{A = 20\text{ m}}

\textbf{(b)} One revolution is one period, so the period is $8$ minutes and $B = \dfrac{2\pi}{8} = \dfrac{\pi}{4}$. The model is $h(t) = 20\sin\!\left(\dfrac{\pi t}{4}\right) + 22$. \ans{B = \tfrac{\pi}{4}}

\textbf{(c)} \emph{Instructor-judged.} The sketch must show two complete revolutions across the $16$ minute grid, starting at the centre height $22$ and rising first. Check for: a horizontal midline at $22$; peaks at $42$ and troughs at $2$; the first peak at $t = 2$ and the first trough at $t = 6$; a smooth curve, not straight segments. Labels on the midline, the maximum and the minimum are required for full credit.

\problem{$T(t) = 8\sin\!\left(\dfrac{\pi t}{12}\right) + 20$ degrees. Find all $t$ in $0 \le t < 24$ with $T = 24$.}

\textbf{Solution:}
\begin{align*}
  8\sin\!\left(\frac{\pi t}{12}\right) + 20 &= 24 \\
  \sin\!\left(\frac{\pi t}{12}\right) &= \frac{1}{2} \\
  \frac{\pi t}{12} = \frac{\pi}{6} \quad&\text{or}\quad \frac{\pi t}{12} = \frac{5\pi}{6}
\end{align*}
Multiplying by $\dfrac{12}{\pi}$: $t = 2$ and $t = 10$. Over $[0, 24)$ the angle covers $[0, 2\pi)$ once, so the list is complete --- and the graph confirms the curve crosses $T = 24$ twice, once rising and once falling. \ans{t = 2,\ 10\text{ hours}}

\vspace{0.1cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.1cm}

\problem{Graph with maximum $4.5$ and minimum $-1.5$. (a) Amplitude. (b) Midline value. (c) Explain why the amplitude is not the maximum.}

\textbf{(a)} $\dfrac{4.5 - (-1.5)}{2} = \dfrac{6}{2} = 3$. \ans{A = 3}

\textbf{(b)} $\dfrac{4.5 + (-1.5)}{2} = \dfrac{3}{2} = 1.5$, so the midline is $y = 1.5$. \ans{D = 1.5}

\textbf{(c)} \emph{Instructor-judged.} A correct response says the maximum is measured from the horizontal axis while the amplitude is measured from the \emph{midline}, and the two agree only when the midline happens to lie on the axis. Here the midline is $y = 1.5$, so the amplitude is $4.5 - 1.5 = 3$, not $4.5$. Repeating the arithmetic without naming the midline as the reference level is partial credit.

\problem{Wheel graph: maximum $46$ m, minimum $2$ m, first maximum at $t = 4$ min, period $8$ min, $h(t) = A\cos\bigl(B(t-4)\bigr) + D$. (a) $A$. (b) $D$. (c) $B$. (d) Times at height $35$ m.}

\textbf{(a)} $A = \dfrac{46 - 2}{2} = 22$. \ans{A = 22\text{ m}}

\textbf{(b)} $D = \dfrac{46 + 2}{2} = 24$. \ans{D = 24\text{ m}}

\textbf{(c)} One revolution is the period, $8$ minutes, so $B = \dfrac{2\pi}{8} = \dfrac{\pi}{4}$. The model is $h(t) = 22\cos\!\left(\dfrac{\pi}{4}(t - 4)\right) + 24$; the shift of $4$ puts cosine's peak where the graph peaks. \ans{B = \tfrac{\pi}{4}}

\textbf{(d)} Set $h = 35$ and isolate the cosine:
\begin{align*}
  22\cos\!\left(\frac{\pi(t-4)}{4}\right) + 24 &= 35 \\
  \cos\!\left(\frac{\pi(t-4)}{4}\right) &= \frac{11}{22} = \frac{1}{2} \\
  \frac{\pi(t-4)}{4} = \frac{\pi}{3} \quad&\text{or}\quad \frac{\pi(t-4)}{4} = -\frac{\pi}{3}
\end{align*}
Multiplying by $\dfrac{4}{\pi}$ gives $t - 4 = \pm\dfrac{4}{3}$, so $t = 4 - \dfrac{4}{3} = \dfrac{8}{3}$ and $t = 4 + \dfrac{4}{3} = \dfrac{16}{3}$. Both lie in $[0, 8)$, and the symmetry about the peak at $t = 4$ is the check. \ans{t = \tfrac{8}{3},\ \tfrac{16}{3}\text{ minutes}}
