# Solving Exponential Equations with Common Bases — three PDFs

Here is a 10-problem precalculus set on solving exponential equations by
matching bases, plus a full answer key and a two-page study guide.

**What you get**

| File | What it is |
|---|---|
| `ss_expcommonbase_curr411.pdf` | Study guide (2 pages) — read this first |
| `ws_expcommonbase_curr411.pdf` | Student worksheet, 10 problems (5 pages) |
| `ak_expcommonbase_curr411.pdf` | Step-by-step answer key (3 pages) |

**The worksheet** rotates through three methods so your student has to *choose*
one rather than repeat one:

1. **Equations that already share a base** (#1, #4, #8) — set the exponents
   equal. #8 makes that exponent equation quadratic, so it has two answers.
2. **Rewriting both sides to a common base** (#2, #5, #7, #10) — `8^x = 32`
   becomes `2^{3x} = 2^5`. #10 uses a reciprocal base, which is the step most
   students drop the sign on.
3. **Reading an exponential model from a table** (#3, #6, #9) — a table with a
   constant ratio, extended one step and then used to solve an equation. Each of
   these has an (a) and a (b) part, so there are 13 answers on 10 problems.

Difficulty ramps from 1 to 5 across the sheet; nothing on it needs logarithms.

**The study guide** has three sections matching those three methods. Each one
gives the rule, a worked example whose first line says *why* that method is the
right one, and a try-it problem with the answer printed upside down inside the
box so your student attempts it before checking.

**How much of this is machine-checked**

All 13 answers — every one of the 10 problems, including both parts of the three
table problems — were recomputed independently with SymPy and matched the key
before the PDFs were built. The same is true of all six study-guide items (three
worked examples, three try-its). **Nothing on this sheet is flagged for
instructor judgement**: every question asks for a value, so every answer carries
a machine guarantee. The answer key's "What is verified" note says the same
thing, because it is generated from the same verification data.

The key also prints a Quick Answers bank at the top for fast grading, and a
Curriculum section listing the standards (HSF-LE.A.4 for the solving work,
HSF-IF.A for the table interpretation) and the difficulty range.
