\problem{$f(x) = \dfrac{|x-3|}{x-3}$. Find (a) $\lim_{x \to 3^-} f(x)$ and
(b) $\lim_{x \to 3^+} f(x)$.}

\textbf{Solution:} Split the absolute value by cases. For $x < 3$ we have
$x - 3 < 0$, so $|x-3| = -(x-3)$ and $f(x) = \frac{-(x-3)}{x-3} = -1$ on that
whole side. The function is the constant $-1$ there, so the left-hand limit is
\ans{-1}

For $x > 3$ we have $x - 3 > 0$, so $|x-3| = x-3$ and $f(x) = 1$ on that whole
side, giving \ans{1}

Because the two one-sided values differ, $\lim_{x\to3} f(x)$ does not exist ---
this is the standard jump at a sign change.

\problem{$g(x) = \dfrac{x-4}{\sqrt{x-4}}$, defined only for $x > 4$. Find
$\lim_{x \to 4^+} g(x)$.}

\textbf{Solution:} Write $x - 4 = \left(\sqrt{x-4}\right)^2$, so for $x > 4$
\[
  g(x) = \frac{\left(\sqrt{x-4}\right)^2}{\sqrt{x-4}} = \sqrt{x-4}.
\]
As $x \to 4^+$ the quantity $x - 4 \to 0^+$ and its square root does too, so the
limit is \ans{0}

Only the right-hand limit is asked because $g$ has no left side: $\sqrt{x-4}$ is
undefined for $x < 4$.

\problem{Evaluate $\displaystyle\lim_{x \to \infty} \frac{3x^2 - 5x + 2}{4x^2+7}$.}

\textbf{Solution:} Divide every term by the highest power in the denominator,
$x^2$:
\[
  \frac{3x^2 - 5x + 2}{4x^2 + 7}
  = \frac{3 - \dfrac{5}{x} + \dfrac{2}{x^2}}{4 + \dfrac{7}{x^2}} .
\]
Each $\frac{c}{x^n} \to 0$ as $x \to \infty$, leaving $\frac{3}{4}$. \ans{\tfrac{3}{4}}

Equivalently: equal degrees, so the limit is the ratio of the leading
coefficients. The constants $2$ and $7$ never enter it.

\problem{$h(x) = \dfrac{x+3}{x-5}$. Find (a) $\lim_{x \to 5^-} h(x)$ and
(b) $\lim_{x \to 5^+} h(x)$.}

\textbf{Solution:} At $x = 5$ the numerator is $8 \neq 0$ and the denominator is
$0$, so $x = 5$ is a vertical asymptote and the answer is decided entirely by the
sign of $x - 5$.

For $x$ slightly below $5$: numerator near $+8$, denominator a small
\emph{negative}, so the quotient is a large negative number. \ans{-\infty}

For $x$ slightly above $5$: numerator near $+8$, denominator a small
\emph{positive}, so the quotient is a large positive number. \ans{+\infty}

\problem{Piecewise shipping cost $f(x) = 3x-1$ for $x<2$ and $f(x) = x^2+4$ for
$x \ge 2$. Find (a) the left-hand limit at $2$, (b) the right-hand limit at $2$,
(c) whether $\lim_{x\to2} f(x)$ exists.}

\textbf{Solution (a):} Approaching $2$ from below uses only the rule for
$x < 2$, so evaluate the limit of $3x - 1$ at $2$: $\ 3(2) - 1$. \ans{5}

\textbf{Solution (b):} Approaching $2$ from above uses only the rule for
$x \ge 2$, so evaluate the limit of $x^2 + 4$ at $2$: $\ 2^2 + 4$. \ans{8}

\textbf{Solution (c) --- instructor-judged, no machine check.} The correct
conclusion is that $\lim_{x\to2} f(x)$ \textbf{does not exist}, and the required
reason is that the two one-sided limits disagree ($5$ from the left, $8$ from the
right), so there is no single number the outputs approach from both sides ---
the cost jumps by \$3 at a weight of 2\,kg. Award no credit for a bare ``DNE''
with no reason. Do not accept ``the limit is 8 because $f(2) = 8$'': the value
of the function at the point is not what a limit asks about.

\vspace{0.2cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.2cm}

\problem{Evaluate $\displaystyle\lim_{x \to -\infty} \frac{2x^3 + x}{5 - x^3}$.}

\textbf{Solution:} Divide through by $x^3$:
\[
  \frac{2x^3 + x}{5 - x^3} = \frac{2 + \dfrac{1}{x^2}}{\dfrac{5}{x^3} - 1}
  \longrightarrow \frac{2 + 0}{0 - 1}.
\]
The direction of approach does not matter here --- every discarded term tends to
$0$ at both ends --- so the limit is \ans{-2}

\vspace{0.2cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.2cm}

\problem{$k(x) = \dfrac{x^2-4}{x^2-5x+6}$. Find (a) $\lim_{x\to2} k(x)$ and
(b) $\lim_{x\to3^+} k(x)$.}

\textbf{Solution:} Factor both parts first --- that is what separates the hole
from the asymptote:
\[
  k(x) = \frac{(x-2)(x+2)}{(x-2)(x-3)} = \frac{x+2}{x-3} \qquad (x \neq 2).
\]

\textbf{(a)} The factor $x-2$ cancels, so $x = 2$ is a removable discontinuity, a
hole. Substitute into the reduced form: $\frac{2+2}{2-3} = \frac{4}{-1}$. \ans{-4}

\textbf{(b)} The factor $x - 3$ does \emph{not} cancel, so $x = 3$ is a genuine
vertical asymptote. As $x \to 3^+$ the numerator tends to $5 > 0$ and $x - 3$ is a
small positive, so the quotient grows without bound. \ans{+\infty}

\vspace{0.2cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.2cm}

\problem{Evaluate $\displaystyle\lim_{x \to \infty} \frac{5x^2 - 3}{2x^3 + x}$.}

\textbf{Solution:} The denominator has the higher degree, so divide by $x^3$:
\[
  \frac{5x^2 - 3}{2x^3 + x} = \frac{\dfrac{5}{x} - \dfrac{3}{x^3}}{2 + \dfrac{1}{x^2}}
  \longrightarrow \frac{0 - 0}{2 + 0}.
\]
The bottom outgrows the top, so the quotient is squeezed to \ans{0}

Comparing leading coefficients only ($\frac{5}{2}$) is the classic error: that
shortcut is valid only when the degrees are equal.

\vspace{0.2cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.2cm}

\problem{Evaluate $\displaystyle\lim_{x \to 2^-} \frac{x^2-4}{|x-2|}$.}

\textbf{Solution:} Approaching from the left means $x < 2$, so $x - 2 < 0$ and
$|x-2| = -(x-2) = 2 - x$. Factor the numerator and cancel:
\[
  \frac{x^2-4}{|x-2|} = \frac{(x-2)(x+2)}{-(x-2)} = -(x+2) \qquad (x < 2).
\]
Now let $x \to 2^-$ in $-(x+2)$: the value tends to $-(2+2)$. \ans{-4}

(From the right the same work gives $+4$, so the two-sided limit does not exist.)

\problem{Challenge. $r(x) = \dfrac{\sqrt{9x^2+4}}{3x-1}$. Find (a)
$\lim_{x\to\infty} r(x)$ and (b) $\lim_{x\to-\infty} r(x)$.}

\textbf{Solution:} The key identity is $\sqrt{x^2} = |x|$, not $x$. Divide
numerator and denominator by $|x|$, noting $\sqrt{9x^2+4}/|x| = \sqrt{9 + 4/x^2}$.

\textbf{(a)} For $x \to \infty$ we have $|x| = x$, so
\[
  r(x) = \frac{\sqrt{9 + \dfrac{4}{x^2}}}{3 - \dfrac{1}{x}}
  \longrightarrow \frac{\sqrt{9}}{3} = \frac{3}{3}. \qquad \ans{1}
\]

\textbf{(b)} For $x \to -\infty$ we have $|x| = -x$, so dividing the denominator
by $|x|$ introduces a minus sign:
\[
  r(x) = \frac{\sqrt{9 + \dfrac{4}{x^2}}}{-3 + \dfrac{1}{x}}
  \longrightarrow \frac{3}{-3}. \qquad \ans{-1}
\]
A numerator built from a square root is never negative, while $3x-1$ is very
negative at the left end --- so a negative answer is exactly what the graph
predicts.
