\problem{$f(x) = 3 \cdot 2^{\,x}$. Find $f(0)$ and $f(3)$.}

\textbf{Solution (a):} $2^0 = 1$, so $3 \cdot 1$. \ans{f(0) = 3}

\textbf{Solution (b):} $2^3 = 8$, so $3 \cdot 8$. \ans{f(3) = 24}

\vspace{0.2cm}\noindent\rule{\linewidth}{0.2pt}

\problem{$g(x) = 5^{\,x}$. Find $g(2)$ and $g(0)$.}

\textbf{Solution (a):} $5 \cdot 5$. \ans{g(2) = 25}

\textbf{Solution (b):} Any nonzero base to the power $0$ is $1$. \ans{g(0) = 1}

\vspace{0.2cm}\noindent\rule{\linewidth}{0.2pt}

\problem{$h(x) = 2^{\,x}$: complete the table for $x = -1, 0, 1, 2, 3$ and graph it.}

\textbf{Solution:} A negative exponent is a reciprocal: $2^{-1} = \frac{1}{2}$. \ans{h(-1) = \tfrac{1}{2}}

$2^0 = 1$. \ans{h(0) = 1}

$2^1 = 2$. \ans{h(1) = 2}

$2^2 = 4$. \ans{h(2) = 4}

$2^3 = 8$. \ans{h(3) = 8}

The plotted points $(-1, 0.5)$, $(0,1)$, $(1,2)$, $(2,4)$, $(3,8)$ rise ever more steeply and flatten towards the $x$-axis on the left without meeting it.

\vspace{0.2cm}\noindent\rule{\linewidth}{0.2pt}

\problem{$p(x) = 100 \cdot (0.5)^{\,x}$. Find $p(0)$ and $p(3)$.}

\textbf{Solution (a):} $(0.5)^0 = 1$, so $100 \cdot 1$. \ans{p(0) = 100}

\textbf{Solution (b):} $(0.5)^3 = 0.125$, so $100 \times 0.125$ --- or halve three times: $100, 50, 25$. \ans{p(3) = 12.5}

\vspace{0.2cm}\noindent\rule{\linewidth}{0.2pt}

\problem{Solve $2^{\,x} = 64$.}

\textbf{Solution:} Write the right side as a power of the same base: $64 = 2^6$. Equal powers of the same base force equal exponents. \ans{x = 6}

\vspace{0.2cm}\noindent\rule{\linewidth}{0.2pt}

\problem{$q(x) = 16 \cdot \left(\frac{1}{2}\right)^{x}$: complete the table for $x = 0$ to $4$ and graph it.}

\textbf{Solution:} At $x = 0$ the power is $1$, so $16 \cdot 1$. \ans{q(0) = 16}

Each step halves: $16 \div 2$. \ans{q(1) = 8}

$8 \div 2$. \ans{q(2) = 4}

$4 \div 2$. \ans{q(3) = 2}

$2 \div 2$. \ans{q(4) = 1}

The curve falls steeply at first and then flattens --- decay, because the multiplier is between $0$ and $1$.

\vspace{0.2cm}\noindent\rule{\linewidth}{0.2pt}

\problem{\$800 growing $5\%$ a year: find the balance after $6$ years.}

\textbf{Solution:} $1.05^6 = 1.340095640625$, so $800 \times 1.340095640625 = 1072.0765\ldots$, rounded to two decimal places. \ans{1072.08}

\vspace{0.2cm}\noindent\rule{\linewidth}{0.2pt}

\problem{Solve $5 \cdot 3^{\,x} = 405$.}

\textbf{Solution:} Divide both sides by $5$ before touching the exponent: $3^{\,x} = 81$. Then $81 = 3^4$, so the exponents match. Check: $5 \cdot 3^4 = 5 \cdot 81 = 405$ $\checkmark$ \ans{x = 4}

\vspace{0.2cm}\noindent\rule{\linewidth}{0.2pt}

\problem{$f(x) = 2 \cdot 3^{\,x}$. Find $f(4)$ and $f(-2)$.}

\textbf{Solution (a):} $3^4 = 81$, so $2 \cdot 81$. \ans{f(4) = 162}

\textbf{Solution (b):} $3^{-2} = \frac{1}{9}$, so $2 \cdot \frac{1}{9}$. The minus sign is in the exponent, not in front of the answer. \ans{f(-2) = \tfrac{2}{9}}

\vspace{0.2cm}\noindent\rule{\linewidth}{0.2pt}

\problem{$y = 4 \cdot 2^{\,x}$: table, graph, solve $4 \cdot 2^{\,x} = 64$, and why the curve misses the axis.}

\textbf{Solution:} $2^0 = 1$, so $4 \cdot 1$. \ans{4}

$2^1 = 2$, so $4 \cdot 2$. \ans{8}

$2^2 = 4$, so $4 \cdot 4$. \ans{16}

$2^3 = 8$, so $4 \cdot 8$. \ans{32}

Solving: divide by $4$ to get $2^{\,x} = 16 = 2^4$, so the exponents match. \ans{x = 4}

\textbf{--- instructor-judged.} A correct answer says the curve never meets the horizontal axis because the output is $4$ multiplied by a power of $2$, and a power of $2$ is always strictly positive however negative the input becomes; halving repeatedly shrinks the value towards zero without ever reaching it. Full credit for stating that the output is always positive and giving the never-reaches-zero reason; partial credit for saying only that the curve gets close to the axis.

\vspace{0.2cm}\noindent\rule{\linewidth}{0.2pt}

\problem{Solve $\left(\frac{1}{2}\right)^{x} = \frac{1}{32}$.}

\textbf{Solution:} $\frac{1}{32}$ is $\left(\frac{1}{2}\right)^{5}$, since halving five times from $1$ gives $\frac{1}{32}$. Same base, so the exponents match. \ans{x = 5}

\vspace{0.2cm}\noindent\rule{\linewidth}{0.2pt}

\problem{Culture doubling every $3$ hours from $500$: count $= 500 \cdot 2^{\,t/3}$. (a) $t = 9$. (b) $t = 5$. (c) When does it reach $16{,}000$?}

\textbf{Solution (a):} $t/3 = 3$, so the count is $500 \cdot 2^3 = 500 \cdot 8$ --- three doublings. \ans{4000}

\textbf{Solution (b):} $t/3 = \frac{5}{3}$, and $2^{5/3} = 3.174802\ldots$, so $500 \times 3.174802 = 1587.401\ldots$, rounded to two decimal places. \ans{1587.40}

\textbf{Solution (c):} Divide by $500$: $2^{\,t/3} = 32 = 2^5$, so $\frac{t}{3} = 5$. Check: $500 \cdot 2^5 = 16000$ $\checkmark$ \ans{t = 15}
