\problem{Add $34 + 25$ by breaking both numbers apart.}

\textbf{Solution:} Break apart: $34 = 30 + 4$ and $25 = 20 + 5$.
Tens: $30 + 20 = {}$ \ans{50}

Ones: $4 + 5 = {}$ \ans{9} \quad Together: $50 + 9 = {}$ \ans{59}

\problem{Add $41 + 37$ by breaking both numbers apart.}

\textbf{Solution:} Break apart: $41 = 40 + 1$ and $37 = 30 + 7$.
Tens: $40 + 30 = {}$ \ans{70}

Ones: $1 + 7 = {}$ \ans{8} \quad Together: $70 + 8 = {}$ \ans{78}

\problem{Add $26 + 48$ (the ones make more than a ten).}

\textbf{Solution:} Tens: $20 + 40 = {}$ \ans{60}

Ones: $6 + 8 = {}$ \ans{14} --- that is one ten and 4 ones, so regroup it
into the tens when combining: $60 + 14 = 60 + 10 + 4$. \ans{74}

\problem{Base-ten blocks for $37 + 25$: (a) cubes in all, (b) the sum.}

\textbf{Solution:} (a) The cubes are the ones: $7 + 5 = {}$ \ans{12}

(b) Twelve cubes trade into 1 rod and 2 cubes. Rods: $3 + 2 + 1 = 6$, so the
sum is 6 rods and 2 cubes: $30 + 20 + 12 = {}$ \ans{62}

\problem{Number-line jumps for $46 + 38$: $+30$, then $+8$.}

\textbf{Solution:} Start at 46. The first jump adds the tens:
$46 + 30 = {}$ \ans{76}

The second jump adds the ones: $76 + 8 = 84$, so $46 + 38 = {}$ \ans{84}

\problem{Mia's friendly-number strategy for $39 + 24$.}

\textbf{Solution:} The friendly number 40 is easy to add:
$40 + 24 = {}$ \ans{64}

But 40 is one \emph{more} than 39, so the sum is one too big --- take the
extra one away: $64 - 1 = 63$, so $39 + 24 = {}$ \ans{63}

\emph{What a good explanation contains:} Mia added 40 instead of 39, which is
one too many, so she must take one away at the end to make it fair.

\problem{Place-value chart for $57 + 36$.}

\textbf{Solution:} Tens row: $50 + 30 = {}$ \ans{80}

Ones row: $7 + 6 = {}$ \ans{13} --- one ten and 3 ones. Combine and regroup:
$80 + 13 = 80 + 10 + 3$. \ans{93}

\problem{Challenge: $45 + 27 + 13$, and which pair to group first.}

\textbf{Solution:} Look at the ones digits: 7 and 3 make a friendly ten, so
group $27 + 13 = 40$ first. Then $45 + 40 = 85$, so $45 + 27 + 13 = {}$ \ans{85}

\emph{What a good explanation contains:} the pair 27 and 13 was grouped first
because their ones digits (7 and 3) make ten, giving the round number 40,
which is easy to add to 45. (Any grouping that names the friendly ten earns
full credit.)
