\begin{center}
Comparing models and qualifying what the data supports
\end{center}

\noindent\textbf{Directions:}
\begin{itemize}[leftmargin=1.2cm, itemsep=2pt]
  \item Two questions run through the whole sheet: \emph{which model describes this data better?} and \emph{what does that entitle me to say?}
  \item A residual is $\text{observed} - \text{predicted}$. Squaring the residuals and adding them gives one number per model, and the smaller number is the closer fit.
  \item Every claim you write should name the group it applies to. A number computed from a sample describes that sample first, and anything beyond it needs a reason.
\end{itemize}
