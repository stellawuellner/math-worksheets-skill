\wstitleblock{Off-by-One Errors in Sequence Indexing}{Algebra 1}{}

\noindent\textbf{Directions}
\begin{itemize}[leftmargin=0.8cm, itemsep=1pt, topsep=2pt]
  \item Every problem shows work in which the index is off by exactly one. Repair the computation, and where asked, say what the miscount was.
  \item Two counts get confused all through this topic: the number of \textbf{terms} and the number of \textbf{jumps} between them. A run of terms always has one more term than jump.
  \item So reaching term $n$ from term $1$ takes $n - 1$ jumps, and the list $a_j, \ldots, a_k$ holds $k - j + 1$ terms.
  \item Show the corrected arithmetic beside each blank.
\end{itemize}
