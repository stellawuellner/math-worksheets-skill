# Counting Forward Practice (Kindergarten–Grade 1)

Three PDFs are ready:

- **ws_counting_curr001.pdf** — an 8-problem worksheet on counting forward from
  varied starting numbers within 100. Every problem uses a concrete model —
  number tracks, count-on sequences, and hundred-chart rows — and each model is
  connected to the written numerals the child fills in. Difficulty ramps from
  counting on from 3 to a challenge that crosses from 97 into 100.
- **ak_counting_curr001.pdf** — the step-by-step answer key. Each solution
  shows the count-on reasoning ("one more than 43 is 44"), with a quick-answers
  bank up front for fast grading and a generated Curriculum section listing the
  standards (K.CC.A.1, K.CC.A.2) and difficulty range.
- **ss_counting_curr001.pdf** — a one-page study guide with three skill
  sections (counting on by ones, crossing into a new tens group, reading a
  hundred-chart row), each with a rule box, a worked example, and a try-it with
  the answer printed upside down.

**What is verified:** 21 of the 22 responses on the worksheet are
machine-checked with SymPy — every missing number the child writes has its own
verified entry, and each blank is labeled in the answer bank so you can see
which value answers which box. **One item is instructor-judged:** in the
challenge problem the child circles the greatest number they wrote; the key
tells you what to accept (a clear mark around 100 only). The study guide's
worked examples and try-its are machine-verified the same way.
