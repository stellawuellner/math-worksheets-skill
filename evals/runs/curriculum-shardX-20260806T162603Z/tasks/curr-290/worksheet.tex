\wstitleblock{Choosing and Combining Factoring Techniques}{Algebra 1}{Common factor first, monic and non-monic trinomials, and differences of squares}

\begin{itemize}[leftmargin=0.7cm, itemsep=1pt, topsep=2pt]
  \item The expressions below are \textbf{mixed on purpose}. Nobody tells you which method to use --- deciding that is the skill this sheet practises.
  \item Run the same three questions on every problem, in this order: \textbf{(1)} Is there a common factor in every term? \textbf{(2)} How many terms are left? \textbf{(3)} Which pattern fits what is left?
  \item \textbf{Factor completely.} You are not finished while something inside the parentheses still factors.
  \item Check any answer by multiplying it back out.
\end{itemize}
