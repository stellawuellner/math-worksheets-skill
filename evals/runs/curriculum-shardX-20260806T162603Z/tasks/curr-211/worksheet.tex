\wstitleblock{Solving Equations with Variables on Both Sides}{Grade 8 / Pre-Algebra}{}

\begin{center}
\textit{Collecting variable terms on one side, building the equation from a model, and
recognizing special cases}
\end{center}

\noindent\textbf{The balance model behind every step}
\begin{itemize}[leftmargin=0.9cm, itemsep=1pt, topsep=2pt]
  \item An equation is a balanced scale. Whatever you do to one pan you must do to the
        other, or the balance is lost.
  \item \textbf{Step 1:} clear any brackets. \textbf{Step 2:} take the smaller variable
        term off \emph{both} pans, so the variable survives on one side only.
        \textbf{Step 3:} undo the constant, then undo the coefficient.
  \item Every move undoes something, so use the \emph{inverse} operation: a subtraction is
        cleared by adding.
  \item Check by substituting your answer back into the original equation.
\end{itemize}

\problem{A balance scale is level. Each bag on it holds the same unknown number of blocks,
and the loose blocks are all identical.
\par\vspace{0.15cm}
\begin{center}
\begin{tabular}{|l|l|}
\hline
\textbf{Left pan} & \textbf{Right pan} \\
\hline
$3$ bags and $4$ blocks & one bag and $12$ blocks \\
\hline
\end{tabular}
\end{center}
\par\vspace{0.15cm}
Write the balance as an equation in $x$, where $x$ is the number of blocks in one bag, and
solve it.
