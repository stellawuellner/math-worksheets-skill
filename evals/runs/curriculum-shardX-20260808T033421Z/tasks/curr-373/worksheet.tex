\wstitleblock{Radical Equations and Extraneous Roots}{Algebra 2}{}

\begin{center}
\textit{Isolating and undoing a radical, testing every candidate in the original equation, and solving radical models from real measurements}
\end{center}

\noindent\textbf{Directions}
\begin{itemize}[leftmargin=1.1cm, itemsep=1pt, topsep=3pt]
  \item Isolate the radical first, then raise both sides to the matching power.
  \item Squaring is not reversible: it can produce candidates the original equation never had. \textbf{Every} candidate must be tested in the original equation before it is reported as a solution.
  \item A square root is never negative. If the isolated radical is set equal to a negative quantity, that candidate cannot work.
  \item In the modelling problems the units are given. Give each answer in the unit asked for, rounded as stated.
\end{itemize}
