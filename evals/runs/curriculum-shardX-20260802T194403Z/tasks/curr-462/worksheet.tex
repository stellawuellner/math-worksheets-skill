\wstitleblock{Derivatives of Inverse and Inverse-Trigonometric Functions}{AP Calculus AB/BC --- Differentiation}{}

\noindent\small\textbf{Skills practised:} Chain rule on arc-functions, the inverse-function
derivative, products and quotients, and second derivatives.
\smallskip

\noindent\textbf{Worked pattern.} $\dfrac{d}{dx}\arctan(u) = \dfrac{u'}{1 + u^2}$, so for
$y = \arctan(x^3)$ take $u = x^3$, $u' = 3x^2$, and write
$y' = \dfrac{3x^2}{1 + x^6}$ --- substitute the inner function into the formula, then multiply by
its derivative. The same shape works for every arc-function; only the denominator changes.
\smallskip

\noindent\small Leave answers unsimplified only where simplification is genuinely impossible; state
exact values (no decimals). Show the inner function $u$ you used.\normalsize

\problem[6cm]{Let $f(x) = x^{3} + 2x + 1$. The function $f$ is increasing, so $f^{-1}$ exists.

\textbf{(b)} Use $\left(f^{-1}\right)'(a) = \dfrac{1}{f'(b)}$ to compute
$\left(f^{-1}\right)'(4)$.}
