\begin{center}
\textit{Counting a picture and writing the numeral, matching a number word to
its numeral, and comparing two amounts shown in different ways}
\end{center}

\noindent\textbf{Three ways to show the same number.}
\begin{itemize}[leftmargin=1.2cm, itemsep=2pt, topsep=2pt]
\item The \textbf{picture} shows how many things there are. Touch and count
each one.
\item The \textbf{numeral} is the written sign, like $4$ or $9$.
\item The \textbf{number word} is what you say, like \emph{four} or
\emph{nine}.
\item They all name the same amount. A full five-frame is $5$ and a full
ten-frame is $10$, so you can start there and count on.
\end{itemize}
