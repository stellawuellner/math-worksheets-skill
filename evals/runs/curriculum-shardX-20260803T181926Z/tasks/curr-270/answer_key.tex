\problem{\textbf{Evaluate $f(x) = 4x - 7$ at $x = 3$.}

\textbf{Step 1.} The notation $f(3)$ names an input, so the only move is to
replace every $x$ in the rule with $3$.

\textbf{Step 2.} $f(3) = 4(3) - 7 = 12 - 7$.

\textbf{Step 3.} So the output is $\ans{5}$.

\textit{Listen for:} a student who answers ``$f$ times $3$''. $f(3)$ is not a
product --- it is the output of the machine named $f$ when $3$ goes in.}

\problem{\textbf{Read $H(4)$ from Graph B.}

\textbf{Step 1.} $H(4)$ asks for the output at the input $t = 4$, so travel
along the horizontal axis to $4$ and then straight up to the marked point.

\textbf{Step 2.} That point sits at a height of $40$ on the vertical axis, and
the vertical axis is measured in feet.

\textbf{Step 3.} $H(4) = \ans{40 \text{ ft}}$.

\textit{Teaching note:} the drone is at the same height at $t = 2$ and $t = 4$.
Two different inputs may share one output --- that is allowed for a function.
Two different outputs for one input would not be.}

\problem{\textbf{Compare two readings on Graph B.}

\textbf{Step 1.} The question asks how much \emph{higher}, so it is a
difference of two \emph{outputs} --- read both heights before subtracting
anything.

\textbf{Step 2.} From the graph, $H(6) = 100$ and $H(2) = 40$.

\textbf{Step 3.} $H(6) - H(2) = 100 - 40 = \ans{60 \text{ ft}}$.

\textit{Common wrong answer:} $4$ --- the two \emph{inputs} $6$ and $2$ were
subtracted instead of the two heights.}

\problem{\textbf{Evaluate $g(x) = x^2 - 5x + 2$ at $x = -2$.}

\textbf{Step 1.} A negative input is the place substitution goes wrong, so
write the parentheses in before simplifying anything: $g(-2) = (-2)^2 - 5(-2) + 2$.

\textbf{Step 2.} $(-2)^2 = 4$ because a negative times a negative is positive,
and $-5(-2) = +10$.

\textbf{Step 3.} $g(-2) = 4 + 10 + 2 = \ans{16}$.

\textit{Common wrong answer:} $8$ --- the square was taken as $-4$, which is
what $-2^2$ means, not what $(-2)^2$ means.}

\problem{\textbf{Run $f(x) = 4x - 7$ backwards from the output $21$.}

\textbf{Step 1.} Here the output is known and the input is not, so this is an
equation to solve rather than a substitution: $4x - 7 = 21$.

\textbf{Step 2.} Add $7$ to both sides: $4x = 28$.

\textbf{Step 3.} Divide by $4$: $\ans{x = 7}$.

\textit{Check:} $f(7) = 4(7) - 7 = 21$ $\checkmark$ --- evaluating is how you
check a solve, and solving is how you undo an evaluate.}

\problem{\textbf{Build a rule from Table A, then use it.}

\textbf{(a)} \textbf{Step 1.} The problem says the cost rises by the same
amount each hour, so the rate is a difference between two neighbouring
outputs.

\textbf{Step 2.} $C(2) - C(1) = 34 - 22 = 12$, and the same gap appears again:
$46 - 34 = 12$ and $58 - 46 = 12$.

\textbf{Step 3.} The cost rises by $\ans{12}$ per extra hour.

\textbf{(b)} \textbf{Step 4.} A constant rise of $12$ per hour makes the rule
linear, $C(x) = 12x + b$, and one table entry pins down $b$: $22 = 12(1) + b$,
so $b = 10$ --- a fixed launch fee charged once.

\textbf{Step 5.} The rule is $C(x) = 12x + 10$, so
$C(6) = 12(6) + 10 = 72 + 10$.

\textbf{Step 6.} A six-hour rental costs $\ans{82}$ dollars.

\textit{Teaching note:} the table never lists $6$ hours. Turning the table into
a rule is exactly what makes an unlisted input answerable.}

\problem{\textbf{Where the tank's domain ends.}

\textbf{Step 1.} The rule keeps subtracting $24$ forever, but the tank cannot
hold less than nothing, so the story --- not the algebra --- decides where the
domain stops: at the moment the tank is empty.

\textbf{Step 2.} Empty means $V(t) = 0$, so solve $480 - 24t = 0$, giving
$24t = 480$.

\textbf{Step 3.} $t = 480 / 24 = \ans{20 \text{ min}}$.

\textit{Grading note:} full credit needs the reason as well as the number ---
after $20$ minutes the rule would return negative gallons, which the situation
has no meaning for. A sensible domain is $0 \le t \le 20$.}

\problem{\textbf{Find the input that gives $300$ gallons.}

\textbf{Step 1.} The amount of water is the output, so $300$ goes on the output
side and the unknown minute count is what is being solved for:
$480 - 24t = 300$.

\textbf{Step 2.} Subtract $480$ from both sides: $-24t = -180$.

\textbf{Step 3.} Divide by $-24$: $t = 180 / 24 = \ans{7.5 \text{ min}}$.

\textit{Check:} $V(7.5) = 480 - 24(7.5) = 480 - 180 = 300$ $\checkmark$. Note
that $7.5$ minutes is inside the domain found in Problem 7, so it is a legal
answer for this story.}

\problem{\textbf{Evaluate the tank rule at $t = 9$.}

\textbf{Step 1.} This time the input is given, so substitute rather than solve:
$V(9) = 480 - 24(9)$.

\textbf{Step 2.} $24(9) = 216$, so $V(9) = 480 - 216$.

\textbf{Step 3.} $V(9) = \ans{264 \text{ gallons}}$, meaning $264$ gallons are
still in the tank nine minutes after the drain opened.}

\problem{\textbf{Find and fix the mistake.}

\textbf{Step 1.} Test the student's rule against the table before repairing it:
$C(x) = 22x$ gives $C(2) = 44$, but Table A says $34$. The rule is wrong, so
the reasoning behind it is wrong too.

\textbf{Step 2.} What went wrong: $22$ is the cost of the \emph{first} hour,
not the cost of \emph{each} hour. It already contains the one-time launch fee
of $10$ dollars, so charging $22$ again for every later hour charges that fee
over and over.

\textbf{Step 3.} The correct rule separates them: $C(x) = 12x + 10$, so
$C(5) = 12(5) + 10 = 60 + 10 = \ans{70}$ dollars.

\textit{Common wrong answer:} $110$ --- the student's rule $22 \times 5$.}

\problem{\textbf{Range and domain for the ticket function.}

\textbf{(a)} \textbf{Step 1.} The range is the set of outputs, and $T(n) = 9n$
grows as $n$ grows, so the largest output comes from the largest legal input.

\textbf{Step 2.} The order limit makes $8$ the largest legal input, so the top
of the range is $T(8) = 9(8)$.

\textbf{Step 3.} The largest value in the range is $\ans{72}$ dollars.

\textbf{(b)} \textbf{Step 4.} \textit{(Open response --- flagged for manual
review; read the student's sentence.)} A full-credit answer says both things:
tickets come only in whole numbers, so inputs such as $2.5$ have no meaning
here, and the order limit caps the input at $8$. The domain is therefore
$\{0, 1, 2, 3, 4, 5, 6, 7, 8\}$ and the range is
$\{0, 9, 18, 27, 36, 45, 54, 63, 72\}$ --- nine values, not an interval.

\textit{Listen for:} ``the domain is all real numbers, because you can multiply
anything by $9$.'' True of the bare rule, false of this situation. The rule and
the story together decide the domain.}

\problem{\textbf{Synthesis --- open response, flagged for manual review.}

There is no single correct paragraph here. A strong answer contains all of the
following.

\textbf{Drone (Graph B).} A realistic domain is $0 \le t \le 8$ seconds --- the
recorder only stored readings over that window. A realistic range runs from
$0$ up to $100$ feet, the lowest and highest heights the graph reaches. The
\emph{graph} makes both easy to see: the domain is how far the picture runs
left to right, and the range is how far it runs bottom to top.

\textbf{Tank ($V(t) = 480 - 24t$).} A realistic domain is
$0 \le t \le 20$ minutes and the matching range is $0 \le V \le 480$ gallons.
The \emph{rule} makes this easier: nothing in a table or a picture announces
where the water runs out, but setting the rule equal to $0$ finds that instant
exactly, and reading the rule at $t = 0$ gives the full $480$ gallons.

\textbf{Why.} A graph shows the whole story at once but only to the accuracy
the eye can read; a rule is exact and extends past the data, but you must ask
it a question to get an answer; a table like Table A is exact at the inputs it
lists and silent everywhere else --- which is why Problem 6 needed the rule to
reach $6$ hours.

\textit{Grading note:} accept any well-argued domain and range, but require the
student to name a representation and give a reason. ``The graph is easier''
alone is not a justification.}
