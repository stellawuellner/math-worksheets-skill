\problem{Simplify $\dfrac{1 - \cos^2\theta}{\sin\theta}$.}

\textbf{Solution:} the numerator is the Pythagorean identity rearranged: $1 - \cos^2\theta = \sin^2\theta$. Dividing,
$\dfrac{\sin^2\theta}{\sin\theta} = \sin\theta$ wherever $\sin\theta \ne 0$. \ans{\sin\theta}

\vspace{0.12cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.12cm}

\problem{Exact value of $\cos 15^\circ$.}

\textbf{Solution:} write $15^\circ = 45^\circ - 30^\circ$ and use $\cos(A - B) = \cos A\cos B + \sin A\sin B$:
\begin{align*}
  \cos 15^\circ &= \cos 45^\circ\cos 30^\circ + \sin 45^\circ\sin 30^\circ \\
  &= \frac{\sqrt{2}}{2}\cdot\frac{\sqrt{3}}{2} + \frac{\sqrt{2}}{2}\cdot\frac{1}{2}
   = \frac{\sqrt{6}}{4} + \frac{\sqrt{2}}{4}.
\end{align*}
\ans{\dfrac{\sqrt{6} + \sqrt{2}}{4}}

\vspace{0.12cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.12cm}

\problem{$\sin\theta = \dfrac{3}{5}$, $\theta$ in quadrant I. Find $\sin 2\theta$.}

\textbf{Solution:} first get the cosine from the Pythagorean identity, taking the positive root because quadrant I has cosine positive:
$\cos\theta = \sqrt{1 - \left(\tfrac{3}{5}\right)^2} = \sqrt{\tfrac{16}{25}} = \tfrac{4}{5}$. Then
\[ \sin 2\theta = 2\sin\theta\cos\theta = 2\cdot\frac{3}{5}\cdot\frac{4}{5}. \]
\ans{\dfrac{24}{25}}

\vspace{0.12cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.12cm}

\problem{Solve $2\cos\theta - \sqrt{3} = 0$ on $0^\circ \le \theta < 360^\circ$.}

\textbf{Solution:} $\cos\theta = \dfrac{\sqrt{3}}{2}$, reference angle $30^\circ$, and cosine is positive in quadrants I and IV, so
$\theta = 30^\circ$ and $\theta = 360^\circ - 30^\circ = 330^\circ$. \ans{\theta = 30^\circ,\ 330^\circ}

\vspace{0.12cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.12cm}

\problem{Exact value of $\tan 15^\circ$.}

\textbf{Solution:} with $\tan(A - B) = \dfrac{\tan A - \tan B}{1 + \tan A\tan B}$ and $15^\circ = 45^\circ - 30^\circ$:
\[ \tan 15^\circ = \frac{1 - \frac{1}{\sqrt{3}}}{1 + \frac{1}{\sqrt{3}}} = \frac{\sqrt{3} - 1}{\sqrt{3} + 1}. \]
Multiply above and below by $\sqrt{3} - 1$: the numerator becomes $(\sqrt{3}-1)^2 = 4 - 2\sqrt{3}$ and the denominator becomes $3 - 1 = 2$. \ans{2 - \sqrt{3}}

\vspace{0.12cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.12cm}

\problem{Solve $\sin 2\theta = \sin\theta$ on $0^\circ \le \theta < 360^\circ$.}

\textbf{Solution:} expand the double angle, collect on one side, and factor --- never divide by $\sin\theta$.
\[ 2\sin\theta\cos\theta - \sin\theta = 0 \quad\Longrightarrow\quad \sin\theta\,(2\cos\theta - 1) = 0 \]
$\sin\theta = 0$ gives $0^\circ, 180^\circ$; \ $\cos\theta = \dfrac{1}{2}$ gives $60^\circ, 300^\circ$. \ans{\theta = 0^\circ,\ 60^\circ,\ 180^\circ,\ 300^\circ}

\vspace{0.12cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.12cm}

\problem{Simplify $\dfrac{1}{1 + \cos\theta} + \dfrac{1}{1 - \cos\theta}$.}

\textbf{Solution:} the common denominator is a difference of squares, which is exactly where the Pythagorean identity enters:
\[ \frac{(1 - \cos\theta) + (1 + \cos\theta)}{(1 + \cos\theta)(1 - \cos\theta)} = \frac{2}{1 - \cos^2\theta} = \frac{2}{\sin^2\theta}. \]
\ans{\dfrac{2}{\sin^2\theta}}

\vspace{0.12cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.12cm}

\problem{Solve $2\cos^2\theta + \cos\theta - 1 = 0$ on $0^\circ \le \theta < 360^\circ$.}

\textbf{Solution:} this is a quadratic in $\cos\theta$; factor it as one.
\[ (2\cos\theta - 1)(\cos\theta + 1) = 0 \]
$\cos\theta = \dfrac{1}{2}$ gives $60^\circ, 300^\circ$; \ $\cos\theta = -1$ gives $180^\circ$ --- once only, because $-1$ is the minimum of cosine. \ans{\theta = 60^\circ,\ 180^\circ,\ 300^\circ}

\vspace{0.12cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.12cm}

\problem{Solve $\sin 2\theta = \cos\theta$ on $0^\circ \le \theta < 360^\circ$.}

\textbf{Solution:} expand and factor, keeping the common $\cos\theta$ as a factor.
\[ 2\sin\theta\cos\theta - \cos\theta = 0 \quad\Longrightarrow\quad \cos\theta\,(2\sin\theta - 1) = 0 \]
$\cos\theta = 0$ gives $90^\circ, 270^\circ$; \ $\sin\theta = \dfrac{1}{2}$ gives $30^\circ, 150^\circ$. \ans{\theta = 30^\circ,\ 90^\circ,\ 150^\circ,\ 270^\circ}

\vspace{0.12cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.12cm}

\problem{Exact value of $\cos 105^\circ$.}

\textbf{Solution:} $105^\circ = 60^\circ + 45^\circ$, and $\cos(A + B) = \cos A\cos B - \sin A\sin B$:
\begin{align*}
  \cos 105^\circ &= \cos 60^\circ\cos 45^\circ - \sin 60^\circ\sin 45^\circ \\
  &= \frac{1}{2}\cdot\frac{\sqrt{2}}{2} - \frac{\sqrt{3}}{2}\cdot\frac{\sqrt{2}}{2}
   = \frac{\sqrt{2}}{4} - \frac{\sqrt{6}}{4}.
\end{align*}
The result is negative, as it must be for a quadrant II angle. \ans{\dfrac{\sqrt{2} - \sqrt{6}}{4}}

\vspace{0.12cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.12cm}

\problem{Identity: $\dfrac{\sin\theta}{1 + \cos\theta} + \dfrac{1 + \cos\theta}{\sin\theta} = \dfrac{2}{\sin\theta}$. (a) Simplify the left side. (b) Prove it.}

\textbf{(a)} Over the common denominator $\sin\theta\,(1 + \cos\theta)$:
\[ \frac{\sin^2\theta + (1 + \cos\theta)^2}{\sin\theta\,(1 + \cos\theta)}
 = \frac{\sin^2\theta + 1 + 2\cos\theta + \cos^2\theta}{\sin\theta\,(1 + \cos\theta)}
 = \frac{2 + 2\cos\theta}{\sin\theta\,(1 + \cos\theta)}. \]
Factor the numerator as $2(1 + \cos\theta)$ and cancel. \ans{\dfrac{2}{\sin\theta}}

\textbf{(b)} \emph{Instructor-judged.} A correct proof works on the left-hand side only and names each move: common denominator $\sin\theta(1+\cos\theta)$; expand $(1+\cos\theta)^2$; apply $\sin^2\theta + \cos^2\theta = 1$ to collapse the numerator to $2 + 2\cos\theta$; factor out $2$ and cancel the shared $(1 + \cos\theta)$; state that the identity holds wherever $\sin\theta \ne 0$ and $\cos\theta \ne -1$. A chain of equalities that manipulates both sides at once, or a check at one angle, is not a proof.

\vspace{0.12cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.12cm}

\problem{$\cos 2\theta + 3\sin\theta = 2$ on $0^\circ \le \theta < 360^\circ$. (a) Rewrite and factor. (b) Solve. (c) Explain the count.}

\textbf{(a)} Use the form of the double angle that produces sine only, $\cos 2\theta = 1 - 2\sin^2\theta$:
\[ 1 - 2\sin^2\theta + 3\sin\theta - 2 = -2\sin^2\theta + 3\sin\theta - 1 = (1 - 2\sin\theta)(\sin\theta - 1). \]
\ans{(1 - 2\sin\theta)(\sin\theta - 1)}

\textbf{(b)} $1 - 2\sin\theta = 0$ gives $\sin\theta = \dfrac{1}{2}$, so $\theta = 30^\circ$ and $150^\circ$; \ $\sin\theta - 1 = 0$ gives $\theta = 90^\circ$. \ans{\theta = 30^\circ,\ 90^\circ,\ 150^\circ}

\textbf{(c)} \emph{Instructor-judged.} A correct response explains the count factor by factor: $\sin\theta = \dfrac{1}{2}$ is met twice in a full turn (quadrants I and II), while $\sin\theta = 1$ is the maximum of sine and is met exactly once, at $90^\circ$ --- two plus one is three. Saying only that the quadratic has two roots, without noting that one root yields a single angle, is partial credit.
