\problem{$f(x) = x^2 - 6x + 5$. (a) Axis of symmetry. (b) Vertex $y$-value.}

\textbf{Solution (a):} Here $a = 1$ and $b = -6$, so $x = -\frac{b}{2a} = -\frac{-6}{2}$. \ans{x = 3}

\textbf{Solution (b):} The vertex sits on that line, so evaluate there: $3^2 - 6(3) + 5 = 9 - 18 + 5$. The vertex is $(3, -4)$. \ans{y = -4}

\vspace{0.2cm}\noindent\rule{\linewidth}{0.2pt}

\problem{$g(x) = x^2 - 2x - 8$. (a) $x$-intercepts. (b) $y$-intercept.}

\textbf{Solution (a):} Set the output to zero and factor: $x^2 - 2x - 8 = (x + 2)(x - 4)$, since $(+2)(-4) = -8$ and $2 + (-4) = -2$. A product is zero only when a factor is.
\[ \boxed{x = -2 \quad \text{or} \quad x = 4} \]

\textbf{Solution (b):} The $y$-intercept is the output at input $0$: $0 - 0 - 8$ --- the constant term. \ans{y = -8}

\vspace{0.2cm}\noindent\rule{\linewidth}{0.2pt}

\problem{$h(x) = -3x^2 + 12x - 5$. (a) Opening direction, justified. (b) Axis of symmetry.}

\textbf{(a) --- instructor-judged.} A correct answer says the parabola opens downward and gives the reason: the coefficient of the squared term is $-3$, which is negative, so large inputs in either direction drive the output far below the vertex. Full credit for the direction plus the sign of the leading coefficient as the reason; partial credit for the direction alone.

\textbf{Solution (b):} $a = -3$ and $b = 12$, so $x = -\frac{12}{2(-3)} = -\frac{12}{-6}$. \ans{x = 2}

\vspace{0.2cm}\noindent\rule{\linewidth}{0.2pt}

\problem{$f(x) = 2x^2 + 12x + 13$. (a) Axis of symmetry. (b) Vertex $y$-value.}

\textbf{Solution (a):} $a = 2$ and $b = 12$, so $x = -\frac{12}{2(2)} = -\frac{12}{4}$. \ans{x = -3}

\textbf{Common wrong answer:} $-12$ comes from stopping at the numerator and never dividing by $2a$.

\textbf{Solution (b):} $2(-3)^2 + 12(-3) + 13 = 18 - 36 + 13$. The vertex is $(-3, -5)$. \ans{y = -5}

\vspace{0.2cm}\noindent\rule{\linewidth}{0.2pt}

\problem{$f(x) = x^2 + 4x - 12$. (a) $x$-intercepts. (b) $y$-intercept.}

\textbf{Solution (a):} $x^2 + 4x - 12 = (x + 6)(x - 2)$, since $(+6)(-2) = -12$ and $6 + (-2) = 4$. Setting each factor to zero \emph{flips} its sign.
\[ \boxed{x = -6 \quad \text{or} \quad x = 2} \]

\textbf{Common wrong answer:} $6$ and $-2$ come from reading the numbers straight off the factors without changing their signs.

\textbf{Solution (b):} The output at input $0$ is the constant term. \ans{y = -12}

\vspace{0.2cm}\noindent\rule{\linewidth}{0.2pt}

\problem{$f(x) = (x - 4)^2 - 9$. (a) Vertex $y$-value. (b) $y$-intercept.}

\textbf{Solution (a):} A square is never negative, so the smallest the expression can be is when $(x-4)^2 = 0$, at $x = 4$. There the value is $0 - 9$, and the vertex is $(4, -9)$. \ans{y = -9}

\textbf{Solution (b):} At input $0$: $(0 - 4)^2 - 9 = 16 - 9$. \ans{y = 7}

\vspace{0.2cm}\noindent\rule{\linewidth}{0.2pt}

\problem{$f(x) = -x^2 + 6x - 8$. (a) $x$-intercepts. (b) $y$-intercept.}

\textbf{Solution (a):} Factor out $-1$ first: $-(x^2 - 6x + 8) = -(x - 2)(x - 4)$. The overall $-1$ can never be zero, so the zeros come from the two brackets.
\[ \boxed{x = 2 \quad \text{or} \quad x = 4} \]

\textbf{Solution (b):} At input $0$: $-0 + 0 - 8$. \ans{y = -8}

\vspace{0.2cm}\noindent\rule{\linewidth}{0.2pt}

\problem{$f(x) = x^2 - 4x + 3$. (a) Axis. (b) Vertex $y$-value. (c) $x$-intercepts. (d) Labelled sketch.}

\textbf{Solution (a):} $a = 1$, $b = -4$, so $x = -\frac{-4}{2}$. \ans{x = 2}

\textbf{Solution (b):} $2^2 - 4(2) + 3 = 4 - 8 + 3$. The vertex is $(2, -1)$. \ans{y = -1}

\textbf{Solution (c):} $x^2 - 4x + 3 = (x - 1)(x - 3)$.
\[ \boxed{x = 1 \quad \text{or} \quad x = 3} \]

\textbf{(d) --- instructor-judged.} The sketch must show an upward-opening parabola whose lowest point sits at $(2, -1)$, whose curve crosses the horizontal axis at $x = 1$ and $x = 3$, and whose vertical axis of symmetry $x = 2$ is drawn and labelled through the vertex. Full credit when all four features are drawn and labelled and the curve is symmetric about that line; partial credit for a correct curve with unlabelled features.

\vspace{0.2cm}\noindent\rule{\linewidth}{0.2pt}

\problem{$f(x) = 3x^2 - 18x + 20$. (a) Axis. (b) Vertex $y$-value. (c) Maximum or minimum, justified.}

\textbf{Solution (a):} $a = 3$, $b = -18$, so $x = -\frac{-18}{2(3)} = \frac{18}{6}$. \ans{x = 3}

\textbf{Solution (b):} $3(3)^2 - 18(3) + 20 = 27 - 54 + 20$. The vertex is $(3, -7)$. \ans{y = -7}

\textbf{(c) --- instructor-judged.} A correct answer says the vertex is a minimum, because the coefficient of the squared term is positive, so the parabola opens upward and the vertex is its lowest point; every other input gives a larger output. Full credit for the label plus the sign-of-the-leading-coefficient reason; partial credit for the label alone.

\vspace{0.2cm}\noindent\rule{\linewidth}{0.2pt}

\problem{$f(x) = -2x^2 + 8x + 10$. (a) Direction and vertex type. (b) Axis. (c) Vertex $y$-value. (d) $x$-intercepts.}

\textbf{(a) --- instructor-judged.} A correct answer says the parabola opens downward because the coefficient of the squared term is $-2$, which is negative, and therefore its vertex is a maximum rather than a minimum. Full credit for both the direction and the consequence for the vertex, each tied to the sign of that coefficient; partial credit for the direction alone.

\textbf{Solution (b):} $a = -2$, $b = 8$, so $x = -\frac{8}{2(-2)} = -\frac{8}{-4}$. \ans{x = 2}

\textbf{Solution (c):} $-2(2)^2 + 8(2) + 10 = -8 + 16 + 10$. The vertex is $(2, 18)$, the highest point of the curve. \ans{y = 18}

\textbf{Solution (d):} Factor out $-2$: $-2(x^2 - 4x - 5) = -2(x - 5)(x + 1)$.
\[ \boxed{x = -1 \quad \text{or} \quad x = 5} \]
