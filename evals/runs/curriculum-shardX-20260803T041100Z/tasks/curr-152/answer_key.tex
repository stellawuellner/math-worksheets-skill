\problem{\textbf{Muffins: $2$ cups flour to $5$ cups milk; complete the milk
row for $4$, $6$ and $10$ cups of flour.}
\par
Every column must be the starting column times one number. Read the scale
factor off the flour row, then apply the same factor to the milk entry.
\par
$4 = 2 \times 2$, so milk $= 5 \times 2 = \ans{10}$. \quad
$6 = 2 \times 3$, so milk $= 5 \times 3 = \ans{15}$. \quad
$10 = 2 \times 5$, so milk $= 5 \times 5 = \ans{25}$.
\par\smallskip
\emph{Grading note:} $13$ in the last cell is the additive error --- the
student saw flour go up by $8$ and added $8$ to the milk. Point at the second
column: $4$ is not $2 + 8$, it is $2 \times 2$, and the same operation has to
be used on both rows.}

\problem{\textbf{Beads: $3$ red to $8$ white; a row has $21$ red.}
\par
Find the multiplier first, from the row where both entries are known:
\[ 21 \div 3 = 7 \]
so the scale factor is $\ans{7}$. Apply it to the partner entry:
$8 \times 7 = 56$.
\par
$\ans{56}$ white beads}

\problem{\textbf{$5$ teachers per $90$ students; complete for $180$ and $270$
students.}
\par
This time the known row is the \emph{student} row, so scale from there.
$180 \div 90 = 2$, so teachers $= 5 \times 2 = \ans{10}$.
\par
$270 \div 90 = 3$, so teachers $= 5 \times 3 = \ans{15}$.
\par
The direction does not matter --- what matters is that the same factor is used
on both rows of a column.}

\problem{\textbf{$6$ bottles every $4$ seconds; find the unit rate.}
\par
The unit-rate column is the one whose seconds entry is $1$. Divide both entries
of the known column by $4$:
\[ \frac{6}{4} = \frac{3}{2} \]
\par
$\ans{1.5}$ bottles per second}

\problem{\textbf{Is $4:6$ equivalent to $14:21$?}
\par
Write each as a fraction and reduce:
\[ \frac{4}{6} = \frac{2}{3}, \qquad \frac{14}{21} = \frac{2}{3} \]
Both tables are built from the same ratio $2:3$, so the tables are equivalent.
\par
$\ans{4/6 = 14/21}$
\par\smallskip
\emph{Grading note:} the cross-product check is the same statement:
$4 \times 21 = 84 = 6 \times 14$.}

\problem{\textbf{Video: $8$ minutes to $20$ megabytes; next column is $12$
minutes.}
\par
The scale factor need not be a whole number. Divide the new entry by the old:
$k = 12 \div 8 = \ans{1.5}$
\par
Apply it to the storage row: $20 \times 1.5 = 30$.
\par
$\ans{30}$ megabytes
\par\smallskip
\emph{Grading note:} $24$ means the student added the difference
$12 - 8 = 4$ to $20$. That keeps the \emph{difference} constant, not the
ratio, and it is the single most common ratio-table error.}

\problem{\textbf{Paint: $3$ blue to $5$ yellow; find the two missing entries.}
\par
Left blank (yellow is $20$): $20 \div 5 = 4$, so blue $= 3 \times 4 = 12$.
\par
Right blank (blue is $15$): $15 \div 3 = 5$, so yellow $= 5 \times 5 = 25$.
\par
Blue: $\ans{12}$ \qquad Yellow: $\ans{25}$
\par\smallskip
Each column is scaled from the \emph{first} column, not from its neighbour ---
though scaling from the neighbour works too if the factor is computed
correctly.}

\problem{\textbf{Train: $150$ miles in $4$ hours; find the speed.}
\par
The unit-rate column has hours $= 1$, so divide both entries by $4$:
\[ \frac{150}{4} = 37.5 \]
Since the hours entry is now $1$, the miles entry \emph{is} the speed in miles
per hour.
\par
$\ans{37.5\ \text{mph}}$}

\problem{\textbf{Lemonade: recipe P is $3$ scoops to $5$ cups, recipe Q is $5$
scoops to $8$ cups. Which is stronger?}
\par
``Stronger'' means more mix per cup, so compare the scoops-per-cup unit rates
--- or, equivalently, the two fractions with a common denominator:
\[ \frac{3}{5} = \frac{24}{40}, \qquad \frac{5}{8} = \frac{25}{40} \]
\par
$\ans{3/5 < 5/8}$, so \textbf{recipe Q} is the stronger mix.
\par\smallskip
\emph{Grading note:} ``Q has more scoops, so Q is stronger'' is right here but
for the wrong reason --- Q also has more water. Insist on the unit rate.}

\problem{\textbf{A table built from $5:3$ has a column reading $x$ to $42$.}
\par
Equivalent columns mean equal ratios, so set the two fractions equal:
\[ \frac{x}{42} = \frac{5}{3} \]
Cross-multiply (or notice $42 = 3 \times 14$, so the factor is $14$):
\[ 3x = 5 \times 42 = 210 \quad\Longrightarrow\quad x = \frac{210}{3} \]
\par
$\ans{x = 70}$
\par\smallskip
Check with the scale factor: $5 \times 14 = 70$ and $3 \times 14 = 42$.}

\problem{\textbf{A table starts at $9$ to $12$; a later column has $84$ in the
second row. Find $k$ and the missing entry.}
\par
The scale factor $k$ multiplies \emph{both} rows, so it satisfies
\[ 12k = 84 \quad\Longrightarrow\quad k = \frac{84}{12} \]
\par
$\ans{k = 7}$
\par
Now apply it to the first row: $9 \times 7 = 63$.
\par
$\ans{63}$}

\problem{\textbf{Synthesis: blue to yellow is $4:7$, and a batch totals $66$
ounces.}
\par
Add a total row to the table. One ``part-set'' of the ratio is
$4 + 7 = 11$ ounces, so the total row of the starting column is $11$.
\par
The batch's total row reads $66$, so the whole table was scaled by $x$ where
\[ 11x = 66 \quad\Longrightarrow\quad x = \frac{66}{11} \]
\par
$\ans{x = 6}$
\par
Scale each row by $6$: blue $= 4 \times 6$ and yellow $= 7 \times 6$.
\par
Blue: $\ans{24}$ ounces \qquad Yellow: $\ans{42}$ ounces
\par\smallskip
Check: $24 + 42 = 66$ $\checkmark$ and $24 : 42$ reduces to $4 : 7$
$\checkmark$.
\par\smallskip
\emph{Grading note:} $16.5$ ounces of blue means the student divided $66$ by
$4$ --- treating the ratio numbers as divisors instead of counting the $11$
equal parts the total splits into.}
