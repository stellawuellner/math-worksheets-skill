\problem{\textbf{$\dfrac{dy}{dx} = 6x^2$, \; $y(0) = 1$.}

\textbf{Step 1.} The right side already holds no $y$, so separation is just
$dy = 6x^2\,dx$.

\textbf{Step 2.} Integrate both sides. The antiderivative of the right side is
$\ans{2x^3}$, so $y = 2x^3 + C$.

\textbf{Step 3.} Apply $y(0) = 1$: \; $1 = 2(0)^3 + C$, so $C = 1$ and the
particular solution is $y = 2x^3 + 1$.

\textbf{Step 4.} $y(2) = 2(8) + 1 = \ans{17}$

\textit{Note:} the $+C$ goes on one side only. Writing $C_1$ and $C_2$ on both
sides is not wrong, but it is one more thing to carry.}

\problem{\textbf{$\dfrac{dy}{dx} = 3x^2 - 4$, \; $y(2) = 5$.}

\textbf{Step 1.} Separate: $dy = (3x^2 - 4)\,dx$.

\textbf{Step 2.} Integrating the right side gives $\ans{x^3 - 4x}$, so
$y = x^3 - 4x + C$.

\textbf{Step 3.} Apply the condition at $x = 2$: \; $5 = 8 - 8 + C$, which
gives $\ans{C = 5}$

\textbf{Step 4.} Particular solution: $y = x^3 - 4x + 5$.

\textit{Listen for:} students who leave the answer as $y = x^3 - 4x + C$. An
initial-value problem is not finished until the constant is a number.}

\problem{\textbf{$\dfrac{dy}{dx} = xy$, \; $y(0) = 2$.}

\textbf{Step 1.} Both variables appear, so separate properly:
$\dfrac{dy}{y} = x\,dx$.

\textbf{Step 2.} Integrate. The right side gives $\ans{x^2/2}$, and the left
gives $\ln|y|$, so $\ln|y| = \dfrac{x^2}{2} + C$.

\textbf{Step 3.} Exponentiate: $y = Ae^{x^2/2}$ where $A = e^{C}$. Applying
$y(0) = 2$ gives $2 = Ae^{0}$, so $A = 2$ and
$y = 2e^{x^2/2}$.

\textbf{Step 4.} $y(2) = 2e^{2} = \ans{14.78}$ (to two decimal places).

\textit{Common wrong answer:} $7.39$ --- the initial condition was never
applied, leaving the coefficient at $1$.}

\problem{\textbf{$\dfrac{dy}{dx} = \dfrac{2x+1}{y}$, \; $y(0) = 3$.}

\textbf{Step 1.} Cross-multiply into separated form: $y\,dy = (2x+1)\,dx$.

\textbf{Step 2.} Integrate: $\dfrac{y^2}{2} = x^2 + x + C$.

\textbf{Step 3.} Apply $y(0) = 3$ \emph{now}, before solving for $y$:
$\dfrac{9}{2} = 0 + 0 + C$, so $\ans{C = \tfrac{9}{2}}$

\textbf{Step 4.} Multiply through by $2$: $y^2 = 2x^2 + 2x + 9$, and the
initial value is positive, so $y = \sqrt{2x^2 + 2x + 9}$. Then
$y(2) = \sqrt{21} = \ans{4.58}$

\textit{Common wrong answer:} $3.24$ --- the equation was not multiplied by $2$
before taking the square root.}

\problem{\textbf{$\dfrac{dy}{dx} = y^2$, \; $y(1) = 1$.}

\textbf{Step 1.} Separate: $\dfrac{dy}{y^2} = dx$, that is $y^{-2}\,dy = dx$.

\textbf{Step 2.} The left side integrates to $\ans{-1/y}$, so
$-\dfrac{1}{y} = x + C$.

\textbf{Step 3.} Apply $y(1) = 1$: \; $-1 = 1 + C$, so $C = -2$ and
$-\dfrac{1}{y} = x - 2$, giving $y = \dfrac{1}{2 - x}$.

\textbf{Step 4.} $y(1.5) = \dfrac{1}{0.5} = \ans{2}$

\textbf{Step 5 (domain).} The solution blows up at $x = 2$. The initial point
$x = 1$ lies to the left of that, so the particular solution is defined on
$x < 2$ --- a solution of an IVP lives on the interval containing the initial
point, not on every $x$ where the formula happens to evaluate.}

\problem{\textbf{Radioactive decay: $80$ mg, half-life $10$ days.}

\textbf{Step 1.} $\dfrac{dA}{A} = -k\,dt$ integrates to $\ln A = -kt + C$, so
$A = A_0e^{-kt}$ with $A_0 = 80$ mg.

\textbf{Step 2.} Half-life: $40 = 80e^{-10k}$, so $e^{-10k} = \frac{1}{2}$ and
$k = \dfrac{\ln 2}{10} \approx 0.069315$ per day.

\textbf{Step 3.} After $25$ days:
$A(25) = 80e^{-(\ln 2/10)(25)} = 80 \cdot 2^{-2.5}$.

\textbf{Step 4.} $A(25) = \ans{14.14\ \text{mg}}$

\textit{Common wrong answer:} $20$ mg --- $25$ days was rounded down to two
whole half-lives. Two and a half half-lives is not two.}

\problem{\textbf{$\dfrac{dy}{dx} = y\cos x$, \; $y(0) = 4$.}

\textbf{Step 1.} Separate: $\dfrac{dy}{y} = \cos x\,dx$.

\textbf{Step 2.} The right side integrates to $\ans{\sin(x)}$, so
$\ln|y| = \sin x + C$.

\textbf{Step 3.} Exponentiate to $y = Ae^{\sin x}$, and $y(0) = 4$ with
$\sin 0 = 0$ gives $A = 4$. Particular solution: $y = 4e^{\sin x}$.

\textbf{Step 4.} At $x = 1$ radian, $\sin 1 \approx 0.841471$, so
$y(1) = 4e^{0.841471} = \ans{9.28}$

\textit{Common wrong answer:} $1.72$ --- cosine was integrated to $-\sin x$.
Differentiation introduces the minus sign; integration does not.}

\problem{\textbf{$\dfrac{dy}{dx} = \dfrac{3x^2}{2y}$, \; $y(1) = 2$.}

\textbf{Step 1.} Separate: $2y\,dy = 3x^2\,dx$.

\textbf{Step 2.} The left side integrates to $\ans{y^2}$ and the right to
$x^3$, so $y^2 = x^3 + C$.

\textbf{Step 3.} Apply $y(1) = 2$: \; $4 = 1 + C$, so $C = 3$ and
$y^2 = x^3 + 3$. The initial value $y = 2$ is positive, which selects the
positive branch: $y = \sqrt{x^3 + 3}$.

\textbf{Step 4.} $y(3) = \sqrt{27 + 3} = \sqrt{30} = \ans{5.48}$

\textit{Why the branch matters:} $y = -\sqrt{x^3+3}$ satisfies the same
differential equation, but not the initial condition. The condition picks one
of the two branches, and the solution never crosses $y = 0$.}

\problem{\textbf{Population: $\dfrac{dP}{dt} = 0.08P$, \; $P(0) = 500$.}

\textbf{Step 1.} $\dfrac{dP}{P} = 0.08\,dt$ integrates to
$\ln P = 0.08t + C$, so $P = 500e^{0.08t}$ after applying $P(0) = 500$.

\textbf{Step 2.} Set $P = 1500$: \; $1500 = 500e^{0.08t}$, so $e^{0.08t} = 3$.
Note that only the \emph{ratio} $1500/500$ survives.

\textbf{Step 3.} Take logarithms: $0.08t = \ln 3$, so
$t = \dfrac{\ln 3}{0.08}$.

\textbf{Step 4.} $t = \ans{13.73\ \text{years}}$

\textit{Common wrong answer:} $91.42$ years --- $\ln 1500$ was used instead of
$\ln 3$, because the initial population was not divided out first.}

\problem{\textbf{Logistic equation $\dfrac{dy}{dx} = y(3-y)$.}
\emph{Part (b) is an open construction and explanation, flagged for manual
review; the model answer is below.}

\textbf{Step 1 (part a).} Equilibrium solutions are the constant solutions,
where $\frac{dy}{dx} = 0$ for all $x$. Setting $y(3-y) = 0$ gives
$\ans{y = 0 \text{ and } y = 3}$

\textbf{Step 2 (the slope field).} The slope depends only on $y$, so every
segment in a horizontal row is parallel --- that is the fastest way to fill the
lattice. Row by row: at $y = -1$ the slope is $(-1)(4) = -4$ (steeply
falling); at $y = 0$ and $y = 3$ it is $0$ (horizontal); at $y = 1$ it is
$(1)(2) = 2$ (rising); at $y = 2$ it is $(2)(1) = 2$ (rising); at $y = 4$ it is
$(4)(-1) = -4$ (steeply falling).

\textbf{Step 3 (long-run behaviour).} The solution through $(0,1)$ starts
between the two equilibria, where the slope is positive, so it increases. It
can never cross $y = 3$, because that would require crossing an equilibrium
solution. Therefore it rises and approaches $y = 3$ asymptotically as $x$ grows
--- $y = 3$ is the carrying capacity.

\textit{Full credit:} both equilibria found in (a); segments drawn horizontal
along $y = 0$ and $y = 3$, up-sloping strictly between them and down-sloping
outside; and a sentence saying the solution increases toward $3$ without
reaching it. A sketch whose segments cross $y = 3$ is the error to look for.}
