\problem{$f(x) = x^{2}$, $g(x) = 2f(x - 3) + 1$. Find $g(5)$.}

\textbf{Solution:} Work inside first. $g(5) = 2f(5 - 3) + 1 = 2f(2) + 1 = 2(4) + 1 = 9$. \ans{g(5) = 9}

\vspace{0.1cm}\noindent\rule{\linewidth}{0.2pt}

\problem{$f(x) = x^{2}$, $g(x) = f(x + 4) - 7$. \textbf{(a)} Find $g(-2)$. \textbf{(b)} Describe the transformations in order.}

\textbf{Solution (a):} $g(-2) = f(-2 + 4) - 7 = f(2) - 7 = 4 - 7 = -3$. \ans{g(-2) = -3}

\textbf{Solution (b):} \emph{Instructor-judged.} A complete answer names two shifts with the right directions: a horizontal shift of $4$ units \textbf{left} (the $+4$ is inside, so the graph moves toward negative $x$ --- opposite to the sign's appearance), then a vertical shift of $7$ units \textbf{down}. Because one shift is horizontal and one is vertical, either order gives the same graph, and a student may say so. Reading $x + 4$ as ``4 right'' is the standard error and should not earn that half.

\vspace{0.1cm}\noindent\rule{\linewidth}{0.2pt}

\problem{$f(x) = x^{2}$, $g(x) = -\dfrac{1}{2}f(x + 4) - 3$. Expand.}

\textbf{Solution:} Substitute, expand the square, then distribute the $-\tfrac{1}{2}$.
\begin{align*}
  g(x) &= -\tfrac{1}{2}(x + 4)^{2} - 3 \\
       &= -\tfrac{1}{2}\left(x^{2} + 8x + 16\right) - 3 \\
       &= -\tfrac{1}{2}x^{2} - 4x - 8 - 3
\end{align*}
So \ans{g(x) = -\tfrac{1}{2}x^{2} - 4x - 11}

\problem{$f(x) = x^{2} + 3$, $g(x) = f(2x) - 5$. \textbf{(a)} Find $g(1)$. \textbf{(b)} Find $g(2)$.}

\textbf{Solution (a):} The $2x$ doubles the input before $f$ sees it: $g(1) = f(2) - 5$. The table gives $f(2) = 7$, so $g(1) = 7 - 5 = 2$. \ans{g(1) = 2}

\textbf{Solution (b):} $g(2) = f(4) - 5$, and $4$ is off the end of the table, so use the rule: $f(4) = 4^{2} + 3 = 19$, hence $g(2) = 19 - 5 = 14$. \ans{g(2) = 14}

\vspace{0.1cm}\noindent\rule{\linewidth}{0.2pt}

\problem{$f(x) = \sqrt{x}$, $g(x) = -3f(x) + 2$. \textbf{(a)} Find $g(9)$. \textbf{(b)} Describe the transformations in order.}

\textbf{Solution (a):} $g(9) = -3\sqrt{9} + 2 = -3(3) + 2 = -7$. \ans{g(9) = -7}

\textbf{Solution (b):} \emph{Instructor-judged.} Every parameter is outside $f$, so nothing at all happens horizontally. A complete answer gives a vertical stretch by a factor of $3$ and a reflection in the $x$-axis (these two may be combined as ``multiply the outputs by $-3$''), \textbf{then} a shift of $2$ units up. The stretch must come before the vertical shift; a horizontal stretch or a left/right shift is wrong.

\vspace{0.1cm}\noindent\rule{\linewidth}{0.2pt}

\problem{$f(x) = x^{2} - 4x$, $g(x) = f(x - 2) + 5$. Expand.}

\textbf{Solution:} Replace every $x$ in the rule for $f$ by $x - 2$:
\begin{align*}
  g(x) &= (x - 2)^{2} - 4(x - 2) + 5 \\
       &= x^{2} - 4x + 4 - 4x + 8 + 5
\end{align*}
Collecting like terms gives \ans{g(x) = x^{2} - 8x + 17}

\vspace{0.1cm}\noindent\rule{\linewidth}{0.2pt}

\problem{$p(x) = x^{3}$, $q(x) = -p(x - 1) + 2$. \textbf{(a)} Find $q(0)$. \textbf{(b)} Find $q(3)$.}

\textbf{Solution (a):} $q(0) = -p(0 - 1) + 2 = -p(-1) + 2 = -(-1) + 2 = 3$. \ans{q(0) = 3}

\textbf{Solution (b):} $q(3) = -p(3 - 1) + 2 = -p(2) + 2 = -8 + 2 = -6$. \ans{q(3) = -6}

\vspace{0.1cm}\noindent\rule{\linewidth}{0.2pt}

\problem{$f(x) = x^{3}$, $g(x) = f(6 - x)$. \textbf{(a)} Find $g(2)$. \textbf{(b)} Rewrite the input and describe the transformations in order.}

\textbf{Solution (a):} $g(2) = f(6 - 2) = f(4) = 4^{3} = 64$. \ans{g(2) = 64}

\textbf{Solution (b):} \emph{Instructor-judged.} The input factors as $6 - x = -(x - 6)$, and until it is written that way no transformation can be read off. A complete answer then names a reflection in the $y$-axis and a horizontal shift of $6$ units \textbf{right}, with an order that actually works: reflect in the $y$-axis first and then shift right $6$. Reading $6 - x$ unfactored and answering ``shift $6$ left'' is the error this problem targets.

\vspace{0.1cm}\noindent\rule{\linewidth}{0.2pt}

\problem{$f(x) = \sqrt{x}$, $g(x) = 3f(2x - 8) + 1$. Rewrite as $a\sqrt{b(x - h)} + k$.}

\textbf{Solution:} The parameters are only readable once $b$ is factored out of the input:
\[ 2x - 8 = 2(x - 4) \]
So $g(x) = 3\sqrt{2(x - 4)} + 1$: a horizontal compression by a factor of $\tfrac{1}{2}$, a shift $4$ right, a vertical stretch by $3$, and a shift $1$ up. \ans{g(x) = 3\sqrt{2(x-4)} + 1}

\vspace{0.1cm}\noindent\rule{\linewidth}{0.2pt}

\problem{$g(x) = 4x^{2} + 24x + 41$. \textbf{(a)} Complete the square. \textbf{(b)} Describe the transformations in order.}

\textbf{Solution (a):} Factor the leading coefficient out of the $x$-terms first:
\begin{align*}
  g(x) &= 4\left(x^{2} + 6x\right) + 41 \\
       &= 4\left(x^{2} + 6x + 9\right) - 36 + 41 \\
       &= 4(x + 3)^{2} + 5
\end{align*}
So \ans{g(x) = 4(x+3)^{2} + 5}

\textbf{Solution (b):} \emph{Instructor-judged.} From $4(x + 3)^{2} + 5$: a vertical stretch by a factor of $4$, a shift $3$ units \textbf{left}, and a shift $5$ units \textbf{up}. The order that matters is stretch-before-vertical-shift: applying the $+5$ first and then stretching by $4$ would multiply that $5$ as well and land the vertex at $y = 20$ instead of $y = 5$. The horizontal shift may be done at any point.
