\problem{Evaluate: \quad $-5 - 8$}

\textbf{Solution:} Rewrite the subtraction as adding the opposite: $-5 - 8 = -5 + (-8)$.
Both numbers are negative, so add the absolute values ($5 + 8 = 13$) and keep the
negative sign. \ans{-13}

\problem{Evaluate: \quad $-7 - (-12)$}

\textbf{Solution:} Subtracting $-12$ is the same as adding $12$:
$-7 - (-12) = -7 + 12$. The signs differ, so subtract $12 - 7 = 5$ and keep the sign
of the number with the larger absolute value, which is $+12$. \ans{5}

\problem{Evaluate: \quad $-(-8) - 15$}

\textbf{Solution:} The opposite of $-8$ is $8$, so $-(-8) = 8$. Then
$8 - 15 = 8 + (-15) = -7$. \ans{-7}

\problem{Jorge computes $-4 - (-6)$ and writes $-4 - (-6) = -10$.
(a) What error did Jorge make? (b) Find the correct value of $-4 - (-6)$.}

\textbf{Solution:} (a) Jorge treated subtracting $-6$ as subtracting positive $6$: he
computed $-4 - 6 = -10$. Subtracting a negative means \emph{adding}, so the double
negative should have become $+\,6$. A correct one-sentence answer must say that
$-(-6)$ is $+6$ (or that subtracting a negative is adding).

(b) $-4 - (-6) = -4 + 6 = 2$. \ans{2}

\problem{Write $<$ or $>$ in the blank: \ $-3 - 5 \;\square\; -3 - (-5)$}

\textbf{Solution:} Left side: $-3 - 5 = -8$. Right side: $-3 - (-5) = -3 + 5 = 2$.
Since $-8$ is to the left of $2$ on the number line, the true statement
is \ans{-3 - 5 \;<\; -3 - (-5)}

\problem{Evaluate: \quad $3 - (2 - 9)$}

\textbf{Solution:} The minus in front of the parentheses applies to \emph{every} term
inside: $3 - (2 - 9) = 3 - 2 + 9$. Left to right: $3 - 2 = 1$, then $1 + 9 = 10$.
(Check by working inside first: $2 - 9 = -7$, and $3 - (-7) = 10$.) \ans{10}

\problem{Maya computes $-\tfrac{1}{2} - \tfrac{3}{4}$ and writes
$-\tfrac{1}{2} - \tfrac{3}{4} = \tfrac{1}{4}$. (a) Explain Maya's error.
(b) Find the correct value.}

\textbf{Solution:} (a) Maya \emph{added} $\tfrac{3}{4}$ instead of subtracting it: she
computed $-\tfrac{1}{2} + \tfrac{3}{4} = \tfrac{1}{4}$. The expression subtracts a
positive $\tfrac{3}{4}$, so the answer must be \emph{less} than $-\tfrac{1}{2}$, not
positive. A correct explanation names the subtraction-turned-addition error.

(b) With a common denominator of 4: $-\tfrac{1}{2} = -\tfrac{2}{4}$, so
$-\tfrac{2}{4} - \tfrac{3}{4} = -\tfrac{5}{4}$. \ans{-\tfrac{5}{4}}

\problem{\textbf{Challenge.} Evaluate: \quad
$-\tfrac{3}{4} - \left(-\tfrac{5}{6}\right) + \left(-\tfrac{1}{3}\right)$}

\textbf{Solution:} Rewrite every subtraction as adding the opposite:
$-\tfrac{3}{4} + \tfrac{5}{6} - \tfrac{1}{3}$. Use the common denominator 12:
\[ -\tfrac{9}{12} + \tfrac{10}{12} - \tfrac{4}{12} = \tfrac{-9 + 10 - 4}{12} = -\tfrac{3}{12}. \]
Simplify by dividing top and bottom by 3, giving \ans{-\tfrac{1}{4}}
