Here are the three PDFs for the triangle-congruence practice set:

- **Worksheet** — `ws_congruence_curr313.pdf` (5 pages)
- **Answer key** — `ak_congruence_curr313.pdf` (3 pages)
- **Study guide** — `ss_congruence_curr313.pdf` (2 pages)

**What the worksheet covers.** Eight problems, all on using a congruence
statement to solve for corresponding parts (CPCTC). Every problem is set in a
real fabrication context with the units stated — gusset plates, a kite frame, a
footbridge truss, a roof frame, sail panels, a bicycle-frame joint, tent panels,
and a crane support. A value-free reference diagram at the top shows how the
vertex-matching convention is written, so no problem has to carry a labelled
figure that a neighbouring problem could be misread against.

The set ramps: problems 1–2 are single equations from one pair of matching
parts; 3–5 add a second question (a side length, a third angle, a perimeter);
6–8 are multi-part items that combine two unknowns with a reasoning question.
Problems 3, 4 and 5 were designed around specific misconceptions, and the key
prints the wrong number each one produces, so a wrong answer tells you which
error the student made.

**What is verified, honestly.** The verification file holds 17 entries — one per
response the worksheet asks for, not one per problem.

- **15 entries are machine-checked** with SymPy (every value: x, y, n, w, k, the
  side lengths, the angle measures, the perimeter). Six of the eight problems
  are fully machine-checked end to end.
- **2 entries are instructor-judged**: problem 6(c) ("explain how you know
  m∠J = m∠M without measuring") and problem 8(c) ("explain why one side and one
  angle is not enough, and name what would settle it"). These are written
  reasoning, so no computer algebra system can mark them. The answer key prints
  a grading rubric for each, and its "What is verified" note names problems 6
  and 8 as the two carrying an instructor-judged part — the Quick Answers bank
  shows `---` in exactly those two slots.

Nothing on this sheet is marked `[unchecked]`: every printed answer blank is
either machine-verified or explicitly flagged for you to read.

**Study guide.** Three skills, each with a rule box, a worked example that opens
with the strategy in words, a try-it that re-parameterizes it (answer printed
upside down inside the box), and a watch-out box for the two mistakes that cost
the most marks: pairing vertices alphabetically instead of by position, and
using CPCTC before the congruence has been established.
