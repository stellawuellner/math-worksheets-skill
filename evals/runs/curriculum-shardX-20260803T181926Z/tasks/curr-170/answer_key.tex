\problem{\textbf{Evaluate $-8 + 3$.}

\textbf{Step 1.} The signs differ, so the two numbers pull in opposite
directions: start at $-8$ and move $3$ units toward zero.

\textbf{Step 2.} $-8$ is $8$ units from zero and $3$ is only $3$, so the answer
keeps the negative sign, and the size is $8 - 3 = 5$.

\ans{-5}

\textit{Listen for:} $-11$, which comes from adding the sizes instead of
subtracting them.}

\problem{\textbf{Evaluate $-6 - (-11)$.}

\textbf{Step 1.} Subtracting a number is adding its opposite, so rewrite
first: $-6 - (-11) = -6 + 11$.

\textbf{Step 2.} Now the signs differ: $11$ is further from zero than $6$, so
the answer is positive, with size $11 - 6 = 5$.

\ans{5}

\textit{Listen for:} $-17$ --- the two minus signs were read as one.}

\problem{\textbf{Evaluate $(-4)(7)$.}

\textbf{Step 1.} Multiply the sizes, then decide the sign by counting negative
factors.

\textbf{Step 2.} $4 \times 7 = 28$, and there is exactly one negative factor
--- an odd count --- so the product is negative.

\ans{-28}

\textit{Teaching note:} four groups of $7$ removed is the story behind the
rule.}

\problem{\textbf{Order $-1$, $-\frac{3}{4}$, $-0.6$, $\frac{1}{2}$ from least
to greatest.}

\textbf{Step 1.} The numbers are written three different ways, so convert them
to one form --- decimals: $-1$, $-0.75$, $-0.6$, $0.5$.

\textbf{Step 2.} On a number line, least is furthest left. All three negatives
come before the positive, and among the negatives the one furthest from zero,
$-1$, is smallest.

\ans{-1 < -\tfrac{3}{4} < -0.6 < \tfrac{1}{2}}

\textit{Listen for:} $-0.6 < -0.75$, from ordering the negatives as if they
were positive.}

\problem{\textbf{Evaluate $-3 + 4(-2)$.}

\textbf{Step 1.} Multiplication outranks addition, so $4(-2)$ must be
evaluated before anything is added.

\textbf{Step 2.} $4(-2) = -8$, so the expression is $-3 + (-8)$.

\textbf{Step 3.} Two negatives added: the sizes add and the sign stays
negative, giving $-11$.

\ans{-11}

\textit{Listen for:} $-2$, from adding $-3 + 4$ first.}

\problem{\textbf{Evaluate $\left(-\frac{3}{4}\right)\left(\frac{8}{9}\right)$.}

\textbf{Step 1.} One negative factor, so the answer is negative; multiply the
sizes as fractions.

\textbf{Step 2.} Multiply straight across:
$\dfrac{3 \times 8}{4 \times 9} = \dfrac{24}{36}$.

\textbf{Step 3.} $\dfrac{24}{36} = \dfrac{2}{3}$ in lowest terms, and the sign
is negative.

\ans{-\tfrac{2}{3}}

\textit{Faster route:} cancel before multiplying --- $8$ and $4$ share a factor
of $4$, and $3$ and $9$ share a factor of $3$.}

\problem{\textbf{Evaluate $2.5 + (-7.25)$.}

\textbf{Step 1.} Different signs again, so subtract the smaller size from the
larger and keep the sign of the larger.

\textbf{Step 2.} $7.25 - 2.5 = 4.75$, and $-7.25$ is the one further from zero,
so the answer is negative.

\ans{-4.75}

\textit{Check:} lining the decimal points up matters here --- $7.25 - 2.5$ is
not $7.25 - 2.05$.}

\problem{\textbf{Compare $-\frac{5}{6}$ and $-0.8$.}

\textbf{Step 1.} One is a fraction and one is a decimal, so put them in the
same form before comparing: $-\dfrac{5}{6} = -0.8333\ldots$

\textbf{Step 2.} Both are negative, so the one further from zero is smaller.
$0.8333\ldots > 0.8$, so $-\dfrac{5}{6}$ sits further left.

\ans{-\tfrac{5}{6} < -0.8}

\textit{Listen for:} the reversed answer, from comparing $0.8333$ with $0.8$
and forgetting that both are negative.}

\problem{\textbf{Evaluate $(-2)^3 + 12 \div (-4)$.}

\textbf{Step 1.} Exponents come first, then division, and only then the
addition.

\textbf{Step 2.} $(-2)^3 = (-2)(-2)(-2) = -8$ --- an odd number of negative
factors, so the result is negative.

\textbf{Step 3.} $12 \div (-4) = -3$, so the expression is $-8 + (-3) = -11$.

\ans{-11}

\textit{Listen for:} $8$ for $(-2)^3$; that is $(-2)^2 \cdot 2$ thinking. Note
also that $(-2)^3$ and $-2^3$ agree here, while $(-2)^2$ and $-2^2$ do not.}

\problem{\textbf{Priya's $-24 \div (-6) \cdot (-2)$.}

\textbf{Step 1.} Division and multiplication have equal rank, so they run
\emph{left to right} --- Priya multiplied $(-6)(-2)$ first, which changes the
meaning of the expression.

\textbf{Step 2.} Left to right: $-24 \div (-6) = 4$ (two negatives, so
positive).

\textbf{Step 3.} Then $4 \cdot (-2) = -8$.

\ans{-8}

\textit{What Priya did wrong:} she computed $-24 \div \left[(-6)(-2)\right]
= -24 \div 12 = -2$. Equal-rank operations are never reordered.}

\problem{\textbf{Evaluate $-3(2-5) - \frac{4^2}{8}$.}

\textbf{Step 1.} Brackets first, then the exponent and the division, then the
subtraction that joins the two halves.

\textbf{Step 2.} $2 - 5 = -3$, so the first term is $-3(-3) = 9$ --- two
negative factors, so positive.

\textbf{Step 3.} $4^2 = 16$ and $16 \div 8 = 2$, so the expression is
$9 - 2$.

\ans{7}

\textit{Listen for:} $-11$, from multiplying $-3 \cdot 2$ before doing the
bracket.}

\problem{\textbf{Challenge: order $-2.5$, $-\frac{11}{4}$, $-2.05$,
$-\frac{9}{4}$ from greatest to least.}

\textbf{Step 1.} Four negatives written two ways --- convert the fractions to
decimals so a single comparison rule applies:
$-\dfrac{11}{4} = -2.75$ and $-\dfrac{9}{4} = -2.25$.

\textbf{Step 2.} The list is now $-2.5$, $-2.75$, $-2.05$, $-2.25$. Greatest
means closest to zero, so read them by distance from zero: $2.05$, $2.25$,
$2.5$, $2.75$.

\textbf{Step 3.} Greatest to least reverses that size order, because a larger
distance from zero means a smaller negative number.

\ans{-2.05 > -\tfrac{9}{4} > -2.5 > -\tfrac{11}{4}}

\textit{Sentence to look for:} something like ``I turned every fraction into a
decimal first, then ordered by how far each one is from zero.''}
