\problem{Row A (4 dots) and Row B (6 dots): count each, then which has more.}

\textbf{Solution:} Count Row A one-to-one: \ans{4}

Count Row B: \ans{6}

When counting, 4 is said before 6, so 4 is less --- Row \textbf{B} has more.
\ans{4 < 6}

\problem{Row A (7 dots) and Row B (5 dots): count each, then which has fewer.}

\textbf{Solution:} Row A: \ans{7}

Row B: \ans{5}

5 is said before 7 when counting, so Row \textbf{B} has fewer. \ans{7 > 5}

\problem{Two rows arranged differently: count each, then more, fewer, or the
same.}

\textbf{Solution:} Row A: \ans{6}

Row B: \ans{6} \quad Spreading dots out does not change how many there are.

The counts match, so the rows have the \textbf{same} number. \ans{6 = 6}

\problem{Row A has 3, Row B has 8: count on to find how many more.}

\textbf{Solution:} Start at 3 and count on to 8: ``4, 5, 6, 7, 8'' --- those
are the hop lines. That is five hops, so Row B has \ans{5} more dots.

\problem{Array A (3 rows of 3) and Group B (7 dots): which has more.}

\textbf{Solution:} Array A row by row: $3 + 3 + 3$ gives \ans{9}

Group B: \ans{7}

9 comes after 7 in the count, so Array \textbf{A} has more. \ans{9 > 7}

\problem{Ana has 4 grapes, Ben has 7: how many more does Ana need to have the
same?}

\textbf{Solution:} Count on from 4 to 7: ``5, 6, 7'' --- three hops. Ana needs
\ans{3} more grapes.

\problem{Ten-frames showing 6 and 10: how many more in the full frame?}

\textbf{Solution:} Count on from 6 to 10: ``7, 8, 9, 10'' --- four hops. The
full frame has \ans{4} more dots.

\problem{Array A (3 rows of 4) and Row B (9 dots): which has more.}

\textbf{Solution:} Array A row by row: $4 + 4 + 4$ gives \ans{12}

Row B: \ans{9}

12 comes after 9 in the count, so Array \textbf{A} has more. \ans{12 > 9}

\problem{Kim has 5 crayons, Jo has 9: how many more does Kim need?}

\textbf{Solution:} Count on from 5 to 9: ``6, 7, 8, 9'' --- four hops. Kim
needs \ans{4} more crayons.

\problem{Challenge: Row A (7 dots), Row B (9 dots) --- counts, how many more,
and how you counted on.}

\textbf{Solution:} Row A: \ans{7}

Row B: \ans{9}

Count on from 7 to 9: ``8, 9'' --- two hops, so Row B has \ans{2} more dots.

\textbf{Say how you counted on (instructor-judged):} accept any wording that
shows counting on from the smaller number (``I started at 7 and said 8, 9 ---
two hops''), not recounting both rows from one. Recounting still earns credit
for the number if it lands on 2, but the strategy asked for is counting on.
