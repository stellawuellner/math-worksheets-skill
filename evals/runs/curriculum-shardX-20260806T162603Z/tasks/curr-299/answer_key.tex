\problem{$f(x) = 2x+1$ for $x < 3$, and $12 - x$ for $x \ge 3$. Find $f(3)$.}

\textbf{Solution:} Read the conditions before the formulas. The first says $x < 3$, which stops just short of $3$; the second says $x \ge 3$, which includes it. So $3$ belongs to the second rule: $12 - 3$. \ans{9}

\problem{Using the same $f$, find $f(2)$ and $f(5)$.}

\textbf{Solution:} $2 < 3$ takes the first rule; $5 \ge 3$ takes the second.
\begin{align*}
  f(2) &= 2(2) + 1 = 4 + 1 \\
  f(5) &= 12 - 5
\end{align*}
\[ \boxed{f(2) = 5, \quad f(5) = 7} \]

\problem{Leo computes $g(4) = 3(4)+1 = 13$, where $g(x) = x^2 - 2$ for $x \le 4$ and $3x+1$ for $x > 4$. (a) Name his error. (b) Find $g(4)$.}

\textbf{(a) --- instructor-judged.} Leo's arithmetic is correct: $3(4)+1$ really is $13$. The error is the choice of rule. The value $4$ satisfies $x \le 4$, so the \emph{first} rule owns the boundary; the second is written for $x > 4$ strictly, so it says nothing at all about $x = 4$. Full credit requires naming the condition that decides it, not merely recomputing.

\textbf{Solution (b):} $g(4) = 4^2 - 2 = 16 - 2$. \ans{14}

\problem{With $g$ as above and $g(x) = 23$: (a) solve $x^2 - 2 = 23$; (b) which value is genuine?}

\textbf{Solution (a):} $x^2 = 25$, and two numbers square to $25$.
\[ \boxed{x = -5 \quad \text{and} \quad x = 5} \]
\textbf{(b) --- instructor-judged.} Only $x = -5$ is a solution of $g(x) = 23$. Both values satisfy the \emph{formula}, but the formula $x^2 - 2$ is only in force when $x \le 4$. Since $-5 \le 4$, that value survives; since $5 > 4$, the rule does not apply there and the value must be discarded. Full credit requires rejecting $5$ on the condition. Calling $5$ an arithmetic mistake is wrong --- it does satisfy the equation. (For completeness: on the other branch $3x + 1 = 23$ gives $x = 7\tfrac{1}{3}$, which does satisfy $x > 4$, so a full investigation finds that solution too; the question here asks only about the first rule.)

\problem{$h(x) = 3x + k$ for $x < 2$, and $x^2 + 1$ for $x \ge 2$. Find $k$ so there is no jump at $x = 2$.}

\textbf{Solution:} ``No jump'' means the two formulas produce the same value at the boundary, so set them equal \emph{at $x = 2$} --- not at any other input.
\begin{align*}
  3(2) + k &= 2^2 + 1 \\
  6 + k &= 5
\end{align*}
\ans{k = -1}

\problem{Sofia writes the second condition of $C(t) = 2t+2$ ($0 \le t \le 2$), $4t$ ($t > 2$) as $t \ge 2$. (a) Name the error. (b) $C(2)$. (c) $C(3)$.}

\textbf{(a) --- instructor-judged.} With $t \ge 2$ on the second rule, both conditions would claim $t = 2$, and the two formulas disagree there: $2(2)+2 = 6$ while $4(2) = 8$. A price list that returns two different costs for the same two-hour stay is not a function --- each input must have exactly one output. Full credit requires naming the overlap \emph{and} the two conflicting values. Saying only ``the sign should be $>$'' with no reason is partial credit.

\textbf{Solution (b):} As printed, $t = 2$ satisfies $0 \le t \le 2$, so the first rule applies: $2(2) + 2$. \ans{6}

\textbf{Solution (c):} $3 > 2$, so the second rule: $4(3)$. \ans{12}

\problem{$p(x) = cx$ for $x < 5$, and $2x + 5$ for $x \ge 5$. Find $c$ so there is no jump at $x = 5$.}

\textbf{Solution:} Equate the two formulas at the boundary $x = 5$, carrying the whole second formula --- the constant $5$ is part of it.
\begin{align*}
  c(5) &= 2(5) + 5 \\
  5c &= 15
\end{align*}
\ans{c = 3}

\problem{\textbf{Synthesis challenge.} $q(x) = x + a$ for $x \le -1$, and $x^2$ for $x > -1$. (a) Find $a$. (b) $q(-1)$ and $q(2)$. (c) Which rule gives $q(-1)$, and why?}

\textbf{Solution (a):} Set the formulas equal at $x = -1$: $-1 + a = (-1)^2 = 1$. \ans{a = 2}

\textbf{Solution (b):} With $a = 2$: the input $-1$ satisfies $x \le -1$, so use $x + a$; the input $2$ satisfies $x > -1$, so use $x^2$.
\begin{align*}
  q(-1) &= -1 + 2 \\
  q(2) &= 2^2
\end{align*}
\[ \boxed{q(-1) = 1, \quad q(2) = 4} \]
\textbf{(c) --- instructor-judged.} $q(-1)$ comes from the first rule, $x + a$, because that rule's condition is written with $\le$ and therefore includes the boundary; the second rule is written for $x > -1$ strictly and does not reach it. Full credit also requires the second half: if both conditions used $\le$, the input $-1$ would be claimed by both rules and the definition would hand back two outputs for one input, so it would not define a function. (Choosing $a = 2$ makes the two agree there, which is why the graph has no jump --- but agreement is a bonus, not what makes the definition legal.) Answering only that ``the value would be different'' is not full credit.
