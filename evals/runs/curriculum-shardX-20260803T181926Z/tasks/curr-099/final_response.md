# Reading graphs carefully — find the mistake, then fix it (Grades 2–3)

Three PDFs: the student worksheet, a step-by-step answer key, and a two-page
study guide.

**What the worksheet does.** Eight problems, every one of them about the same
family of slip: reading a graph's *scale* wrong, or naming a shape by how it
looks instead of by counting. Two graphs sit at the top of the sheet and are
used by name, so a young reader is never hunting for which picture belongs to
which question.

* Graph A is a bar graph of books read, drawn deliberately with a scale of
  **two per step** — the single most common source of bar-graph errors at this
  age. Problems 1–4 read it: one straight reading, one difference, and two
  find-and-fix items where a character counted steps instead of books.
* Graph B is a line plot of pencils per box. Problem 5 is a find-and-fix where
  a character confused the number *under* the line with the number of *marks*
  above it. Problem 6 asks which number happened most often, with the same
  confusion available and warned against.
* Problem 7 is a find-and-fix on shape attributes: a side-count table with two
  entries swapped, checked against four drawn shapes.
* Problem 8 is open: draw a four-sided shape that is not a square and say in one
  sentence what a square has that it does not.

Difficulty climbs from 1 to 4 across the sheet.

**What was machine-verified.** Seven of the eight answers were recomputed from
the same data that draws the graphs — the bar heights, the line-plot marks and
the side-count table are all read out of one source, so the picture and the
answer key cannot disagree. Seven misconception traps are declared and each was
proved to give a *different* number from the correct answer, which is what makes
these find-and-fix items diagnostic: if your child writes 3 on problem 2 or 6 on
problem 4, the answer key names the exact step they took.

**What is flagged for manual review.** Problem 8 only, because it asks for a
drawing and a sentence. The answer key gives a model drawing, lists several
other correct answers, and says what a full-credit sentence must name.

**The study guide** has three sections — reading the numbers up the side,
counting the marks on a line plot, and naming a shape by counting — each with a
short rule box, a worked example (with its own small line plot to read), and a
try-it whose answer is printed upside down inside the box.
