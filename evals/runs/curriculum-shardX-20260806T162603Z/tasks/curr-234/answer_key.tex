\problem{$f(x) = 5x + 1$. \quad Find $f(4)$.}

\textbf{Solution:} \quad The $4$ inside the brackets is the input, so it replaces $x$:
$f(4) = 5(4) + 1 = 20 + 1$. \ans{f(4) = 21}

\problem{Devin wrote $h(-2) = 4(-9) - 2 = -38$ for $h(x) = 4x - 9$. Correct it and say what he did wrong.}

\textbf{(a) Solution:} \quad The input is $-2$, so $-2$ replaces $x$ and the $-9$ stays where it
is: $h(-2) = 4(-2) - 9 = -8 - 9$. \ans{h(-2) = -17}

\textbf{(b) Diagnosis (instructor-judged).} A correct response says the two numbers were
swapped: Devin multiplied $4$ by the constant $-9$ and then subtracted the input $-2$, when the
input belongs in the $x$ slot and the constant stays at the end. Accept any wording that names
the swap. Correcting the value without saying what went wrong is only half the task.

\problem{$f(x) = 2x + 7$. \quad Find the value of $x$ for which $f(x) = 15$.}

\textbf{Solution:} \quad Here $15$ is the \textit{output}, so it goes on the left of the equals
sign and $x$ stays unknown. Solve $2x + 7 = 15$:
\[ 2x = 8, \qquad x = \tfrac{8}{2} \]
Check by substituting back: $2(4) + 7 = 15$ $\checkmark$. \ans{x = 4}

\problem{From the table for $t$: find $t(4)$, and find the input $n$ with $t(n) = 8$.}

\textbf{Solution:} \quad The two questions travel through the table in opposite directions.
For $t(4)$, find $4$ in the top row and read down: the output is $18$. For $t(n) = 8$, find $8$
in the bottom row and read up: the input is $2$.
\[ \boxed{t(4) = 18 \qquad n = 2} \]

\problem{Rosa was asked which input of $c$ gives an output of $19$, and answered $19$. Correct
her and say what went wrong.}

\textbf{(a) Solution:} \quad Find $19$ in the output row of the table and read up to the input
row above it. The input paired with $19$ is $3$. \ans{x = 3}

\textbf{(b) Diagnosis (instructor-judged).} A correct response says that $19$ is an output --- it
lives in the bottom row --- and the question asked for the input in the top row that produces it.
Accept any wording that separates the two rows or the two roles. Simply writing the corrected
number is not a diagnosis.

\problem{$f(x) = 3x + 4$, $g(x) = 4x + 3$. Compare $f(2)$ and $g(2)$, and judge the claim that
they must be equal.}

\textbf{Solution:} \quad $f(2) = 3(2) + 4 = 6 + 4 = 10$ and $g(2) = 4(2) + 3 = 8 + 3 = 11$, so
the first is smaller. \ans{10 < 11}

\textbf{Judgement (instructor-judged).} A correct response says the claim is wrong and explains
why swapping matters: only the coefficient is multiplied by the input, so moving the $3$ and the
$4$ changes which number gets doubled. Accept any wording that ties the difference to the
coefficient. A bare ``no'' is not an explanation.

\problem{$p(x) = -2x + 11$. \quad (a) Find $p(5)$. \quad (b) Find $x$ with $p(x) = 5$.}

\textbf{Solution:} \quad In (a) the $5$ is an input, so substitute it:
$p(5) = -2(5) + 11 = -10 + 11$. In (b) the $5$ is an output, so it goes on the right of the
equation and you solve: $-2x + 11 = 5$, so $-2x = -6$ and $x = 3$. The same number plays
opposite roles in the two parts.
\[ \boxed{p(5) = 1 \qquad x = 3} \]

\noindent\rule{\linewidth}{0.2pt}

\problem{$d(x) = 3x + 2$ and $d(6) = 20$. Rewrite Kofi's sentence correctly, then check the
statement with the rule.}

\textbf{(a) Rewrite (instructor-judged).} A correct sentence puts $6$ in the input role and $20$
in the output role: ``when the input is $6$, the output is $20$''. Accept any equivalent wording
(``$d$ takes $6$ to $20$'', ``an input of $6$ gives an output of $20$''). Kofi has the two roles
the wrong way round, so his sentence describes a different pairing entirely.

\textbf{(b) Solution:} \quad Substitute the input into the rule: $d(6) = 3(6) + 2 = 18 + 2$,
which confirms the statement is true. \ans{d(6) = 20}
