\begin{center}
\textit{Mean, median and mode; range and interquartile range; and choosing the
pair that describes a data set honestly}
\end{center}

\noindent\textbf{Directions:}
\begin{itemize}
  \item \textbf{Worked pattern.} For $6, 2, 4, 8$: the mean is
        $(6 + 2 + 4 + 8) \div 4 = 5$; in order the values are $2, 4, 6, 8$, so
        the median is $(4 + 6) \div 2 = 5$ and the range is $8 - 2 = 6$.
  \item \textbf{Always order the values first} before finding a median, a
        quartile or a range. Most lost marks on this page start there.
  \item \textbf{Quartiles:} split the ordered values into a lower half and an
        upper half (leave a middle value out if there is one), then take the
        median of each half. Interquartile range $=$ upper $-$ lower.
  \item Show the ordered list in your work space, not just the answer.
\end{itemize}
