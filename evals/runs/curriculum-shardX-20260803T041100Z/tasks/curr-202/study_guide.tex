\sstitleblock{Evaluating Perfect Square Roots and Cube Roots}

\begin{formulabox}
\textbf{A root is a question about equal factors.}
$\sqrt{n} = s$ means $s \cdot s = n$; \; $\sqrt[3]{n} = s$ means
$s \cdot s \cdot s = n$. The index says \emph{how many equal factors}.\\[3pt]
\begin{tabular}{@{}ll@{}}
Squares: & $1,\,4,\,9,\,16,\,25,\,36,\,49,\,64,\,81,\,100,\,121,\,144,\,169,\,196,\,225$ \\
Cubes: & $1,\,8,\,27,\,64,\,125,\,216,\,343,\,512,\,729,\,1000$ \\
\end{tabular}\\[3pt]
If the radicand is in the matching list the root is exact; if it is not, the
root is irrational and can only be bracketed and rounded.
\end{formulabox}

\skillheading{1. Perfect square roots}

\begin{formulabox}
Ask ``what times itself?'' and read the square list. For a radicand past the
list, split it into perfect-square factors and root each piece:
$\sqrt{ab} = \sqrt{a}\sqrt{b}$, e.g. $\sqrt{400} = \sqrt{4}\sqrt{100} = 20$.
\end{formulabox}

\begin{examplebox}
\textbf{Example:} Evaluate $\sqrt{196}$.
\step{The question asks for a factor used twice, so scan the square list instead
of dividing --- division is the operation that produces the classic wrong
answer here.}
\step{$14 \cdot 14 = 196$, and $196$ is in the list, so the root is exact.}
\[ \sqrt{196} = \ans{14} \]
\end{examplebox}

\begin{tryitbox}
\textbf{Try it:} Evaluate $\sqrt{121}$.\\[2pt]
\rotatebox{180}{\footnotesize check: $\ans{11}$}
\end{tryitbox}

\skillheading{2. Perfect cube roots}

\begin{formulabox}
Ask ``what times itself \emph{three} times?'' and read the cube list. Cubes grow
fast, so the list is short --- $\sqrt[3]{1000} = 10$ is the last one worth
memorising. Unlike square roots, cube roots also work on negatives:
$\sqrt[3]{-8} = -2$.
\end{formulabox}

\begin{examplebox}
\textbf{Example:} Evaluate $\sqrt[3]{64}$.
\step{The index is $3$, so the cube list is the right table --- $64$ appears in
both lists, which is exactly why the index has to be read first.}
\step{$4 \cdot 4 \cdot 4 = 64$, so the cube root is $4$ (while the
\emph{square} root of $64$ is $8$).}
\[ \sqrt[3]{64} = \ans{4} \]
\end{examplebox}

\begin{tryitbox}
\textbf{Try it:} Evaluate $\sqrt[3]{125}$.\\[2pt]
\rotatebox{180}{\footnotesize check: $\ans{5}$}
\end{tryitbox}

\skillheading{3. Roots of fractions and decimals}

\begin{formulabox}
A root distributes over a quotient:
$\sqrt{\dfrac{a}{b}} = \dfrac{\sqrt{a}}{\sqrt{b}}$ and
$\sqrt[3]{\dfrac{a}{b}} = \dfrac{\sqrt[3]{a}}{\sqrt[3]{b}}$.\\[2pt]
For a decimal, rewrite it as a fraction first: $0.49 = \frac{49}{100}$,
$0.008 = \frac{8}{1000}$. Whatever you do on top you must do underneath.
\end{formulabox}

\begin{examplebox}
\textbf{Example:} Evaluate $\sqrt{\dfrac{9}{16}}$.
\step{Both parts are in the square list, so splitting the root across the
fraction turns one hard root into two easy ones.}
\step{$\dfrac{\sqrt{9}}{\sqrt{16}} = \dfrac{3}{4}$, and squaring back gives
$\frac{9}{16}$.}
\[ \ans{\tfrac{3}{4}} \]
\end{examplebox}

\begin{tryitbox}
\textbf{Try it:} Evaluate $\sqrt{0.49}$ exactly.\\[2pt]
\rotatebox{180}{\footnotesize check: $\ans{0.7}$}
\end{tryitbox}

\skillheading{4. Estimating a root that is not perfect}

\begin{formulabox}
Trap the radicand between the two nearest entries of the matching list, then the
root sits between their roots:
\[ p^2 < n < q^2 \;\Longrightarrow\; p < \sqrt{n} < q \]
Refine by squaring a guess. A rounded decimal is a \emph{stand-in}: it is
rational, the root is not, so write $\approx$, never $=$.
\end{formulabox}

\begin{examplebox}
\textbf{Example:} Estimate $\sqrt{30}$ to two decimal places.
\step{$30$ is not in the square list, so bracket it first rather than hunting
for an exact value that does not exist.}
\step{$25 < 30 < 36$ gives $5 < \sqrt{30} < 6$; testing $5.5^2 = 30.25$ shows
the root is just under $5.5$, and to two places it is $5.48$.}
\[ \sqrt{30} \approx \ans{5.48} \]
\end{examplebox}

\begin{tryitbox}
\textbf{Try it:} Estimate $\sqrt{90}$ to two decimal places.\\[2pt]
\rotatebox{180}{\footnotesize check: $\ans{9.49}$}
\end{tryitbox}

\begin{watchoutbox}
\textbf{(!) Watch out:} taking a root is not dividing. $\sqrt{144} \neq 72$ and
$\sqrt[3]{27} \neq 9$ --- check by multiplying your answer back out. And read
the index before the radicand: $64$ is in both lists, so $\sqrt{64} = 8$ while
$\sqrt[3]{64} = 4$.
\end{watchoutbox}
