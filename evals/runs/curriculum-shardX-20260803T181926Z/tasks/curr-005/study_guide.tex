\sstitleblock{Counting On to Compare Two Sets}

\begin{formulabox}
\textbf{Counting on.} You do not have to start at one. If you already know one
group holds $5$ (a full row) or $10$ (a full frame), start there and say the
next numbers as you touch the extra things.\\[3pt]
\textbf{The last number you say tells how many.}\\[3pt]
\textbf{To compare, finish both counts first.} Then $>$ means \emph{is greater
than} and $<$ means \emph{is less than}. The open end always faces the bigger
number. If the two counts are the same number, write $=$.
\end{formulabox}

\skillheading{1. Count on to find how many}

\begin{formulabox}
Say the number of the group you already know. Then touch each extra thing and
say the \emph{next} number. Do not go back to one --- going back to one is what
makes children lose count.
\end{formulabox}

\begin{examplebox}
\textbf{Example:} A full row holds $5$ acorns. There are $2$ more beside it.
How many acorns?
\step{The row is full, so its count is already known and only the loose acorns
still need touching.}
\step{Start at five and count on: ``six, seven''. That is $5$ and $2$ more.}

The last number said is $\ans{7}$ acorns.
\end{examplebox}

\begin{tryitbox}
\textbf{Try it:} A full ten-frame holds $10$ beads. There are $3$ more beside
it. How many beads?\\[2pt]
\rotatebox{180}{\footnotesize check: $\ans{13}$}
\end{tryitbox}

\skillheading{2. Compare two sets}

\begin{formulabox}
Count set one. Count set two. \emph{Then} decide. A set that is spread out, or
drawn in a longer row, is not always the bigger one --- only the two numbers
can settle it.
\end{formulabox}

\begin{examplebox}
\textbf{Example:} Ann has $4$ shells and then $3$ more. Ben has $5$ shells and
then $1$ more. Write $>$ or $<$ between them.
\step{Nothing can be compared until each child's set has one number, so count
each set on to the end first.}
\step{Ann: four, then ``five, six, seven''. Ben: five, then ``six''. Seven is
more than six.}

Ann's set is greater: Ann $\ans{>}$ Ben.
\end{examplebox}

\begin{tryitbox}
\textbf{Try it:} Jar A is a full ten-frame and $2$ more. Jar B is a full
ten-frame and $6$ more. Write $>$ or $<$: \; Jar A \underline{\hspace{0.9cm}}
Jar B.\\[2pt]
\rotatebox{180}{\footnotesize check: $\ans{<}$}
\end{tryitbox}

\skillheading{3. Find how many more}

\begin{formulabox}
Start at the \textbf{smaller} number. Count on until you reach the bigger
number. The answer is how many number \emph{words} you said --- the starting
number is not one of them.
\end{formulabox}

\begin{examplebox}
\textbf{Example:} Kim has $5$ marbles. Joe has $8$ marbles. How many more does
Joe have?
\step{This asks how far apart the two counts are, so counting on from the
smaller one up to the bigger one answers it without any subtracting.}
\step{Start at five: ``six, seven, eight''. Three number words were said.}

Joe has $\ans{3}$ more marbles.
\end{examplebox}

\begin{tryitbox}
\textbf{Try it:} Tam has $7$ stickers. Ros has $12$ stickers. How many more
does Ros have?\\[2pt]
\rotatebox{180}{\footnotesize check: $\ans{5}$}
\end{tryitbox}

\begin{watchoutbox}
\textbf{(!) Watch out:} when you count on for ``how many more'', do not say the
starting number as one of the extras --- from five to eight is
``six, seven, eight'', which is three, not four. And a longer row is not
proof: count both sets all the way before you write $>$ or $<$.
\end{watchoutbox}
