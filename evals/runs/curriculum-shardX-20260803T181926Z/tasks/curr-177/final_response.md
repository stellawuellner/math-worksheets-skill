# Two-Step Equations — Grade 7 practice set

Three PDFs are ready:

- **`ss_twostep_curr177.pdf` — Skills Summary (2 pages).** Read this first. Three
  sections, each with a rule box, a worked example, and a "try it" whose answer is
  printed upside down inside the box: (1) solving `ax + b = c` by undoing the
  operations in reverse order, (2) equations where the variable is divided
  (`x/a + b = c`), and (3) checking a solution by substituting it back into the
  original equation. A watch-out box flags the most common slip — forgetting that
  the minus sign belongs to the coefficient.
- **`ws_twostep_curr177.pdf` — Student worksheet (5 pages), 12 problems.** The set
  opens with three straightforward `ax + b = c` equations, then interleaves four
  strands so the student has to *choose* a method rather than repeat one:
  two-step equations, equations with negative coefficients or negative answers,
  division-form equations, and checking. Five problems ask for the solution **and**
  a substitution check; problem 7 is an error-analysis item (Maya's incorrect
  answer) where the student substitutes to show the value is wrong, then solves
  correctly. Difficulty ramps 1 → 4; every problem has 4.5–6 cm of work space and
  its own answer line.
- **`ak_twostep_curr177.pdf` — Answer key (3 pages).** Every problem is restated
  with a step-by-step solution (which operation is undone first and why), plus the
  substitution check written out where the worksheet asks for one. It opens with a
  quick-answer bank for fast grading and a generated Curriculum section listing the
  standard (7.EE.B.4) and the difficulty range. Two "common wrong answers" notes
  are printed: `x` evaluated as `(6-5)x` instead of `6x-5`, and dropping the
  negative sign on the coefficient in `-4x - 9`.

**Verification.** All 17 machine checks (12 solves, 5 substitution evaluations)
were recomputed independently with SymPy and passed — no answer on the key is
hand-asserted. The study guide's six worked examples and try-its were verified the
same way. Both declared misconception traps were confirmed to produce values the
problem's own check rejects, so each trap really does distinguish the error it
targets. **Nothing on this sheet is flagged for manual review** — every problem has
a single checkable numeric answer.
