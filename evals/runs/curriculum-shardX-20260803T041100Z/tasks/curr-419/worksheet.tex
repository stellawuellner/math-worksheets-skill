\wstitleblock{Unit Circle and Trigonometric Graphs --- Diagnosing Degree-Radian and Quadrant-Sign Errors}{Precalculus}{}

\noindent\small Two errors account for most wrong unit-circle answers, and both
produce a clean-looking number:
\begin{itemize}[leftmargin=0.8cm, itemsep=1pt, topsep=2pt]
  \item \textbf{Mode error} --- a bare number is read in the wrong angle unit
        (a calculator left in radian mode, or a conversion run the wrong way).
  \item \textbf{Quadrant-sign error} --- the reference angle's value is copied
        without the sign the quadrant demands.
  \end{itemize}
Give exact values (no decimals) unless a problem asks for a decimal, and state the
quadrant you used. Show the reference angle in your work.\normalsize

\problem[4.5cm]{Warm up. Give the exact value of $\sin\dfrac{7\pi}{6}$.
Name the reference angle and the quadrant before you write the value.}

\problem[5cm]{\textbf{Find and fix.} Reva needs $\sin 30^\circ$. She types
\texttt{sin(30)} into a calculator that is set to radians and reports
$\sin 30^\circ \approx -0.99$.\par
Explain what the calculator actually computed, then give the exact value of
$\sin 30^\circ$.}

\problem[5cm]{\textbf{Find and fix.} Ari evaluates $\cos\dfrac{4\pi}{3}$. He writes:
``the reference angle is $\dfrac{\pi}{3}$ and $\cos\dfrac{\pi}{3} = \dfrac{1}{2}$,
so the answer is $\dfrac{1}{2}$.''\par
Name the step Ari skipped, then give the exact value of $\cos\dfrac{4\pi}{3}$.}

\problem[5cm]{\textbf{Find and fix.} Sena evaluates $\tan 150^\circ$ and reports
$\approx 0.58$, the value of the tangent of its reference angle.\par
State the quadrant of $150^\circ$ and the sign the tangent must carry there, then
give the exact value of $\tan 150^\circ$.}

\problem[5cm]{\textbf{Find and fix.} Bo converts $225^\circ$ to radians by
multiplying by $\dfrac{180}{\pi}$ and gets about $12891.6$.\par
Explain how the size of that answer alone shows the conversion ran the wrong way,
then give the exact radian measure of $225^\circ$.}

\problem[6cm]{Solve $2\sin\theta + 1 = 0$ for $0^\circ \le \theta < 360^\circ$.\par
Cal reports $\theta = 30^\circ$ and $\theta = 150^\circ$. He found the reference
angle correctly and then placed it in the two quadrants where the sine is
\emph{positive}. Give the correct solutions, in degrees.}

\problem[6cm]{Solve $2\cos x - \sqrt{2} = 0$ for $0 \le x < 2\pi$. Give exact
radian answers.\par
State how many solutions you expect before solving, and which quadrants they lie
in.}

\problem[7cm]{\textbf{Challenge.} A student writes ``$\cos 3 = 0.9986$''.\par
\textbf{(a)} Explain what two different angles the bare number $3$ could mean, and
what the student assumed it meant.\par
\textbf{(b)} Compute $\cos 3$ correctly, with $3$ measured in radians, rounded to
two decimal places.\par
\textbf{(c)} Say which quadrant the angle $3$ radians lies in, and explain how that
quadrant alone tells you the sign of your answer in part (b).}
