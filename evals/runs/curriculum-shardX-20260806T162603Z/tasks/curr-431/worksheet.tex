\begin{center}\small\textit{Polar to rectangular, rectangular to polar, choosing the angle by quadrant, and naming one point in more than one way}\end{center}

\vspace{0.1cm}
\noindent\textbf{The picture behind the formulas.} Drop a perpendicular from the point $P$ to the horizontal axis. The right triangle it makes has legs $x$ and $y$ and hypotenuse $r$, with the angle $\theta$ at the origin. Every conversion formula below is read straight off this triangle. \emph{No values are shown here --- use the numbers given in each problem.}

\vspace{-0.1cm}
\noindent\textbf{Directions.}
\begin{itemize}[leftmargin=0.9cm, itemsep=1pt, topsep=3pt]
  \item Polar $\to$ rectangular: $x = r\cos\theta$, \ $y = r\sin\theta$. These always work, including when $r$ is negative.
  \item Rectangular $\to$ polar: $r = \sqrt{x^2 + y^2}$, \ and $\theta$ from $\tan\theta = \dfrac{y}{x}$ --- but the calculator's $\tan^{-1}$ only reports angles between $-90^\circ$ and $90^\circ$, so \textbf{check the quadrant and add $180^\circ$ when $x < 0$}.
  \item Give exact values (radicals, fractions) unless a problem asks for decimals. Use $0^\circ \le \theta < 360^\circ$ unless told otherwise.
\end{itemize}
