\problem{Priya hikes $1\tfrac{1}{4}$ mi and then $2\tfrac{1}{4}$ mi. Total?}

\textbf{Solution:} Add wholes and parts separately: wholes $1 + 2 = 3$;
fourths $\tfrac{1}{4} + \tfrac{1}{4} = \tfrac{2}{4} = \tfrac{1}{2}$.
Total: $3 + \tfrac{1}{2}$, so she hikes
$\ans{3\tfrac{1}{2}\ \text{mi}}$

\problem{A $4\tfrac{3}{8}$ ft board loses a $2\tfrac{1}{8}$ ft piece. How
much is left?}

\textbf{Solution:} Subtract wholes and parts separately: wholes $4 - 2 = 2$;
eighths $\tfrac{3}{8} - \tfrac{1}{8} = \tfrac{2}{8} = \tfrac{1}{4}$.
Board left: $\ans{2\tfrac{1}{4}\ \text{ft}}$

\problem{Recipes use $2\tfrac{2}{3}$ cups and $1\tfrac{2}{3}$ cups of flour.
Total?}

\textbf{Solution:} Wholes: $2 + 1 = 3$. Thirds:
$\tfrac{2}{3} + \tfrac{2}{3} = \tfrac{4}{3} = 1\tfrac{1}{3}$ --- more than a
whole, so regroup it into the whole-number part: $3 + 1\tfrac{1}{3} =
4\tfrac{1}{3}$. Flour needed: $\ans{4\tfrac{1}{3}\ \text{cups}}$

\problem{A pitcher holds $3\tfrac{5}{6}$ L; guests drink $1\tfrac{1}{6}$ L.
How much is left?}

\textbf{Solution:} Wholes: $3 - 1 = 2$. Sixths:
$\tfrac{5}{6} - \tfrac{1}{6} = \tfrac{4}{6} = \tfrac{2}{3}$.
Lemonade left: $\ans{2\tfrac{2}{3}\ \text{L}}$

\problem{Watermelons weigh $1\tfrac{3}{5}$ kg and $2\tfrac{4}{5}$ kg. Total
weight?}

\textbf{Solution:} Wholes: $1 + 2 = 3$. Fifths:
$\tfrac{3}{5} + \tfrac{4}{5} = \tfrac{7}{5} = 1\tfrac{2}{5}$ --- regroup the
extra whole: $3 + 1\tfrac{2}{5} = 4\tfrac{2}{5}$. Total:
$\ans{4\tfrac{2}{5}\ \text{kg}}$

\problem{A spool holds $5\tfrac{1}{4}$ m; Deshi uses $2\tfrac{3}{4}$ m. How
much rope is left?}

\textbf{Solution:} We cannot take $\tfrac{3}{4}$ from $\tfrac{1}{4}$, so
regroup one whole: $5\tfrac{1}{4} = 4\tfrac{5}{4}$. Now subtract: wholes
$4 - 2 = 2$; fourths $\tfrac{5}{4} - \tfrac{3}{4} = \tfrac{2}{4} =
\tfrac{1}{2}$. Rope left: $\ans{2\tfrac{1}{2}\ \text{m}}$

\problem{Jo's pumpkin weighs $6\tfrac{1}{8}$ kg, Ben's $3\tfrac{5}{8}$ kg.
How much heavier is Jo's?}

\textbf{Solution:} $\tfrac{5}{8}$ is more than $\tfrac{1}{8}$, so regroup:
$6\tfrac{1}{8} = 5\tfrac{9}{8}$. Wholes: $5 - 3 = 2$. Eighths:
$\tfrac{9}{8} - \tfrac{5}{8} = \tfrac{4}{8} = \tfrac{1}{2}$. Difference:
$\ans{2\tfrac{1}{2}\ \text{kg}}$

\problem{Mira works $1\tfrac{1}{2}$ hours, then $2\tfrac{1}{4}$ hours. Total
time?}

\textbf{Solution:} The parts have different denominators, so rewrite halves
as fourths: $\tfrac{1}{2} = \tfrac{2}{4}$. Wholes: $1 + 2 = 3$. Fourths:
$\tfrac{2}{4} + \tfrac{1}{4} = \tfrac{3}{4}$. Total time:
$\ans{3\tfrac{3}{4}\ \text{hours}}$

\problem{Zoe needs $4\tfrac{1}{3}$ m of fabric and has $1\tfrac{2}{3}$ m.
How much more does she need?}

\textbf{Solution:} Missing amount $= 4\tfrac{1}{3} - 1\tfrac{2}{3}$. Regroup:
$4\tfrac{1}{3} = 3\tfrac{4}{3}$. Wholes: $3 - 1 = 2$. Thirds:
$\tfrac{4}{3} - \tfrac{2}{3} = \tfrac{2}{3}$. She needs
$\ans{2\tfrac{2}{3}\ \text{m}}$ more.

\problem{A 6-cup bowl gets $2\tfrac{3}{4}$ cups of orange juice and
$1\tfrac{3}{4}$ cups of pineapple juice. How much more fills it?}

\textbf{Solution:} First the juice so far:
$2\tfrac{3}{4} + 1\tfrac{3}{4} = 3 + \tfrac{6}{4} = 3 + 1\tfrac{2}{4} =
4\tfrac{1}{2}$ cups. Then the space left:
$6 - 4\tfrac{1}{2} = 5\tfrac{2}{2} - 4\tfrac{1}{2}$, which leaves
$\ans{1\tfrac{1}{2}\ \text{cups}}$
