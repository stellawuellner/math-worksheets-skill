\problem{$P$ moves so that $PC = 5$ with $C(3,-2)$. Write the expanded equation.}

\textbf{Solution:} ``Distance from $C$ is $5$'' is the definition of a circle, so square the distance formula:
\begin{align*}
  (x-3)^{2} + (y+2)^{2} &= 25 \\
  x^{2} - 6x + 9 + y^{2} + 4y + 4 &= 25
\end{align*}
Collecting the constants gives \ans{x^{2} + y^{2} - 6x + 4y - 12 = 0}

\problem{$x^{2} = 12y$ (focus $(0,3)$, directrix $y = -3$). Find $y$ when $x = 6$.}

\textbf{Solution:} $36 = 12y$, so $y = 3$. Notice the point $(6, 3)$ sits level with the focus --- its distance to the focus is $6$ and its distance to the directrix is $3 - (-3) = 6$. \ans{y = 3}

\vspace{0.1cm}\noindent\rule{\linewidth}{0.2pt}

\problem{Where does $y = x^{2}$ meet $y = 4$?}

\textbf{Solution:} Setting the two expressions for $y$ equal gives $x^{2} = 4$, and a horizontal line cuts the parabola twice.
\[ \boxed{x = -2 \quad \text{and} \quad x = 2} \]

\vspace{0.1cm}\noindent\rule{\linewidth}{0.2pt}

\problem{$x^{2} + y^{2} - 6x + 4y - 12 = 0$. Complete the square and state the radius.}

\textbf{Solution:} Group and complete each square:
\begin{align*}
  \left(x^{2} - 6x + 9\right) + \left(y^{2} + 4y + 4\right) &= 12 + 9 + 4 \\
  (x - 3)^{2} + (y + 2)^{2} &= 25
\end{align*}
The centre is $(3, -2)$ and the radius is $\sqrt{25}$. \ans{r = 5}

\vspace{0.1cm}\noindent\rule{\linewidth}{0.2pt}

\problem{Vertex $(0,0)$, focus $(0,5)$, $x^{2} = 4py$. \textbf{(a)} $4p$. \textbf{(b)} $x$ when $y = 5$.}

\textbf{Solution (a):} $p$ is the directed distance from the vertex to the focus, so $p = 5$ and $4p = 20$. \ans{4p = 20}

\textbf{Solution (b):} The equation is $x^{2} = 20y$, so at $y = 5$: $x^{2} = 100$. This chord through the focus has length $20$, which is exactly $|4p|$.
\[ \boxed{x = -10 \quad \text{and} \quad x = 10} \]

\vspace{0.1cm}\noindent\rule{\linewidth}{0.2pt}

\problem{Intersect $y = x^{2} - 3$ with $y = 2x$.}

\textbf{Solution:} Substitute the line into the parabola:
\begin{align*}
  x^{2} - 3 &= 2x \\
  x^{2} - 2x - 3 &= 0 \\
  (x - 3)(x + 1) &= 0
\end{align*}
Then $y = 2x$ gives the matching heights: $x = 3 \Rightarrow y = 6$, and $x = -1 \Rightarrow y = -2$.
\[ \boxed{(3,\ 6) \quad \text{and} \quad (-1,\ -2)} \]

\vspace{0.1cm}\noindent\rule{\linewidth}{0.2pt}

\problem{$PA = 2\,PB$ with $A(0,0)$, $B(6,0)$. \textbf{(a)} Simplify. \textbf{(b)} Radius.}

\textbf{Solution (a):} Squaring the condition avoids the radicals: $PA^{2} = 4\,PB^{2}$.
\begin{align*}
  x^{2} + y^{2} &= 4\left[(x-6)^{2} + y^{2}\right] \\
  x^{2} + y^{2} &= 4x^{2} - 48x + 144 + 4y^{2} \\
  0 &= 3x^{2} + 3y^{2} - 48x + 144
\end{align*}
Dividing by $3$ gives \ans{x^{2} + y^{2} - 16x + 48 = 0}

\textbf{Solution (b):} Complete the square: $(x - 8)^{2} + y^{2} = 64 - 48 = 16$. The centre is $(8, 0)$ --- not at $A$, not at $B$, and not at their midpoint. \ans{r = 4}

\vspace{0.1cm}\noindent\rule{\linewidth}{0.2pt}

\problem{Intersect $x^{2} + y^{2} = 25$ with $y = x + 1$.}

\textbf{Solution:} Substitute the line into the circle:
\begin{align*}
  x^{2} + (x + 1)^{2} &= 25 \\
  2x^{2} + 2x - 24 &= 0 \\
  x^{2} + x - 12 &= 0 \\
  (x - 3)(x + 4) &= 0
\end{align*}
Back-substituting into $y = x + 1$: $x = 3 \Rightarrow y = 4$, and $x = -4 \Rightarrow y = -3$.
\[ \boxed{(3,\ 4) \quad \text{and} \quad (-4,\ -3)} \]

\vspace{0.1cm}\noindent\rule{\linewidth}{0.2pt}

\problem{$y^{2} = 8x$ (focus $(2,0)$, directrix $x = -2$). \textbf{(a)} $y$ when $x = 2$. \textbf{(b)} Locus argument for $(2,4)$.}

\textbf{Solution (a):} $y^{2} = 8(2) = 16$.
\[ \boxed{y = -4 \quad \text{and} \quad y = 4} \]

\textbf{Solution (b):} \emph{Instructor-judged.} The argument has to use the defining property. Distance from $(2,4)$ to the focus $(2,0)$ is $4$; distance from $(2,4)$ to the directrix $x = -2$ is $2 - (-2) = 4$. Equal distances is precisely what places a point on the parabola. Substituting into $y^{2} = 8x$ checks the algebra rather than the definition and earns no credit for this part.

\vspace{0.1cm}\noindent\rule{\linewidth}{0.2pt}

\problem{$PA^{2} + PB^{2} = 50$ with $A(-3,0)$, $B(3,0)$. \textbf{(a)} Simplify. \textbf{(b)} Describe the locus.}

\textbf{Solution (a):} Write both squared distances and add:
\begin{align*}
  (x+3)^{2} + y^{2} + (x-3)^{2} + y^{2} &= 50 \\
  2x^{2} + 18 + 2y^{2} &= 50 \\
  2x^{2} + 2y^{2} - 32 &= 0
\end{align*}
Dividing by $2$ gives \ans{x^{2} + y^{2} - 16 = 0}

\textbf{Solution (b):} \emph{Instructor-judged.} A complete answer names all three features and points to the equation for each: it is a circle (the $x^{2}$ and $y^{2}$ coefficients match and are positive), centred at the origin (no $x$ or $y$ term survived), with radius $4$ (since $x^{2} + y^{2} = 16$). The observation worth crediting is that $A$ and $B$ have disappeared from the answer: the cross terms cancelled, so the condition does not care which fixed point $P$ is nearer. Shape alone, without centre and radius, is half credit.

\vspace{0.1cm}\noindent\rule{\linewidth}{0.2pt}

\problem{Intersect $x^{2} + y^{2} = 25$ with $y = x^{2} - 13$.}

\textbf{Solution:} The parabola gives $x^{2} = y + 13$; substitute that into the circle so the equation is in $y$ alone:
\begin{align*}
  (y + 13) + y^{2} &= 25 \\
  y^{2} + y - 12 &= 0 \\
  (y + 4)(y - 3) &= 0
\end{align*}
For $y = 3$: $x^{2} = 16$, so $x = \pm 4$. For $y = -4$: $x^{2} = 9$, so $x = \pm 3$. Each $y$ supplies two points, which is why there are four.
\[ \boxed{(4,\ 3),\ (-4,\ 3),\ (3,\ -4),\ (-3,\ -4)} \]

\vspace{0.1cm}\noindent\rule{\linewidth}{0.2pt}

\problem{$y = x + k$ meets $x^{2} + y^{2} = 8$ at exactly one point. \textbf{(a)} Find $k$. \textbf{(b)} What one point means.}

\textbf{Solution (a):} Substitute and collect:
\begin{align*}
  x^{2} + (x + k)^{2} &= 8 \\
  2x^{2} + 2kx + \left(k^{2} - 8\right) &= 0
\end{align*}
One intersection means one repeated root, so the discriminant vanishes:
\begin{align*}
  (2k)^{2} - 4(2)\left(k^{2} - 8\right) &= 0 \\
  -4k^{2} + 64 &= 0
\end{align*}
\[ \boxed{k = -4 \quad \text{and} \quad k = 4} \]

\textbf{Solution (b):} \emph{Instructor-judged.} Two links are needed. Algebraically, exactly one intersection means the quadratic in $x$ has a repeated root, which is what a zero discriminant says. Geometrically, that is the line touching the circle at a single point --- a tangent, and the two values of $k$ are the tangent lines of slope $1$ on either side of the centre. A response that computes the discriminant without saying what a repeated root means for the picture, or that says ``tangent'' without the discriminant, has made only one of the two links.
