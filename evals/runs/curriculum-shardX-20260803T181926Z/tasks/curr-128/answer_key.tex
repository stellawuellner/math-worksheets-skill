\problem{\textbf{Rosa's walk: $2\tfrac{3}{8} + 1\tfrac{1}{8}$ miles.}

\textbf{Step 1.} Both distances are measured in eighths, so the fraction parts
can be added directly --- no rewriting is needed.

\textbf{Step 2.} Wholes: $2 + 1 = 3$. Eighths: $\tfrac{3}{8} + \tfrac{1}{8} =
\tfrac{4}{8}$.

\textbf{Step 3.} $\tfrac{4}{8}$ simplifies to $\tfrac{1}{2}$, so Rosa walked
\ans{3\,\tfrac{1}{2} \text{ miles}}

\textit{Teaching note:} the sum of the fraction parts is less than one whole
here, so nothing is traded. Problem 3 is the case where something is.}

\problem{\textbf{Juice: $1\tfrac{5}{12} + 3\tfrac{1}{12}$ cups.}

\textbf{Step 1.} Twelfths and twelfths again --- like denominators, so add the
two parts separately.

\textbf{Step 2.} Wholes: $1 + 3 = 4$. Twelfths: $\tfrac{5}{12} + \tfrac{1}{12}
= \tfrac{6}{12}$.

\textbf{Step 3.} $\tfrac{6}{12}$ is one half, so the recipe uses
\ans{4\,\tfrac{1}{2} \text{ cups}}

\textit{Listen for:} an answer of $4\tfrac{6}{24}$ --- the denominators were
added too. Twelfths plus twelfths are still twelfths.}

\problem{\textbf{Practice time: $2\tfrac{5}{6} + 1\tfrac{4}{6}$ hours.}

\textbf{Step 1.} Like denominators again, but watch the fraction column: five
sixths plus four sixths is more than one whole, so this sum will need
regrouping.

\textbf{Step 2.} Wholes: $2 + 1 = 3$. Sixths: $\tfrac{5}{6} + \tfrac{4}{6} =
\tfrac{9}{6}$, which is $1\tfrac{3}{6}$.

\textbf{Step 3.} Trade the extra whole: $3 + 1\tfrac{3}{6} = 4\tfrac{3}{6}$,
and $\tfrac{3}{6}$ is one half. Devon practised
\ans{4\,\tfrac{1}{2} \text{ hours}}

\textit{Common wrong answer:} $3\tfrac{9}{12}$ --- the denominators were added
along with the numerators.}

\problem{\textbf{Birdseed: $5\tfrac{1}{4} - 2\tfrac{3}{4}$ pounds.}

\textbf{Step 1.} Three quarters cannot be taken from one quarter, so regroup
before subtracting: borrow one whole from the $5$.

\textbf{Step 2.} $5\tfrac{1}{4} = 4 + \tfrac{4}{4} + \tfrac{1}{4} =
4\tfrac{5}{4}$.

\textbf{Step 3.} Now subtract in columns: $4 - 2 = 2$ and $\tfrac{5}{4} -
\tfrac{3}{4} = \tfrac{2}{4} = \tfrac{1}{2}$, so the birdseed left in the bag
is \ans{2\,\tfrac{1}{2} \text{ pounds}}

\textit{Common wrong answer:} $3\tfrac{2}{4}$ --- the smaller fraction was
taken from the larger one in the fraction column, which quietly changes the
problem.}

\problem{\textbf{Pitcher: poured out $3\tfrac{2}{5}$ cups, $4\tfrac{3}{5}$ cups
left.}

\textbf{Step 1.} The starting amount is unknown, so name it $x$ and write what
the story does to it: $x - 3\tfrac{2}{5} = 4\tfrac{3}{5}$.

\textbf{Step 2.} Undo the pouring by adding the two known amounts:
$x = 4\tfrac{3}{5} + 3\tfrac{2}{5}$.

\textbf{Step 3.} Wholes: $4 + 3 = 7$. Fifths: $\tfrac{3}{5} + \tfrac{2}{5} =
\tfrac{5}{5}$, one more whole. So the pitcher held
\ans{8 \text{ cups}}

\textit{Teaching note:} the fraction parts made exactly one whole, so the
answer has no fraction left. That is worth pointing out --- it is the same
trade as problem 3, just complete.}

\problem{\textbf{Broth: $1\tfrac{1}{2} + 2\tfrac{1}{3}$ cups.}

\textbf{Step 1.} Halves and thirds are different-sized pieces, so they cannot
be added until both are written over the same denominator. The smallest number
both $2$ and $3$ divide is $6$.

\textbf{Step 2.} $\tfrac{1}{2} = \tfrac{3}{6}$ and $\tfrac{1}{3} =
\tfrac{2}{6}$.

\textbf{Step 3.} Wholes: $1 + 2 = 3$. Sixths: $\tfrac{3}{6} + \tfrac{2}{6} =
\tfrac{5}{6}$. The pot holds \ans{3\,\tfrac{5}{6} \text{ cups}}

\textit{Listen for:} $3\tfrac{2}{5}$, which is what adding straight across
gives. Ask which is bigger, a half or a fifth.}

\problem{\textbf{Bike path: $4\tfrac{3}{4} - 1\tfrac{2}{3}$ miles.}

\textbf{Step 1.} Fourths and thirds again need one common denominator; $12$ is
the smallest number both $4$ and $3$ divide.

\textbf{Step 2.} $\tfrac{3}{4} = \tfrac{9}{12}$ and $\tfrac{2}{3} =
\tfrac{8}{12}$. Nine twelfths is larger than eight twelfths, so no regrouping
is needed.

\textbf{Step 3.} Wholes: $4 - 1 = 3$. Twelfths: $\tfrac{9}{12} - \tfrac{8}{12}
= \tfrac{1}{12}$, so Priya still has to ride
\ans{3\,\tfrac{1}{12} \text{ miles}}

\textit{Common wrong answer:} $3\tfrac{1}{1}$, from subtracting numerators and
denominators straight across. Denominators name the piece size; they are never
subtracted.}

\problem{\textbf{Rain barrel: held $7\tfrac{1}{6}$ gallons, $3\tfrac{5}{6}$
gallons left.}

\textbf{Step 1.} The amount used is unknown, so call it $x$ and write the
story as an equation: $7\tfrac{1}{6} - x = 3\tfrac{5}{6}$.

\textbf{Step 2.} That makes $x = 7\tfrac{1}{6} - 3\tfrac{5}{6}$. Five sixths
cannot be taken from one sixth, so regroup: $7\tfrac{1}{6} = 6\tfrac{7}{6}$.

\textbf{Step 3.} Wholes: $6 - 3 = 3$. Sixths: $\tfrac{7}{6} - \tfrac{5}{6} =
\tfrac{2}{6} = \tfrac{1}{3}$. The gardener used
\ans{3\,\tfrac{1}{3} \text{ gallons}}

\textit{Teaching note:} checking is quick and worth doing:
$3\tfrac{1}{3} + 3\tfrac{5}{6}$ must return $7\tfrac{1}{6}$.}

\problem{\textbf{Error analysis: Sam wrote $4\tfrac{4}{8}$ for $6\tfrac{1}{8} -
2\tfrac{5}{8}$ inches.}

\textbf{Step 1.} Look only at the fraction column. Sam needed
$\tfrac{1}{8} - \tfrac{5}{8}$, could not do it, and turned it around into
$\tfrac{5}{8} - \tfrac{1}{8}$ instead. Reversing a subtraction changes the
problem; the fix is to regroup.

\textbf{Step 2.} Borrow one whole from the $6$: $6\tfrac{1}{8} = 5\tfrac{9}{8}$
because one whole is $\tfrac{8}{8}$.

\textbf{Step 3.} Wholes: $5 - 2 = 3$. Eighths: $\tfrac{9}{8} - \tfrac{5}{8} =
\tfrac{4}{8} = \tfrac{1}{2}$. The trim is
\ans{3\,\tfrac{1}{2} \text{ inches}}

\textit{What to say:} Sam's answer is bigger than the starting length minus
two whole inches, which is a signal by itself. Estimating first
($6 - 3 \approx 3$) catches this error every time.}

\problem{\textbf{Flour: $3\tfrac{1}{4} - 1\tfrac{2}{3}$ cups.}

\textbf{Step 1.} This one needs both moves: a common denominator first, and
then regrouping, because a quarter is smaller than two thirds. Use twelfths.

\textbf{Step 2.} $3\tfrac{1}{4} = 3\tfrac{3}{12}$ and $1\tfrac{2}{3} =
1\tfrac{8}{12}$. Three twelfths is less than eight twelfths, so regroup:
$3\tfrac{3}{12} = 2\tfrac{15}{12}$.

\textbf{Step 3.} Wholes: $2 - 1 = 1$. Twelfths: $\tfrac{15}{12} -
\tfrac{8}{12} = \tfrac{7}{12}$, so Ana still needs
\ans{1\,\tfrac{7}{12} \text{ cups}}

\textit{Teaching note:} estimate first --- a bit over $3$ minus a bit under $2$
should land near $1\tfrac{1}{2}$, and $1\tfrac{7}{12}$ does.}
