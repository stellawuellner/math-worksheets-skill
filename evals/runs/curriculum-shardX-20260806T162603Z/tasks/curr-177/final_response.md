# Two-Step Equations & Checking Solutions (Grades 6-7)

Three PDFs are ready:

- **Worksheet** (`ws_twostep_curr177.pdf`) — 12 problems for procedural
  fluency. It opens with a fully worked pattern (3x + 4 = 10, undo-then-check),
  then ramps through varied skeletons — ax + b = c with negative results, x/a
  forms, variable on the right, a grouped (x + 5)/3, negative coefficients —
  with no two problems sharing an identical skeleton. Checking solutions is
  practiced explicitly: one problem verifies a classmate's claimed solution by
  substitution, one find-and-fix catches a wrong solution through its failed
  check, and the finale is a bike-rental equation solved and checked.
- **Answer key** (`ak_twostep_curr177.pdf`) — every solution shows both undo
  steps and the substitution check, plus a quick-answers column, a
  common-wrong-answer note for the planted error (x = 3 from subtracting
  instead of adding 6), and the curriculum section (7.EE.B.4).
- **Study guide** (`ss_twostep_curr177.pdf`) — a two-page card with four
  sections: ax + b = c, x/a + b = c, negative coefficients (with a sign
  watch-out), and checking by substitution, each with rule, strategy-first
  worked example, and an upside-down-answer try-it.

**What is verified:** 13 of the 15 responses the worksheet asks for are
machine-checked with a computer algebra system (all ten equation solutions,
both substitution values, and the planted wrong answer proven to fail the
problem's own check). The 2 written parts — 7(b) and 11(c), one-sentence
judgments/error naming — are open responses flagged for instructor review,
with the key stating what each correct sentence must contain. The key's
"What is verified" note reflects the same split.
