\problem{Ravi was asked to plot $(2, 5)$ on the Grid. His mark landed on point $B$. (a) Write $B$'s ordered pair. (b) Explain the mistake.}

\textbf{Solution (a):} Read $B$ the way any point is read --- across first, then up. It sits 5 squares across and 2 squares up. \ans{(5, 2)}

\textbf{(b) --- instructor-judged.} Look for a response naming the order: the first number of an ordered pair counts \emph{across} and the second counts \emph{up}, so Ravi used 5 as the across number when it was meant to be the up number. $(2, 5)$ and $(5, 2)$ are different places built from the same two digits.

Saying only ``he put it in the wrong spot'' describes the symptom, not the error.

\problem{Leo says Thursday shows 7 books because the bar reaches the 7th mark. How many books does Thursday actually show?}

\textbf{Solution:} The vertical axis is marked every 5 books, so each mark is worth 5, not 1. Seven marks means $7 \times 5$. \ans{35}

\emph{Common wrong answer:} 7 --- the number of marks, read as if the axis counted single books.

\vspace{0.15cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.15cm}

\problem{Sam counted the marks on the Wednesday bar and reported 2 books. (a) How many books does Wednesday actually show? (b) Explain Sam's mistake.}

\textbf{Solution (a):} Two marks, each worth 5 books: $2 \times 5$. \ans{10}

\textbf{(b) --- instructor-judged.} Look for a response that names the size of one interval: on this axis the gap between marks is 5 books, so counting marks gives the number of \emph{marks}, and each one still has to be multiplied by 5. The first thing to read on any graph is what one interval is worth.

\emph{Common wrong answer:} 2 --- the mark count reported as the book count.

\vspace{0.15cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.15cm}

\problem{Points $C$ and $D$ are a reversed pair. Measured left to right, how far apart are they?}

\textbf{Solution:} $C$ is at $(4, 7)$ and $D$ is at $(7, 4)$. Left-to-right distance uses only the across numbers: $7 - 4$. \ans{3 \text{ units}}

\emph{Common wrong answer:} 0 --- from assuming that a reversed pair names the same place. It does not, and this problem measures exactly how far apart the two readings put you.

\vspace{0.15cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.15cm}

\problem{Mia added the mark counts and reported 21 books for the week. How many books were actually read?}

\textbf{Solution:} Read each bar in books, then add: $15 + 25 + 10 + 35 + 20$. \ans{105}

\emph{Common wrong answer:} 21 --- the sum of the mark counts $3 + 5 + 2 + 7 + 4$. Notice that $21 \times 5 = 105$: her total was right in \emph{marks} and simply never converted to books.

\vspace{0.15cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.15cm}

\problem{The data is redrawn with the vertical axis marked every 2 books. (a) How many marks tall is the Friday bar now? (b) Were more books read on Friday?}

\textbf{Solution (a):} Friday is 20 books. On an axis where one mark is worth 2 books, that takes $20 \div 2$ marks. \ans{10}

\textbf{(b) --- instructor-judged.} No. Look for a response saying the data did not change --- the same 20 books simply need more marks when each mark is worth less, so the bar is drawn taller. Changing the interval changes the picture, never the amount. A response that compares only the heights has fallen for the trap the question sets.

\emph{Common wrong answer:} 4 --- from keeping the old interval of 5 books per mark on an axis that now uses 2.

\vspace{0.15cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.15cm}

\problem{A student averaged the mark counts and reported 4.2 books per day. (a) Actual mean. (b) Range of the five daily totals.}

\textbf{Solution (a):} Use the book values: $15 + 25 + 10 + 35 + 20 = 105$, and $105 \div 5$. \ans{21}

\textbf{(b)} Largest daily total minus smallest: $35 - 10$. \ans{25}

\emph{Common wrong answer:} 4.2 --- the mean of the mark counts. Again it is out by exactly the interval: $4.2 \times 5 = 21$.

\vspace{0.15cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.15cm}

\problem{A student plots $(3, 30)$ where the horizontal axis is marked every 1 and the vertical axis every 5. The student counts 3 across and 30 up. (a) How many marks up should they have counted? (b) Counting 30 marks up, what $y$-value did the mark reach? (c) Explain the two things that went wrong.}

\textbf{Solution (a):} Each mark up is worth 5, so reaching 30 takes $30 \div 5$ marks. \ans{6}

\textbf{(b)} Counting 30 marks when each is worth 5 lands at $30 \times 5$. \ans{150}

\textbf{(c) --- instructor-judged.} Two separate faults, and a full-credit answer names both.

First, the two axes do not share an interval: 3 marks across really is 3, but the same mark-counting habit is wrong going up. Second, having used the number 30 as a mark count instead of a value, the mark ended at 150 --- five times too high --- so the point plotted is nowhere near $(3, 30)$.

\emph{Common wrong answer:} 30 in part (a) --- from applying the horizontal interval of 1 to the vertical axis.
