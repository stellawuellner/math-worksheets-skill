\problem{A row of dots --- write the numeral that matches.}

\textbf{Solution:} Count one-to-one: ``one, two, three.'' The quantity is
three, and the numeral that shows three is \ans{3}

\problem{The word card says \emph{seven}. Write the numeral.}

\textbf{Solution:} The word \emph{seven} names the same number as the numeral
7 --- word and numeral are two ways to write one number. The numeral is \ans{7}

\problem{Ten-frame: full top row and one more dot. Write the numeral.}

\textbf{Solution:} The full top row is 5. Count on for the bottom row:
``six.'' $5 + 1 = 6$, so the numeral is \ans{6}

\problem{The word card says \emph{nine}. Write the numeral.}

\textbf{Solution:} \emph{Nine} is the number word just before ten in the
counting sequence, so the matching numeral is \ans{9}

\problem{The numeral card shows 8. Draw that many dots.}

\textbf{Solution (instructor-judged):} the numeral 8 tells the child to draw
exactly eight dots. Count the drawn dots one-to-one: eight dots earns credit,
in any arrangement --- rows of four, a ten-frame layout, or a scatter. Seven
or nine dots shows the numeral was read but the one-to-one match slipped.

\problem{Two groups of dots (four dots and three dots). Write the numeral and
the number word.}

\textbf{Solution:} Count through both groups without starting over: ``one,
two, three, four --- five, six, seven.'' $4 + 3 = 7$, so the numeral is \ans{7}

\textbf{Number word (instructor-judged):} the word is \emph{seven}. Accept
invented spelling that clearly reads as seven (such as ``sevin'').

\problem{Ten-frame dots and the numeral card 9: write the numeral for the
dots, then compare with $<$, $>$ or $=$.}

\textbf{Solution:} Full top row is 5, count on ``six, seven, eight'':
$5 + 3 = 8$, so the dots show \ans{8}

Compare 8 with the card's 9: when we count, 8 comes \emph{before} 9, so 8 is
less. \ans{8 < 9}

\problem{Challenge: word card \emph{six}, dot card, numeral card 5 --- write
each as a numeral, then order least to greatest.}

\textbf{Solution:} Card A: the word \emph{six} matches the numeral \ans{6}

Card B: count the dots one-to-one --- the count ends at seven, so \ans{7}

Card C already shows the numeral 5. Now order all three by the counting
sequence: 5 is said first, then 6, then 7. \ans{5,\ 6,\ 7}
