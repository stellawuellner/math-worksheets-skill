\sstitleblock{Handling the Ambiguous SSA Case Completely}

\skillheading{Skill 1 --- The height test}

\begin{formulabox}
Given side $a$, side $b$ and the angle $A$ opposite $a$ (SSA), the perpendicular from $C$ to the base line has length $h = b\sin A$. Compare $a$ with it:\par
\begin{itemize}[leftmargin=0.9cm, itemsep=1pt, topsep=2pt]
  \item $a < h$: no triangle --- the swinging side never reaches the line;
  \item $a = h$: one right triangle; \quad $h < a < b$: \textbf{two} triangles;
  \item $a \ge b$: one triangle.
\end{itemize}
\end{formulabox}

\begin{examplebox}
\textbf{Example:} \quad $b = 14$, $A = 38^\circ$. Find the height $h$ that decides the case.
\step{Before solving anything I need the perpendicular distance from the far vertex to the base line, because that is the length the swinging side has to beat.}
\step{$h = b\sin A = 14\sin 38^\circ = 14(0.6157)$}
$\Rightarrow\quad h \approx \ans{8.62}$, so any $a$ below $8.62$ gives no triangle at all.
\end{examplebox}

\begin{tryitbox}
\textbf{Try it:} \quad $b = 9$, $A = 55^\circ$. Find $h$.\\[2pt]
\rotatebox{180}{\footnotesize check: $h \approx \ans{7.37}$}
\end{tryitbox}

\skillheading{Skill 2 --- When only one triangle fits}

\begin{formulabox}
If $a \ge b$, the side opposite the given angle is the longer one, so the angle $B$ opposite $b$ must be \emph{smaller} than $A$ --- and therefore acute. The obtuse partner is impossible and is discarded without further thought.\par
$\sin B = \dfrac{b\sin A}{a}$, then $C = 180^\circ - A - B$.
\end{formulabox}

\begin{examplebox}
\textbf{Example:} \quad $a = 16$, $b = 10$, $A = 48^\circ$. Find $B$.
\step{Here $a$ is bigger than $b$, so one triangle exists and the angle opposite the shorter side has to be acute --- no second case to carry.}
\step{$\sin B = \dfrac{10\sin 48^\circ}{16} = 0.4645$}
$\Rightarrow\quad B \approx \ans{27.68}^\circ$
\end{examplebox}

\begin{tryitbox}
\textbf{Try it:} \quad $a = 19$, $b = 12$, $A = 41^\circ$. Find $B$.\\[2pt]
\rotatebox{180}{\footnotesize check: $B \approx \ans{24.48}^\circ$}
\end{tryitbox}

\skillheading{Skill 3 --- When two triangles fit}

\begin{formulabox}
If $h < a < b$, the swinging side crosses the base line twice and there are \emph{two} answers. The calculator returns only the acute one.\par
$B_1 = \sin^{-1}\!\left(\dfrac{b\sin A}{a}\right)$, \qquad $B_2 = 180^\circ - B_1$.\par
Keep $B_2$ only if $A + B_2 < 180^\circ$ --- in this case it always is.
\end{formulabox}

\begin{examplebox}
\textbf{Example:} \quad $a = 7$, $b = 9$, $A = 47^\circ$. Find both values of $B$.
\step{The height is $9\sin 47^\circ = 6.58$, and $6.58 < 7 < 9$, so this is the two-triangle case and stopping at one answer would report only part of it.}
\step{$\sin B = \dfrac{9\sin 47^\circ}{7} = 0.9403$, so $B_1 = 70.10^\circ$ and $B_2 = 180^\circ - 70.10^\circ$.}
$\Rightarrow\quad B = \ans{70.10}^\circ$ or $\ans{109.90}^\circ$.
\end{examplebox}

\begin{tryitbox}
\textbf{Try it:} \quad $a = 10$, $b = 13$, $A = 40^\circ$. Find both values of $B$.\\[2pt]
\rotatebox{180}{\footnotesize check: $B \approx \ans{56.68}^\circ$ or $\ans{123.32}^\circ$}
\end{tryitbox}

\skillheading{Skill 4 --- Reporting both cases in context}

\begin{formulabox}
In a real measurement, two triangles mean the data genuinely does not decide the answer. Report both, and say what extra information would settle it (a further distance, or whether the unknown angle is acute).\par
Discarding the obtuse case because it "looks wrong" is the commonest way to lose half the answer.
\end{formulabox}

\begin{examplebox}
\textbf{Example:} \quad A station at $A$ sees a boat at $C$, $b = 300$ m away; the boat is $a = 250$ m from a marker at $B$ on the shoreline, and $A = 49^\circ$. Find both possible angles at the marker.
\step{The height is $300\sin 49^\circ = 226.4$ m and $226.4 < 250 < 300$, so the measurements fit two boat positions and both must be reported.}
\step{$\sin B = \dfrac{300\sin 49^\circ}{250} = 0.9055$, so $B_1 = 64.91^\circ$ and $B_2 = 180^\circ - 64.91^\circ$.}
$\Rightarrow\quad B = \ans{64.91}^\circ$ or $\ans{115.09}^\circ$.
\end{examplebox}

\begin{tryitbox}
\textbf{Try it:} \quad Same setup with $b = 220$ m, $a = 180$ m and $A = 46^\circ$. Find both possible angles at the marker.\\[2pt]
\rotatebox{180}{\footnotesize check: $B \approx \ans{61.55}^\circ$ or $\ans{118.45}^\circ$}
\end{tryitbox}
