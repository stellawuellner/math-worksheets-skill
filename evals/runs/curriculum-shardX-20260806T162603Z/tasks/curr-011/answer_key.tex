\problem{Cats and bowls: count each, then more cats or more bowls?}

\textbf{Solution:} Count the cats: \ans{3}

Count the bowls: \ans{5}

When counting, 3 comes before 5, so there are more \textbf{bowls}. \ans{3 < 5}

\problem{Row A (6 dots) and Row B (4 dots): which has fewer?}

\textbf{Solution:} Row A: \ans{6}

Row B: \ans{4}

4 is the smaller count, so Row \textbf{B} has fewer. \ans{6 > 4}

\problem{Stars and moons: more, fewer, or the same?}

\textbf{Solution:} Stars: \ans{5}

Moons: \ans{5}

The counts match, so the groups are the \textbf{same}. \ans{5 = 5}

\problem{Draw pairing lines between Row A (7) and Row B (6), then circle the
row with more.}

\textbf{Solution:} Row A: \ans{7}

Row B: \ans{6}

After pairing, Row A has a dot with no partner, so Row \textbf{A} has more.
\ans{7 > 6}

\textbf{Pairing and circling (instructor-judged):} each Row A dot connects to
one Row B dot, no dot used twice; one Row A dot is left unpaired, and the
circle goes around Row A. The leftover dot \emph{is} the proof of more.

\problem{Tam has 8 grapes, Ana has 6: who has fewer?}

\textbf{Solution:} Tam: \ans{8}

Ana: \ans{6}

6 is the smaller count, so \textbf{Ana} has fewer grapes. \ans{8 > 6}

\problem{Squeezed row and spread-out row, 4 dots each: more, fewer, or the
same?}

\textbf{Solution:} Row A: \ans{4}

Row B: \ans{4}

Spreading dots out changes how the row \emph{looks}, never how many there are.
The counts match: the \textbf{same}. \ans{4 = 4}

\problem{Array A (3 rows of 3) and Group B (7 dots): which has more?}

\textbf{Solution:} Array A, row by row: $3 + 3 + 3$ gives \ans{9}

Group B: \ans{7}

9 comes after 7 in the count, so Array \textbf{A} has more. \ans{9 > 7}

\problem{Challenge: rows of 6, 8, and 6 --- find the two with the same number
and tell how you know.}

\textbf{Solution:} Row A: \ans{6}

Row B: \ans{8}

Row C: \ans{6}

Rows \textbf{A} and \textbf{C} both count to six: \ans{6 = 6}

\textbf{Tell how you know (instructor-judged):} accept ``both counts ended at
six'' or ``the rows pair up dot for dot with none left over.'' Either the
equal-counts reason or the pairing reason earns credit.
