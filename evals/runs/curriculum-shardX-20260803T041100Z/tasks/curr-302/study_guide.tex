\sstitleblock{Postulates, Theorems, Converses and Biconditionals}

\begin{formulabox}
\textbf{The four labels.} \; \textbf{Definition} --- states what a term means;
reversible by agreement. \; \textbf{Postulate} --- assumed without proof, so the
system has a starting point. \; \textbf{Theorem} --- proved from definitions,
postulates and earlier theorems. \; \textbf{Biconditional} --- ``$p$ if and only
if $q$'', valid only when $p \rightarrow q$ and $q \rightarrow p$ are
\emph{both} true.\\[3pt]
\textbf{The converse} of ``if $p$, then $q$'' is ``if $q$, then $p$''. Swapping
is free; \emph{truth is not carried along}. One counterexample kills a converse.
\end{formulabox}

\skillheading{1. Applying a postulate to compute}

\begin{formulabox}
Two postulates do most of the algebra in this unit.\\[2pt]
\textbf{Segment Addition:} if $B$ is between $A$ and $C$, then $AB + BC = AC$.\\
\textbf{Angle Addition:} if $D$ is interior to $\angle ABC$, then
$m\angle ABD + m\angle DBC = m\angle ABC$.\\[2pt]
Name the postulate first, then write the equation it licenses.
\end{formulabox}

\begin{examplebox}
\textbf{Example:} $B$ is between $A$ and $C$, $AB = x+4$, $BC = 2x$, $AC = 22$.
Find $x$.
\step{Betweenness is what licenses adding the parts, so the Segment Addition
Postulate supplies the equation before any algebra happens.}
\step{$(x+4) + 2x = 22$ gives $3x + 4 = 22$, so $3x = 18$.}
\[ \ans{x = 6} \quad\text{(check: } 10 + 12 = 22\text{)} \]
\end{examplebox}

\begin{tryitbox}
\textbf{Try it:} $\overrightarrow{BD}$ is interior to $\angle ABC$ with
$m\angle ABD = 3x$, $m\angle DBC = 2x+10$, $m\angle ABC = 85^\circ$. Find $x$.
\\[2pt]
\rotatebox{180}{\footnotesize check: $\ans{x = 15}$}
\end{tryitbox}

\skillheading{2. Postulate, theorem, or definition?}

\begin{formulabox}
Ask two questions.\\[2pt]
\emph{Could it be proved from something earlier?} No $\rightarrow$ postulate.
Yes $\rightarrow$ theorem.\\
\emph{Is it telling me what a word means, both ways?} $\rightarrow$ definition.
\\[2pt]
Obviousness decides nothing: ``vertical angles are congruent'' is obvious and is
still a theorem, because it has a proof.
\end{formulabox}

\begin{examplebox}
\textbf{Example:} Classify \emph{through any three non-collinear points there is
exactly one plane}.
\step{Start with the provability question, since that is the only thing that
separates a postulate from a theorem.}
\step{There is no earlier statement about planes to derive it from --- it is one
of the assumptions that gives the word \emph{plane} its behaviour, and it is not
unpacking a definition.}
So it is a \textbf{postulate}. \emph{(Classification is read by a person, not
computed --- flagged for manual review.)}
\end{examplebox}

\begin{tryitbox}
\textbf{Try it:} Classify \emph{a segment bisector is a segment, ray or line
that divides a segment into two congruent segments}, and give the reason.\\[2pt]
\rotatebox{180}{\footnotesize check: definition --- it states what the term
means, and it reverses}
\end{tryitbox}

\skillheading{3. Testing the truth of a converse}

\begin{formulabox}
To test ``if $q$, then $p$'', hunt for one case where $q$ holds and $p$ fails.
With an equation, that means solving \textbf{completely}: if the solution set is
bigger than the value named, the extra solution \emph{is} the counterexample.
\end{formulabox}

\begin{examplebox}
\textbf{Example:} Is the converse of ``if $x = 7$, then $x^2 = 49$'' true?
\step{The converse claims $x^2 = 49$ forces $x = 7$, so the test is whether $7$
is the only number whose square is $49$ --- solve, do not substitute.}
\step{$x^2 - 49 = 0$ factors as $(x-7)(x+7) = 0$, giving two solutions.}
\[ \ans{x = -7 \text{ or } x = 7} \]
$x = -7$ satisfies the hypothesis and not the conclusion, so the converse is
\textbf{false}.
\end{examplebox}

\begin{tryitbox}
\textbf{Try it:} Is the converse of ``if $x = 5$, then $3x = 15$'' true? Solve
$3x = 15$ completely and decide.\\[2pt]
\rotatebox{180}{\footnotesize check: $\ans{x = 5}$ only, so the converse is true}
\end{tryitbox}

\skillheading{4. When a biconditional is valid}

\begin{formulabox}
``$p$ if and only if $q$'' is valid exactly when the two sides describe the
\textbf{same set of cases}. Check the conditional and its converse separately;
if either fails, the biconditional fails. Definitions always pass this test ---
that is what makes them definitions.
\end{formulabox}

\begin{examplebox}
\textbf{Example:} Is ``$5x + 2 = 17$ if and only if $x = 3$'' valid?
\step{Two sides, two directions --- compare the solution sets rather than
checking one substitution.}
\step{$5x + 2 = 17$ gives $5x = 15$, whose solution set is a single value; and
substituting that value returns $17$, so the reverse direction holds too.}
\[ \ans{x = 3} \quad\text{--- both directions hold, so the biconditional is valid.} \]
\end{examplebox}

\begin{tryitbox}
\textbf{Try it:} Is ``$x^2 - 2x - 8 = 0$ if and only if $x = 4$'' valid? Solve
completely first.\\[2pt]
\rotatebox{180}{\footnotesize check: $\ans{x = -2 \text{ or } x = 4}$, so it is
not valid}
\end{tryitbox}
