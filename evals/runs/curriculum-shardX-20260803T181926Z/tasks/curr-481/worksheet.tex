\begin{center}
\textit{Slopes at lattice points, reading a printed field, and sketching the
solution curve through a point}
\end{center}

\noindent\textbf{Directions.} A slope field draws, at each lattice point, a
short segment whose slope is the value the differential equation gives there.
Work each problem in this order:
\begin{itemize}[leftmargin=1.2cm, itemsep=2pt, topsep=2pt]
\item \textbf{Substitute} the point's coordinates into the right-hand side ---
that number \emph{is} the slope of the segment at that point.
\item \textbf{Look for structure} before drawing. If the right-hand side has no
$y$ in it, every segment in a vertical column is parallel; with no $x$, every
segment in a horizontal row is parallel. Setting the right-hand side equal to
zero gives the curve along which every segment is horizontal.
\item \textbf{Follow the flow} to sketch a solution curve: start at the given
point and move so that the curve stays tangent to the nearby segments, never
crossing one at an angle.
\end{itemize}

\problem[2.6cm]{The field below was generated by exactly one of
