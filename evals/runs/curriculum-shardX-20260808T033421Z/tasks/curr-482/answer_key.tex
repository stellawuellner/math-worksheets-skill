\problem{Separate the variables in $\dfrac{dy}{dx} = 5x^4 y$ and integrate both sides. Write your result in the form $\ln|y| = F(x) + C$.}

\textbf{Solution:} The right side already factors as (function of $x$)(function of $y$), so divide by $y$ and multiply by $dx$:
\[ \frac{dy}{y} = 5x^4\,dx. \]
Integrating each side, $\displaystyle\int \frac{dy}{y} = \ln|y|$ and $\displaystyle\int 5x^4\,dx = x^5$. Put the single constant on the $x$ side. \ans{\ln|y| = x^5 + C}

\problem{Separate the variables in $\dfrac{dy}{dx} = \dfrac{4x}{y}$ and integrate both sides. Write your result in the form $\frac{1}{2}y^2 = G(x) + C$.}

\textbf{Solution:} Multiply both sides by $y\,dx$:
\[ y\,dy = 4x\,dx. \]
Now $\displaystyle\int y\,dy = \tfrac{1}{2}y^2$ and $\displaystyle\int 4x\,dx = 2x^2$. \ans{\frac{1}{2}y^2 = 2x^2 + C}

\problem{Solve the initial value problem $\dfrac{dy}{dx} = 2xy$, $y(0) = 5$. Write the particular solution $y = f(x)$, then evaluate $y(1)$ to three decimal places.}

\textbf{Solution:} Separate and integrate:
\[ \frac{dy}{y} = 2x\,dx \quad\Longrightarrow\quad \ln|y| = x^2 + C. \]
Exponentiate: $y = Ae^{x^2}$ with $A = e^{C}$. The initial condition $y(0) = 5$ gives $5 = Ae^{0} = A$, so $A = 5$. \ans{y = 5e^{x^2}}

Then $y(1) = 5e^{1} = 13.5914\ldots$, which rounds to \ans{y(1) \approx 13.591}

\vspace{0.2cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.2cm}

\problem{A quantity $y$ satisfies $\dfrac{dy}{dx} = \dfrac{y}{4}$ with $y(0) = 12$ and $y > 0$. Solve the initial value problem, then find the value of $x$ at which $y = 48$.}

\textbf{Solution:} Separate: $\dfrac{dy}{y} = \dfrac{dx}{4}$. Integrating the left side gives $\ln|y|$ and the right side gives $\dfrac{x}{4} + C$, so with $y > 0$,
\[ y = Ae^{x/4}, \qquad y(0) = 12 \Longrightarrow A = 12, \qquad y = 12e^{x/4}. \]
Set $12e^{x/4} = 48$, so $e^{x/4} = 4$ and $\dfrac{x}{4} = \ln 4$. \ans{x = 4\ln 4 \approx 5.545}

\problem{Separate the variables in $\dfrac{dy}{dx} = \dfrac{\cos x}{2y}$ and integrate. (a) Carry out the separation and the integration. (b) Explain why this does not determine a single function until an initial condition is given.}

\textbf{Solution (a):} Multiply by $2y\,dx$: \; $2y\,dy = \cos x\,dx$. Integrating, $\displaystyle\int 2y\,dy = y^2$ and $\displaystyle\int \cos x\,dx = \sin x$. \ans{y^2 = \sin x + C}

\textbf{Solution (b) --- instructor-judged.} A correct response says that solving $y^2 = \sin x + C$ for $y$ gives \emph{two} branches, $y = +\sqrt{\sin x + C}$ and $y = -\sqrt{\sin x + C}$, because squaring destroyed the sign. Nothing in the differential equation selects one of them; an initial condition such as $y(0) = 2$ picks the branch (and fixes $C$) at the same time. Full credit requires both the plus-or-minus ambiguity and the role of the initial value.

\problem{Solve the initial value problem $\dfrac{dy}{dx} = \dfrac{3x^2}{y}$, $y(1) = 4$, for the branch with $y > 0$. Write the particular solution, then evaluate $y(2)$ to three decimal places.}

\textbf{Solution:} Separate: $y\,dy = 3x^2\,dx$. Integrating, $\tfrac{1}{2}y^2 = x^3 + C$, so $y^2 = 2x^3 + K$ where $K = 2C$. Apply $y(1) = 4$:
\[ 16 = 2(1)^3 + K \quad\Longrightarrow\quad K = 14. \]
Since $y > 0$ we take the positive root. \ans{y = \sqrt{2x^3 + 14}}

Then $y(2) = \sqrt{2(8) + 14} = \sqrt{30} = 5.4772\ldots$, which rounds to \ans{y(2) \approx 5.477}

\problem{A colony of bacteria has mass $P$ (in thousands of cells) after $t$ days and satisfies $\dfrac{dP}{dt} = 0.08P$ with $P(0) = 25$. Find $P(10)$ to two decimal places.}

\textbf{Solution:} Separating gives $\dfrac{dP}{P} = 0.08\,dt$, so $\ln P = 0.08t + C$ and $P = Ae^{0.08t}$. From $P(0) = 25$ we get $A = 25$, so $P = 25e^{0.08t}$. At $t = 10$, $P = 25e^{0.8} = 55.6385\ldots$ \ans{P(10) \approx 55.64}

\vspace{0.2cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.2cm}

\problem{Solve the initial value problem $\dfrac{dy}{dx} = e^{\,x-y}$, $y(0) = \ln 3$. Write the particular solution, then evaluate $y(\ln 5)$ to three decimal places.}

\textbf{Solution:} Write $e^{\,x-y} = e^x e^{-y}$; the equation is separable once you see that factorisation:
\[ e^{y}\,dy = e^{x}\,dx \quad\Longrightarrow\quad e^{y} = e^{x} + C. \]
At $x = 0$, $y = \ln 3$, so $e^{\ln 3} = e^{0} + C$, i.e. $3 = 1 + C$ and $C = 2$. \ans{y = \ln(e^x + 2)}

Then $y(\ln 5) = \ln(5 + 2) = \ln 7 = 1.9459\ldots$, which rounds to \ans{y(\ln 5) \approx 1.946}

\problem{Water drains from a tank so that the depth $h$ (centimetres) satisfies $\dfrac{dh}{dt} = -\dfrac{3}{2\sqrt{h}}$, $t$ in minutes, with $h = 36$ at $t = 0$. Find the time until the tank is empty.}

\textbf{Solution:} Separate: $2\sqrt{h}\,dh = -3\,dt$. Integrating, $\dfrac{4}{3}h^{3/2} = -3t + C$. At $t = 0$, $h = 36$, and $36^{3/2} = 216$, so
\[ C = \frac{4}{3}(216) = 288. \]
The tank is empty when $h = 0$: \; $0 = -3t + 288$, so $t = \dfrac{288}{3}$. \ans{t = 96.0}

\problem{Consider $\dfrac{dy}{dx} = y^2\sin x$, $y(0) = \frac{1}{2}$. (a) Find the particular solution and confirm $y(0) = \frac{1}{2}$. (b) Explain why the interval of definition stops before $x = \pi$.}

\textbf{Solution (a):} Separate: $y^{-2}\,dy = \sin x\,dx$. Integrating, $-\dfrac{1}{y} = -\cos x + C$, so $\dfrac{1}{y} = \cos x - C$. At $x = 0$, $y = \frac{1}{2}$, so $2 = 1 - C$ and $C = -1$. Hence $\dfrac{1}{y} = \cos x + 1$. \ans{y = \dfrac{1}{1 + \cos x}}

Check the initial value: at $x = 0$, $1 + \cos 0 = 2$, so \ans{y(0) = \frac{1}{2}}

\textbf{Solution (b) --- instructor-judged.} A correct response notes that $1 + \cos x = 0$ exactly when $x = \pi$, so the formula has a zero denominator there and $y \to \infty$ as $x \to \pi^{-}$. The solution through $(0, \frac{1}{2})$ therefore lives on $(-\pi, \pi)$ and cannot be continued past $x = \pi$. Full credit names the vanishing denominator and states the consequence for the interval.
