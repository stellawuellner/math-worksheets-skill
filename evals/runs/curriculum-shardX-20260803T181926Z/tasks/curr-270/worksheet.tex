\begin{center}
\textit{Evaluating a rule, finding the input for a given output, reading values
from a table or a graph, and describing domain and range in context}
\end{center}

\noindent\textbf{Before you start.}
\begin{itemize}[leftmargin=1.2cm, itemsep=2pt, topsep=2pt]
\item $f(3)$ is an instruction: put $3$ in for the input and simplify. The
answer is the \emph{output}.
\item ``Find $x$ when $f(x) = 21$'' runs the same rule backwards: set the rule
equal to $21$ and solve.
\item On a graph, a point $(a, b)$ says $f(a) = b$. In a table, the input
column and the output column say the same thing.
\item The \textbf{domain} is the set of inputs allowed; the \textbf{range} is
the set of outputs they produce. A story can shrink both.
\end{itemize}
