\problem{\textbf{$2^{\,x+1} = 2^{\,3x-5}$.}

\textbf{Solution:} The bases are both 2 and $2^{u}$ is one-to-one, so the equation
holds exactly when the exponents agree:
\[ x + 1 = 3x - 5. \]
Subtract $x$ from both sides: $1 = 2x - 5$. Add 5: $6 = 2x$, so $x = 3$.

\textbf{Check.} Left exponent $3 + 1 = 4$; right exponent $3(3) - 5 = 4$. Both
sides are $2^{4} = 16$ $\checkmark$.
$\ans{x = 3}$}

\problem{\textbf{$3^{\,2x} = 3^{\,x+4}$.}

\textbf{Solution:} Same base 3, so equate exponents: $2x = x + 4$, giving $x = 4$.

\textbf{Check.} $2(4) = 8$ and $4 + 4 = 8$; both sides are $3^{8}$ $\checkmark$.
$\ans{x = 4}$}

\problem{\textbf{$9^{\,x} = 27$.}

\textbf{Solution:} 9 and 27 are both powers of 3, so put the whole equation over
base 3: $9 = 3^{2}$ and $27 = 3^{3}$, hence
\[ \left(3^{2}\right)^{x} = 3^{3} \quad\Longrightarrow\quad 3^{\,2x} = 3^{3}. \]
Equate exponents: $2x = 3$, so $x = \tfrac{3}{2}$.

\textbf{Check.} $9^{3/2} = \left(\sqrt{9}\right)^{3} = 3^{3} = 27$ $\checkmark$. A
fractional exponent is expected here --- nothing says the solution must be an
integer.
$\ans{x = \tfrac{3}{2}}$}

\problem{\textbf{$5^{\,3x-1} = 5^{\,x+9}$.}

\textbf{Solution:} Same base 5, so $3x - 1 = x + 9$. Subtract $x$: $2x - 1 = 9$.
Add 1: $2x = 10$, so $x = 5$.

\textbf{Check.} $3(5) - 1 = 14$ and $5 + 9 = 14$; both sides are $5^{14}$
$\checkmark$. Checking the exponents is enough --- there is no need to evaluate a
14-digit power.
$\ans{x = 5}$}

\problem{\textbf{$4^{\,2x} = 8^{\,x+1}$.}

\textbf{Solution:} $4 = 2^{2}$ and $8 = 2^{3}$, so rewrite both sides over base 2:
\[ \left(2^{2}\right)^{2x} = \left(2^{3}\right)^{x+1} \quad\Longrightarrow\quad
   2^{\,4x} = 2^{\,3x+3}. \]
Note that the outer exponent multiplies the inner one --- $(b^{m})^{n} = b^{mn}$ ---
so the left exponent is $4x$, not $2 + 2x$. Equating exponents gives
$4x = 3x + 3$, so $x = 3$.

\textbf{Check.} $4^{6} = 4096$ and $8^{4} = 4096$ $\checkmark$.
$\ans{x = 3}$}

\problem{\textbf{$\left(\tfrac{1}{2}\right)^{x} = 32$.}

\textbf{Solution:} A reciprocal base is a negative exponent:
$\tfrac{1}{2} = 2^{-1}$, so the left side is $\left(2^{-1}\right)^{x} = 2^{-x}$.
The right side is $32 = 2^{5}$. Therefore
\[ 2^{-x} = 2^{5} \quad\Longrightarrow\quad -x = 5 \quad\Longrightarrow\quad x = -5. \]

\textbf{Check.} $\left(\tfrac{1}{2}\right)^{-5} = 2^{5} = 32$ $\checkmark$. The sign
is the whole point: a base below 1 decreases as the exponent grows, so reaching a
number above 1 requires a negative exponent.
$\ans{x = -5}$}

\problem{\textbf{Doubling: $5 \cdot 2^{\,t} = 320$.}

\textbf{Solution:} The coefficient 5 is not part of the power, so clear it first:
divide both sides by 5 to get $2^{\,t} = 64$. Now both sides are powers of 2, since
$64 = 2^{6}$:
\[ 2^{\,t} = 2^{6} \quad\Longrightarrow\quad t = 6. \]

\textbf{Check against the table.} The counts run 5, 10, 20, 40, 80, 160, 320, so
320 cells first appear after 6 hours $\checkmark$. The table and the algebra are the
same statement --- the table steps the doubling one hour at a time, and the
exponent counts how many doublings have happened.
$\ans{t = 6}$}

\problem{\textbf{Check the claim: $25^{\,x-1} = 125^{\,x}$.}

\textbf{Solving it independently.} $25 = 5^{2}$ and $125 = 5^{3}$, so
\[ 5^{\,2(x-1)} = 5^{\,3x} \quad\Longrightarrow\quad 2x - 2 = 3x
   \quad\Longrightarrow\quad x = -2. \]
The student's value is correct.

\textbf{Confirming numerically.} At $x = -2$ the left side is
$25^{-3} = \tfrac{1}{15625}$ and the right side is
$125^{-2} = \tfrac{1}{15625}$. If the claim is true the difference of the two sides
must be exactly zero, and it is: $25^{\,x-1} - 125^{\,x} = 0$ at $x = -2$.
$\ans{0}$

\noindent\textit{Grading:} the value asked for is the difference, which must be 0.
A student who writes $x = -2$ here has answered the first half; give credit for
both parts separately.}

\problem{\textbf{Decay: $240\left(\tfrac{1}{2}\right)^{t/5} = 15$.}

\textbf{Solution:} Divide both sides by 240 to isolate the power:
\[ \left(\tfrac{1}{2}\right)^{t/5} = \tfrac{15}{240} = \tfrac{1}{16}. \]
Both sides are powers of $\tfrac{1}{2}$, since
$\tfrac{1}{16} = \left(\tfrac{1}{2}\right)^{4}$, so
\[ \tfrac{t}{5} = 4 \quad\Longrightarrow\quad t = 20 \text{ years}. \]

\textbf{Half-lives and why it came out whole.} $\tfrac{t}{5} = 4$ says exactly four
half-lives have passed. It had to be a whole number because the target mass,
15 mg, is $240$ divided by 16, and 16 is a power of 2 --- had the target been, say,
20 mg, the ratio $\tfrac{1}{12}$ is not a power of $\tfrac{1}{2}$ and the common-base
method would not finish the job; that is the case logarithms exist for.

\textbf{Check.} $240 \cdot \tfrac{1}{16} = 15$ $\checkmark$.
$\ans{t = 20}$}

\problem{\textbf{Challenge: $9^{\,x}\cdot 27^{\,x+1} = 81$.}

\textbf{Single power of 3.} Rewrite each factor over base 3 and add the exponents:
\[ 9^{\,x}\cdot 27^{\,x+1} = 3^{\,2x}\cdot 3^{\,3x+3} = 3^{\,2x + 3x + 3}
   = 3^{\,5x+3}. \]

\textbf{Solving.} The right side is $81 = 3^{4}$, so
\[ 3^{\,5x+3} = 3^{4} \quad\Longrightarrow\quad 5x + 3 = 4
   \quad\Longrightarrow\quad x = \tfrac{1}{5}. \]

\textbf{Check.} $5\left(\tfrac{1}{5}\right) + 3 = 4$, so both sides are $3^{4} = 81$
$\checkmark$.
\[ \boxed{9^{\,x}\cdot 27^{\,x+1} = 3^{\,5x+3}, \qquad x = \tfrac{1}{5}} \]

\noindent\textit{Watch for:} a student who multiplies the exponents instead of
adding them gets $3^{6x^{2}+6x}$ and a quadratic. The product rule adds; the power
rule multiplies.}
