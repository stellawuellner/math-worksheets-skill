\problem{\textbf{Classify $\sqrt{49}$.}

\textbf{Step 1.} $49$ appears in the perfect-square row of the table
($7^2 = 49$), so the root comes out exactly.

\textbf{Step 2.} $\sqrt{49} = 7$, and $7 = \dfrac{7}{1}$ --- a ratio of two whole
numbers with a non-zero denominator. That is exactly the definition of rational.
\ans{7}

\textit{Classification:} \textbf{rational}.}

\problem{\textbf{Classify $\sqrt{196}$.}

\textbf{Step 1.} Read the table: the last column gives $14^2 = 196$, so $196$ is
a perfect square.

\textbf{Step 2.} $\sqrt{196} = 14 = \dfrac{14}{1}$.
\ans{14}

\textit{Classification:} \textbf{rational}. A root is rational precisely when
the radicand is a perfect square (of a rational number) --- being ``a decimal
that looks tidy'' is not the test.}

\problem{\textbf{Terminating decimal to fraction.}

\textbf{Step 1.} Read the decimal aloud: ``thirty-five hundredths''. The words
give the fraction: $0.35 = \dfrac{35}{100}$.

\textbf{Step 2.} Reduce by the common factor $5$:
$\dfrac{35}{100} = \dfrac{7}{20}$.
\ans{\tfrac{7}{20}}

\textit{Classification:} \textbf{rational}. Completed table row: $0.35$ $\mid$
$\frac{35}{100}$ $\mid$ $\frac{7}{20}$ $\mid$ yes. Every terminating decimal
converts this way, so \emph{every} terminating decimal is rational.}

\problem{\textbf{$\sqrt{50}$: locate, classify, approximate.}

\textbf{(a)} From the table, $7^2 = 49$ and $8^2 = 64$. Since
$49 < 50 < 64$, we get $7 < \sqrt{50} < 8$.

\textbf{(b)} $50$ is not a perfect square, and no fraction squares to $50$
either, so $\sqrt{50}$ is \textbf{irrational}: its decimal never ends and never
repeats.

\textbf{(c)} $\sqrt{50} = 7.0710678\ldots$, which rounds to
\ans{7.07}

\textit{Why the rounded value is a different number:} $7.07$ terminates, so
$7.07 = \frac{707}{100}$ is rational; $\sqrt{50}$ is not. The rounded value is a
useful stand-in on a number line, never an equality.

\textit{Common wrong answer:} $25$ --- halving the radicand instead of taking
the square root.}

\problem{\textbf{Order $\sqrt{13}$, $3.5$, $\frac{18}{5}$.}

\textbf{Step 1.} Put all three in decimal form.
$\dfrac{18}{5} = 3.6$ exactly, and $3.5$ is already a decimal.

\textbf{Step 2.} Bracket the root with the square table: $3^2 = 9$ and
$4^2 = 16$, so $\sqrt{13}$ is between $3$ and $4$. Squaring the candidates
settles it: $3.6^2 = 12.96 < 13$, so $\sqrt{13} > 3.6$.
\[ \boxed{3.5 \;<\; \tfrac{18}{5} \;<\; \sqrt{13}} \]

\textit{Classification:} $\sqrt{13}$ is the irrational one; $3.5$ and
$\frac{18}{5}$ are both rational. Note that the irrational number is not the
largest ``because it has a radical'' --- it lands where its size puts it.}

\problem{\textbf{Repeating decimal to fraction.}

\textbf{(a)} A repeating decimal is rational because the repeat is a
\emph{pattern}, and any repeating pattern can be captured by a fraction. Only
decimals that never end \emph{and} never repeat escape being a ratio.

\textbf{(b)} Reduce $\dfrac{45}{99}$ by the common factor $9$:
$\dfrac{45}{99} = \dfrac{5}{11}$.
\ans{\tfrac{5}{11}}

\textit{Check:} dividing $5$ by $11$ by hand returns the repeating block
again. \textit{Classification:} \textbf{rational}.}

\problem{\textbf{$\sqrt{30}$: locate, classify, approximate.}

\textbf{(a)} Two entries from the square table bracket it: $5^2 = 25$ and
$6^2 = 36$, and $25 < 30 < 36$, so $5 < \sqrt{30} < 6$.

\textbf{(b)} $30$ is not a perfect square, so $\sqrt{30}$ is
\textbf{irrational}.

\textbf{(c)} $\sqrt{30} = 5.4772255\ldots$, which rounds to
\ans{5.48}

\textit{Common wrong answer:} $15$ --- halving $30$ instead of taking its
square root.}

\problem{\textbf{Is $\sqrt{2} = 1.41$?}

\textbf{Step 1.} Test the claim by squaring the right-hand side:
$1.41^2 = 1.9881$, which is less than $2$. A number whose square is too small is
itself too small.

\textbf{Step 2.} Therefore
\[ \boxed{\sqrt{2} \;>\; 1.41} \]

\textit{What $1.41$ really is:} a rational two-decimal approximation of
$\sqrt{2}$ --- close enough for a sketch, but a different number. The true
decimal $1.41421356\ldots$ never ends and never repeats.}

\problem{\textbf{Classify $\sqrt{\frac{9}{16}}$.}

\textbf{Step 1.} The square root of a quotient is the quotient of the roots:
$\sqrt{\dfrac{9}{16}} = \dfrac{\sqrt{9}}{\sqrt{16}}$.

\textbf{Step 2.} The table shows $3^2 = 9$ and $4^2 = 16$, so both roots are
exact and the result is a ratio of whole numbers.
\ans{\tfrac{3}{4}}

\textit{Classification:} \textbf{rational}. A radical sign does not make a
number irrational --- what matters is whether the root comes out exactly.}

\problem{\textbf{A product of two irrational numbers.}

\textbf{(a)} Multiply under one radical:
$\sqrt{8} \cdot \sqrt{2} = \sqrt{8 \cdot 2} = \sqrt{16}$, and $16$ is a perfect
square.
\ans{4}

\textbf{(b)} Expected sentence: the claim is \textbf{false}, and this is a
counterexample --- $\sqrt{8}$ and $\sqrt{2}$ are both irrational, yet their
product is the rational number $4$. One counterexample is enough to disprove an
``always'' statement. (Accept any answer that identifies the claim as false and
points at this product as the reason.)}
