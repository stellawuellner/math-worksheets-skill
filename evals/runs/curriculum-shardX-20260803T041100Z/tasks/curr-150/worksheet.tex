  \item Show your work in the space under each problem, then write the final answer on
        the answer line.
\end{itemize}

\problem[5cm]{Pattern A adds 2 each time and Pattern B adds 8 each time. Both patterns
start at zero. Matching terms are written as ordered pairs $(A, B)$.

\smallskip
Find the $B$-value of the ordered pair whose $A$-value is 10.}

\problem[6cm]{Pattern A adds 2 each time and Pattern B adds 8 each time, both starting at
zero, exactly as before. Every $B$-value is the same number of times its $A$-value.

\smallskip
Find that multiplier, then use it to find the $A$-value of the ordered pair whose
$B$-value is 72.}

\problem[5cm]{Use \textbf{Line Plot A}. How many students read exactly 5 books? Write the
count, and also write it as the ordered pair (books read, number of students).}

\problem[7cm]{Use \textbf{Line Plot A}. Twelve students are shown on the plot. Find the
mean number of books read by a student in this class.}

\problem[6cm]{Use \textbf{Line Plot A}. The reading club gives 5 points for every book a
student reads. How many points did the student who read the most books earn?}

\problem[6cm]{Pattern P starts at one and adds three each time. Pattern Q starts at three
and adds nine each time.

\smallskip
Write the first four matching ordered pairs $(P, Q)$, plot them on \textbf{Grid A} above,
and describe in words how each $Q$-value is related to its $P$-value.}

\problem[7cm]{Use \textbf{Line Plot A}. Find the median number of books read.

\smallskip
Then state whether that median is greater than, less than, or equal to the mean you found
earlier, and say what that comparison tells you about the shape of the plot.}

\problem[7cm]{Use \textbf{Line Plot A}. Next month every student in the class plans to
read 2 more books than they read last month.

\smallskip
What will the new mean number of books be? Explain why you do not have to add up all
twelve students' new totals to find it.}

\problem[8cm]{Pattern S starts at zero and adds 5 each time. Pattern T starts at zero and
adds 15 each time. Sara says the ordered pair $(20, 45)$ is one of the matching pairs of
these two patterns.

\smallskip
Find the correct $T$-value that goes with the $S$-value 20, and explain what Sara did
wrong.}

\problem[7cm]{Use \textbf{Line Plot A}. Find the total number of books read by the whole
class last month.

\smallskip
Then write the class as one ordered pair: (number of students, total books read).}

\problem[7cm]{The school gives the class one bonus point for every book beyond 40 that
the whole class reads in a month. Use the class total you found from \textbf{Line Plot
A}.

\smallskip
How many bonus points does the class earn?}

\problem[9cm]{\textbf{Challenge.} Suppose the class total grows by six books every month,
starting from last month's class total.

\smallskip
Make a table of the class total for the first four months and write each month as an
ordered pair (month number, class total). Then describe the pattern in those ordered
pairs, and explain what the four plotted points would look like on a grid.}
