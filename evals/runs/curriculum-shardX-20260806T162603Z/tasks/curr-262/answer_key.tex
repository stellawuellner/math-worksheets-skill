\problem{$y = x + 3$, \ $2x + y = 12$.}

\textbf{Solution:} \quad The first equation already gives $y$, so put $x + 3$ into the second in
place of $y$: $2x + (x + 3) = 12$, so $3x = 9$ and $x = 3$. Substituting back,
$y = 3 + 3 = 6$. Check: $2(3) + 6 = 12$. \ans{(3,\,6)}

\vspace{0.15cm}\noindent\rule{\linewidth}{0.2pt}

\problem{$x = y - 2$, \ $3x + 2y = 9$.}

\textbf{Solution:} \quad Here it is $x$ that is ready. Substituting into the second equation:
$3(y - 2) + 2y = 9$, so $3y - 6 + 2y = 9$, $5y = 15$, $y = 3$. Then $x = 3 - 2 = 1$.
Check: $3(1) + 2(3) = 9$. \ans{(1,\,3)}

\vspace{0.15cm}\noindent\rule{\linewidth}{0.2pt}

\problem{$y = 2x - 1$, \ $4x - y = 7$.}

\textbf{Solution:} \quad Substituting, and keeping the brackets so the minus sign reaches both
terms: $4x - (2x - 1) = 7$, so $4x - 2x + 1 = 7$, $2x = 6$, $x = 3$. Then
$y = 2(3) - 1 = 5$. Dropping those brackets and writing $4x - 2x - 1$ is the usual slip.
\ans{(3,\,5)}

\vspace{0.15cm}\noindent\rule{\linewidth}{0.2pt}

\problem{$x + y = 9$, \ $3x - y = 11$.}

\textbf{Solution:} \quad Neither equation is ready. The first has coefficients of $1$, so isolate
there: $y = 9 - x$. Substituting into the second: $3x - (9 - x) = 11$, so $3x - 9 + x = 11$,
$4x = 20$, $x = 5$, and $y = 9 - 5 = 4$. Check: $3(5) - 4 = 11$. \ans{(5,\,4)}

\vspace{0.15cm}\noindent\rule{\linewidth}{0.2pt}

\problem{$y = -2x + 9$, \ $y = x - 3$.}

\textbf{Solution:} \quad Both sides equal $y$, so they equal each other: $-2x + 9 = x - 3$, giving
$12 = 3x$ and $x = 4$. Then $y = 4 - 3 = 1$. Check in the first equation:
$-2(4) + 9 = 1$. \ans{(4,\,1)}

\vspace{0.15cm}\noindent\rule{\linewidth}{0.2pt}

\problem{$2x + y = 7$, \ $3x - 4y = 5$.}

\textbf{Solution:} \quad The $y$ in the first equation has coefficient $1$, so isolating there
avoids fractions: $y = 7 - 2x$. Substituting into the second:
\begin{align*}
  3x - 4(7 - 2x) &= 5\\
  3x - 28 + 8x &= 5\\
  11x &= 33 \;\Rightarrow\; x = 3,
\end{align*}
and $y = 7 - 2(3) = 1$. Check: $3(3) - 4(1) = 5$. \ans{(3,\,1)}

\vspace{0.15cm}\noindent\rule{\linewidth}{0.2pt}

\problem{$y = 4x - 2$, \ $8x - 2y = 10$: (a) solve; (b) what does the last line mean?}

\textbf{Solution (a):} \quad Substituting into the second equation:
$8x - 2(4x - 2) = 10$, so $8x - 8x + 4 = 10$, which reduces to $4 = 10$. Every $x$ has vanished and
the statement left behind is false. \ans{\text{no solution}}

\noindent\textbf{Solution (b) --- instructor-judged.} Because $4 = 10$ is false, there is no pair
$(x, y)$ that satisfies both equations at once. On a graph, the second equation rearranges to
$y = 4x - 5$: same slope of $4$ as the first, different intercept, so the two lines are parallel and
never cross. Full credit connects the false statement to there being no solution.

\vspace{0.15cm}\noindent\rule{\linewidth}{0.2pt}

\problem{$x - 3y = 1$, \ $2x + 5y = 24$.}

\textbf{Solution:} \quad The $x$ in the first equation has coefficient $1$: $x = 3y + 1$.
Substituting: $2(3y + 1) + 5y = 24$, so $6y + 2 + 5y = 24$, $11y = 22$, $y = 2$, and
$x = 3(2) + 1 = 7$. Check: $7 - 3(2) = 1$ and $2(7) + 5(2) = 24$. \ans{(7,\,2)}

\vspace{0.15cm}\noindent\rule{\linewidth}{0.2pt}

\problem{$y = 3x - 4$, \ $6x - 2y = 8$: (a) solve the second for $y$; (b) how many solutions?}

\textbf{Solution (a):} \quad Subtract $6x$ from both sides and divide by $-2$, or rearrange as
$2y = 6x - 8$ and halve: $y = 3x - 4$. \ans{y = 3x - 4}

\noindent\textbf{Solution (b) --- instructor-judged.} Substituting the first equation into the
second gives $6x - 2(3x - 4) = 8$, that is $6x - 6x + 8 = 8$, or $8 = 8$ --- true for every value of
$x$. Part (a) explains why: the second equation \emph{is} the first, written differently, so the two
graphs are one line and every point on it satisfies both. The system has infinitely many solutions.
Full credit ties the always-true statement to the two equations being the same line.

\vspace{0.15cm}\noindent\rule{\linewidth}{0.2pt}

\problem{$3x + 2y = 4$, \ $x - y = 3$.}

\textbf{Solution:} \quad The second equation isolates cleanly: $x = y + 3$. Substituting:
$3(y + 3) + 2y = 4$, so $3y + 9 + 2y = 4$, $5y = -5$, $y = -1$, and $x = -1 + 3 = 2$.
Check: $3(2) + 2(-1) = 4$. \ans{(2,\,-1)}

\vspace{0.15cm}\noindent\rule{\linewidth}{0.2pt}

\problem{Booth: $45$ tickets, $285$ dollars, adults $8$ dollars, children $5$ dollars.}

\textbf{Solution:} \quad Counting tickets gives $x + y = 45$; counting money gives
$8x + 5y = 285$. Isolate from the count equation, where both coefficients are $1$: $y = 45 - x$.
Substituting into the money equation:
\begin{align*}
  8x + 5(45 - x) &= 285\\
  8x + 225 - 5x &= 285\\
  3x &= 60 \;\Rightarrow\; x = 20,
\end{align*}
so $y = 45 - 20 = 25$. Twenty adult tickets and twenty-five child tickets.
Check: $20 + 25 = 45$ and $8(20) + 5(25) = 160 + 125 = 285$. \ans{(20,\,25)}

\vspace{0.15cm}\noindent\rule{\linewidth}{0.2pt}

\problem{$y = \dfrac{2}{3}x + 1$, \ $x + y = 11$: (a) solve; (b) why substitution here?}

\textbf{Solution (a):} \quad The first equation is already solved for $y$, so substitute it into the
second:
\begin{align*}
  x + \tfrac{2}{3}x + 1 &= 11\\
  \tfrac{5}{3}x &= 10 \;\Rightarrow\; x = 6,
\end{align*}
and then $y = \tfrac{2}{3}(6) + 1 = 5$. Check: $6 + 5 = 11$. \ans{(6,\,5)}

\noindent\textbf{Solution (b) --- instructor-judged.} One equation is already in the form
``$y =$ an expression in $x$'', which is exactly the shape substitution wants --- one replacement and
the system becomes a single equation in $x$. Elimination would first need the fraction cleared and
the coefficients matched, which is more work for the same answer. Full credit points at one equation
already being solved for a variable as the signal to substitute.
