\problem{$A(1,1)$, $B(4,5)$ translated $5$ right to $A'(6,1)$, $B'(9,5)$. Find $AB$ and $A'B'$.}

\textbf{Solution:} \quad $AB = \sqrt{3^2 + 4^2} = \sqrt{25}$ and
$A'B' = \sqrt{3^2 + 4^2} = \sqrt{25}$. A translation shifts both endpoints the same way, so the
rise and the run are unchanged.
\[ \boxed{AB = 5 \qquad A'B' = 5} \]

\vspace{0.2cm}

\noindent\rule{\linewidth}{0.2pt}

\problem{$C(1,2)$, $D(7,10)$ reflected in the $y$-axis to $C'(-1,2)$, $D'(-7,10)$. Find $CD$ and $C'D'$.}

\textbf{Solution:} \quad $CD = \sqrt{6^2 + 8^2} = \sqrt{100}$. For the image the run is
$-7 - (-1) = -6$, and squaring removes the sign, so $C'D' = \sqrt{36 + 64} = \sqrt{100}$.
\[ \boxed{CD = 10 \qquad C'D' = 10} \]

\vspace{0.2cm}

\noindent\rule{\linewidth}{0.2pt}

\problem{Triangles with sides $3, 4, 5$ and $9, 12, 15$: divide each larger side by its match.}

\textbf{Solution:} \quad $\dfrac{9}{3} = 3$, \quad $\dfrac{12}{4} = 3$, \quad
$\dfrac{15}{5} = 3$. All three ratios agree, which is exactly the evidence that the triangles
are similar with scale factor $3$.
\[ \boxed{3 \qquad 3 \qquad 3} \]

\vspace{0.2cm}

\noindent\rule{\linewidth}{0.2pt}

\problem{$E(2,5)$, $F(6,7)$ rotated $180^\circ$ about the origin to $E'(-2,-5)$, $F'(-6,-7)$.
Compare the slopes.}

\textbf{Solution:} \quad Slope of $EF = \dfrac{7-5}{6-2} = \dfrac{2}{4}$. Slope of
$E'F' = \dfrac{-7-(-5)}{-6-(-2)} = \dfrac{-2}{-4}$. Both signs cancel, giving the same value.
\[ \boxed{\text{slope } EF = \tfrac{1}{2} \qquad \text{slope } E'F' = \tfrac{1}{2}} \]

\vspace{0.2cm}

\noindent\rule{\linewidth}{0.2pt}

\problem{Triangle $P$: $(1,2)$, $(5,2)$, $(1,5)$. Triangle $Q$: $(1,-2)$, $(5,-2)$, $(1,-5)$.
Find both bases and name the transformation.}

\textbf{Solution:} \quad Both bases are horizontal, so each length is the gap between
the two $x$-values: $5 - 1 = 4$ in each triangle.
\[ \boxed{\text{base of } P = 4 \qquad \text{base of } Q = 4} \]

\textbf{Transformation (instructor-judged).} Every vertex keeps its $x$-coordinate and has its
$y$-coordinate negated, so the map is a reflection in the $x$-axis. A correct response also says
why that settles congruence: a reflection is a rigid motion, so it preserves every length and
angle, and the two triangles must be congruent. Naming the reflection without the length
argument is only half the answer.

\vspace{0.2cm}

\noindent\rule{\linewidth}{0.2pt}

\problem{Is $(0,0)$, $(6,0)$, $(0,4)$ congruent to $(0,0)$, $(3,0)$, $(0,2)$?}

\textbf{Solution:} \quad Both bases lie on the $x$-axis, so read them straight off: the first is
$6$ and the second is $3$.
\[ \boxed{\text{first base} = 6 \qquad \text{second base} = 3} \]

\textbf{Judgement (instructor-judged).} A correct response says the student is wrong. Congruent
figures need equal matching lengths, and $6 \neq 3$. The right description is \textit{similar}:
every side of the second triangle is half the matching side of the first, so the two are the same
shape at half the size. Accept any wording that rejects congruence on the unequal lengths and
names the halving.

\vspace{0.2cm}

\noindent\rule{\linewidth}{0.2pt}

\problem{$G(0,0)$, $H(4,3)$ dilated about the origin to $G'(0,0)$, $H'(12,9)$. Find both lengths
and the scale factor.}

\textbf{Solution:} \quad $GH = \sqrt{4^2 + 3^2} = \sqrt{25} = 5$ and
$G'H' = \sqrt{12^2 + 9^2} = \sqrt{225} = 15$. The scale factor is the image length over the
original: $\dfrac{15}{5}$.
\[ \boxed{GH = 5 \qquad G'H' = 15 \qquad k = 3} \]

\vspace{0.2cm}

\noindent\rule{\linewidth}{0.2pt}

\problem{$J(2,1)$, $K(6,4)$ dilated by $2$ to $J'(4,2)$, $K'(12,8)$. Compare the slopes.}

\textbf{Solution:} \quad Slope of $JK = \dfrac{4-1}{6-2} = \dfrac{3}{4}$. Slope of
$J'K' = \dfrac{8-2}{12-4} = \dfrac{6}{8}$, the same fraction. The dilation doubled both the rise
and the run, so the ratio could not change.
\[ \boxed{\text{slope } JK = \tfrac{3}{4} \qquad \text{slope } J'K' = \tfrac{3}{4}} \]

\vspace{0.2cm}

\noindent\rule{\linewidth}{0.2pt}

\problem{$(2,1)$, $(5,1)$, $(2,3)$ maps to $(-2,1)$, $(-5,1)$, $(-2,3)$. Find both bases and name
the transformation.}

\textbf{Solution:} \quad The first base runs from $x = 2$ to $x = 5$, a length of $3$; the image
base runs from $x = -2$ to $x = -5$, also a length of $3$.
\[ \boxed{\text{first base} = 3 \qquad \text{image base} = 3} \]

\textbf{Transformation (instructor-judged).} Each $x$-coordinate is negated and each
$y$-coordinate is unchanged, so this is a reflection in the $y$-axis. A correct response adds
that a reflection preserves distance, so matching sides stay equal and the triangles are
congruent. A name alone is half the answer.

\vspace{0.2cm}

\noindent\rule{\linewidth}{0.2pt}

\problem{Right triangles from the origin to $(5,12)$ and to $(15,36)$. Find both longest sides and
their ratio.}

\textbf{Solution:} \quad $\sqrt{5^2 + 12^2} = \sqrt{169} = 13$ and
$\sqrt{15^2 + 36^2} = \sqrt{1521} = 39$. Dividing gives $\dfrac{39}{13}$, and the legs scale the
same way ($15 = 3 \cdot 5$, $36 = 3 \cdot 12$), so the two triangles are similar.
\[ \boxed{13 \qquad 39 \qquad \text{ratio} = 3} \]

\vspace{0.2cm}

\noindent\rule{\linewidth}{0.2pt}

\problem{$A(0,0)$, $B(4,0)$, $C(0,3)$ dilated by $2$ to $A'(0,0)$, $B'(8,0)$, $C'(0,6)$. Compare
the slopes of $BC$ and $B'C'$.}

\textbf{Solution:} \quad Slope of $BC = \dfrac{3-0}{0-4} = -\dfrac{3}{4}$ and slope of
$B'C' = \dfrac{6-0}{0-8} = -\dfrac{6}{8}$, which reduces to the same number.
\[ \boxed{\text{slope } BC = -\tfrac{3}{4} \qquad \text{slope } B'C' = -\tfrac{3}{4}} \]

\textbf{Reason (instructor-judged).} A correct response says the equal slopes make $BC$ and
$B'C'$ parallel, and that the same is true of every pair of matching sides, so the matching
angles of the two triangles are equal. That is what makes the image similar to the original
rather than a different shape.

\vspace{0.2cm}

\noindent\rule{\linewidth}{0.2pt}

\problem{$ABC$: $A(-4,-2)$, $B(0,-2)$, $C(-4,1)$. $DEF$: $D(0,0)$, $E(6,0)$, $F(0,4.5)$.
Congruent, similar, or neither?}

\textbf{Solution:} \quad $AB$ is horizontal from $x = -4$ to $x = 0$, so $AB = 4$; $DE$ is
horizontal from $x = 0$ to $x = 6$, so $DE = 6$. The ratio is $\dfrac{6}{4}$, which reduces to
$\tfrac{3}{2}$. The other pair matches it too: $AC = 3$ and $DF = 4.5$, and
$4.5 \div 3 = 1.5$ as well.
\[ \boxed{AB = 4 \qquad DE = 6 \qquad \text{ratio} = \tfrac{3}{2}} \]

\textbf{Conclusion (instructor-judged).} A correct response chooses \textit{similar but not
congruent} and supports it with both facts: the matching lengths are unequal ($4$ against $6$),
which rules out congruence, and every pair of matching sides is in the same ratio $3 : 2$, which
is what similarity requires. A choice with no computed support earns no credit.
