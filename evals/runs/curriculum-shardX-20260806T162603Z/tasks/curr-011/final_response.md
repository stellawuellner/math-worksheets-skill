# More, Fewer, or the Same? (Kindergarten–Grade 1)

Three PDFs are ready:

- **ws_morefewer_curr011.pdf** — an 8-problem guided concept worksheet on
  using *more*, *fewer*, and *the same* with object sets. Every problem shows
  concrete sets (cats and bowls, grape rows, star/moon rows, arrays), the
  child counts and writes each number, and the comparison language is
  connected to the counts. One problem has the child draw one-to-one pairing
  lines — the concrete model behind "more" — and a spread-out-row problem
  targets the classic "longer looks bigger" misconception.
- **ak_morefewer_curr011.pdf** — the step-by-step answer key: each solution
  writes the counts, states the comparison in words, and shows the symbol form
  (3 < 5), with a quick-answers bank and generated Curriculum section
  (K.CC.C.6).
- **ss_morefewer_curr011.pdf** — a one-page study guide: matching pairs to
  compare, more or fewer by counting, and spotting the same number, each with
  a rule, worked example, and try-it, plus a watch-out about spread-out rows.

**What is verified:** 24 of the 26 responses are machine-checked with SymPy —
every count is verified against the dot data that draws its set, and every
more/fewer/same answer is verified as the underlying comparison (each labeled
in the answer bank so you can see which value answers which blank). **Two
items are instructor-judged:** the drawn pairing lines with the circled row,
and the challenge's "tell how you know" — the key states exactly what to
accept for each. The study guide's examples and try-its are machine-verified
the same way.
