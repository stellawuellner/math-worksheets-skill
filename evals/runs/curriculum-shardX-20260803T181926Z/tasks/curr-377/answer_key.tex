\problem{Evaluate using the product property. \quad $\log_2 8 + \log_2 4$}

\textbf{Solution:} The product property runs backwards here: a sum of logs with the same base is the log of the product.
\[ \log_2 8 + \log_2 4 = \log_2(8 \cdot 4) = \log_2 32 \]
Since $2^5 = 32$, the value is five.

$\Rightarrow$ \ans{5}

\vspace{0.15cm}\noindent\rule{\linewidth}{0.2pt}

\problem{Expand into separate terms, writing the constant term as a multiple of $\ln 2$. \quad $\ln(8x)$}

\textbf{Solution:} Product property first, then the power property on the constant:
\[ \ln(8x) = \ln 8 + \ln x = \ln(2^3) + \ln x \]

$\Rightarrow$ \ans{3\ln 2 + \ln x}

\vspace{0.15cm}\noindent\rule{\linewidth}{0.2pt}

\problem{Write as a single logarithm, then evaluate. \quad $2\log_3 6 - \log_3 4$}

\textbf{Solution:} Power property on the coefficient, then the quotient property:
\[ 2\log_3 6 - \log_3 4 = \log_3(6^2) - \log_3 4 = \log_3\!\left(\frac{36}{4}\right) \]
The quotient is nine, and $3^2 = 9$.

$\Rightarrow$ \ans{\log_3 9 = 2}

\vspace{0.15cm}\noindent\rule{\linewidth}{0.2pt}

\problem{Evaluate using the product property. \quad $\log_6 4 + \log_6 9$}

\textbf{Solution:} Combine first, then recognise the power of the base:
\[ \log_6 4 + \log_6 9 = \log_6(4 \cdot 9) = \log_6 36 \]
Since $6^2 = 36$, the value is two.

$\Rightarrow$ \ans{2}

\vspace{0.15cm}\noindent\rule{\linewidth}{0.2pt}

\problem{Expand using the quotient property. \quad $\log_2\!\left(\dfrac{x}{32}\right)$}

\textbf{Solution:} The quotient property splits a fraction into a difference:
\[ \log_2\!\left(\frac{x}{32}\right) = \log_2 x - \log_2 32 \]
and $\log_2 32 = 5$ because $2^5 = 32$, so the second term is a plain number.

$\Rightarrow$ \ans{\log_2 x - 5}

\vspace{0.15cm}\noindent\rule{\linewidth}{0.2pt}

\problem{Solve for $x$. \quad $\log_3 x + \log_3 4 = \log_3 20$}

\textbf{Solution:} Condense the left side with the product property, then use that the logarithm is one-to-one:
\[ \log_3(4x) = \log_3 20 \;\Longrightarrow\; 4x = 20 \]
Dividing by four gives five, and $x = 5$ makes both logarithms' arguments positive, so it is not extraneous.

$\Rightarrow$ \ans{x = 5}

\vspace{0.15cm}\noindent\rule{\linewidth}{0.2pt}

\problem{Write as a single logarithm. \quad $3\ln 2 + 2\ln 5$}

\textbf{Solution:} Power property on each coefficient, then the product property:
\[ 3\ln 2 + 2\ln 5 = \ln(2^3) + \ln(5^2) = \ln(8 \cdot 25) \]

$\Rightarrow$ \ans{\ln 200}

\vspace{0.15cm}\noindent\rule{\linewidth}{0.2pt}

\problem{\textbf{(a)} Expand $\log_2\!\left(\dfrac{x^5}{16}\right)$. \quad \textbf{(b)} Evaluate it at $x = 4$.}

\textbf{Solution (a):} Quotient property first, then the power property on the numerator:
\[ \log_2\!\left(\frac{x^5}{16}\right) = \log_2(x^5) - \log_2 16 = 5\log_2 x - 4 \]

$\Rightarrow$ \ans{5\log_2 x - 4}

\textbf{Solution (b):} At $x = 4$, $\log_2 4 = 2$, so the expanded form gives $5(2) - 4$.

$\Rightarrow$ \ans{6}

\vspace{0.15cm}\noindent\rule{\linewidth}{0.2pt}

\problem{Solve for $x$. \quad $\log x - \log 3 = \log 7$}

\textbf{Solution:} Condense the left side with the quotient property:
\[ \log\!\left(\frac{x}{3}\right) = \log 7 \;\Longrightarrow\; \frac{x}{3} = 7 \]
Multiplying by three gives twenty-one, which is positive, so it is a genuine solution.

$\Rightarrow$ \ans{x = 21}

\vspace{0.15cm}\noindent\rule{\linewidth}{0.2pt}

\problem{Using only $\log 2 \approx 0.3010$, $\log 3 \approx 0.4771$ and the properties, approximate $\log 48$.}

\textbf{Solution:} Factor $48$ into powers of the two numbers whose logs are known: $48 = 2^4 \cdot 3$. Now the product and power properties do the rest:
\[ \log 48 = \log(2^4) + \log 3 = 4\log 2 + \log 3 \approx 4(0.3010) + 0.4771 \]
That sum is $1.2040 + 0.4771 = 1.6811$, which rounds to three decimal places as follows.

$\Rightarrow$ \ans{1.681}

\vspace{0.15cm}\noindent\rule{\linewidth}{0.2pt}

\problem{\textbf{(a)} Write $3\ln x - \ln y - 2\ln z$ as a single logarithm. \quad \textbf{(b)} Evaluate at $x = 2$, $y = 4$, $z = 1$.}

\textbf{Solution (a):} Power property on every coefficient first, then one product and one quotient step. Both subtracted logs go into the denominator:
\[ 3\ln x - \ln y - 2\ln z = \ln(x^3) - \ln y - \ln(z^2) \]

$\Rightarrow$ \ans{\ln\!\left(\dfrac{x^3}{y z^2}\right)}

\textbf{Solution (b):} Substituting gives $\dfrac{2^3}{4 \cdot 1^2} = \dfrac{8}{4}$, and the logarithm of that quotient is the exact answer below.

$\Rightarrow$ \ans{\ln 2}

\vspace{0.15cm}\noindent\rule{\linewidth}{0.2pt}

\problem{Solve for $x$. \quad $3\log_2 x = \log_2 27$}

\textbf{Solution:} Power property turns the coefficient into an exponent, then match arguments:
\[ 3\log_2 x = \log_2(x^3) = \log_2 27 \;\Longrightarrow\; x^3 = 27 \]
The only real cube root of twenty-seven is three, and it is positive, so the domain condition holds.

$\Rightarrow$ \ans{x = 3}
