\noindent\textbf{Directions:}
\begin{itemize}[leftmargin=1.1cm, itemsep=1pt, topsep=2pt]
  \item All angles $\theta$ are measured in radians.
  \item Give exact values where an exact value exists; otherwise round to two decimal places.
  \item Work in the space under each problem and write the final answer on the answer line.
\end{itemize}

\problem[4.5cm]{The cardioid $r = 4 + 4\cos\theta$ is graphed one point at a time.
Find the exact value of $r$ when $\theta = \dfrac{\pi}{3}$.}

Find $r$ when $\theta = \dfrac{\pi}{3}$, which locates one point of that circle.}
