# Find the Error: Rounding and Place Value — Grades 4–5

Here are the three PDFs for this error-analysis set:

- **Worksheet** (`ws_rounderrors_curr104.pdf`) — 8 problems built around
  diagnosing rounding-boundary and placeholder errors. Three are find-and-fix
  items showing a named student's wrong work (Leo's 4,972 → "4,900", Mia's
  30 × 40 = "120", Jon's 50,000 + 300 + 7 = "5,307"); the rest exercise the
  same trap-prone skills directly: rounding across a 9 (2,963; 39,725; 9,984),
  a circle-all item on which numbers round to 700, and a final "Ava" item on
  what shared rounded values do and do not prove.
- **Answer key** (`ak_rounderrors_curr104.pdf`) — quick-answers bank, then full
  reasoning for every problem, including a full-credit rubric for each written
  explanation. Every planted wrong result is declared as a machine-checked
  misconception trap, so the key prints a "common wrong answers" line for each
  (e.g. "If they got 4,900: rounded down despite the tens digit 7") — grading
  doubles as diagnosis. Curriculum section: 4.NBT.A.1, 4.NBT.A.2, 4.NBT.A.3.
- **Study guide** (`ss_rounderrors_curr104.pdf`) — three sections: rounding
  across a nine, zeros that hold a place, and what rounding does (and does not)
  claim, each with rule, worked example, and try-it.

**What is verified:** 12 numeric answers are machine-checked (every rounding,
product, and standard-form value, including all four roundings in the
circle-all problem), and all six planted wrong results are machine-verified to
be distinguishably wrong via declared traps. Five responses are
instructor-judged and flagged for manual review: the four written explanations
(problems 3, 4, 6, 8) and the circled selection in problem 7 — each with an
explicit rubric in the key. The key's "What is verified" note reflects this
same split.
