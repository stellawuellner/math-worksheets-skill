\problem{\textbf{3 counters, then 2 more.}\\
\textbf{Step 1.} The story starts with 3 and 2 more are added, so this is an
add-to story: $3 + 2 = \;?$\\
\textbf{Step 2.} Count on from 3: ``4, 5.'' Two counts, so the frame holds
$\ans{5}$ counters in all.}

\problem{\textbf{Maya: 4 stickers, then 3 more.}\\
\textbf{Step 1.} Start amount 4, change $+3$: $4 + 3 = \;?$\\
\textbf{Step 2.} Count on from 4: ``5, 6, 7.'' Three counts, so Maya has
$\ans{7}$ stickers.}

\problem{\textbf{4 birds, then 5 more land.}\\
\textbf{Step 1.} The number sentence is $4 + 5 = \;?$ --- the two parts are
4 and 5 and the whole is unknown.\\
\textbf{Step 2.} Start at the bigger part, 5, and count on 4: ``6, 7, 8, 9.''
So $4 + 5 = \ans{9}$ birds.}

\problem{\textbf{6 counters, then 2 more.}\\
\textbf{Step 1.} The frame already shows 6 (a full row of 5 and 1 more), and
2 counters are added: $6 + 2 = \;?$\\
\textbf{Step 2.} Count on from 6: ``7, 8.'' The frame holds $\ans{8}$
counters in all.}

\problem{\textbf{2 fish, then 6 more.}\\
\textbf{Step 1.} $2 + 6 = \;?$ Adding in either order gives the same total, so
start at the bigger part, 6.\\
\textbf{Step 2.} Count on 2 from 6: ``7, 8.'' There are $\ans{8}$ fish in all.
(Counting on from 2 gives the same answer but takes six counts.)}

\problem{\textbf{5 blocks, then 3 more.}\\
\textbf{Step 1.} Start amount 5, change $+3$, total unknown, so the number
sentence is $5 + 3 = \;?$\\
\textbf{Step 2.} Count on from 5: ``6, 7, 8.'' The finished sentence is
$5 + 3 = \ans{8}$ blocks.}

\problem{\textbf{Ana: 3 crayons, then 2 more, then 4 more.}\\
\textbf{Step 1.} Two changes are added to the same start, so one sentence
covers the whole story: $3 + 2 + 4 = \;?$\\
\textbf{Step 2.} Add the first change: $3 + 2 = 5$. Now count on 4 from 5:
``6, 7, 8, 9.'' Ana has $\ans{9}$ crayons.}

\problem{\textbf{Ben: 4 cars, then 3 more, then 2 more.}\\
\textbf{Step 1.} The sentence for the whole story is $4 + 3 + 2 = \;?$\\
\textbf{Step 2.} $4 + 3 = 7$, then count on 2 from 7: ``8, 9.''\\
\textbf{Step 3.} Ben is \textbf{not} right. He said 8 because he started
counting at 4 instead of 5, which loses one car. The correct total is
$\ans{9}$ cars.}
