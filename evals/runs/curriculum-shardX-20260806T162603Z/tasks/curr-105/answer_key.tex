\problem{$60{,}000 + 2{,}000 + 400 + 9$ in standard form.}

\textbf{Solution:} 6 ten-thousands, 2 thousands, 4 hundreds, 0 tens (zero holds
the empty place), 9 ones. \ans{62409}

\problem{$8{,}315 = 8{,}000 + \square + 10 + 5$}

\textbf{Solution:} The 8 thousands, 1 ten, and 5 ones are already listed; the
digit 3 of $8{,}315$ sits in the hundreds place, so the missing addend is
$300$. Check: $8{,}000 + 300 + 10 + 5 = 8{,}315$. \ans{300}

\problem{$36{,}254 \;\square\; 36{,}245$}

\textbf{Solution:} Ten-thousands, thousands, hundreds all match (3, 6, 2);
tens differ: $5 > 4$. \ans{36{,}254 > 36{,}245}

\problem{Round $7{,}438$ to the nearest hundred.}

\textbf{Solution:} Hundreds digit 4; tens digit $3 < 5$, so round down —
keep 4 hundreds. \ans{7400}

\problem{Which number is $30{,}000 + 500 + 20 + 8$?}

\textbf{Solution:} 3 ten-thousands, 0 thousands (placeholder!), 5 hundreds,
2 tens, 8 ones. \ans{30528}

\problem{Round $52{,}499$ to the nearest thousand.}

\textbf{Solution:} Thousands digit 2; look right at the hundreds digit:
$4 < 5$, so round \emph{down}. The trailing 499 is below the midpoint 500, so
$52{,}499 \rightarrow 52{,}000$. \ans{52000}

\problem{Order least to greatest: $8{,}742$; $8{,}724$; $8{,}772$.}

\textbf{Solution:} All share 8 thousands and 7 hundreds; compare tens:
$2 < 4 < 7$. \ans{8{,}724,\ 8{,}742,\ 8{,}772}

\problem{Round $63{,}970$ to the nearest hundred.}

\textbf{Solution:} Hundreds digit 9; tens digit $7 \geq 5$, so round up: 639
hundreds become 640 hundreds — the carry rolls into the thousands:
$64{,}000$. \ans{64000}

\problem{$40{,}000 + 3{,}000 + 70$ in standard form, then compare with $43{,}900$.}

\textbf{Solution:} The total is 4 ten-thousands, 3 thousands, 0 hundreds
(placeholder), 7 tens, 0 ones: $43{,}070$. \ans{43070}

Compare with $43{,}900$: hundreds differ, $0 < 9$.
\ans{43{,}070 < 43{,}900}

\problem{$45{,}067$ ducks: nearest thousand, nearest hundred, and which is
closer?}

\textbf{Solution:} Nearest thousand: hundreds digit $0 < 5$, round down.
\ans{45000}

Nearest hundred: the hundreds block is 0 and the tens digit is $6 \geq 5$, so
round up to 1 hundred: \ans{45100}

Closer: $45{,}100$ is $45{,}100 - 45{,}067 = 33$ away, while $45{,}067 -
45{,}000 = 67$. The nearest-hundred value is closer — rounding to a smaller
place always stays at least as close.

\problem{Ben says $76{,}099 > 76{,}105$.}

\textbf{Solution:} Line up places. Ten-thousands, thousands match (7, 6);
hundreds differ: $0 < 1$, so $76{,}099$ is smaller.
\ans{76{,}099 < 76{,}105}

Full-credit explanation: Ben judged by the eye-catching trailing nines, but the
nines sit in the tens and ones places. Comparison is decided at the highest
place that differs — here the hundreds — and $0 < 1$.

\problem{Attendances $41{,}807$, $41{,}490$, $42{,}088$.}

\textbf{Solution:} (a) Compare thousands first: $42{,}088$ has 42 thousands,
the others 41; between those, hundreds $8 > 4$.
\ans{42{,}088,\ 41{,}807,\ 41{,}490}

(b) $42{,}088$: tens digit $8 \geq 5$, so 0 hundreds round up to 1:
\ans{42100}

(c) Check each hundreds digit against the thousand below it: $41{,}807$ rounds
up to $42{,}000$ ($8 \geq 5$); $42{,}088$ rounds down to $42{,}000$ ($0 < 5$);
$41{,}490$ rounds down to $41{,}000$ ($4 < 5$). So $41{,}807$ and $42{,}088$
round to the same value, $42{,}000$ — one from below, one from above.
