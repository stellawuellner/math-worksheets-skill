\problem{Table $5, 9, 13, 17$. (a) A difference. (b) A ratio. (c) Which model, and why.}

\textbf{Solution (a):} $9 - 5$. \ans{4}

\textbf{Solution (b):} $9 \div 5$. \ans{1.8}

The remaining differences are $13 - 9 = 4$ and $17 - 13 = 4$: constant. The remaining ratios are $13 \div 9 \approx 1.44$ and $17 \div 13 \approx 1.31$: not constant.

\textbf{(c) --- instructor-judged.} A correct answer names the table linear and gives the constant-difference reason: every one-step increase in the input adds the same amount, $4$, to the output, while the ratios of successive outputs are not equal. Full credit for the label plus the constant-difference evidence; partial credit for the label alone.

\problem{Table $6, 18, 54, 162$. (a) A ratio. (b) First difference. (c) Second difference.}

\textbf{Solution (a):} $18 \div 6$. \ans{3}

\textbf{Solution (b):} $18 - 6$. \ans{12}

\textbf{Solution (c):} $54 - 18$. \ans{36}

The ratio stays at $3$ ($54 \div 18 = 3$, $162 \div 54 = 3$) while the differences $12$, $36$, $108$ keep growing --- the signature of exponential growth, with rule $y = 6 \cdot 3^{\,x}$.

\vspace{0.2cm}\noindent\rule{\linewidth}{0.2pt}

\problem{$f(x) = 4 + 6x$, $g(x) = 4 \cdot 2^{\,x}$. Find $f(5)$ and $g(5)$.}

\textbf{Solution (a):} $4 + 6(5) = 4 + 30$. \ans{f(5) = 34}

\textbf{Solution (b):} $2^5 = 32$, so $4 \cdot 32$. \ans{g(5) = 128}

Both start at $4$; five steps of $+6$ reach $34$, five doublings reach $128$.

\vspace{0.2cm}\noindent\rule{\linewidth}{0.2pt}

\problem{Town of $200$: model $L$ adds $30$ a year, model $E$ multiplies by $1.15$ a year. Populations after $4$ years.}

\textbf{Solution (a):} $200 + 30(4) = 200 + 120$. \ans{320}

\textbf{Solution (b):} $1.15^4 = 1.74900625$, so $200 \times 1.74900625 = 349.80125$, which rounds to two decimal places. \ans{349.80}

\vspace{0.2cm}\noindent\rule{\linewidth}{0.2pt}

\problem{Table $80, 40, 20, 10$. (a) The ratio. (b) The value at $x = 4$.}

\textbf{Solution (a):} $40 \div 80$. \ans{0.5}

\textbf{Solution (b):} The pattern halves, so continue by halving rather than by subtracting: $80 \cdot \left(\tfrac{1}{2}\right)^4 = \tfrac{80}{16}$, which is $10 \div 2$. \ans{5}

\vspace{0.2cm}\noindent\rule{\linewidth}{0.2pt}

\problem{$f(x) = 50 + 20x$, $g(x) = 5 \cdot 2^{\,x}$. Find $f(4)$, $g(4)$, $f(8)$, $g(8)$.}

\textbf{Solution (a):} $50 + 20(4) = 50 + 80$. \ans{f(4) = 130}

\textbf{Solution (b):} $2^4 = 16$, so $5 \cdot 16$. \ans{g(4) = 80}

\textbf{Solution (c):} $50 + 20(8) = 50 + 160$. \ans{f(8) = 210}

\textbf{Solution (d):} $2^8 = 256$, so $5 \cdot 256$. \ans{g(8) = 1280}

At $x = 4$ the linear rule is ahead; by $x = 8$ the exponential rule is six times larger. An exponential eventually passes any linear rule.

\vspace{0.2cm}\noindent\rule{\linewidth}{0.2pt}

\problem{Two \$500 plans: $A$ adds \$40 a month, $B$ multiplies by $1.06$ a month. Values after $12$ months, and which is better.}

\textbf{Solution (a):} $500 + 40(12) = 500 + 480$. \ans{980}

\textbf{Solution (b):} $1.06^{12} = 2.01219647\ldots$, so $500 \times 2.01219647 = 1006.0982\ldots$, rounded to two decimal places. \ans{1006.10}

\textbf{(c) --- instructor-judged.} A correct answer says plan $B$ is worth more after twelve months and that its lead keeps widening, because a fixed percentage is applied to an ever-larger balance while the fixed monthly amount never changes. Full credit for naming plan $B$ and giving the growing-base reason; partial credit for the comparison at twelve months alone.

\vspace{0.2cm}\noindent\rule{\linewidth}{0.2pt}

\problem{$g(x) = 3 \cdot 2^{\,x}$. Solve $g(x) = 96$.}

\textbf{Solution:} Divide both sides by $3$: $2^{\,x} = 32$. Now write $32$ as a power of $2$: $32 = 2^5$, so the exponents match. Check: $3 \cdot 2^5 = 3 \cdot 32 = 96$ $\checkmark$ \ans{x = 5}

\vspace{0.2cm}\noindent\rule{\linewidth}{0.2pt}

\problem{Car worth \$24{,}000: straight line subtracts \$2400 a year, percentage method multiplies by $0.88$ a year. Values after $5$ years.}

\textbf{Solution (a):} $24000 - 2400(5) = 24000 - 12000$. \ans{12000}

\textbf{Solution (b):} $0.88^5 = 0.5277319168$, so $24000 \times 0.5277319168 = 12665.5660\ldots$, rounded to two decimal places. \ans{12665.57}

The percentage method leaves the car worth more here, because each year's loss is taken from a smaller value than the year before.

\vspace{0.2cm}\noindent\rule{\linewidth}{0.2pt}

\problem{$f(x) = 100 + 25x$, $g(x) = 100 \cdot 1.2^{\,x}$. Values at $x = 3$ and $x = 4$, and where $g$ overtakes.}

\textbf{Solution (a):} $100 + 25(3) = 100 + 75$. \ans{f(3) = 175}

\textbf{Solution (b):} $1.2^3 = 1.728$, so $100 \times 1.728$. \ans{g(3) = 172.80}

\textbf{Solution (c):} $100 + 25(4) = 100 + 100$. \ans{f(4) = 200}

\textbf{Solution (d):} $1.2^4 = 2.0736$, so $100 \times 2.0736$. \ans{g(4) = 207.36}

\textbf{(e) --- instructor-judged.} A correct answer states that the exponential model first overtakes the linear one at input $4$, and justifies it from the two computed pairs: at input $3$ the linear value $175$ is still the larger, and at input $4$ the exponential value $207.36$ has passed $200$. Full credit for the value $4$ supported by both comparisons; partial credit for the value with only one comparison.
