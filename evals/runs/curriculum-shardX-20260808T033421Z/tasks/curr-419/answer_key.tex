\problem{Convert $\dfrac{5\pi}{6}$ radians to degrees. Student wrote $\dfrac{5\pi}{6}\cdot\dfrac{\pi}{180} = 0.0457$.}

\textbf{(a)} A half turn is $\pi$ radians and also $180^\circ$, so the two conversion factors are $\dfrac{\pi}{180}$ (degrees $\to$ radians) and $\dfrac{180}{\pi}$ (radians $\to$ degrees). The measure given is already in radians, so use the second:
\[ \frac{5\pi}{6}\cdot\frac{180}{\pi} = \frac{5 \cdot 180}{6} = 150. \]
The $\pi$ cancels, which is the signal that the direction is right. \ans{150^\circ}

\textbf{(b)} \emph{Instructor-judged.} The response must say the factor was used upside down: $\dfrac{\pi}{180}$ converts degrees into radians, and the given measure was already in radians, so $\dfrac{180}{\pi}$ was needed. Full credit requires naming the direction; ``the answer is too small'' alone is partial. A useful check to point out: the $\pi$ did not cancel, and a leftover $\pi^2$ is always a sign the factor was inverted.

\problem{Evaluate $\cos 210^\circ$. Student wrote $+\dfrac{\sqrt{3}}{2}$, from reference angle $30^\circ$.}

\textbf{(a)} $210^\circ = 180^\circ + 30^\circ$, so the reference angle is $30^\circ$ and the terminal side lies in quadrant III. In quadrant III cosine is negative, so
\[ \cos 210^\circ = -\cos 30^\circ = -\frac{\sqrt{3}}{2} \approx -0.866. \]
\ans{-\dfrac{\sqrt{3}}{2}}

\textbf{(b)} \emph{Instructor-judged.} The response must locate the fault in the \emph{sign} step, not the reference angle: both the reference angle $30^\circ$ and the value $\dfrac{\sqrt{3}}{2}$ are correct, but $210^\circ$ is in quadrant III, where cosine is negative, so the minus sign has to be attached at the end. Full credit requires naming the quadrant and the sign of cosine there.

\vspace{0.15cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.15cm}

\problem{Solve $2\sin\theta - 1 = 0$ on $0^\circ \le \theta < 360^\circ$. Student reported $0.5236$ and $2.6180$.}

\textbf{(a)} $2\sin\theta = 1$, so $\sin\theta = \dfrac{1}{2}$. Sine is positive in quadrants I and II, and the reference angle with sine $\dfrac{1}{2}$ is $30^\circ$, so
\[ \theta = 30^\circ \quad\text{and}\quad \theta = 180^\circ - 30^\circ = 150^\circ. \]
\ans{\theta = 30^\circ,\ 150^\circ}

\textbf{(b)} \emph{Instructor-judged.} The response must say the calculator was left in radian mode while the interval was stated in degrees. A strong answer notes that $0.5236 \approx \dfrac{\pi}{6}$ and $2.6180 \approx \dfrac{5\pi}{6}$ are the \emph{same two angles} measured in radians, so the mathematics was right and only the mode was wrong. ``The numbers are too small'' alone is partial credit.

\vspace{0.15cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.15cm}

\problem{Solve $\tan\theta = -1$ on $0^\circ \le \theta < 360^\circ$. Student reported the single solution $-45^\circ$.}

\textbf{(a)} Tangent is negative in quadrants II and IV, and $\tan 45^\circ = 1$, so the reference angle is $45^\circ$:
\[ \theta = 180^\circ - 45^\circ = 135^\circ \quad\text{(II)}, \qquad \theta = 360^\circ - 45^\circ = 315^\circ \quad\text{(IV)}. \]
Tangent has period $180^\circ$, so a $360^\circ$ interval always holds two solutions. \ans{\theta = 135^\circ,\ 315^\circ}

\textbf{(b)} \emph{Instructor-judged.} Two distinct faults must be named. (i) $\tan^{-1}$ returns an angle strictly between $-90^\circ$ and $90^\circ$, so its output must be moved into the requested interval --- here by adding $180^\circ$. (ii) A $360^\circ$ interval spans two periods of tangent, so there are two solutions, not one. Naming only one fault is half credit.

\vspace{0.15cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.15cm}

\problem{Evaluate $\sin\dfrac{7\pi}{6}$. Student wrote $-\dfrac{\sqrt{3}}{2}$.}

\textbf{(a)} $\dfrac{7\pi}{6} = \pi + \dfrac{\pi}{6}$, so the reference angle is $\dfrac{\pi}{6}$ and the angle is in quadrant III, where sine is negative. The sine of $\dfrac{\pi}{6}$ is $\dfrac{1}{2}$, not $\dfrac{\sqrt{3}}{2}$:
\[ \sin\frac{7\pi}{6} = -\sin\frac{\pi}{6} = -\frac{1}{2}. \]
\ans{-\tfrac{1}{2}}

\textbf{(b)} \emph{Instructor-judged.} The response must say the sign was right and the ratio was wrong: $\dfrac{\sqrt{3}}{2}$ is the \emph{cosine} of $\dfrac{\pi}{6}$, while its sine is $\dfrac{1}{2}$. The quadrant fixes only the sign, never which ratio to read. Full credit requires naming the sine-for-cosine swap explicitly.

\vspace{0.15cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.15cm}

\problem{Find $\sin(2)$ with $2$ in radians. Student's calculator returned $0.0349$.}

\textbf{(a)} In radian mode, $\sin(2) = 0.9092974\ldots$, so to four decimal places. \ans{0.9093}

\textbf{(b)} \emph{Instructor-judged.} The response must say the calculator was in degree mode, so it evaluated $\sin 2^\circ$ rather than the sine of an arc of $2$ radians. A strong answer adds the reason the gap is so wide: $2$ radians is about $114.6^\circ$, an angle in quadrant II not far from the maximum of sine, whereas $2^\circ$ is nearly a zero angle. Checking that $\sin 2^\circ \approx 0.0349$ reproduces the student's number exactly is the confirmation.

\problem{Given $\sin\theta = -\dfrac{3}{5}$ and $\cos\theta > 0$. Student put $\theta$ in quadrant III and wrote $\cos\theta = -\dfrac{4}{5}$.}

\textbf{(a)} From the Pythagorean identity, $\cos^2\theta = 1 - \sin^2\theta = 1 - \dfrac{9}{25} = \dfrac{16}{25}$, so $\cos\theta = \pm\dfrac{4}{5}$. The problem states $\cos\theta > 0$, which selects the positive root. \ans{\cos\theta = \tfrac{4}{5}}

\textbf{(b)} \emph{Instructor-judged.} The response must place $\theta$ in quadrant IV and give the two-sign argument: a negative sine rules out quadrants I and II, a positive cosine rules out quadrants II and III, and only quadrant IV survives both. The error was to decide the quadrant from the sign of sine alone and then to \emph{derive} the sign of cosine from that guess, discarding the second given. Naming the quadrant without the argument is partial credit.

\vspace{0.15cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.15cm}

\problem{Solve $\cos\theta = -\dfrac{1}{2}$ on $0 \le \theta < 2\pi$. Student reported $120$ and $240$.}

\textbf{(a)} Cosine is negative in quadrants II and III, and the reference angle with cosine $\dfrac{1}{2}$ is $\dfrac{\pi}{3}$:
\[ \theta = \pi - \frac{\pi}{3} = \frac{2\pi}{3} \quad\text{(II)}, \qquad \theta = \pi + \frac{\pi}{3} = \frac{4\pi}{3} \quad\text{(III)}. \]
\ans{\theta = \tfrac{2\pi}{3},\ \tfrac{4\pi}{3}}

\textbf{(b)} \emph{Instructor-judged.} Two faults, and the check that catches them. (i) The interval was written in radians ($0$ to $2\pi$), so the answers must be radian measures; the student found the right angles but reported them in degrees. (ii) Neither reported value lies in the stated interval at all, since $2\pi \approx 6.28$. The fix is to multiply each degree measure by $\dfrac{\pi}{180}$, and the check is to confirm every answer actually falls inside the interval before writing it down.
