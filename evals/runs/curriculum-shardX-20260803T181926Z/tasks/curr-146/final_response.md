# Reading and plotting first-quadrant coordinate points (Grades 4–5)

Three PDFs are ready:

- **`ws_coords_curr146.pdf`** — the student worksheet, 10 problems, 6 pages.
- **`ak_coords_curr146.pdf`** — the answer key with the reasoning written out, 3 pages.
- **`ss_coords_curr146.pdf`** — a 2-page study guide.

## What the worksheet does

One idea runs through all ten problems: **an ordered pair is a pair of instructions, and
the order is part of the meaning**. Across first, then up. Every problem carries its own
first-quadrant grid — some with points already plotted to read, some blank to plot on — so
the child never has to hold a picture in their head while working on another page.

The ten problems:

1–3. Read points $A(2,5)$, $B(6,3)$ and then $E(0,6)$ — the last one sitting right on the
   $y$-axis, where a coordinate of $0$ is a real instruction ("don't go across at all") and
   not a mistake.
4. Plot $P(3,6)$ and $Q(8,6)$, join them, and find the flat line's length: 5 squares.
5. Plot $R(4,2)$ and $S(4,9)$ — an upright line this time: 7 squares. Problems 4 and 5 are
   deliberately paired so the child sees that only one coordinate does the work each time.
6. "How much higher is $C(4,8)$ than $B(6,3)$?" — with a built-in distractor: $B$ is further
   *across*, so a child working from the first numbers gets the wrong quantity. That error
   is a declared, machine-checked trap, and the answer key names it.
7–8. Two counting rules (add 1, add 2) produce five ordered pairs that fall on a straight
   line; the child completes the table, plots them, notices that $y$ is always twice $x$,
   and extends the pattern to $(5,10)$.
9. A story graph: how many books Maya read each week. Read the five heights, total them
   (25) and share them evenly (mean 5).
10. Explain to a friend why $(3,7)$ and $(7,3)$ are not the same point.

## What was verified, and what was not

**Fourteen machine checks across problems 1–9**, all passing: every coordinate read off a
grid, both line lengths, the comparison in problem 6, all three pattern values, and the
total and mean in problem 9 were recomputed independently from the same coordinates that
draw the grids — so the pictures and the answer key cannot disagree.

**Problem 10 is flagged for manual review.** It asks for an explanation, which no checker
can grade. The answer key gives a model answer, a marking guide (full credit for saying
what the *order* means or describing the two journeys; partial credit for "different order
so different point" with no account of what the order does), and a suggestion for what to
do if the child still insists the two points are the same.

## The study guide

Three sections, each with a rule, a worked example whose first step explains why the method
applies, and a distinct try-it with the answer printed upside down inside the box: reading a
point (with a grid showing the across-then-up journey as two red arrows), plotting a point
and measuring a straight line, and turning two counting rules into a list of points. A
closing watch-out box names the one mistake worth checking first. All eight study-guide
values were verified by the same checker as the worksheet.

Standards covered: 5.G.A.1–A.2 / 5.OA.B.3 (coordinate plane, ordered pairs and numerical
patterns) and 4.MD / 5.MD for the data-graph problem. Difficulty ramps 1 → 5.
