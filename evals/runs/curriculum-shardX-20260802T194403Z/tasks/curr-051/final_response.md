Here are the three documents for reading hundreds, tens, and ones from base-ten
models (Grade 2–3, place value through 1,000).

**Worksheet — 8 problems.** Every problem is a drawn base-ten model (flats, rods,
units), so the student reads the picture rather than a numeral. A key at the top
names the three blocks once; no picture carries a printed number, so a student
can never borrow the wrong figure's values. The ramp goes: read a model (1–2,
including one with an empty tens place), write the model in expanded form (3–4),
find the value of one group of blocks (5), trade ten rods for a flat before
reading (6), and compare two models (7–8). Problem 8 is the challenge: Model B
shows twelve rods, so it must be traded before the comparison, and the stem
plants the usual wrong reasoning ("more flats, so it must be bigger") for the
student to knock down.

**Answer key — step by step.** Each solution counts the groups, converts each to
its value, and says why the place matters; problems 2 and 4 call out the
zero-as-placeholder slip (306, not 36) and problem 8 explains exactly where
Rosa's flat-counting argument breaks.

**Study guide — 2 pages, four sections.** Reading a model, expanded form,
trading ten rods for one flat, and comparing two models. Each section has a rule
box, a worked example whose first step says *why* that method applies, and a
try-it with the answer printed upside down inside the box. A watch-out box
covers the missing-zero error.

**Verification.** All 8 worksheet answers were machine-checked with SymPy (6
`eval` place-value computations, 2 `compare` relations) and all 8 study-guide
results as well — nothing on this sheet is flagged manual, because every answer
is a computed number or a comparison. The full gate chain is green, including
the per-problem binding that requires each printed boxed answer to equal its own
verified value.
