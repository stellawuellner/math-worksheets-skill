# Rules, Tables, Graphs, and Sensible Domains — Algebra 1

Three PDFs are ready:

- **Worksheet** (`ws_funcsynth_curr270.pdf`) — 12 interleaved problems that move between the
  four ways a function shows up. Some hand you a **rule** and ask for a table; two hand you a
  **table** and ask for the rule, a missing output, or the input behind an output; two ask you
  to **graph** a rule on the grid provided and read the crossing point off your own line; and
  four are **models** (taxi fare, field-trip cost, a burning candle, a rectangle of fixed
  perimeter) where the question is which inputs the situation actually allows. After the
  warm-up the four types are shuffled, so the student has to decide what each problem is
  asking before starting. Difficulty ramps 1 → 5.
- **Answer key** (`ak_funcsynth_curr270.pdf`) — every value worked out with the substitution or
  the undo-the-rule chain shown, the graph problems explained in points, and a written rubric
  for each open response. Quick Answers and a Curriculum block (HSF-IF.A, difficulty range) sit
  at the top for grading.
- **Study guide** (`ss_funcsynth_curr270.pdf`) — 2 pages, four sections matching the four
  worksheet skills: rule → table, solving when the output is given, rule → graph, and which
  inputs the situation allows. Each has a rule box, a worked example whose first step says why
  that method applies, and a try-it with the answer upside down inside the box.
