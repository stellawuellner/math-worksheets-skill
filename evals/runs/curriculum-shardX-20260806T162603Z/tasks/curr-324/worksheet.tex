\noindent\textbf{Directions}
\begin{itemize}[leftmargin=0.8cm, itemsep=1pt, topsep=2pt]
  \item Each problem shows a calculation that produced a wrong answer. The
        arithmetic is done correctly every time --- the fault is the ratio
        chosen, the inverse function chosen, or the calculator's angle mode.
  \item Redo the calculation correctly and write the value, with its unit, on
        the answer line. Round lengths to two decimal places and angles to two
        decimal places.
  \item Then name the error in a sentence, and where you can, say what about
        the wrong answer should have given it away.
  \item Every diagram is drawn to scale from that problem's givens.
\end{itemize}

\problem{In the right triangle below the hypotenuse is $20$ cm and
$m\angle A = 34^\circ$. To find the side opposite $\angle A$, a student computed
$20\cos 34^\circ = 16.58$ cm.
\par\vspace{0.05cm}
\probfig{1}
\par\vspace{0.05cm}
(a) Find the correct length of the side opposite $\angle A$, in centimetres.
\answerline{cm}
\par\vspace*{2.5cm}
(b) Name the error in the student's choice of ratio.
\par\vspace*{1.9cm}}
