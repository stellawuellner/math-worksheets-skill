# Perimeter and Area of Coordinate Polygons — High School Geometry

Three PDFs are ready:

- **Worksheet** (`ws_coordpolygons_curr328.pdf`, 5 pages) — 8 problems, each with
  its own blank coordinate grid to plot the polygon on before computing.
- **Answer key** (`ak_coordpolygons_curr328.pdf`, 3 pages) — a three-step solution
  per problem, a quick-answer bank, and a generated Curriculum section.
- **Study guide** (`ss_coordpolygons_curr328.pdf`, 2 pages) — three skill sections
  (perimeter, area, justify-then-measure), each with a rule box, a worked
  example, and a separate try-it.

## What is on the worksheet

Every problem is a real object placed on a grid — a sail, a concrete slab, a
floor tile, a flowerbed, a banner, a park, a building lot, a designer's
quadrilateral — and every problem ends in a perimeter or an area.

1. **Perimeter from coordinates** (1, 3): read the axis-parallel sides straight
   off the grid, use the distance formula only on the slanted ones, then add.
2. **Area from coordinates** (2, 4, 7): an axis-aligned rectangle, a triangle
   with no horizontal or vertical side, and an irregular quadrilateral lot where
   shoelace is the only clean route.
3. **Justify, then measure** (5, 6, 8): find both diagonal midpoints of a banner
   to show they bisect before using equal sides to get the perimeter; use two
   slopes to establish a right angle in a park before treating those sides as
   base and height; and decide whether a designer's quadrilateral really is a
   square.

Units are stated in every stem (one grid unit = one metre where the context has
a real size) and each answer blank is labelled with its unit — m, m², units,
square units. Difficulty ramps 1 → 4.

## What was verified

Sixteen machine checks across the 8 problems: distances, midpoints, slopes,
shoelace areas, and the sums that turn side lengths into perimeters. Every boxed
answer in the key was bound problem-by-problem to those verified values, units
included, and the six study-guide items were verified the same way.

Four misconception traps are declared and each was machine-tested to be
distinguishable from the correct answer: adding the two legs instead of using
the distance formula, computing perimeter when area was asked, and twice using
the bounding rectangle instead of the polygon inside it. They print in the key as
"common wrong answers".

**One item is flagged for manual review**, correctly: problem 8's written
justification. The two numbers in that problem (the side length √29 and the area
29) are machine-verified, but the argument that congruent sides *plus* one right
angle make a square — and that congruent sides alone would only give a rhombus —
is prose, so the build reports it as needing a human read. The key includes a
model justification and tells the grader exactly what a complete answer must
contain.

## One note on the standards tags

The curriculum map lists this topic as the range `HSG-GPE.B.4–B.7`. Rather than
copy the whole range onto every problem, each problem carries the specific
standard it exercises: `HSG-GPE.B.7` for the perimeter and area work,
`HSG-GPE.B.5` for the slope criterion for perpendicular lines, and
`HSG-GPE.B.4` for the coordinate-proof problems. The generated Curriculum
section in the answer key shows which problems fall under each.
