\problem{$A(2, 3)$ is dilated about the origin with $k = 3$. Find $A'$.}

\textbf{Solution:} \quad A dilation about the origin multiplies both coordinates by $k$, so
$x' = 3 \cdot 2 = 6$ and $y' = 3 \cdot 3 = 9$. \ans{A'(6, 9)}

\noindent\rule{\linewidth}{0.2pt}

\problem{$P(1, 2)$, $Q(4, 6)$; images $P'(2, 4)$, $Q'(8, 12)$ under $k = 2$. Find $PQ$ and $P'Q'$.}

\textbf{Solution:} \quad Use the distance formula on each pair.
\[ PQ = \sqrt{(4-1)^2 + (6-2)^2} = \sqrt{9 + 16} = \sqrt{25} \]
\[ P'Q' = \sqrt{(8-2)^2 + (12-4)^2} = \sqrt{36 + 64} = \sqrt{100} \]
The image is exactly twice as long, which is what the scale factor $2$ promises.
\[ \boxed{PQ = 5 \qquad P'Q' = 10} \]

\problem{Print $6$ cm by $9$ cm; similar enlargement is $15$ cm on the short side. Find $k$ and
the long side.}

\textbf{Solution:} \quad The scale factor is the image length divided by the matching original
length, taken on the pair we know: $k = \dfrac{15}{6}$, which reduces to $\tfrac{5}{2}$ (that is
$2.5$). Apply the same factor to the long side: $9 \cdot \tfrac{5}{2} = \tfrac{45}{2}$.
\[ \boxed{k = \tfrac{5}{2} \qquad \text{long side} = 22.5 \text{ cm}} \]

\noindent\rule{\linewidth}{0.2pt}

\problem{$A(1, 2)$, $B(4, 8)$; images $A'(0.5, 1)$, $B'(2, 4)$ under $k = \tfrac{1}{2}$. Compare
the slopes.}

\textbf{Solution:} \quad Slope is rise over run.
\[ \text{slope } AB = \frac{8 - 2}{4 - 1} = \frac{6}{3}, \qquad
   \text{slope } A'B' = \frac{4 - 1}{2 - 0.5} = \frac{3}{1.5} \]
Both reduce to the same number.
\[ \boxed{\text{slope } AB = 2 \qquad \text{slope } A'B' = 2} \]

\textbf{Reason (instructor-judged).} A correct response says that equal slopes on two different
segments mean the segments are parallel, and that a dilation about the origin always produces a
parallel image of a segment that does not pass through the centre. Accept any wording that gets
from ``same slope'' to ``parallel''; two numbers with no conclusion is not a reason.

\problem{Dilate $A(-3,-1)$, $B(1,-1)$, $C(1,2)$ by $k = 2$ about the origin; draw the image and
find $A'B'$.}

\textbf{Drawing (instructor-judged).} Doubling both coordinates gives $A'(-6, -2)$, $B'(2, -2)$
and $C'(2, 4)$. Full credit for a triangle drawn at exactly those three points with the vertices
labelled and the sides joined. A correctly shaped triangle in the wrong place, or image vertices
that are not exactly twice the originals, loses credit.

\textbf{Solution:} \quad $A'B'$ is horizontal, so its length is the difference of the
$x$-coordinates: $|2 - (-6)| = 8$. \ans{A'B' = 8}

\vspace{0.25cm}

\noindent\rule{\linewidth}{0.2pt}

\problem{A photograph $8$ cm wide and $12$ cm tall is enlarged to $20$ cm wide. How tall is the
enlargement?}

\textbf{Solution:} \quad Similar figures scale by one factor, so the height scales the same way
the width did: $k = \dfrac{20}{8} = 2.5$, and the new height is $12 \cdot 2.5$.
\ans{30 \text{ cm}}

\noindent\rule{\linewidth}{0.2pt}

\problem{$D(2,1)$, $E(4,5)$; images $D'(6,3)$, $E'(12,15)$. Find both slopes and the scale
factor.}

\textbf{Solution:} \quad
\[ \text{slope } DE = \frac{5-1}{4-2} = \frac{4}{2}, \qquad
   \text{slope } D'E' = \frac{15-3}{12-6} = \frac{12}{6} \]
Both equal $2$, so the segments are parallel. The scale factor comes from any pair of matching
coordinates: $k = \dfrac{6}{2}$.
\[ \boxed{\text{slope } DE = 2 \qquad \text{slope } D'E' = 2 \qquad k = 3} \]

\vspace{0.25cm}

\noindent\rule{\linewidth}{0.2pt}

\problem{Is the triangle $(0,0)$, $(8,0)$, $(0,9)$ a dilation of $RST$ with $R(0,0)$, $S(4,0)$,
$T(0,3)$?}

\textbf{Solution:} \quad Compare each side with its match. Along $RS$: $\dfrac{8}{4} = 2$. Along
$RT$: $\dfrac{9}{3} = 3$.
\[ \boxed{\text{factor along } RS = 2 \qquad \text{factor along } RT = 3} \]

\textbf{Judgement (instructor-judged).} A correct response says the student is wrong: a dilation
uses ONE scale factor in every direction, and here the horizontal is multiplied by $2$ while the
vertical is multiplied by $3$. That is a stretch, and the second triangle is not similar to
$RST$. Accept any wording that contrasts the two factors; ``no'' on its own earns no credit.

\vspace{0.25cm}

\noindent\rule{\linewidth}{0.2pt}

\problem{A model bridge scales up by $40$: span $3.2$ m, tower $0.45$ m. Find the real lengths.}

\textbf{Solution:} \quad Every real length is $40$ times the model length, so multiply each
measurement by $40$: $3.2 \cdot 40 = 128$ and $0.45 \cdot 40 = 18$.
\[ \boxed{\text{span} = 128 \text{ m} \qquad \text{tower} = 18 \text{ m}} \]

\problem{$J(0,0)$, $K(6,0)$, $L(0,8)$ dilated by $k = 1.5$. Find $KL$, the perimeter of $JKL$,
and the perimeter of the image.}

\textbf{Solution:} \quad $JK = 6$ and $JL = 8$ are along the axes. For $KL$,
\[ KL = \sqrt{(0-6)^2 + (8-0)^2} = \sqrt{36 + 64} = \sqrt{100} = 10 \]
so the perimeter of $JKL$ is $6 + 8 + 10 = 24$. Every image side is $1.5$ times its original, so
the image perimeter is $24 \cdot 1.5 = 36$.
\[ \boxed{KL = 10 \qquad \text{perimeter } JKL = 24 \qquad \text{perimeter } J'K'L' = 36} \]

\textbf{Reason (instructor-judged).} A correct response says that because every side is
multiplied by $1.5$, the sum of the sides is multiplied by $1.5$ too, so the image perimeter is
$24 \cdot 1.5 = 36$ without finding a single image coordinate. Accept any wording that applies
the factor to the whole perimeter; recomputing the coordinates without saying why the shortcut
works earns no credit.
