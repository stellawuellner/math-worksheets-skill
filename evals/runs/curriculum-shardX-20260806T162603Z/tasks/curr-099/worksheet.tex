\noindent\textbf{Directions:} In every problem another student has made a mistake. Part (a) asks you
to fix the answer. Part (b) asks you to say what went wrong --- write it in a sentence, in your own
words. Use \textbf{Line Plot P} and \textbf{Shape Set Q} below.

\problem[3.4cm]{A student drew a scale under a line plot and labelled the five ticks
$1$, $2$, $3$, $5$, $6$. The steps are supposed to be the same size all the way along.
\begin{itemize}
  \item[(a)] Which number belongs where the student wrote $5$? \quad \ansblank
  \item[(b)] Explain why an uneven scale makes a line plot misleading.
\end{itemize}}

\problem[3cm]{Looking at Line Plot P, a student says ``$5$ students borrowed $3$ books,'' because
five numbers are printed along the scale.
\begin{itemize}
  \item[(a)] How many students really borrowed $3$ books? \quad \ansblank
  \item[(b)] Name the mistake the student made.
\end{itemize}}

\problem[3cm]{A student says shape X in Shape Set Q is a square, because it has four sides that are
all the same length.
\begin{itemize}
  \item[(a)] How many square corners does shape X really have? \quad \ansblank
  \item[(b)] Name the mistake the student made.
\end{itemize}}

\problem[3cm]{To find how many students are shown on Line Plot P, a student added the numbers along
the scale and got $15$.
\begin{itemize}
  \item[(a)] How many students are really shown on the plot? \quad \ansblank
  \item[(b)] Name the mistake the student made.
\end{itemize}}

\problem[3cm]{A student found the difference between the greatest and the least number of books on
Line Plot P by adding them, and got $6$.
\begin{itemize}
  \item[(a)] What is the correct difference? \quad \ansblank
  \item[(b)] Name the mistake the student made.
\end{itemize}}

\problem[3cm]{A student put shape Y from Shape Set Q into the group ``has two pairs of parallel
sides.''
\begin{itemize}
  \item[(a)] How many pairs of parallel sides does shape Y really have? \quad \ansblank
  \item[(b)] Name the mistake the student made.
\end{itemize}}

\problem[3.4cm]{A student drew a scale from $1$ to $5$, counting by $1$, but made the gap between two
of the ticks twice as wide as the others.
\begin{itemize}
  \item[(a)] On a correct scale from $1$ to $5$ counting by $1$, how many equal gaps are there
        between the first tick and the last? \quad \ansblank
  \item[(b)] Explain why gaps of different widths make the finished plot misleading.
\end{itemize}}

\problem[4.4cm]{A student copied Line Plot P, which shows $12$ students, but the copy has only
$11$ marks on it.
\begin{itemize}
  \item[(a)] How many marks are missing from the copy? \quad \ansblank
  \item[(b)] Explain how to find which value was left out, without plotting the whole thing again.
\end{itemize}}
