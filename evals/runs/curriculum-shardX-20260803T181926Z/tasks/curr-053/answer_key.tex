\problem{\textbf{Red bin $462$ books, blue bin $429$ books.}
\par
Chart both numbers, then read from the left.
\par
Hundreds: $4$ and $4$ --- the same, so the hundreds place decides nothing.
\par
Tens: $6$ and $2$. Six tens is more than two tens, so the red bin wins here and
the ones digits never have to be looked at.
\par
$\ans{462 > 429}$}

\problem{\textbf{Ella: $3$ flats, $5$ rods, $2$ cubes. Ryan: $3$ flats, $2$
rods, $8$ cubes.}
\par
Each flat is one hundred, each rod is one ten, each cube is one.
\par
Ella: $3 \times 100 + 5 \times 10 + 2 = 300 + 50 + 2$, so
$\ans{352}$
\par
Ryan: $3 \times 100 + 2 \times 10 + 8 = 300 + 20 + 8$, so
$\ans{328}$
\par
Same hundreds ($3$ each), so compare tens: $5$ rods beats $2$ rods.
\par
$\ans{352 > 328}$
\par\smallskip
\emph{Grading note:} Ryan has more cubes, so a student who compares ones first
will pick Ryan. Comparing always starts at the left.}

\problem{\textbf{Compare $508$ and $580$.}
\par
Hundreds: $5$ and $5$ --- tied.
\par
Tens: $0$ and $8$. Zero tens is fewer than eight tens, so $508$ is the smaller
number. The \textbf{tens place} is the place that decides this pair.
\par
$\ans{508 < 580}$
\par\smallskip
\emph{Grading note:} the $0$ is not "nothing there'' --- it holds the tens
place open so the $8$ stays in the ones place.}

\problem{\textbf{Oak $615$ cans, Pine $651$ cans.}
\par
Hundreds: $6$ and $6$ --- tied. Tens: $1$ and $5$, so Pine has more tens.
\par
$\ans{615 < 651}$
\par
\textbf{Pine School} collected more cans.}

\problem{\textbf{Order $473$, $437$, $743$ from least to greatest.}
\par
Compare hundreds first: $4$, $4$, and $7$. The $7$ hundreds is the biggest, so
$743$ goes last no matter what.
\par
The two numbers with $4$ hundreds are separated by their tens: $7$ tens against
$3$ tens, so $437$ comes before $473$.
\par
$\ans{437, 473, 743}$}

\problem{\textbf{Sam: $2$ flats, $0$ rods, $9$ cubes. Nina: $1$ flat, $9$ rods,
$8$ cubes.}
\par
Sam: $2 \times 100 + 0 \times 10 + 9 = 200 + 0 + 9$, so
$\ans{209}$
\par
Nina: $1 \times 100 + 9 \times 10 + 8 = 100 + 90 + 8$, so
$\ans{198}$
\par
Nina really does have more rods, but rods are only tens. Sam has $2$ hundreds
against Nina's $1$ hundred, and hundreds are compared first, so Sam's number is
greater.
\par
$\ans{209 > 198}$
\par\smallskip
\emph{Grading note:} $29$ means the empty tens place was skipped when writing
Sam's number --- the $0$ has to be written so the $9$ stays in the ones place.}

\problem{\textbf{Compare $384$ and $389$.}
\par
Hundreds tie at $3$. Tens tie at $8$. So the ones place is the only place left,
and $4$ is less than $9$.
\par
$\ans{384 < 389}$}

\problem{\textbf{Maya $892$ steps, Ben $928$ steps.}
\par
Maya is looking at the wrong place. Comparing starts at the hundreds:
$8$ hundreds against $9$ hundreds. Ben has more hundreds, so Ben's number is
greater and the tens digits are never needed.
\par
$\ans{892 < 928}$
\par
Ben walked more steps. Maya is not right.}

\problem{\textbf{Order $605$, $650$, $560$ from greatest to least.}
\par
Hundreds: $6$, $6$, and $5$. The number with $5$ hundreds, $560$, is the
smallest, so it goes last.
\par
The two numbers with $6$ hundreds split on their tens: $0$ tens against $5$
tens, so $650$ is greater than $605$.
\par
$\ans{650, 605, 560}$}

\problem{\textbf{Challenge: $5$ hundreds, missing tens, $7$ ones.}
\par
Try the tens digits in order. The hundreds and ones already match $547$, so the
tens digit is what settles both tests.
\par
A tens digit of $4$ gives $547$, which is equal to $547$ and not greater than
it. The next digit up is $5$, giving
$\ans{557}$
\par
Check the first test --- same hundreds, and $5$ tens beats $4$ tens:
\par
$\ans{557 > 547}$
\par
Check the second test --- same hundreds, and $5$ tens is fewer than $8$ tens:
\par
$\ans{557 < 587}$
\par\smallskip
So the smallest number that passes both tests is $557$; any tens digit from
$5$ to $7$ works, but $5$ is the smallest of them.}
