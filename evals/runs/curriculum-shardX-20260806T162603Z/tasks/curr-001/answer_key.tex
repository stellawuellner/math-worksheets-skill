\problem{Count forward along the number track 3, 4, 5, 6, \_\_, \_\_.}

\textbf{Solution:} Point to each box and count on by ones: ``3, 4, 5, 6 \ldots''
The box after 6 is one more than 6, so it is \ans{7}

The last box is one more than 7, so it is \ans{8}

\problem{Keep counting forward: 16, 17, 18, \_\_, \_\_.}

\textbf{Solution:} Count on from 18. One more than 18 is \ans{19}

One more than 19 is \ans{20}

\problem{Start at 38. Count forward and write the next three numbers.}

\textbf{Solution:} Say ``38'' and count on by ones. One more than 38 is \ans{39}

One more than 39 is \ans{40} \quad (39 ends in 9, so a new tens group --- the
forties --- begins.)

One more than 40 is \ans{41}

\problem{Hundred-chart row 41--50: fill the empty boxes after 43, after 46, and
after 49.}

\textbf{Solution:} In a hundred-chart row each box is one more than the box to
its left. One more than 43 is \ans{44}

One more than 46 is \ans{47}

One more than 49 is \ans{50} \quad (49 ends in 9, so the fifties begin.)

\problem{Start at 59. Count forward and write the next two numbers.}

\textbf{Solution:} 59 ends in 9, so the next number starts the sixties. One
more than 59 is \ans{60}

One more than 60 is \ans{61}

\problem{Number track: 74, \_\_, \_\_, \_\_.}

\textbf{Solution:} Count on from 74 by ones. One more than 74 is \ans{75}

One more than 75 is \ans{76}

One more than 76 is \ans{77}

\problem{Hundred-chart row 81--90: fill the empty boxes after 81, after 84, and
after 87.}

\textbf{Solution:} Each box is one more than its left neighbor. One more than
81 is \ans{82}

One more than 84 is \ans{85}

One more than 87 is \ans{88}

\problem{Challenge. Start at 97, write the next three numbers, then circle the
greatest number you wrote.}

\textbf{Solution:} Count on from 97. One more than 97 is \ans{98}

One more than 98 is \ans{99}

One more than 99 is \ans{100} \quad (99 is the last two-digit number, so the
count moves to one hundred.)

\textbf{Circling task (instructor-judged):} the student should circle
\textbf{100}. When we count forward, every new number is greater than the ones
before it, so the last number written is the greatest. Accept any clear mark
around 100 only.
