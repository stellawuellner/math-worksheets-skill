# Completing Short Algebraic and Segment Proofs — high-school geometry (8 problems)

Three PDFs are ready:

- **Worksheet** (`ws_segment_proofs_curr303.pdf`, 5 pages) — 8 problems set in real
  situations with every length given in its unit: a shelf support, trail markers, a
  handrail, cable runs, fence survey markers, a garden bed, a footbridge. Four problems
  are two-column proofs with the statement column printed and the reason column blank;
  the rest ask for the equation, the value, and the properties that justify it. There is
  no story detail that the mathematics does not use.
- **Answer key** (`ak_segment_proofs_curr303.pdf`, 3 pages) — every equation worked line
  by line with a substitution check, every missing reason named as a *property* rather
  than an operation, a model proof for each open item, and a grading note saying which
  element has to be present.
- **Study guide** (`ss_segment_proofs_curr303.pdf`, 2 pages) — three sections: naming the
  property behind each step, segment addition as an equation, and the overlapping-segment
  move (add the shared middle stretch, rename both sums with the postulate, substitute).
  Each has a rule box, a worked example, and a try-it.

## What is verified, and what is not

**7 of the 14 responses are machine-checked with SymPy** — every numeric answer:
$x = 5$ cm, $x = 7$ and $BC = 11$ m, $x = 8$ cm, $AC = 15.5$ m, $l = 15$ m, and
$WX = 7.3$ m. All six study-guide answers are verified the same way.

**7 responses are flagged for your judgement** — the reason columns of problems 1, 3, 4,
6 and 7, and the written proofs in problems 5(a) and 8(a). A proof is a chain of
justifications, and no computer algebra system grades justification. The answer key gives
the exact reason for each blank line and, for the two written proofs, a model argument
plus the two elements a correct proof must contain (the shared middle stretch added with
a named property, and the Segment Addition Postulate used to rename each sum). The Quick
Answers bank marks these `---`; no `[unchecked]` marks appear.

## Notes

Standards: the four items that justify equation-solving steps are tagged HSA-REI.A.1
("explain each step in solving an equation"), which is where that skill actually lives in
the standards; the segment and two-column proofs are tagged HSG-CO.C. Difficulty ramps
1 to 5, ending with a footbridge problem that needs both the overlapping-segment proof
and the arithmetic that follows from it.
