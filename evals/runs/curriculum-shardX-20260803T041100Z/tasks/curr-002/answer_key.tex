\problem{\textbf{Stars in the ten-frame.}

\textbf{Step 1.} The top row of a ten-frame holds five, and this top row is
full, so the count reaches $5$ at the end of that row.

\textbf{Step 2.} Count on into the bottom row, touching one star per number:
``six, seven''. That is $5 + 2$.

\textbf{Step 3.} The last number said is the answer to \emph{how many}, so the
set has $\ans{7}$ stars.

\textit{Listen for:} a child who recounts the top row from one when moving to
the second row. \textit{Common wrong answer:} $8$ --- one star was touched
twice.}

\problem{\textbf{Scattered counters.}

\textbf{Step 1.} Scattered objects are the classic place to lose track, so give
the set an order: count the upper band first, left to right --- $5$ counters.

\textbf{Step 2.} Continue into the lower band without restarting: ``six, seven,
eight, nine''. That band holds $4$, and $5 + 4$ is the whole set.

\textbf{Step 3.} Every counter was touched exactly once, so the set has
$\ans{9}$ counters.

\textit{Common wrong answer:} $8$ --- one counter was skipped.}

\problem{\textbf{Full ten-frame and two loose dots.}

\textbf{Step 1.} A full ten-frame is $10$. Because it is full, it does not have
to be recounted --- that is the whole point of the frame.

\textbf{Step 2.} Start at ten and count on for the two loose dots: ``eleven,
twelve''. That is $10 + 2$.

\textbf{Step 3.} The last number said is $\ans{12}$ dots.

\textit{Teaching note:} counting on from a known amount is the first step
toward place value --- twelve is ``ten and two more''.}

\problem{\textbf{Ducks in two places.}

\textbf{Step 1.} The ducks are one set shown in two places, so count the pond
first: $4$ ducks.

\textbf{Step 2.} Keep the count going onto the grass: ``five, six, seven,
eight, nine''. That is $4 + 5$.

\textbf{Step 3.} In all there are $\ans{9}$ ducks.

\textit{Common wrong answer:} $5$ --- only the grass group was counted.}

\problem{\textbf{Buttons in uneven rows.}

\textbf{Step 1.} Rows of different lengths tempt a child to assume they match,
so count each row and keep a running total instead of guessing.

\textbf{Step 2.} Row by row: $3$, then $3$ more reaches six, then $2$ more.
That is $3 + 3 + 2$.

\textbf{Step 3.} The last number said is $\ans{8}$ buttons.}

\problem{\textbf{Rosa's shells and Milo's shells.}

\textbf{Step 1.} Comparing needs two finished counts, so count Rosa first:
$5$ shells in her first group and $3$ in her second, which is $5 + 3 = 8$.

\textbf{Step 2.} Now Milo: $4 + 2 = 6$ shells.

\textbf{Step 3.} Eight is more than six, so the true sentence uses the
\emph{greater than} sign: Rosa's shells $\ans{>}$ Milo's shells.

\textit{Listen for:} ``Milo has more because his shells are spread out.'' The
count decides, not how much space the set takes up.}

\problem{\textbf{Red and blue blocks.}

\textbf{Step 1.} Both colours are blocks in the same box, so one count covers
both groups.

\textbf{Step 2.} Count the red blocks: $7$. Count on through the blue ones:
``eight, nine, ten, eleven, twelve, thirteen'' --- that is $7 + 6$.

\textbf{Step 3.} The box holds $\ans{13}$ blocks.}

\problem{\textbf{Full muffin tray.}

\textbf{Step 1.} The tray is full, so the rows are equal --- count one row and
then continue through the second row.

\textbf{Step 2.} The first row holds $8$. Counting on through the second row
gives ``nine, ten, \ldots{}, sixteen'', which is $8 + 8$.

\textbf{Step 3.} There are $\ans{16}$ muffins.}

\problem{\textbf{Three baskets of apples.}

\textbf{Step 1.} Three groups still make one set, so the count must run
straight through all three baskets without restarting.

\textbf{Step 2.} Basket A holds $4$; carry on into basket B --- ``five, six,
seven'' --- which adds $3$; carry on into basket C --- ``eight, nine'' --- which
adds $2$. That is $4 + 3 + 2$.

\textbf{Step 3.} There are $\ans{9}$ apples in all.

\textit{Common wrong answer:} $7$ --- the third basket was never counted.}

\problem{\textbf{Two jars of marbles.}

\textbf{Step 1.} Each ten-frame is full, so each jar starts at $10$ and only
the extra marbles need counting.

\textbf{Step 2.} Jar A: count on from ten for four extras --- ``eleven, twelve,
thirteen, fourteen'', so $10 + 4 = 14$. Jar B: count on for six extras, so
$10 + 6 = 16$.

\textbf{Step 3.} Fourteen is less than sixteen, so the true sentence uses the
\emph{less than} sign: Jar A $\ans{<}$ Jar B.

\textit{Teaching note:} because both jars share the same full ten-frame, only
the loose marbles can decide the comparison --- a useful preview of comparing
teen numbers by their ones digit.}
