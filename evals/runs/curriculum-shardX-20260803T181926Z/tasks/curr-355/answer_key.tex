\problem{\textbf{Multiply $(2 + 3i)(4 - i)$ and write the result as $a + bi$.}

\textbf{Step 1.} Distribute exactly as with binomials --- four products:
$2 \cdot 4 = 8$, \ $2 \cdot (-i) = -2i$, \ $3i \cdot 4 = 12i$, \
$3i \cdot (-i) = -3i^2$.

\textbf{Step 2.} Replace $i^2$ by $-1$: \ $-3i^2 = -3(-1) = 3$. This is the
only step where an imaginary product becomes real.

\textbf{Step 3.} Collect real parts $8 + 3 = 11$ and imaginary parts
$-2i + 12i = 10i$. \ans{11 + 10i}

\textit{Common wrong answer:} $5 + 10i$ --- from treating $i^2$ as $+1$, which
subtracts the $3$ instead of adding it.}

\problem{\textbf{Simplify $i^{23}$.}

\textbf{Step 1.} Powers of $i$ repeat every four steps:
$i^1 = i$, \ $i^2 = -1$, \ $i^3 = -i$, \ $i^4 = 1$, and then the cycle starts
over. So only the remainder of the exponent on division by four matters.

\textbf{Step 2.} $23 = 4 \cdot 5 + 3$, so $i^{23} = (i^4)^5 \cdot i^3 =
1 \cdot i^3$.

\textbf{Step 3.} $i^3 = i^2 \cdot i = -i$. \ans{-i}

\textit{Watch the period:} it is four, not two --- ``the exponent is odd, so
the answer is $i$'' gets this one backwards.}

\problem{\textbf{Solve $x^2 + 49 = 0$; report the complete solution set.}

\textbf{Step 1.} Nothing to factor over the reals, and the equation is already
a square set equal to a number: isolate the square. $x^2 = -49$.

\textbf{Step 2.} Take square roots of both sides, keeping BOTH signs:
$x = \pm\sqrt{-49} = \pm\sqrt{49}\sqrt{-1} = \pm 7i$.

\textbf{Step 3.} A degree-2 equation has two solutions, and here they are a
conjugate pair. \ans{x = 7i \ \text{or} \ x = -7i}

\textit{Check:} $(7i)^2 + 49 = 49i^2 + 49 = -49 + 49 = 0$. \ The same
arithmetic works for $-7i$, because squaring kills the sign.}

\problem{\textbf{Solve $(x - 3)^2 + 16 = 0$; report the complete solution set.}

\textbf{Step 1.} The variable appears only inside one square, so square roots
beat the quadratic formula here. Isolate: $(x - 3)^2 = -16$.

\textbf{Step 2.} $x - 3 = \pm\sqrt{-16} = \pm 4i$.

\textbf{Step 3.} Add $3$ to both sides. The real part comes from the shift,
the imaginary part from the square root.
\ans{x = 3 + 4i \ \text{or} \ x = 3 - 4i}

\textit{Check:} $(3 + 4i - 3)^2 + 16 = (4i)^2 + 16 = -16 + 16 = 0$.}

\problem{\textbf{Show $x = 1 + 4i$ solves $x^2 - 2x + 17 = 0$.}

\textbf{Step 1.} ``Is it a solution?'' is answered by substitution: replace
every $x$ and simplify to one number. A solution makes the left side $0$.

\textbf{Step 2.} Square first:
$(1 + 4i)^2 = 1 + 8i + 16i^2 = 1 + 8i - 16 = -15 + 8i$.

\textbf{Step 3.} Now the linear term: $-2(1 + 4i) = -2 - 8i$.

\textbf{Step 4.} Add the three pieces:
$(-15 + 8i) + (-2 - 8i) + 17 = (-15 - 2 + 17) + (8 - 8)i$. \ans{0}

Because the substitution gives exactly $0$, $x = 1 + 4i$ is a solution.

\textit{Common wrong answer:} $32$ --- from squaring with $i^2$ taken as
$+1$, which makes the imaginary parts cancel into a nonzero real number.}

\problem{\textbf{Every zero of $p(x) = x^4 - 16$.}

\textbf{Step 1.} Degree $4$, so expect four zeros. The expression is a
difference of squares, so factor rather than expand anything.

\textbf{Step 2.} $x^4 - 16 = (x^2 - 4)(x^2 + 4)$, and the first factor is a
difference of squares again: $(x - 2)(x + 2)(x^2 + 4)$.

\textbf{Step 3.} Set each factor to zero. $x - 2 = 0$ and $x + 2 = 0$ give the
real zeros; $x^2 + 4 = 0$ gives $x^2 = -4$, so $x = \pm 2i$.

\textbf{Step 4.} Four zeros, as the degree promised.
\ans{x = 2,\ -2,\ 2i,\ -2i}

\textit{Note:} $x^2 + 4$ does not factor over the reals, which is exactly why
two of the zeros are non-real.}

\problem{\textbf{Solve $x^2 + 4x + 13 = 0$; report the complete solution set.}

\textbf{Step 1.} No integer pair multiplies to $13$ and adds to $4$, so the
quadratic formula is the tool: $a = 1$, $b = 4$, $c = 13$.

\textbf{Step 2.} Discriminant: $b^2 - 4ac = 16 - 52 = -36$. Negative, so both
solutions are non-real.

\textbf{Step 3.} $\sqrt{-36} = 6i$, so
$x = \dfrac{-4 \pm 6i}{2} = -2 \pm 3i$.

\textbf{Step 4.} The pair is a conjugate pair, as it must be for a quadratic
with real coefficients. \ans{x = -2 + 3i \ \text{or} \ x = -2 - 3i}

\textit{Check the real part:} the two solutions must average to
$-b/(2a) = -2$, and they do.}

\problem{\textbf{Complete zero set of $p(x) = x^3 + 4x$.}

\textbf{Step 1.} Degree $3$ promises three zeros. Every term has a factor of
$x$, so pull it out before anything else --- that is what keeps $x = 0$ from
being lost.

\textbf{Step 2.} $x^3 + 4x = x(x^2 + 4)$.

\textbf{Step 3.} $x = 0$ from the first factor. From the second,
$x^2 = -4$, so $x = \pm 2i$.

\textbf{Step 4.} Three zeros for a cubic. \ans{x = 0,\ 2i,\ -2i}

\textit{Common wrong answer:} dividing both sides by $x$ at Step 2 destroys
the solution $x = 0$ and leaves only two zeros for a cubic.}

\problem{\textbf{Ben substituted $x = -3 - 4i$ into $x^2 + 6x + 25$ and got
$32$. Redo it.}

\textbf{Step 1.} Substitution is only as good as the squaring step, so do
$(-3 - 4i)^2$ carefully and keep $i^2 = -1$.

\textbf{Step 2.} $(-3 - 4i)^2 = 9 + 24i + 16i^2 = 9 + 24i - 16 = -7 + 24i$.

\textbf{Step 3.} Linear term: $6(-3 - 4i) = -18 - 24i$.

\textbf{Step 4.} Add: $(-7 + 24i) + (-18 - 24i) + 25 = (-7 - 18 + 25) +
(24 - 24)i$. \ans{0}

Ben's mistake: he treated $i^2$ as $+1$, so his squaring gave
$9 + 24i + 16 = 25 + 24i$; that turns the whole substitution into
$32$ instead of $0$. Since the correct value is $0$, $-3 - 4i$ \emph{is} a
solution --- the conjugate partner of $-3 + 4i$.}

\problem{\textbf{Complete solution set of $x^4 + 3x^2 - 4 = 0$.}

\textbf{Step 1.} Only even powers of $x$ appear, so treat it as a quadratic in
$x^2$ and factor in that variable first.

\textbf{Step 2.} $x^4 + 3x^2 - 4 = (x^2 + 4)(x^2 - 1)$, because
$4 \cdot (-1) = -4$ and $4 + (-1) = 3$.

\textbf{Step 3.} $x^2 - 1 = 0$ gives the real solutions $x = 1$ and
$x = -1$. \ $x^2 + 4 = 0$ gives $x^2 = -4$, so $x = \pm 2i$.

\textbf{Step 4.} Four solutions for a degree-4 equation.
\ans{x = 1,\ -1,\ 2i,\ -2i}

\textit{Watch out:} stopping at $x^2 = 1$ and $x^2 = -4$ is only half the
work --- each of those is still a quadratic and contributes two solutions.}

\problem{\textbf{Solve $4x^2 - 4x + 5 = 0$; report the complete solution set.}

\textbf{Step 1.} The leading coefficient is not $1$ and nothing factors, so
use the quadratic formula with $a = 4$, $b = -4$, $c = 5$.

\textbf{Step 2.} Discriminant: $16 - 80 = -64$, and $\sqrt{-64} = 8i$.

\textbf{Step 3.} $x = \dfrac{4 \pm 8i}{8}$. Divide each part of the numerator
by $8$: the real part is $4/8$ and the imaginary part is $8i/8$.

\textbf{Step 4.} In standard form the real part is a fraction and the
imaginary part is $1$.
\ans{x = \tfrac{1}{2} + i \ \text{or} \ x = \tfrac{1}{2} - i}

\textit{Common wrong answer:} $\tfrac{1}{2} \pm 8i$ --- the $8$ in the
numerator was divided but the $8i$ was not.}

\problem{\textbf{Synthesis: $x = 3i$ is a zero of
$p(x) = x^4 - 2x^3 + 10x^2 - 18x + 9$. Find the complete solution set.}

\textbf{Step 1.} $p$ has real coefficients, so non-real zeros come in
conjugate pairs: $x = -3i$ is a zero too. Two zeros in hand means a known
quadratic factor.

\textbf{Step 2.} That factor is $(x - 3i)(x + 3i) = x^2 - 9i^2 = x^2 + 9$.

\textbf{Step 3.} Divide: $x^4 - 2x^3 + 10x^2 - 18x + 9 = (x^2 + 9)(x^2 - 2x +
1)$. (Check the ends: $x^2 \cdot x^2 = x^4$ and $9 \cdot 1 = 9$.)

\textbf{Step 4.} $x^2 - 2x + 1 = (x - 1)^2$, so $x = 1$ is a zero of
multiplicity two.

\textbf{Step 5.} Counted with multiplicity the degree-4 polynomial has its
four zeros: $1$ twice, and the conjugate pair.
\ans{x = 1 \ (\text{double}),\ 3i,\ -3i}

\textit{Why the conjugate is forced:} if only $3i$ were a zero, the factor
$x - 3i$ would leave a factor with non-real coefficients, which a polynomial
with integer coefficients cannot have.}
