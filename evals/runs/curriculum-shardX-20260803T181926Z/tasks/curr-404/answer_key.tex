\problem{$f(x) = x^2$, $g(x) = f(x - 3) + 2$.

\textbf{Solution:} Substituting into $f$ gives $g(x) = (x - 3)^2 + 2$, and
expanding: $x^2 - 6x + 9 + 2$. \ans{x^2 - 6x + 11}

\noindent In words: the graph shifts right $3$ (an inside operation, so it moves
opposite to the sign) and up $2$ (an outside operation, which moves the way it
reads). This is the one case where inside and outside can be described
independently, because there is only one of each.}

\problem{$h(x) = f(2x - 6)$ \textbf{with} $f(x) = x^2$.

\textbf{Solution (a):} factor the inside before reading anything off it:
$2x - 6 = 2(x - 3)$, so $h(x) = (2(x-3))^2$. \ans{4(x - 3)^2}

The horizontal transformations are: compress by a factor of $\tfrac{1}{2}$
toward the $y$-axis, then shift right $3$. Reading the unfactored inside would
have given a shift of $6$, which is twice the truth --- the compression acts on
the shift as well.

\textbf{Solution (b):} $h(5) = (2(5) - 6)^2 = 4^2$. \ans{16}}

\problem{$f(x) = 2x + 1$, $g(x) = x^2 - 3$: \textbf{both composites.}

\textbf{Solution:} $(f \circ g)(x)$ means $g$ runs first and its output is fed
to $f$:
\[ f(g(x)) = 2(x^2 - 3) + 1 = 2x^2 - 6 + 1 \]
\ans{2x^2 - 5}

Reversing the order feeds $f$'s output to $g$:
\[ g(f(x)) = (2x + 1)^2 - 3 = 4x^2 + 4x + 1 - 3 \]
\ans{4x^2 + 4x - 2}

\noindent They differ because composition is not commutative: the first
function's output becomes the second's input, so which one is applied first
changes what the second one receives. A single test value makes it concrete ---
at $x = 1$ the first gives $-3$ and the second gives $6$.}

\problem{\textbf{Find and fix:} $(f \circ g)(2)$ \textbf{with} $f(x) = \sqrt{x+1}$, $g(x) = 3x - 2$.

\textbf{The mistake:} the notation was read left to right. In $f \circ g$ the
function written on the \emph{right} runs first, so $g$ takes the input and $f$
takes $g$'s output. The student computed $g(f(2))$.

\textbf{Correct work:} compose symbolically first, which makes the order visible:
\[ (f \circ g)(x) = f(3x - 2) = \sqrt{(3x - 2) + 1} \]
\ans{\sqrt{3x - 1}}

Now substitute: $(f \circ g)(2) = \sqrt{3(2) - 1} = \sqrt{5}$. \ans{2.236}

\noindent\textit{Watch for:} $3.196$, which is $3\sqrt{3} - 2$ --- the value of
$g(f(2))$. The two composites are different functions, and here they are not
even close; a symbolic composition before any arithmetic is what prevents the
swap.}

\problem{\textbf{Find and fix:} the graph of $y = f(2x + 8)$.

\textbf{The mistake:} the shift was read off the unfactored inside. A horizontal
shift can only be read once the coefficient of $x$ has been factored out, and
"shift then compress" also has the order backwards.

\textbf{Correct work:} factor the inside:
\[ 2x + 8 = \boxed{2(x + 4)} \]
So $y = f(2(x + 4))$: compress horizontally by a factor of $\tfrac{1}{2}$, then
shift left $4$ --- not $8$. The compression halves the shift, which is exactly
the trap in reading $8$ off the constant term.

\noindent The inside is zero when $2x + 8 = 0$, that is at $x = -4$, confirming
the shift: whatever feature of $f$ sat at input $0$ now sits at $x = -4$.
Substituting that value back gives $2(-4) + 8 = 0$, as it must.

\noindent\textit{Watch for:} testing $x = -8$ instead. That input gives an
inside value of $-8$, nowhere near the $0$ the check is looking for.}

\problem{$f(x) = \sqrt{x - 4} + 1$: \textbf{inverse and its domain.}

\textbf{Solution (a):} write $y = \sqrt{x-4} + 1$, swap the variables, and solve
for $y$:
\[ x = \sqrt{y - 4} + 1 \;\Rightarrow\; x - 1 = \sqrt{y - 4}
   \;\Rightarrow\; (x-1)^2 = y - 4 \]
Expanded this is $x^2 - 2x + 5$, and in completed-square form
\ans{(x - 1)^2 + 4}

\textbf{Solution (b):} the domain of $f^{-1}$ is the range of $f$. Since
$\sqrt{x-4} \ge 0$, the smallest output of $f$ is $1$, so the range of $f$ is
$[1, \infty)$ and the domain of $f^{-1}$ is $x \ge 1$. The algebra alone would
happily accept any $x$, because $(x-1)^2 + 4$ is defined everywhere; the
restriction comes from the squaring step, which was only reversible because
$x - 1$ was known to be non-negative.

\textbf{Solution (c):} $f^{-1}(3) = (3-1)^2 + 4 = 4 + 4$. \ans{8}

\noindent Check the other way: $f(8) = \sqrt{8-4} + 1 = 2 + 1 = 3$.}

\problem{\textbf{Find and fix:} $f(x) = x^2 - 6x + 5$ \textbf{on} $x \ge 3$.

\textbf{The mistake:} two things at once. A $\pm$ cannot appear in a function ---
it names two outputs for one input --- and "domain: all real numbers" ignores
that the domain of an inverse is the range of the original.

\textbf{Correct work:} complete the square to see the vertex:
\[ x^2 - 6x + 5 = (x^2 - 6x + 9) - 4 \]
\ans{(x - 3)^2 - 4}

The restriction $x \ge 3$ keeps the right half of the parabola, where $f$ is
increasing and one-to-one. Solving $y = (x-3)^2 - 4$ for $x$ gives
$x = 3 \pm \sqrt{y + 4}$, and the surviving branch is the one whose outputs
satisfy $x \ge 3$: the plus. So $f^{-1}(x) = 3 + \sqrt{x + 4}$.

\noindent The check that this really inverts $f$ is a composition:
$\left(\left(3 + \sqrt{x+4}\right) - 3\right)^2 - 4 = (x + 4) - 4 = x$.

\noindent The range of $f$ on $x \ge 3$ starts at the vertex value $-4$ and
increases, so the range is $[-4, \infty)$ and the domain of $f^{-1}$ is
$x \ge -4$ --- exactly where $\sqrt{x+4}$ is defined, which is the algebra
agreeing with the graph.

\textbf{Check:} $f^{-1}(5) = 3 + \sqrt{5 + 4} = 3 + 3$. \ans{6}

\noindent\textit{Watch for:} $0$, the value of the rejected branch
$3 - \sqrt{5+4}$. It is a real number and it satisfies $f(0) = 5$, which is why
it looks right --- but $0 < 3$, so it is outside the restricted domain and is
not the inverse's output.}

\problem{\textbf{Explain: order inside, and the domain of an inverse.}
\textit{(Open response --- flagged for manual review; a model answer follows.)}

\textbf{Model answer:} An expression written inside a function is evaluated
before the function is applied, so the transformations it encodes reach the
graph in the reverse of the order they are written. In $f(3x - 12)$ the input
is multiplied by $3$ and then $12$ is subtracted, so on the graph the
compression by $\tfrac{1}{3}$ happens first and the shift second. The shift is
not $12$: factoring gives $3(x - 4)$, so the graph moves right $4$. Reading a
shift off an unfactored inside is the single most common source of the error,
and the sign flips as well, because the input must grow by $4$ to produce the
value the untransformed function had at $0$. Outside operations behave the
opposite way --- they are applied in the order written and in the direction
written --- which is why $f(x) + 2$ really does shift the graph up $2$.

\noindent The domain of $f^{-1}$ is the range of $f$ because the inverse
undoes $f$: its inputs are exactly the outputs $f$ produced, and no others. The
algebra usually cannot see this, since the formula obtained by swapping and
solving is often defined on a larger set. For $f(x) = \sqrt{x-4}+1$ the formula
$(x-1)^2 + 4$ is defined for every real $x$, but $f$ never outputs anything below
$1$, so $f^{-1}$ is only defined for $x \ge 1$. When the original function is not
one-to-one, a restriction has to be imposed first; that restriction is what
makes an inverse exist at all, and it decides which branch of a square root
survives.

\noindent\textit{What a reviewer should look for:} the inside factored before a
shift is read; inside (input) transformations distinguished from outside
(output) ones, including the reversed order and reversed direction; and the
statement that a restriction on the original is what makes the inverse a
function, with the domain of $f^{-1}$ identified as the range of $f$.}
