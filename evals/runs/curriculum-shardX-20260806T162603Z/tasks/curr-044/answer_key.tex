\problem{Pencil: 8 cubes. Crayon: 5 cubes. How many cubes longer is the pencil?}

\textbf{Solution:} Both lengths use the same unit (cubes), so subtract the
counts: $8 - 5 = 3$. The pencil is longer by \ans{3~\text{cubes}}

\vspace{0.2cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.1cm}

\problem{Mia's ribbon: 6 clips with gaps, 9 clips with no gaps. (a) How many
clips did the gaps hide? (b) Which count is true?}

\textbf{Solution:} (a) The difference between the two counts is what the gaps
hid: $9 - 6 = 3$. \ans{3}

(b) \emph{Instructor judges:} the 9-clip count is the true length. Gaps skip
over parts of the ribbon, so a gappy count is always too small.

\vspace{0.2cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.1cm}

\problem{Leo overlapped sticks: his count of 10 is 2 too many. Fix it and
tell what went wrong.}

\textbf{Solution:} Overlapping counts the same part of the table twice, so
take the extra sticks away: $10 - 2 = 8$. The table is really
\ans{8~\text{sticks}}

\emph{Tell what went wrong (instructor judges):} accept any wording like
``Leo piled sticks on top of each other, so he counted some length twice.
His number is too big, and we take the 2 extras away.''

\vspace{0.2cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.1cm}

\problem{Zoe left 3 gaps, each gap exactly 1 clip of rope, and counted 4
clips. Fix it and tell how you know.}

\textbf{Solution:} Each gap is rope that never got a clip, so add the hidden
clips back: $4 + 3 = 7$. The rope is really \ans{7~\text{paper clips}}

\emph{Tell how you know (instructor judges):} accept any wording like ``the
3 gaps each hid 1 clip of rope, so Zoe's 4 is missing 3 clips. Gaps make a
count too small.''

\vspace{0.2cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.1cm}

\problem{Blue string 11 clips, red string 14 clips. Write $>$, $<$, or $=$:
\ 11 \_\_ 14.}

\textbf{Solution:} 11 clips is fewer than 14 clips, so the blue string is
shorter: \ans{11 < 14}

\vspace{0.2cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.1cm}

\problem{Kim overlapped blocks: her count of 15 is 3 too many. Ali counted 12
with no overlaps. (a) Fix Kim's count. (b) Do they agree now?}

\textbf{Solution:} (a) Take away the 3 blocks Kim counted twice:
$15 - 3 = 12$. \ans{12}

(b) \emph{Instructor judges:} yes --- Kim's fixed count is 12 blocks, exactly
Ali's count. Two careful measurements of the same bench with the same unit
should match.
