# Mixed Facts Review (Grade 1, add / subtract / missing number within 20)

Three PDFs are ready:

- **Worksheet** (`ws_addsubmix_curr040.pdf`) — 10 problems. A three-problem
  addition warm-up, then adding, taking away, and missing-number facts are
  interleaved so your child has to decide what each problem is asking before
  computing (including a missing-whole problem, which catches kids who
  subtract on autopilot). It ends with a fact-family challenge: the same
  missing number must fit an addition and a subtraction, and the child tells
  how they know.
- **Answer key** (`ak_addsubmix_curr040.pdf`) — worked reasoning for every
  fact (make ten, count up, fact family), a quick-answers column, and a
  common-wrong-answer note for the missing-whole trap.
- **Study guide** (`ss_addsubmix_curr040.pdf`) — one skill section per
  interleaved subskill (make a ten to add, count up to subtract, use the fact
  family for missing numbers), each with a rule, worked example, and try-it,
  plus a watch-out on reading the problem before working.

**What is verified:** 10 of the 11 responses are machine-checked with SymPy —
every computation and missing number, including the challenge's shared
missing number. The one open response ("tell how you know the same number
works in both") is flagged for instructor judgement, and the key prints a
model explanation. The planted wrong-method trap on the missing-whole problem
is machine-checked to be distinguishably wrong.
