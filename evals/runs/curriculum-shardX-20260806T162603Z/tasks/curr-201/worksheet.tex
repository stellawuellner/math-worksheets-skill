\begin{center}
\textit{Fraction forms of rational numbers, roots and pi, and placing an irrational
number on the number line}
\end{center}

\noindent\textbf{The test you are using}
\begin{itemize}[leftmargin=0.9cm, itemsep=1pt, topsep=2pt]
  \item A number is \textbf{rational} exactly when it can be written as a fraction
        $\dfrac{\text{integer}}{\text{integer}}$. Terminating decimals, repeating
        decimals, and roots that come out exact are all rational.
  \item A number is \textbf{irrational} when no such fraction exists. Its decimal runs
        forever \emph{without} settling into a repeating block.
  \item \textbf{So, unless a problem says otherwise:} if the number is rational, prove it
        by writing the fraction in lowest terms; if it is irrational, write the value
        rounded as the problem asks.
\end{itemize}
