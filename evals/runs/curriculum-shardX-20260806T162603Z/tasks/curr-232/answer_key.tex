\problem{$f(x) = 4x - 3$. \quad Find $f(5)$.}

\textbf{Solution:} \quad The input is $5$, so replace every $x$ in the rule with $5$:
$f(5) = 4(5) - 3 = 20 - 3$. \ans{f(5) = 17}

\vspace{0.25cm}

\noindent\rule{\linewidth}{0.2pt}

\problem{$g(x) = -2x + 9$. \quad Find $g(-3)$.}

\textbf{Solution:} \quad Replace $x$ with $-3$ and keep the negative sign attached to the input:
$g(-3) = -2(-3) + 9 = 6 + 9$. \ans{g(-3) = 15}

\vspace{0.25cm}

\noindent\rule{\linewidth}{0.2pt}

\problem{$h(x) = x^2 - 4x$. \quad Find $h(-2)$.}

\textbf{Solution:} \quad Substitute $-2$ for $x$ in both terms. Square first, then multiply:
\[ h(-2) = (-2)^2 - 4(-2) = 4 + 8 \]
The squared term is positive and the subtracted term becomes an addition. \ans{h(-2) = 12}

\vspace{0.25cm}

\noindent\rule{\linewidth}{0.2pt}

\problem{The table gives the function $p$. \quad Find $p(3)$.}

\textbf{Solution:} \quad $p(3)$ asks for the output paired with the input $3$. Find $3$ in the
$x$ row and read straight down to the $p(x)$ row, which holds $19$. \ans{p(3) = 19}

\vspace{0.25cm}

\noindent\rule{\linewidth}{0.2pt}

\problem{The table gives $c(n)$, the cost in dollars of $n$ tickets. \quad Find $c(4)$.}

\textbf{Solution:} \quad The input is a number of tickets, so look for $n = 4$ in the top row.
The cost paired with it is $48$. (Check: each ticket costs $12$, and $4 \times 12 = 48$.)
\ans{c(4) = 48}

\vspace{0.25cm}

\noindent\rule{\linewidth}{0.2pt}

\problem{Use $f(x) = 4x - 3$ and the table for $p$. Fill in $f(3)$, $p(3)$, and the comparison symbol.}

\textbf{Solution:} \quad Evaluate the rule at $3$: $f(3) = 4(3) - 3 = 12 - 3 = 9$.
Read the table at $3$: $p(3) = 19$. Nine is to the left of nineteen on the number line, so the
correct symbol is ``less than''. \ans{9 < 19}

\vspace{0.25cm}

\noindent\rule{\linewidth}{0.2pt}

\problem{$f(x) = 3x + 2$. Find $f(-4)$, then explain why $f(-4) \neq -f(4)$.}

\textbf{Solution:} \quad $f(-4) = 3(-4) + 2 = -12 + 2$. \ans{f(-4) = -10}

\textbf{Explanation (instructor-judged).} A correct response says that $f(-4)$ puts the
negative number \emph{into} the rule, while $-f(4)$ evaluates $f(4) = 3(4) + 2 = 14$ first and
then takes the opposite, giving $-14$. The minus sign is applied at a different stage, so the
two results differ: $-10$ against $-14$. Accept any wording that makes that difference clear;
give no credit for a numerical answer with no reason.

\problem{The graph of $q$ is shown. \quad Find $q(3)$.}

\textbf{Solution:} \quad Start at $3$ on the horizontal axis, go straight up to the plotted
point, then read across to the vertical axis. The point is $(3, 7)$. \ans{q(3) = 7}

\vspace{0.25cm}

\noindent\rule{\linewidth}{0.2pt}

\problem{The graph of $r$ is shown. For which input is the output of $r$ greatest?}

\textbf{Solution:} \quad The plotted outputs are $4$, $9$, $6$, $2$ and $5$. The highest point
on the graph is $(2, 9)$, so the greatest output is $9$ and it belongs to the input $2$. The
question asks for the input, not the output. \ans{x = 2}

\vspace{0.25cm}

\noindent\rule{\linewidth}{0.2pt}

\problem{The graph of $s$ is shown. Find $s(1)$, $s(4)$, and $s(4) - s(1)$.}

\textbf{Solution:} \quad Read the two plotted points: $(1, 5)$ gives $s(1) = 5$ and $(4, 14)$
gives $s(4) = 14$. Subtract the outputs in the order asked: $14 - 5 = 9$.
\[ \boxed{s(1) = 5 \qquad s(4) = 14 \qquad s(4) - s(1) = 9} \]

\vspace{0.25cm}

\noindent\rule{\linewidth}{0.2pt}

\problem{The graph shows $m$; the rule $n(x) = 4x - 1$ gives $n$. Compare $m(2)$ and $n(2)$.}

\textbf{Solution:} \quad From the graph, the point above $2$ is $(2, 7)$, so $m(2) = 7$. From the
rule, $n(2) = 4(2) - 1 = 8 - 1 = 7$. Two functions given in different forms can still agree at a
particular input.
\[ \boxed{m(2) = 7 \qquad n(2) = 7 \qquad m(2) = n(2)} \]

\vspace{0.25cm}

\noindent\rule{\linewidth}{0.2pt}

\problem{The graph gives $w$, the seedling's height in centimetres after $x$ weeks. Find $w(3)$
and explain what it tells you.}

\textbf{Solution:} \quad The input $3$ means three weeks after the first measurement. The plotted
point there is $(3, 24)$, and the vertical axis is measured in centimetres.
\ans{w(3) = 24\text{ cm}}

\textbf{Interpretation (instructor-judged).} A correct sentence names both quantities with their
units: three weeks after the first measurement the seedling was $24$ centimetres tall. Accept
any wording that ties the input to weeks and the output to a height; a bare repetition of the
number earns no credit.
