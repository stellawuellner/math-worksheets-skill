\problem{Find the average value of $f(x) = 3x^2$ on $[0,4]$.}

\textbf{Solution:} The average value is $\dfrac{1}{b-a}\displaystyle\int_a^b f$, here $\dfrac{1}{4}\displaystyle\int_0^4 3x^2\,dx$:
\[ \frac{1}{4}\int_0^4 3x^2\,dx = \frac{1}{4}\Big[x^3\Big]_0^4 = \frac{64}{4}. \]
So the average value is \ans{f_{\text{avg}} = 16}

\vspace{0.2cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.2cm}

\problem{Water enters a tank at $r(t) = 4t + 2$ litres per minute. How much enters during the first $6$ minutes?}

\textbf{Solution:} Accumulated change is the integral of the rate:
\[ \int_0^6 (4t + 2)\,dt = \Big[2t^2 + 2t\Big]_0^6 = 72 + 12. \]
Litres per minute times minutes gives litres. \ans{84\ \text{L}}

\vspace{0.2cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.2cm}

\problem{A particle has velocity $v(t) = 3t^2 - 12$ m/s. Find its displacement on $[0,4]$.}

\textbf{Solution:} Displacement is the integral of velocity (no absolute value --- the question asks for net change of position):
\[ \int_0^4 (3t^2 - 12)\,dt = \Big[t^3 - 12t\Big]_0^4 = 64 - 48. \]
So the displacement is \ans{16\ \text{m}}

\vspace{0.2cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.2cm}

\problem{Find the average value of $g(x) = \sin x$ on $[0, \pi]$.}

\textbf{Solution:} $\displaystyle \frac{1}{\pi}\int_0^{\pi}\sin x\,dx = \frac{1}{\pi}\Big[-\cos x\Big]_0^{\pi} = \frac{1}{\pi}\big(1 + 1\big)$, so the average value is \ans{g_{\text{avg}} = \frac{2}{\pi} \approx 0.637}

\vspace{0.2cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.2cm}

\problem{Sand accumulates at $r(t) = 9 - t$ kilograms per minute for $0 \le t \le 9$. How much is added?}

\textbf{Solution:} \[ \int_0^9 (9 - t)\,dt = \Big[9t - \tfrac{t^2}{2}\Big]_0^9 = 81 - \frac{81}{2}. \]
So the pile gains \ans{40.5\ \text{kg}}

\vspace{0.2cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.2cm}

\problem{$v(t) = t^2 - 4t + 3$ m/s on $[0,4]$. (a) When does the particle turn? (b) Total distance travelled?}

\textbf{Solution (a):} The particle turns where the velocity changes sign, so solve $t^2 - 4t + 3 = (t-1)(t-3) = 0$. \ans{t = 1,\; t = 3}

\textbf{Solution (b):} Total distance is $\displaystyle\int_0^4 |v(t)|\,dt$, split at the turning times. On $[0,1]$ and $[3,4]$ the velocity is positive; on $[1,3]$ it is negative. With $F(t) = \tfrac{t^3}{3} - 2t^2 + 3t$,
\[ \int_0^4 |v| = \big|F(1)-F(0)\big| + \big|F(3)-F(1)\big| + \big|F(4)-F(3)\big| = \frac{4}{3} + \frac{4}{3} + \frac{4}{3}. \]
So the total distance is \ans{4\ \text{m}}

\vspace{0.2cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.2cm}

\problem{$T(t) = 18 + 6\sin\!\left(\frac{\pi t}{12}\right)$ degrees Celsius. Find the average temperature over $[0, 12]$.}

\textbf{Solution:} \[ \frac{1}{12}\int_0^{12}\left(18 + 6\sin\frac{\pi t}{12}\right)dt = \frac{1}{12}\left[18t - \frac{72}{\pi}\cos\frac{\pi t}{12}\right]_0^{12} = \frac{1}{12}\left(216 + \frac{144}{\pi}\right). \]
So the average temperature is \ans{T_{\text{avg}} = 18 + \frac{12}{\pi} \approx 21.820}

\vspace{0.2cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.2cm}

\problem{Water leaks at $r(t) = 20e^{-0.1t}$ litres per hour. How much leaks out during the first $10$ hours?}

\textbf{Solution:} \[ \int_0^{10} 20e^{-0.1t}\,dt = \Big[-200e^{-0.1t}\Big]_0^{10} = -200e^{-1} + 200. \]
So the tank loses \ans{200\left(1 - e^{-1}\right) \approx 126.42\ \text{L}}

\vspace{0.2cm}\noindent\rule{\linewidth}{0.2pt}\vspace{0.2cm}

\problem{$v(t) = 4 - t$ m/s, $x(0) = 3$ m. (a) When does the particle turn? (b) Where is it at $t = 6$?}

\textbf{Solution (a):} Solve $4 - t = 0$. \ans{t = 4}

\textbf{Solution (b):} Position is the starting value plus the accumulated displacement, so $x(t) = 3 + \displaystyle\int_0^t (4 - u)\,du = 3 + 4t - \tfrac{t^2}{2}$. At $t = 6$ this is $3 + 24 - 18$. \ans{s(6) = 9\ \text{m}}

Note that the particle has travelled further than $6$ metres --- it moved right until $t = 4$ and then back --- which is why part (b) asks for position, not distance.

\problem{$v(t) = t^2 - 6t + 8$ m/s on $[0,5]$, starting at $x = 1$ m. (a) Total distance. (b) Average velocity. (c) Why is the average velocity not the average of the extreme velocities?}

\textbf{Solution (a):} $v = (t-2)(t-4)$, so the sign changes at $t = 2$ and $t = 4$. With $F(t) = \tfrac{t^3}{3} - 3t^2 + 8t$, the three pieces measure $\tfrac{20}{3}$, $\tfrac{4}{3}$ and $\tfrac{4}{3}$, so
\[ \int_0^5 |v|\,dt = \frac{20}{3} + \frac{4}{3} + \frac{4}{3}. \]
The total distance is \ans{\frac{28}{3} \approx 9.33\ \text{m}}

\textbf{Solution (b):} Average velocity is the average value of $v$, i.e. displacement over elapsed time:
\[ \frac{1}{5}\int_0^5 (t^2 - 6t + 8)\,dt = \frac{1}{5}\cdot\frac{20}{3}. \]
So the average velocity is \ans{\frac{4}{3} \approx 1.33\ \text{m/s}}

\textbf{Solution (c) --- instructor-judged.} A correct response says the average value divides the integral by the length of the interval, which weights every instant equally; averaging only the largest and smallest velocities uses two instants and ignores how long the particle spends near each speed. Full credit contrasts the two weightings.
