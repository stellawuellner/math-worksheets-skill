\problem{Hose filling a tank: unit rate in liters per minute from the graph.

\textbf{Solution:} The line passes through the origin and the marked point
$(2, 6)$. Unit rate $= \dfrac{\text{rise}}{\text{run}} = \dfrac{6 - 0}{2 - 0} =
\dfrac{6}{2}$, so the tank fills at \ans{3} liters per minute. (Check: at
$x = 1$ the line is at $y = 3$.)}

\problem{Grapes: price per pound from the graph.

\textbf{Solution:} The line passes through $(0,0)$ and the marked point
$(4, 10)$. Price per pound $= \dfrac{10 - 0}{4 - 0} = \dfrac{10}{4}$, giving
\ans{2.5} dollars per pound.}

\problem{Write the equation $y = kx$ from the graph.

\textbf{Solution:} The marked point is $(5, 20)$, so
$k = \dfrac{20 - 0}{5 - 0} = 4$. The equation is \ans{y = 4x}}

\problem{Muffin recipe table: plot the points; find the unit rate.

\textbf{Solution (a):} \emph{(instructor-judged)} The points $(0,0)$, $(2,5)$,
$(4,10)$, $(6,15)$ all lie on one straight line through the origin --- the
graph should show them joined by that line.

\textbf{Solution (b):} Using $(2, 5)$ and $(6, 15)$: rate
$= \dfrac{15 - 5}{6 - 2} = \dfrac{10}{4}$, so \ans{2.5} cups per batch.}

\problem{Two runners: how much greater is A's unit rate?

\textbf{Solution:} Runner A: $\dfrac{12}{2} = 6$ meters per second. Runner B:
$\dfrac{10}{2} = 5$ meters per second. Difference: $6 - 5 = 1$, so A's rate is
greater by \ans{1} meter per second.}

\problem{Remote-control car: equation, then distance at $7$ seconds.

\textbf{Solution (a):} The marked point is $(3, 18)$, so
$k = \dfrac{18}{3} = 6$ and the equation is \ans{y = 6x}

\textbf{Solution (b):} Substitute $x = 7$: $y = 6 \cdot 7$, so the car travels
\ans{42} meters.}

\problem{Raffle tickets: plot, compute both ratios, decide proportionality.

\textbf{Solution (a):} \emph{(instructor-judged)} Points $(1,4)$, $(2,8)$,
$(3,11)$ plotted; the first two line up with the origin but the third does not.

\textbf{Solution (b):} At $x = 2$: $\dfrac{8}{2}$, so \ans{4} dollars per
ticket. At $x = 3$: $\dfrac{11}{3}$, so \ans{\tfrac{11}{3}} dollars per ticket
(about \$3.67).

\textbf{Solution (c):} \emph{(instructor-judged)} Not proportional: the cost
per ticket changes, so the three points do not lie on one straight line
through the origin. Full credit for either the equal-ratios test or the
straight-line-through-origin test.}

\problem{Shirt printing: equation, then shirts for \$51.

\textbf{Solution (a):} The marked point is $(2, 17)$, so
$k = \dfrac{17}{2} = 8.5$ and the equation is \ans{y = 8.5x}

\textbf{Solution (b):} Solve $8.5x = 51$: $x = \dfrac{51}{8.5}$, so you can buy
\ans{6} shirts.}

\problem{Complete the proportional table, then graph it.

\textbf{Solution (a):} The unit rate is $\dfrac{3.5}{1} = 3.5$. Missing
$x$-value: solve $3.5x = 7$, giving \ans{2} \quad Missing $y$-value:
$y = 3.5 \cdot 5$, giving \ans{17.5}

\textbf{Solution (b):} \emph{(instructor-judged)} The completed points
$(1, 3.5)$, $(2, 7)$, $(5, 17.5)$ lie on one straight line through the origin.}

\problem{Store A ($15$ dollars for $6$ cans, graphed) vs.\ Store B
($y = 2.75x$): compare rates; cost of $12$ cans at the cheaper store.

\textbf{Solution (a):} Store A's rate: $\dfrac{15}{6} = 2.5$ dollars per can.
Store B's rate: $2.75$ dollars per can. So \ans{2.5 < 2.75} --- Store A is
cheaper.

\textbf{Solution (b):} At Store A: $\dfrac{15}{6} \cdot 12$, so $12$ cans cost
\ans{30} dollars.}
