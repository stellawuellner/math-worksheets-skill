\problem{Shirt order: costs $25, 32, 39, 46$ for $n = 0, 1, 2, 3$. (a) Which family? (b) Cost of 10 shirts.}

\textbf{(a)} First differences: $32 - 25 = 7$, $39 - 32 = 7$, $46 - 39 = 7$. They are constant, so the rule is \textbf{linear} --- each extra shirt adds the same amount. (A quadratic table would need constant \emph{second} differences; a piecewise table would change its rule partway.)

\textbf{(b)} Constant difference $7$ is the rate, and $25$ is the value at $n = 0$, so $C(n) = 25 + 7n$. Then $C(10) = 25 + 7(10) = 25 + 70$. \ans{95}

\problem{Cart heights $0, 44, 56, 36$ ft at $t = 0, 1, 2, 3$ s. (a) Which family? (b) Height at $t = 2.5$ s.}

\textbf{(a)} First differences: $44$, $12$, $-20$ --- not constant, so not linear. Second differences: $12 - 44 = -32$ and $-20 - 12 = -32$ --- constant, so the rule is \textbf{quadratic}. Nothing in the table changes rule partway, so it is not piecewise.

\textbf{(b)} Substitute $t = 2.5$ into $h(t) = -16t^2 + 60t$: $\ -16(6.25) + 60(2.5) = -100 + 150$. \ans{50 \, \text{ft}}

\vspace{0.2cm}\noindent\rule{\linewidth}{0.2pt}

\problem{Garage: $\$3$ for the first hour, $\$2$ per hour after. (a) Which family? (b) Charge for 4 hours.}

\textbf{(a)} \textbf{Piecewise.} The rule for the first hour ($\$3$ flat) is not the rule that applies afterwards ($\$2$ per hour), so no single straight-line rule covers the whole domain --- the model needs one piece up to $t = 1$ and a second piece beyond it.

\textbf{(b)} For $t \ge 1$ the charge is $3 + 2(t - 1)$. At $t = 4$: $\ 3 + 2(3) = 3 + 6$. \ans{9}

\vspace{0.2cm}\noindent\rule{\linewidth}{0.2pt}

\problem{Phone plan: $\$12$ per month plus $\$0.05$ per minute; bill $\$27.50$. Find the minutes $m$.}

\textbf{Solution:} the charge grows by the same $\$0.05$ for every minute, so a linear equation models it:
\begin{align*}
  12 + 0.05m &= 27.50 \\
  0.05m &= 15.50 \\
  m &= \frac{15.50}{0.05}
\end{align*}
\ans{m = 310 \, \text{min}}

\vspace{0.2cm}\noindent\rule{\linewidth}{0.2pt}

\problem{Rocket: $h(t) = -16t^2 + 64t$. Solve $h(t) = 0$.}

\textbf{Solution:} the rule is quadratic, so factor rather than divide by $t$ (dividing would lose a root):
\begin{align*}
  -16t^2 + 64t &= 0 \\
  -16t(t - 4) &= 0
\end{align*}
The zero-product property gives $-16t = 0$ or $t - 4 = 0$. \ans{t = 0 \, \text{s} \ \text{or} \ t = 4 \, \text{s}}

\vspace{0.2cm}\noindent\rule{\linewidth}{0.2pt}

\problem{Tank: 5 L/min for 8 min, then 2 L/min. Volume after 15 minutes.}

\textbf{Solution:} the rate changes at $t = 8$, so the model is piecewise. The first piece finishes with $5 \times 8 = 40$ litres. The second piece then runs for $15 - 8 = 7$ minutes at 2 litres per minute: $\ 40 + 2(7) = 40 + 14$. \ans{54 \, \text{L}}

\vspace{0.2cm}\noindent\rule{\linewidth}{0.2pt}

\problem{Gym A: $40 + 15m$. Gym B: $25 + 20m$. Find the month $m$ and cost $y$ where they agree.}

\textbf{Solution:} both fees grow at a constant rate per month, so both are linear. Set the two costs equal:
\begin{align*}
  40 + 15m &= 25 + 20m \\
  15 &= 5m \\
  m &= 3
\end{align*}
Then $y = 40 + 15(3) = 85$. \ans{m = 3 \ \text{months}, \ y = 85}

\vspace{0.2cm}\noindent\rule{\linewidth}{0.2pt}

\problem{Dog run, 40 ft of fence, $A(w) = w(20 - w)$. (a) Which family? (b) Area at $w = 6$.}

\textbf{(a)} \textbf{Quadratic.} Both factors carry the variable: widening the run by one foot lengthens one pair of sides and shortens the other, so $w$ appears twice and the expanded rule $20w - w^2$ is second degree. A linear rule would change the area by the same amount for every extra foot of width, and this one does not.

\textbf{(b)} Substitute $w = 6$: $\ 6(20 - 6) = 6 \times 14$. \ans{84 \, \text{ft}^2}

\vspace{0.2cm}\noindent\rule{\linewidth}{0.2pt}

\problem{Courier: $\$6$ up to 5 lb, then $\$1.20$ per extra pound; parcel cost $\$12$. Find $w$.}

\textbf{Solution:} above 5 pounds the second piece applies, so
\begin{align*}
  6 + 1.20(w - 5) &= 12 \\
  1.20(w - 5) &= 6 \\
  w - 5 &= 5
\end{align*}
\ans{w = 10 \, \text{lb}}

\problem{Table $y = 3, 7, 13, 21$ for $x = 1, 2, 3, 4$; the claim ``linear, because $y$ goes up every time''. (a) Why is that not enough? (b) Predict $y$ at $x = 5$.}

\textbf{(a)} Rising values only rule out a decreasing rule; a quadratic can rise every time too. The test is the differences. First differences: $4$, $6$, $8$ --- not constant, so the rule is not linear. Second differences: $6 - 4 = 2$ and $8 - 6 = 2$ --- constant, so the table is \textbf{quadratic}.

\textbf{(b)} Substitute $x = 5$ into $y = x^2 + x + 1$: $\ 25 + 5 + 1$. \ans{31}

\vspace{0.2cm}\noindent\rule{\linewidth}{0.2pt}

\problem{Electricity: $\$0.11$ per kWh for the first 400 kWh, then $\$0.16$ per kWh. Bill for $k = 650$ kWh.}

\textbf{Solution:} the rate changes at 400 kWh, so the model is piecewise and 650 lies in the second piece. First 400 kWh: $0.11 \times 400 = 44$ dollars. The remaining $650 - 400 = 250$ kWh: $0.16 \times 250 = 40$ dollars. Total $44 + 40$. \ans{84}

\problem{Apples: $R(x) = x(40 - 2x)$, $C(x) = 12x + 48$, both in hundred dollars. (a) Name each family. (b) Solve $R(x) = C(x)$.}

\textbf{(a)} $R$ is \textbf{quadratic}: the price a crate fetches, $40 - 2x$, falls as the number of crates $x$ rises, so the variable sits in both factors and the expanded rule $40x - 2x^2$ is second degree. $C$ is \textbf{linear}: every extra hundred crates adds the same 12, on top of the fixed 48 that is there even at $x = 0$.

\textbf{(b)} Set them equal and collect on one side:
\begin{align*}
  x(40 - 2x) - (12x + 48) &= 0 \\
  40x - 2x^2 - 12x - 48 &= 0 \\
  -2x^2 + 28x - 48 &= 0 \\
  x^2 - 14x + 24 &= 0 \\
  (x - 2)(x - 12) &= 0
\end{align*}
\ans{x = 2 \ \text{or} \ x = 12}
