\sstitleblock{Counting a Set and Telling How Many}

\begin{formulabox}
\textbf{The counting rule (one-to-one).} Touch \emph{one} object, say
\emph{one} number. Touch every object, and touch each one only once.\\[3pt]
\textbf{The how-many rule (cardinality).} The \textbf{last number you say} tells
how many are in the whole set. You do not have to count again to answer ``how
many?''\\[3pt]
Helpers: a full row of a ten-frame is $5$; a full ten-frame is $10$.
\end{formulabox}

\skillheading{1. Count a set and tell how many}

\begin{formulabox}
Give the set an order before you start --- left to right, top row then bottom
row --- and cross off or slide each object as you count it. Order is what keeps
you from skipping one or counting one twice.
\end{formulabox}

\begin{examplebox}
\textbf{Example:} How many dots?\quad
\begin{tabular}{|c|c|c|c|}\hline
$\bullet$ & $\bullet$ & $\bullet$ & $\bullet$ \\[0.2cm]\hline
$\bullet$ & $\bullet$ & & \\[0.2cm]\hline
\end{tabular}
\step{The dots sit in two rows, so count the full row first and then count on
into the second row instead of starting over.}
\step{Top row: one, two, three, four --- that is $4$. Count on: ``five, six'',
which adds $2$.}
The last number said is the answer: $\ans{6}$ dots.
\end{examplebox}

\begin{tryitbox}
\textbf{Try it:} How many dots?\quad
\begin{tabular}{|c|c|c|c|c|}\hline
$\bullet$ & $\bullet$ & $\bullet$ & $\bullet$ & $\bullet$ \\[0.2cm]\hline
$\bullet$ & $\bullet$ & $\bullet$ & & \\[0.2cm]\hline
\end{tabular}\\[2pt]
\rotatebox{180}{\footnotesize check: $\ans{8}$}
\end{tryitbox}

\skillheading{2. Count two groups as one set}

\begin{formulabox}
When a set is shown in two places --- two baskets, two colours, two rows ---
count the first group, then \textbf{keep going} into the second group. Do not
start again at one. The last number you say is how many there are \emph{in
all}.
\end{formulabox}

\begin{examplebox}
\textbf{Example:} $3$ red cubes and $4$ blue cubes. How many cubes in all?
\step{Both colours are cubes in the same pile, so one count has to cover both
groups.}
\step{Count the red ones: one, two, three. Now keep counting the blue ones:
``four, five, six, seven''.}
That is $3 + 4$, so there are $\ans{7}$ cubes in all.
\end{examplebox}

\begin{tryitbox}
\textbf{Try it:} $6$ pencils in the cup and $5$ pencils on the desk. How many
pencils in all?\\[2pt]
\rotatebox{180}{\footnotesize check: $\ans{11}$}
\end{tryitbox}

\skillheading{3. Tell which set has more}

\begin{formulabox}
Finish \textbf{both} counts first, then compare the two numbers.\\[2pt]
$>$ means \emph{is greater than} \qquad $<$ means \emph{is less than}\\[2pt]
The open end of the sign always faces the bigger number.
\end{formulabox}

\begin{examplebox}
\textbf{Example:} Ana has $4$ stickers and then $2$ more. Ben has $3$ stickers
and then $2$ more. Who has more?
\step{Nothing can be compared until each child's set has one number, so count
each set all the way first.}
\step{Ana: $4 + 2 = 6$. Ben: $3 + 2 = 5$. Six is more than five.}
Ana's set is greater, so Ana $\ans{>}$ Ben.
\end{examplebox}

\begin{tryitbox}
\textbf{Try it:} Kim has $5$ marbles and then $2$ more. Lee has $5$ marbles and
then $4$ more. Write $>$ or $<$: \; Kim \underline{\hspace{0.9cm}} Lee.\\[2pt]
\rotatebox{180}{\footnotesize check: $\ans{<}$}
\end{tryitbox}

\begin{watchoutbox}
\textbf{(!) Watch out:} a bigger-looking set is not always more --- spread-out
objects can be fewer than crowded ones, and only the count decides. And when
someone asks ``how many?'' after you have counted, say the last number again.
Recounting the set is the sign that the how-many rule has not clicked yet.
\end{watchoutbox}
